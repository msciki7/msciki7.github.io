# 로지스틱 회귀(Logistic Regression)

&ensp;1. 로지스틱 회귀란?<br/>
&ensp;로지스틱 회귀는 이름에 회귀(Regression)가 들어가지만, 두 개의 클래스 중 하나를 선택하는 이진 분류(Binary Classification) 모델이다.<br/>
&ensp;예를 들면 다음과 같은 문제를 다룬다.<br/>
* 이메일이 스팸인가?
* 환자가 암에 걸렸는가?
* 센서 감지값이 정상인가?

&ensp;핵심은 입력 데이터를 바로 0 또는 1로 분류하는 것이 아니라, 특정 사건이 발생할 확률을 먼저 계산하는 것이다. 예를 들어 기준값을 0.5로 설정하면 다음과 같이 분류할 수 있다.<br/>
* 예측 확률이 0.7이면 긍정 클래스
* 예측 확률이 0.3이면 부정 클래스

$$\hat{y}= \begin{cases} 1, & p \ge 0.5 \ 0, & p < 0.5 \end{cases}$$

---

&ensp;2. Odds → Logit → Sigmoid<br/>
&ensp;이 흐름은 로지스틱 회귀에서 가장 중요한 이론적 연결이다.<br/>
&ensp;Odds: 어떤 사건이 일어날 확률을 $p$라고 할 때 오즈는 다음과 같다.<br/>

$$Odds=\frac{p}{1-p}$$

&ensp;즉, 사건이 발생할 확률과 발생하지 않을 확률의 비율이다.<br/>
&ensp;예를 들어 $p=0.8$이면 다음과 같다.<br/>

$$Odds=\frac{0.8}{0.2}=4$$

&ensp;사건이 발생할 가능성이 발생하지 않을 가능성보다 4배 높다고 해석할 수 있다.<br/>

&ensp;Odds Ratio: 오즈비는 두 상황의 오즈를 비교하는 값이다.<br/>

$$Odds\ Ratio=\frac{Odds_A}{Odds_B}$$

&ensp;Logit: 로짓은 오즈에 로그를 취한 값이다.<br/>

$$logit(p)=\log\left(\frac{p}{1-p}\right)$$

&ensp;로지스틱 회귀에서는 로짓과 입력의 선형 관계를 다음과 같이 가정한다.<br/>
$$logit(p)=w_1x_1+\cdots+w_mx_m+b$$

&ensp;벡터 형태로 표현하면 다음과 같다.<br/>

$$logit(p)=\mathbf{w}^T\mathbf{x}+b$$

&ensp;여기서 선형결합 결과를 $z$라고 두면 다음 관계를 얻는다.<br/>

$$z=\mathbf{w}^T\mathbf{x}+b$$

$$\log\left(\frac{p}{1-p}\right)=z$$

&ensp;Sigmoid: 위 식을 확률 $p$에 대해 풀면 시그모이드 함수가 된다.<br/>

$$p=\sigma(z)=\frac{1}{1+e^{-z}}$$

&ensp;시그모이드 함수는 모든 실수 값을 0과 1 사이의 값으로 변환한다.<br/>
* $z\ll0$이면 $\sigma(z)$는 0에 가까워진다.
* $z=0$이면 $\sigma(z)=0.5$이다.
* $z\gg0$이면 $\sigma(z)$는 1에 가까워진다.

<p align="center"><img src="/assets/img/사물기계학습/2주차/2-1.png" width="600"></p>

&ensp;따라서 로지스틱 회귀의 전체 예측 과정은 다음과 같다.<br/>

$$
\mathbf{x}
\rightarrow
z=\mathbf{w}^T\mathbf{x}+b
\rightarrow
\sigma(z)
\rightarrow
P(y=1\mid\mathbf{x})
\rightarrow
Class
$$

> 입력 데이터 → 선형 점수 계산 → 시그모이드 변환 → 확률 출력 → 클래스 판정

---

&ensp;3. 가능도(Likelihood)<br/>

&ensp;가능도는 현재 모델이 주어진 데이터를 얼마나 잘 설명하는지를 나타낸다. 각 샘플이 서로 독립이라고 가정하면 전체 가능도는 각 샘플의 확률을 곱한 형태가 된다.<br/>

$$\prod_{i=1}^{n}\sigma(z_i)^{y_i}[1-\sigma(z_i)]^{1-y_i}$$

&ensp;여기서 각 기호의 의미는 다음과 같다.<br/>
* $n$: 전체 샘플 수
* $y_i$: $i$번째 샘플의 실제 클래스
* $z_i$: $i$번째 샘플의 선형결합값
* $\sigma(z_i)$: $i$번째 샘플이 클래스 1일 예측 확률

&ensp;실제값이 $y_i=1$이면 $\sigma(z_i)$가 선택되고, $y_i=0$이면 $1-\sigma(z_i)$가 선택된다.<br/>

---

&ensp;4. 로그 가능도(Log-Likelihood)<br/>
&ensp;가능도의 곱셈을 덧셈으로 바꾸기 위해 로그를 취한다.<br/>

$$\sum_{i=1}^{n}\left[y_i\log\sigma(z_i)+(1-y_i)\log(1-\sigma(z_i))\right]$$

&ensp;로그 가능도를 사용하면 다음과 같은 장점이 있다.<br/>
* 곱셈이 덧셈으로 바뀌어 계산과 미분이 쉬워진다.
* 매우 작은 확률을 계속 곱할 때 발생하는 수치적 문제를 줄일 수 있다.

&ensp;가능도와 로그 가능도는 모두 클수록 좋은 모델을 의미한다.<br/>

---

&ensp;5. 로지스틱 손실함수<br/>
&ensp;머신러닝에서는 일반적으로 목적함수를 최소화하는 방식으로 학습한다. 따라서 로그 가능도에 음수를 붙여 손실함수로 사용한다.<br/>
$$\sum_{i=1}^{n}\left[- y_i\log\sigma(z_i) - (1-y_i)\log(1-\sigma(z_i))\right]$$

&ensp;한 샘플에 대한 손실은 다음과 같다.<br/>

$$J=-y\log\sigma(z)-(1-y)\log(1-\sigma(z))$$

&ensp;실제 클래스에 따라 식을 나누면 다음과 같다.<br/>
&ensp;실제값이 $y=1$인 경우<br/>
$$J=-\log\sigma(z)$$

&ensp;모델이 클래스 1의 확률을 낮게 예측할수록 손실이 커진다.<br/>

&ensp;실제값이 $y=0$인 경우<br/>
$$J=-\log(1-\sigma(z))$$

&ensp;모델이 클래스 1의 확률을 높게 예측할수록 손실이 커진다.<br/>

&ensp;Likelihood와 Loss의 관계<br/>
$$
Likelihood\ 최대화 \quad\Longleftrightarrow\quad Negative\ Log\ Likelihood\ 최소화$$

* Likelihood: 클수록 좋다.
* Loss: 작을수록 좋다.

---

&ensp;6. 경사하강법(Gradient Descent)<br/>
&ensp;로지스틱 회귀의 가중치 $\mathbf{w}$와 편향 $b$는 손실함수를 최소화하도록 반복해서 조정한다.<br/>
&ensp;한 샘플에 대한 $j$번째 가중치의 기울기는 다음과 같다.<br/>
$$\frac{\partial J}{\partial w_j}=(a-y)x_j$$

&ensp;여기서 $a=\sigma(z)$는 모델의 출력 확률이다. 같은 식을 다음처럼 표현할 수도 있다.<br/>

$$\frac{\partial J}{\partial w_j}=-(y-a)x_j$$

&ensp;가중치 업데이트<br/>
$$w_j \leftarrow w_j-\eta\frac{\partial J}{\partial w_j}$$

&ensp;위 기울기를 대입하면 다음과 같다.<br/>

$$w_j\leftarrow w_j+\eta(y-a)x_j$$

&ensp;편향은 다음과 같이 업데이트한다.<br/>

$$b\leftarrow b+\eta(y-a)$$

* $\eta$: 학습률(Learning Rate)
* $y-a$: 실제값과 예측값의 차이

# 과적합과 규제

&ensp;1. 과적합과 과소적합<br/>
&ensp;과적합(Overfitting): 훈련 데이터에는 매우 잘 맞지만 새로운 데이터에는 잘 맞지 않는 상태이다.<br/>
&ensp;과소적합(Underfitting): 모델이 너무 단순하여 훈련 데이터의 패턴조차 충분히 학습하지 못한 상태이다.<br/>
<p align="center"><img src="/assets/img/사물기계학습/2주차/2-3.png" width="600"></p>

&ensp;편향-분산 트레이드오프<br/>
* 높은 편향(Bias) → 과소적합 경향
* 높은 분산(Variance) → 과적합 경향

<p align="center"><img src="/assets/img/사물기계학습/2주차/2-4.png" width="600"></p>

| 상태     | Bias | Variance |
| ------ | ---: | -------: |
| 과소적합   |   높음 |       낮음 |
| 적절한 모델 |   적절 |       적절 |
| 과적합    |   낮음 |       높음 |


---

&ensp;2. 규제(Regularization)<br/>
&ensp;규제는 모델의 가중치가 지나치게 커지는 것을 제한하여 과적합을 줄이는 방법이다.<br/>

&ensp;L2 규제<br/>
&ensp;L2 규제는 가중치 제곱합을 패널티 항으로 추가한다.<br/>
$$\frac{\lambda}{2n}\sum_{j=1}^{m}w_j^2$$

* $\lambda$: 규제 강도
* $n$: 샘플 수
* $m$: 특성 수
* $w_j$: $j$번째 가중치

&ensp;규제가 포함된 로지스틱 손실함수<br/>
$$-\sum_{i=1}^{n}\left[y_i\log\sigma(z_i)+(1-y_i)\log(1-\sigma(z_i))\right]+\frac{\lambda}{2n}\lVert\mathbf{w}\rVert^2$$

&ensp;규제 강도 $\lambda$가 커질수록 가중치 크기를 더 강하게 제한한다.<br/>

&ensp;scikit-learn의 로지스틱 회귀에서 사용하는 $C$는 규제 강도의 역수 관계로 이해할 수 있다.<br/>

$$C=\frac{1}{\lambda}$$


&ensp;C가 커지면 C↑ ⇒ 규제↓. 가중치가 커질 수 있다.<br/>
&ensp;C가 작아지면 C↓ ⇒ 규제↑. 가중치가 작아진다.<br/>

# 서포트 벡터 머신(Support Vector Machine, SVM)

&ensp;1. 핵심 개념<br/>
&ensp;SVM은 클래스를 나누는 여러 결정 경계 중에서 마진(Margin)을 최대화하는 경계를 찾는 분류 모델이다.<br/>
&ensp;SVM의 주요 특징은 다음과 같다.<br/>
* 가장 넓은 마진을 가지는 결정 경계를 선택한다.
* 학습 데이터에 과도하게 치우치는 것을 줄여 일반화 성능을 높인다.
* 커널 트릭을 이용하면 비선형 결정 경계를 구현할 수 있다.

<p align="center"><img src="/assets/img/사물기계학습/2주차/2-5.png" width="600"></p>

&ensp;주요 용어<br/>

| 용어                       | 의미                           |
| ------------------------ | ---------------------------- |
| 결정 경계(Decision Boundary) | 클래스를 나누는 기준                  |
| 초평면(Hyperplane)          | 고차원 공간에서의 결정 경계              |
| 마진(Margin)               | 결정 경계와 가장 가까운 샘플 사이의 거리      |
| 서포트 벡터(Support Vector)   | 결정 경계에 가장 가까운 샘플             |
| 하드 마진(Hard Margin)       | 모든 샘플을 오류 없이 분류하는 방식         |
| 소프트 마진(Soft Margin)      | 일부 오류를 허용하는 방식               |
| 슬랙 변수(Slack Variable)    | 각 샘플의 마진 위반 정도               |
| 규제 변수 C               | 오류 허용 정도와 마진의 균형을 조절         |
| 커널(Kernel)               | 고차원 특성 공간에서 내적을 간접 계산하는 함수   |
| RBF Kernel               | 방사 기저 함수 커널                  |
|  $\gamma$                | RBF 커널에서 샘플의 영향 범위와 관련된 파라미터 |

&ensp;2. Hard Margin과 Soft Margin<br/>
&ensp;Hard Margin: 모든 훈련 샘플을 오류 없이 분류해야 한다. 노이즈나 이상치가 존재하는 현실 데이터에서는 적용하기 어렵다.<br/>
&ensp;Soft Margin: 일부 샘플의 마진 위반과 분류 오류를 허용하면서 넓은 마진을 찾는다.<br/>
&ensp;목적함수는 다음과 같다.<br/>
$$\min_{\mathbf{w},b,\boldsymbol{\xi}}\frac{1}{2}\lVert\mathbf{w}\rVert^2 + C\sum_{i=1}^{N}\xi_i$$

&ensp;제약조건은 다음과 같다.<br/>
$$y_i(\mathbf{w}^T\mathbf{x}_i+b)\ge1-\xi_i$$

$$\xi_i\ge0$$

* $\mathbf{w}$: 가중치 벡터
* $b$: 편향
* $\xi_i$: $i$번째 샘플의 슬랙 변수
* $C$: 규제 변수
* $N$: 전체 샘플 수
* $\mathbf{x}_i$: $i$번째 입력
* $y_i$: 실제 클래스

&ensp;$C$의 역할<br/>
&ensp;$C$가 작은 경우<br/>
* 오류를 비교적 많이 허용한다.
* 넓은 마진을 확보하려 한다.
* 일반화를 더 중시한다.

&ensp;$C$가 큰 경우<br/>
* 오류 허용이 감소한다.
* 훈련 데이터에 더 엄격하게 맞춘다.
* 과적합 가능성이 커질 수 있다.

---

&ensp;3. 커널 트릭(Kernel Trick)<br/>
&ensp;원래 데이터가 선형적으로 분리되지 않을 경우 변환 함수 $\phi(\mathbf{x})$를 이용해 데이터를 고차원 공간으로 옮길 수 있다. 예를 들면 다음과 같다. $(x_1,x_2,x_1^2+x_2^2)$ . 하지만 고차원 좌표를 직접 계산하면 연산량이 커질 수 있다. 커널 함수는 변환된 고차원 공간에서의 내적을 직접 변환 없이 계산한다.<br/>

$$\phi(\mathbf{x}^{(i)})^T\phi(\mathbf{x}^{(j)})$$

<p align="center"><img src="/assets/img/사물기계학습/2주차/2-6.png" width="600"></p>

----

&ensp;4. RBF 커널<br/>
&ensp;RBF(Radial Basis Function) 커널은 비선형 데이터를 분류할 때 자주 사용한다.<br/>

$$\exp\left(-\gamma \lVert\mathbf{x}^{(i)}-\mathbf{x}^{(j)}\rVert^2 \right)$$

&ensp;다음과 같은 형태로도 표현한다.<br/>

$$\exp\left(-\frac{\lVert\mathbf{x}^{(i)}-\mathbf{x}^{(j)}\rVert^2 
}{2\sigma^2}\right)$$

&ensp;두 표현의 관계는 다음과 같다.<br/>

$$\gamma=\frac{1}{2\sigma^2}$$

&ensp;$\gamma$가 커질수록 각 샘플의 영향 범위가 좁아져 결정 경계가 더 복잡해질 수 있다.<br/>

* 서포트 벡터는 모든 샘플이 아니라 결정 경계에 가장 가까운 일부 샘플이다.
* 하드 마진은 노이즈와 이상치에 민감하다.
* $C$는 오류 허용 정도를 조절한다.
* $\gamma$는 RBF 커널에서 샘플의 영향 범위를 조절한다.

# 결정 트리(Decision Tree)

&ensp;1. 핵심 개념<br/>
&ensp;결정 트리는 질문을 반복하면서 데이터를 분할하는 모델이다.<br/>
&ensp;구성 요소는 다음과 같다.<br/>
* 루트 노드(Root Node): 트리의 시작 노드
* 가지(Branch): 조건에 따라 나뉘는 경로
* 리프 노드(Leaf Node): 최종 예측값이 위치하는 노드

&ensp;결정 트리는 일반적으로 정보 이득(Information Gain)이 최대가 되는 특성과 기준을 선택해 데이터를 분할한다.<br/>

---

&ensp;2. 정보 이득(Information Gain)<br/>
&ensp;정보 이득은 분할 전후의 불순도 감소량이다.<br/>

$$I(D_p) - \sum_{j=1}^{m} \frac{N_j}{N_p}I(D_j)$$

* $D_p$: 부모 노드의 데이터
* $D_j$: $j$번째 자식 노드의 데이터
* $N_p$: 부모 노드의 샘플 수
* $N_j$: $j$번째 자식 노드의 샘플 수
* $I$: 불순도 함수
* $f$: 분할에 사용한 특성

&ensp;이진 분할에서는 다음과 같이 표현한다.<br/>
$$I(D_p)- \frac{N_{left}}{N_p}I(D_{left}) \frac{N_{right}}{N_p}I(D_{right})$$

&ensp;좋은 분할은 자식 노드의 불순도를 낮춘다.<br/>

---

&ensp;3. 엔트로피(Entropy)<br/>
&ensp;엔트로피는 노드의 불확실성 또는 클래스 혼합 정도를 측정한다.<br/>
$$-\sum_{i=1}^{c}p(i\mid t)\log_2p(i\mid t)$$

* $t$: 현재 노드
* $c$: 클래스 수
* $p(i\mid t)$: 노드 $t$에서 클래스 $i$가 차지하는 비율

&ensp;한 클래스만 존재하면 엔트로피는 0이다.<br/>
&ensp;이진 분류에서 두 클래스의 비율이 50:50이면 엔트로피가 최대가 된다.<br/>

---

&ensp;4. 지니 불순도(Gini Impurity)<br/>
&ensp;지니 불순도는 클래스가 얼마나 섞여 있는지를 나타낸다.<br/>
$$I_G(t)=1-\sum_{i=1}^{c}p(i\mid t)^2$$

&ensp;이진 분류에서 두 클래스의 비율이 50:50이라면 다음과 같다.<br/>
$$1-(0.5^2+0.5^2) = 0.5$$

---

&ensp;5. 분류 오차(Classification Error)<br/>
&ensp;분류 오차는 다수 클래스에 속하지 않는 샘플의 비율을 나타낸다.<br/>
$$I_E(t)=1-\max_i p(i\mid t)$$

&ensp;분류 오차는 가지치기에는 사용할 수 있지만, 엔트로피나 지니 불순도보다 변화에 둔감하여 트리를 구성하는 분할 기준으로는 일반적으로 덜 적합하다.<br/>

---

&ensp;Entropy vs Gini vs Classification Error<br/>

&ensp;같은 분류 오차를 가지는 두 분할도 엔트로피와 지니 불순도로 비교하면 차이가 나타날 수 있다. 따라서 각 자식 노드의 불순도에 샘플 비율을 곱한 뒤 정보 이득을 계산하는 문제를 연습해야 한다.<br/>

# 랜덤 포레스트(Random Forest)

&ensp;1. 핵심 개념<br/>
&ensp;랜덤 포레스트는 여러 개의 결정 트리를 결합하는 앙상블(Ensemble) 모델이다. 여러 결정 트리의 예측 결과를 평균하거나 다수결로 결합하여 일반화 성능을 높이고 단일 결정 트리의 과적합 위험을 줄인다.<br/>
<p align="center"><img src="/assets/img/사물기계학습/2주차/2-8.png" width="600"></p>

&ensp;2. 학습 절차<br/>
1. 원본 데이터에서 랜덤 부트스트랩 샘플을 생성한다.
2. 각 부트스트랩 샘플로 결정 트리를 학습한다.
3. 각 노드에서는 전체 특성 중 일부를 랜덤하게 선택해 분할한다.
4. 위 과정을 반복하여 여러 개의 트리를 만든다.
5. 각 트리의 예측 결과를 다수결 또는 평균으로 결합한다.

&ensp;전체 특성 개수를 $d$라고 할 때, 분류 문제에서는 각 분할에서 고려하는 특성 수 $m$을 다음 정도로 설정할 수 있다.<br/>

$$m\approx\sqrt{d}$$

* $d$: 전체 특성 수
* $m$: 각 분할에서 고려하는 랜덤 특성 수

# k-최근접 이웃(k-Nearest Neighbor, KNN)

&ensp;1. 핵심 개념<br/>
&ensp;KNN은 **게으른 학습기(Lazy Learner)**이다. 훈련 단계에서 별도의 명시적 모델을 만들기보다 데이터를 저장해 두고, 예측 시점에 새로운 샘플과 훈련 샘플 사이의 거리를 계산한다.<br/>
&ensp;KNN 알고리즘<br/>
1. 이웃의 수 $k$를 선택한다.
2. 새로운 샘플과 모든 훈련 샘플 사이의 거리를 계산한다.
3. 가장 가까운 $k$개의 샘플을 선택한다.
4. 다수결로 새로운 샘플의 클래스를 결정한다.

<p align="center"><img src="/assets/img/사물기계학습/2주차/2-9.png" width="600"></p>

---

&ensp;2. Minkowski Distance<br/>
&ensp;민코프스키 거리는 여러 거리 측정 방식을 일반화한 공식이다.<br/>
$$\left[\sum_k \left| x_k^{(i)}-x_k^{(j)} \right|^p \right]^{1/p}$$

* $\mathbf{x}^{(i)},\mathbf{x}^{(j)}$: 두 데이터 샘플
* $x_k^{(i)}$: $i$번째 샘플의 $k$번째 특성값
* $p$: 거리 종류를 결정하는 값

&ensp;$p=2$: 유클리드 거리(Euclidean Distance)<br/>
$$\sqrt{\sum_k (x_k^{(i)}-x_k^{(j)})^2}$$

&ensp;$p=1$: 맨해튼 거리(Manhattan Distance)<br/>
$$\sum_k |x_k^{(i)}-x_k^{(j)}|$$

---

&ensp;3. $k$값의 영향<br/>
&ensp;$k$가 너무 작은 경우<br/>
&ensp;주변의 소수 샘플에 과도하게 반응하므로 결정 경계가 복잡해지고 과적합 가능성이 커진다.<br/>

&ensp;$k$가 너무 큰 경우<br/>
&ensp;멀리 있는 이웃까지 포함하므로 지역적인 패턴을 놓치고 과소적합될 수 있다.<br/>

---

&ensp;4. 차원의 저주(Curse of Dimensionality)<br/>
&ensp;차원이 증가하면 공간의 크기가 급격하게 증가한다. 같은 수의 데이터도 더 넓은 공간에 흩어지므로 가까운 이웃이라는 개념의 의미가 약해진다.<br/>
> 차원이 높아질수록 데이터가 희소해지고 샘플 사이의 거리 차이가 불분명해지는 문제

&ensp;KNN은 거리 계산에 직접 의존하므로 차원의 저주에 특히 민감하다. 따라서 특성 선택, 차원 축소, 스케일링 등을 함께 고려해야 한다.<br/>
