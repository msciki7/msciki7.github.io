# Unit 01. 선형 회귀

&ensp;1. 회귀란?<br/>
&ensp;회귀는 **연속적인 숫자 값을 예측하는 기법**이다.<br/>
&ensp;입력 변수와 목표 변수 사이의 관계를 모델링하고, 새로운 입력에 대한 결과값을 예측한다.<br/>

&ensp;예<br/>
* 주택 가격 예측
* 수요 예측
* 평균 기온 예측
* 매출액 예측

&ensp;회귀의 주요 응용<br/>
* 예측
* 관계 분석
* 추세 파악
* 미래 값 예측

> 회귀 = 연속값 예측
> 분류 = 이산값(클래스) 예측

---

&ensp;2. 회귀와 분류 비교<br/>

| 구분 | 회귀 | 분류 |
| --- | --- | --- |
| 출력 형태 | 연속 값 | 이산 값(클래스) |
| 평가 지표 | MSE, MAE | Accuracy, Precision, Recall |
| 모델 예시 | 선형 회귀, 다항 회귀 | 로지스틱 회귀, 의사결정나무, SVM |

&ensp;공통점<br/>
* 입력 변수와 목표 변수의 관계를 학습

&ensp;차이점<br/>
* 예측하는 값의 성격이 다름
* 평가 방식이 다름
* 사용하는 모델이 다름

---

&ensp;3. 선형 회귀의 정의<br/>
&ensp;선형 회귀는 종속 변수와 하나 이상의 독립 변수 사이의 관계를 **직선 또는 평면**으로 모델링하는 기법이다.<br/>
&ensp;종속 변수와 독립 변수 사이에 선형 관계가 존재한다고 가정한다.<br/>

$$
y = \sum_{i=1}^{m} w_i x_i + b
$$

&ensp;$m=1$이면 단순 선형 회귀이고, $m>1$이면 다중 선형 회귀이다.<br/>

> 선형 회귀의 핵심 = 입력 특성들의 가중합 + 절편

---

&ensp;4. 선형 회귀가 많이 사용되는 이유<br/>
&ensp;① 단순성과 해석 용이성<br/>
* 변수의 영향력을 계수로 직관적으로 해석할 수 있음

&ensp;② 계산 효율성<br/>
* 닫힌 해가 존재하여 계산 속도가 빠름

&ensp;③ 기본 모델로 활용<br/>
* 데이터 경향을 파악하고 베이스라인 모델로 적합

&ensp;④ 확장성<br/>
* 릿지, 라쏘 회귀 등으로 쉽게 확장 가능
* 다항식을 추가하여 비선형 관계에도 대응 가능

---

&ensp;5. 단순 선형 회귀<br/>
&ensp;하나의 특성 $x$와 연속적인 타깃 $y$ 사이의 관계를 모델링한다.<br/>

$$
y = w_1x + b
$$

* $b$: y축 절편
* $w_1$: 특성의 가중치, 즉 기울기

&ensp;데이터에 가장 잘 맞는 직선을 **회귀 직선**이라고 한다.<br/>

&ensp;회귀 직선과 훈련 샘플 사이의 수직 거리를 오프셋(Offset) 또는 예측 오차의 잔차(Residual)라고 한다.<br/>

> 가장 잔차가 작은 직선을 찾는 것이 핵심

---

&ensp;6. 다중 선형 회귀<br/>
&ensp;여러 개의 특성 $x_1, x_2, \cdots, x_m$과 연속적인 타깃 $y$ 사이의 관계를 모델링한다.<br/>

$$
y = w_1x_1 + w_2x_2 + \cdots + w_mx_m + b
$$

&ensp;여러 변수들이 결합하여 목표값에 미치는 영향을 선형적으로 설명하고 정확한 예측을 하는 것이 목적이다.<br/>

---

&ensp;5. 상관관계 행렬 Correlation Matrix<br/>
&ensp;상관관계 행렬은 변수 간의 선형 관계를 정량적으로 표현한 행렬이다.<br/>
&ensp;상관계수는 표준화된 값이므로 -1과 1 사이의 값을 가진다.<br/>

&ensp;피어슨 상관계수<br/>

$$
r = \frac{\sum_{i=1}^{n}(x_i-\mu_x)(y_i-\mu_y)}
{\sqrt{\sum_{i=1}^{n}(x_i-\mu_x)^2}\sqrt{\sum_{i=1}^{n}(y_i-\mu_y)^2}}
= \frac{\sigma_{xy}}{\sigma_x\sigma_y}
$$

* $r=1$: 완벽한 양의 상관관계
* $r=-1$: 완벽한 음의 상관관계
* $r=0$: 선형 상관관계 없음

&ensp;상관관계 행렬 계산<br/>

```python
cm = np.corrcoef(df.values.T)
hm = heatmap(cm, row_names=df.columns, column_names=df.columns)
```

&ensp;강의자료에서는 타깃 변수 `SalePrice`와 `Gr Liv Area`의 상관관계가 **0.71**로 높게 나타난다.<br/>
&ensp;따라서 선형 회귀 모델을 훈련할 때 타깃 변수와 상관관계가 높은 특성이 회귀점에 중요한 역할을 할 수 있다.<br/>

# Unit 02. 선형 회귀 모델 구현 및 평가

&ensp;1. 최소 제곱 선형 회귀의 목표<br/>
&ensp;선형 회귀의 목표는 예측값 $\hat{y}$이 실제값 $y$에 최대한 가까워지도록 가중치 $w$와 절편 $b$를 찾는 것이다.<br/>

$$
L(w,b)=\frac{1}{2n}\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
$$

$$
\hat{y}=\mathbf{w}^T\mathbf{x}+b
$$

&ensp;MSE는 예측값과 실제값의 차이를 제곱한 뒤 평균한 값이므로, 작을수록 모델이 실제값을 잘 예측한다는 의미이다.<br/>

---

&ensp;2. 경사 하강법으로 회귀 모델의 파라미터 구하기<br/>
&ensp;강의자료에서는 `LinearRegressionGD` 클래스를 만들어 경사 하강법 기반 선형 회귀를 구현한다.<br/>

&ensp;클래스의 주요 함수<br/>
* `__init__`: 학습률, 반복 횟수, 난수 초기값 설정
* `fit`: 경사 하강법으로 모델 학습
* `net_input`: 선형 회귀 출력 계산
* `predict`: 예측값 반환

&ensp;핵심 업데이트 코드<br/>

```python
output = self.net_input(X)
errors = (y - output)
self.w_ += self.eta * 2.0 * X.T.dot(errors) / X.shape[0]
self.b_ += self.eta * 2.0 * errors.mean()
loss = (errors**2).mean()
```

&ensp;학습할 때는 `Gr Liv Area`를 입력으로 사용하고 `SalePrice`를 타깃으로 사용한다.<br/>

```python
X = df[['Gr Liv Area']].values
y = df['SalePrice'].values
```

&ensp;7. 정규 방정식 Normal Equation<br/>

$$
\mathbf{w}=(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}
$$

&ensp;정규 방정식은 반복적인 최적화 과정 없이 한 번에 해를 얻는 닫힌 형식(Closed-form)의 해법이다.<br/>
&ensp;단, 매우 큰 데이터셋에서는 역행렬을 구하는 계산 비용이 커질 수 있다.<br/>

&ensp;회귀식에 절편을 포함하려면 입력 행렬 $X$의 첫 열에 1을 추가한다.<br/>

```python
Xb = np.hstack((np.ones((X.shape[0], 1)), X))
z = np.linalg.inv(np.dot(Xb.T, Xb))
w = np.dot(z, np.dot(Xb.T, y))
```

# Unit 02-1. RANSAC을 이용한 안정된 회귀 모델

&ensp;1. RANSAC이란?<br/>
&ensp;RANSAC(Random Sample Consensus)은 이상치를 직접 제거하는 대신 **정상치라고 판단되는 일부 데이터로 회귀 모델을 훈련하는 방법**이다.<br/>

&ensp;데이터 일부를 무작위로 선택하여 모델을 만들고, 모델에 따른 정상치 집합을 반복적으로 확장한다.<br/>

---

&ensp;2. RANSAC 알고리즘 동작 단계<br/>
&ensp;① 랜덤하게 일부 샘플을 정상치로 선택하여 모델 훈련<br/>
&ensp;② 훈련된 모델에서 다른 모든 포인트를 테스트<br/>
&ensp;③ 사용자가 입력한 허용 오차 안에 속한 포인트를 정상치에 추가<br/>
&ensp;④ 모든 정상치를 사용하여 모델을 다시 훈련<br/>
&ensp;⑤ 훈련된 모델과 정상치 간의 오차 추정<br/>
&ensp;⑥ 성능이 사용자가 지정한 임계값에 도달하거나 지정된 반복 횟수에 도달하면 종료, 아니면 처음부터 반복<br/>

---

&ensp;3. RANSACRegressor 주요 설정<br/>

```python
ransac = RANSACRegressor(
    LinearRegression(),
    max_trials=100,
    min_samples=0.95,
    loss='absolute_error',
    residual_threshold=None,
    random_state=123
)
```

* `max_trials=100`: 최대 반복 횟수
* `min_samples=0.95`: 모델을 학습할 때 사용하는 최소 샘플 비율
* `loss='absolute_error'`: 절대 오차 사용
* `residual_threshold`: 정상치/이상치를 구분하는 잔차 임계값
* `random_state=123`: 무작위성 재현

&ensp;정상치와 이상치 마스크<br/>

```python
inlier_mask = ransac.inlier_mask_
outlier_mask = np.logical_not(inlier_mask)
```

> inlier = 정상치
> outlier = 이상치

---

&ensp;4. residual_threshold와 MAD<br/>
&ensp;`residual_threshold=None`으로 지정하면 정상치 임계값이 중앙값 절대 편차(MAD, Median Absolute Deviation)로 결정된다.<br/>

```python
def median_absolute_deviation(data):
    return np.median(np.abs(data - np.median(data)))
```

&ensp;더 적은 수의 데이터 포인트를 이상치로 구분하고 싶다면 MAD보다 더 큰 값으로 임계값을 설정한다.<br/>

&ensp;강의자료에서는 `residual_threshold=65000`을 사용한다.<br/>

&ensp;2. 좋은 잔차 그래프의 형태<br/>
&ensp;예측이 완벽하면 잔차는 정확히 0이 된다.<br/>
&ensp;좋은 회귀 모델이라면 잔차들이 중앙선인 0 주변에 랜덤하게 흩어져 있어야 한다.<br/>

> 잔차가 0 주변에 고르게 분포 → 모델이 체계적으로 과대·과소 예측하지 않음

* 다항 특성 추가 또는 비선형 모델 고려 필요

&ensp;예측값이 커질수록 잔차의 폭이 넓어지는 부채꼴 형태가 나타나면<br/>
* 잔차의 분산이 일정하지 않음을 의미
* 로그 변환이나 가중 회귀 등을 고려할 수 있음

&ensp;3. 평균 제곱 오차 MSE<br/>

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
$$

&ensp;특징<br/>
* 각 샘플에서 실제값과 예측값의 차이를 제곱한 뒤 평균

* 작을수록 모델이 실제값에 가깝게 예측한다는 의미

&ensp;훈련 MSE와 테스트 MSE를 반드시 함께 확인해야 한다.<br/>
&ensp;훈련 MSE가 테스트 MSE보다 작은 경우 과대적합 가능성이 있지만, 모델 비교나 분류 정확도와 달리 명확한 단일 임계값은 없다.<br/>


&ensp;4. 평균 절대 오차 MAE<br/>

$$
MAE=\frac{1}{n}\sum_{i=1}^{n}|y^{(i)}-\hat{y}^{(i)}|
$$

&ensp;MAE는 오차의 절댓값을 평균한 값이다.<br/>
&ensp;평균 제곱근 오차(RMSE)와 함께 자주 사용되는 회귀 평가 지표이다.<br/>

&ensp;훈련 MAE가 테스트 MAE보다 작은 경우 과대적합일 수 있다.<br/>
&ensp;훈련 MAE와 테스트 MAE가 비슷하고 모두 낮으면 안정적으로 일반화된 것으로 볼 수 있다.<br/>


&ensp;5. 결정 계수 $R^2$<br/>
&ensp;결정 계수는 모델이 타깃 변수의 변동성을 얼마나 설명하는지를 비율로 표현한다.<br/>

$$
R^2 = 1 - \frac{SSE}{SST}
$$

&ensp;제곱 오차합 SSE<br/>

$$
SSE=\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
$$

&ensp;전체 제곱합 SST<br/>

$$
SST=\frac{1}{n}\sum_{i=1}^{n}\left(y^{(i)}-\mu_y\right)^2
$$

&ensp;강의자료의 관계식<br/>

$$
R^2 = 1-\frac{MSE}{Var(y)}
$$

&ensp;해석<br/>
* 훈련 데이터의 $R^2$는 일반적으로 0과 1 사이
* 테스트 데이터에서는 음수가 될 수 있음
* $R^2=0$: 샘플 평균을 나타내는 수평선보다 데이터를 더 잘 학습하지 못함
* $R^2=1$: MSE가 0이며 데이터를 완벽하게 학습

# Unit 02-3. 회귀에 규제 적용

&ensp;1. 규제의 목적<br/>
&ensp;규제는 부가 정보를 손실에 추가하여 과대적합을 방지하고, 모델의 복잡도를 낮추어 새로운 데이터에 대한 일반화 성능을 높이는 방법이다.<br/>

&ensp;규제 방법<br/>
&ensp;복잡도에 대한 페널티를 추가하여 모델 파라미터의 값을 감소시킨다.<br/>

---

&ensp;2. 선형 회귀에 널리 사용되는 규제<br/>

| 방법 | 규제 | 핵심 특징 |
| --- | --- | --- |
| Ridge | L2 | 가중치를 전체적으로 작게 만듦 |
| LASSO | L1 | 일부 가중치를 정확히 0으로 만들 수 있음 |
| Elastic Net | L1 + L2 | 릿지의 안정성과 라쏘의 특성 선택 효과 결합 |

---

&ensp;3. 릿지 회귀 Ridge Regression<br/>
&ensp;릿지 회귀는 최소 제곱 손실 함수에 가중치의 제곱합을 추가한 **L2 규제 모델**이다.<br/>

$$
J(\mathbf{w})_{Ridge}=
\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
+\alpha\|\mathbf{w}\|_2^2
$$

$$
\alpha\|\mathbf{w}\|_2^2=\alpha\sum_{j=1}^{m}w_j^2
$$

&ensp;특징<br/>
* $\alpha$가 증가하면 규제 강도가 증가하고 가중치가 감소
* $\alpha$가 0에 가까우면 일반 선형 회귀와 비슷하게 동작
* 절편 $b$는 규제하지 않음

&ensp;사이킷런 사용<br/>

```python
from sklearn.linear_model import Ridge

ridge = Ridge(alpha=1000)
ridge.fit(X_train, y_train)
```

---

&ensp;4. 라쏘 LASSO<br/>
&ensp;LASSO는 희소한 모델을 만들 수 있는 L1 규제 기법이다.<br/>

$$
J(\mathbf{w})_{LASSO}=
\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
+\alpha\|\mathbf{w}\|_1
$$

$$
\alpha\|\mathbf{w}\|_1=\alpha\sum_{j=1}^{m}|w_j|
$$

&ensp;특징<br/>
* 규제 강도에 따라 어떤 가중치는 0이 될 수 있음
* 많은 변수 중 핵심적인 것만 남기는 데 유용
* 서로 강하게 상관관계가 있는 변수들이 존재하면 일부만 남기고 나머지를 0으로 만드는 경향이 있어 결과가 임의적일 수 있음
* 표준화를 거친 데이터에 사용하는 것이 중요
* $\alpha$는 교차검증으로 적절하게 조정해야 함
* $\alpha$가 너무 크면 과소적합, 너무 작으면 과대적합 가능

&ensp;사이킷런 사용<br/>

```python
from sklearn.linear_model import Lasso

lasso = Lasso(alpha=1000)
lasso.fit(X_train, y_train)
```

&ensp;강의자료 코드 결과에서는 일부 회귀 계수가 **0**이 되어 예측에 사용되지 않는 특성이 생기는 모습을 보여준다.<br/>

---

&ensp;5. 엘라스틱 넷 Elastic Net<br/>
&ensp;엘라스틱 넷은 L1 규제와 L2 규제를 함께 적용하여 릿지의 안정성과 라쏘의 특성 선택 효과를 동시에 얻는 방법이다.<br/>

$$
J(\mathbf{w})_{ElasticNet}=
\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
+\lambda_1\|\mathbf{w}\|_1
+\lambda_2\|\mathbf{w}\|_2^2
$$

&ensp;사이킷런에서는 다음과 같이 구현한다.<br/>

$$
J(\mathbf{w})=
\sum_{i=1}^{n}\left(y^{(i)}-\hat{y}^{(i)}\right)^2
+\alpha\left(l1\_ratio\cdot\|\mathbf{w}\|_1+(1-l1\_ratio)\cdot\|\mathbf{w}\|_2^2\right)
$$

&ensp;`l1_ratio`의 의미<br/>
* `l1_ratio = 0`: L2 규제만 적용 → 릿지 회귀
* `l1_ratio = 1`: L1 규제만 적용 → 라쏘 회귀
* `0 < l1_ratio < 1`: L1과 L2 규제를 혼합 적용

&ensp;사용 시 효과적인 방법<br/>
* 입력 데이터 표준화
* 규제 강도 `alpha`와 혼합 비율 `l1_ratio`를 교차검증으로 함께 최적화

&ensp;특히 다중공선성이 존재하거나 특성 수가 샘플 수보다 훨씬 많은 환경에서 희소성과 안정성을 동시에 확보하고자 할 때 유용하다.<br/>

```python
from sklearn.linear_model import ElasticNet

elanet = ElasticNet(alpha=1000, l1_ratio=0.5)
elanet.fit(X_train, y_train)
```

# Unit 03-1. 결정 트리 회귀

&ensp;1. 결정 트리 회귀 Decision Tree Regression<br/>
&ensp;결정 트리 회귀는 특정한 형태의 데이터 전처리나 특성 변환 없이도 다양한 특성에 효과적으로 작동하는 회귀 기법이다.<br/>

&ensp;특징<br/>
* 임의의 특성에 잘 동작하므로 비선형 데이터를 다룰 때 특성 변환이 필요하지 않음
* 가중치가 적용된 특성 조합을 보는 것이 아니라 한 번에 하나의 특성을 평가
* 특성 정규화나 표준화가 필요하지 않음
* 리프 노드 순수도가 충분해질 때까지 반복적으로 노드를 분할

---

&ensp;2. 회귀 트리의 불순도 기준<br/>
&ensp;분류 결정 트리에서는 정보 이득(IG)이 최대화되는 특성 분할을 찾는다.<br/>

$$
IG(D_p,x)=I(D_p)-\frac{N_{left}}{N_p}I(D_{left})-\frac{N_{right}}{N_p}I(D_{right})
$$

&ensp;회귀 결정 트리에서는 연속적인 특성에 적합한 불순도 지표로 MSE를 사용한다.<br/>

$$
I(t)=MSE(t)=\frac{1}{N_t}\sum_{i\in D_t}(y^{(i)}-\hat{y}_t)^2
$$

$$
\hat{y}_t=\frac{1}{N_t}\sum_{i\in D_t}y^{(i)}
$$

&ensp;결정 트리 회귀에서 MSE는 노드 내 분산이라고도 한다.<br/>
&ensp;분할 기준은 분산 감소라고 해석할 수 있으며, 부모 노드의 분산에서 자식 노드들의 분산 가중합을 뺀 값이 최대가 되도록 분할할 특성을 선택한다.<br/>

---

&ensp;3. DecisionTreeRegressor<br/>

```python
from sklearn.tree import DecisionTreeRegressor

tree = DecisionTreeRegressor(max_depth=3)
tree.fit(X, y)
```

&ensp;`max_depth=3`으로 분할 횟수를 제한하여 지나친 세분화를 막고 과대적합을 완화한다.<br/>

&ensp;필요에 따라 조절 가능한 하이퍼파라미터<br/>
* `max_depth`
* `min_samples_leaf`
* `min_samples_split`
* `max_leaf_nodes`

&ensp;결정 트리 회귀는 데이터의 일반적인 경향을 잘 포착하지만, 예측이 계단형으로 나타나므로 연속적이고 매끄러운 형태를 잘 나타내지 못할 수 있다.<br/>

# Unit 03-2. 랜덤 포레스트 회귀

&ensp;1. 랜덤 포레스트 회귀 Random Forest Regression<br/>
&ensp;랜덤 포레스트는 여러 개의 결정 트리를 연결하는 앙상블 방법이다.<br/>

&ensp;특징<br/>
* 일반적으로 단일 결정 트리보다 더 우수한 일반화 성능
* 무작위성이 모델의 분산을 낮춰주는 데 도움
* 데이터셋에 있는 이상치에 덜 민감
* 하이퍼파라미터 튜닝이 많이 필요하지 않음

&ensp;회귀에서는 분류와 달리 개별 결정 트리를 성장시키기 위해 MSE 기준을 사용한다.<br/>
&ensp;타깃 값 예측은 **모든 결정 트리의 예측을 평균하여 계산**한다.<br/>

---

&ensp;2. RandomForestRegressor 설정<br/>

```python
forest = RandomForestRegressor(
    n_estimators=1000,
    criterion='squared_error',
    random_state=1,
    n_jobs=-1
)
```

* `n_estimators=1000`: 결정 트리 개수를 1000개로 설정
* `criterion='squared_error'`: 분할 기준으로 평균 제곱 오차 사용
* `random_state=1`: 무작위성 시드 고정
* `n_jobs=-1`: 모든 CPU 코어를 사용하여 병렬 연산

&ensp;모델 학습과 예측<br/>

```python
forest.fit(X_train, y_train)
y_train_pred = forest.predict(X_train)
y_test_pred = forest.predict(X_test)
```

&ensp;성능 평가<br/>

```python
mae_train = mean_absolute_error(y_train, y_train_pred)
mae_test = mean_absolute_error(y_test, y_test_pred)

r2_train = r2_score(y_train, y_train_pred)
r2_test = r2_score(y_test, y_test_pred)
```

&ensp;강의자료의 결과<br/>
* MAE 훈련: 약 8,395.18
* MAE 테스트: 약 20,821.77
* $R^2$ 훈련: 약 0.98
* $R^2$ 테스트: 약 0.85

&ensp;훈련 데이터보다 테스트 데이터에서 MAE가 더 크고 $R^2$가 더 낮아 과적합이 일부 발생한다.<br/>
&ensp;하지만 다변량 선형 회귀 모델보다 더 작은 예측 오차를 보여 랜덤 포레스트 회귀가 주택 가격 예측에서 더 안정적이고 강건한 성능을 보인다.<br/>
