# 분류 앙상블

## 앙상블 학습

&ensp;앙상블 학습(Ensemble Learning)은 여러 개의 약한 학습기를 결합하여 하나의 모델보다 더 좋은 성능을 얻는 방법이다. 여러 분류기를 하나의 메타 분류기로 연결해 **개별 분류기보다 더 좋른 일반화 성능을 얻는 것** 을 목표로 한다. 여러 관점에서 예측하기 때문에 안정성은 높이고 신뢰성은 향샹시킬 수 있다.<br/>

<p align="center"><img src="/assets/img/사물기계학습/4주차/4-1.png" width="600"></p>

```
여러 개의 분류기
        ↓
각자 예측
        ↓
예측 결과 결합
        ↓
최종 예측
```

&ensp;앙상블 학습의 목표: 여러 분류기를 하나의 메타 분류기로 연결하여 개별 분류기보다 더 좋은 일반화 성능을 달성하는 것이 목표이다.<br/>

&ensp;성능이 좋아지는 이유: 각 분류기가 서로 다른 방식으로 오류를 낼 수 있기 때문이다.<br/>
&ensp;예를 들어 분류기 1 → 틀림, 분류기 2 → 맞음, 분류기 3 → 맞음 이라면 다수결을 사용했을 때 최종 결과는 맞을 수 있다. 따라서 핵심은 **개별 모델의 오류가 서로 완전히 똑같지 않아야 한다.** <br/>

## 과반수 투표 Majority Voting

&ensp;과반수 투표는 여러 분류기가 예측한 클래스 중에서 가장 많은 표를 받은 클래스를 최종 예측값으로 선택하는 방식이다.<br/>
<p align="center"><img src="/assets/img/사물기계학습/4주차/4-2.png" width="600"></p>

&ensp;예를 들어 3개의 분류기 중 2개가 클래스 A를 선택하면 최종 예측은 클래스 A가 된다.<br/>

&ensp;수식<br/>
&ensp;분류기가 m개 존재하고 각각의 예측을 $C_1​(x),C_2​(x),⋯,C_m​(x)$ 라고 하면 최종 예측은 $\hat{y} = mode{C_1(x), C_2(x), ... , C_m(x)}$ 이다. 여기서 mode는 최빈값을 의미한다.<br/>

---

&ensp;과반수 투표 앙상블의 오류<br/>
* 이진 분류 작업에 대해 동일한 에러율 \(\epsilon\)을 가진 \(n\)개의 분류기
* 분류기들은 서로 독립적
* 발생하는 오차에는 상관관계가 없음

&ensp;앙상블 분류기의 오차 확률은 다음과 같다.<br/>

$$P(y \geqslant k) = \sum\limits_{k = n/2}^{n}{\begin{pmatrix}  n \\ k  \end{pmatrix}\epsilon _k (1 - \epsilon)^{n-k}} = \epsilon _{ensemble}$$

> n개의 개별 분류기에서 예측이 틀린 \(k\)개의 분류기를 뽑는 조합의 개수

&ensp;개별 분류기의 에러율이 50% 미만이면, 분류기가 많을수록 앙상블 전체의 에러율은 기하급수적으로 감소한다.<br/>

---

&ensp;다수결 투표를 사용한 분류 앙상블<br/>
&ensp;단순 다수결과 가중 다수결<br/>
&ensp;개별 분류기의 신뢰도에 따라 가중치를 부여하여 연결할 수 있다.<br/>
&ensp;단순 다수결: 각 분류기에 동일한 비중을 부여한다.<br/>
&ensp;가중 다수결: 분류기마다 서로 다른 가중치를 부여한다.<br/>

> 더 믿을 수 있는 분류기일수록 더 높은 가중치를 주는 방식

&ensp;가중 다수결 수식<br/>

$$\hat{y} = arg \underset{i}{max} \sum\limits_{j=1}^{m}{w_j X_A (C_j(x) = i)}$$

* A: 고유한 클래스 레이블의 집합
* $w_j$ : 개별 분류기 $C_j$ 에 연결된 가중치
* $\chi_A(C_j(x)=i)$ : 특정 함수 또는 지시 함수
* $\hat y$ : 앙상블이 예측한 클래스 레이블

&ensp;가중치가 모두 동일하면 앞에서 본 단순 다수결과 같아진다.<br/>

---

&ensp;클래스 레이블 투표와 클래스 확률 투표<br/>
&ensp;클래스 레이블 사용<br/>
&ensp;각 분류기가 예측한 클래스 레이블을 모아 다수가 선택한 레이블을 최종 예측으로 사용한다. 하지만 이 경우 각 분류기가 자신의 예측에 대해 얼마나 확신하는지는 반영하지 못한다.<br/>

&ensp;클래스 확률 사용<br/>
&ensp;클래스 레이블 대신 각 분류기의 예측 클래스 확률을 사용할 수 있다.<br/>
$$\hat{y} = arg\underset{i}{max}\sum\limits_{j=1}^{m}{w_j P_{ij}}$$

&ensp;여기서 $P_{ij​}$ 는 클래스 레이블 i에 대한 j번째 분류기의 예측 확률이다.<br/>
* 신뢰도 있는 확률 예측을 제공하는 분류기에 유용
* 단순 투표보다 더 부드럽고 정교한 결정 경계를 만들 수 있음

---

&ensp;MajorityVoteClassifier 구현<br/>
&ensp;여러 개의 분류기를 하나로 묶어 다수결 또는 확률 기반 방식으로 결정하는 MajorityVoteClassifier를 구현하는 방법<br/>

&ensp;초기화<br/>
```python
class MajorityVoteClassifier(BaseEstimator, ClassifierMixin):
    def __init__(self, classifiers, vote='classlabel', weights=None):
```

&ensp;주요 설정:<br/>
* classifiers : 사용할 분류기
* vote : 투표 방식
* weights : 각 분류기의 가중치

&ensp;fit()<br/>
* vote 값이 `probability` 또는 `classlabel`인지 확인
* 분류기 개수와 가중치 개수 확인
* `LabelEncoder`를 이용해 클래스 레이블을 정수로 인코딩
* 각각의 분류기를 복제하여 훈련

&ensp;predict()<br/>
&ensp;확률 투표인 경우<br/>
```python
np.argmax(self.predict_proba(X), axis=1)
```

&ensp;을 사용한다.<br/>
&ensp;클래스 레이블 투표인 경우 각 분류기의 예측 결과를 모은 뒤 np.bincount()와 가중치를 이용하여 다수결을 수행한다.<br/>

&ensp;predict_proba()<br/>
```python
probas = np.asarray([
    clf.predict_proba(X)
    for clf in self.classifiers_
])

avg_proba = np.average(
    probas,
    axis=0,
    weights=self.weights
)
```

&ensp;각 분류기의 클래스 확률 예측을 평균하여 앙상블의 확률값을 만든다.<br/>

## 배깅 Bagging

&ensp;Bagging은 Bootstrap aggregating이다. 개별 분류기를 동일한 훈련 데이터셋으로 학습하는 것이 아니라 원본 훈련 데이터셋에서 부트스트랩 샘플, 즉 중복을 허용한 랜덤 샘플을 뽑아 사용한다.<br/>
&ensp;각각의 분류기를 학습한 뒤 결과를 다수결 투표, 평균 등을 통해 결합한다.<br/>

&ensp;배깅의 특징<br/>
&ensp;동일한 알고리즘을 사용하다러도 각 훈련 샘플이 서로 다르기 때문에 분류기마다 학습된 결정 경계가 달라진다.<br/>
&ensp;따라서 모델 분산 감소, 과적합 가능성 감소 효과가 있으며 특히 결정 트리처럼 분산이 큰 모델일수록 배깅의 효과가 크다고 설명한다.<br/>

<p align="center"><img src="/assets/img/사물기계학습/4주차/4-5.png" width="600"></p>

&ensp;배깅 알고리즘의 작동 방식<br/>
1. 1에서 7까지 인덱스가 부여된 7개의 훈련 샘플을 준비
2. 중복을 허용하여 랜덤하게 샘플링
3. 각각의 Bootstrap sample을 이용하여 분류기 $C_j$ 를 학습
4. 다수결 투표를 사용하여 예측을 모음

<p align="center"><img src="/assets/img/사물기계학습/4주차/4-6.png" width="600"></p>

```
원본 훈련 데이터
        ↓
중복을 허용한 랜덤 샘플링
        ↓
여러 Bootstrap Sample
        ↓
각각의 분류기 학습
        ↓
다수결 투표
        ↓
최종 예측
```

# 에이다부스트 AdaBoost

&ensp;AdaBoost는 이전 학습기에서 잘못 예측한 샘플에 더 큰 가중치를 부여하면서 반복 학습을 진행한다. 또한 각 학습기의 분류 성능에 따라 예측 결과에 가중치를 적용하여 최종 예측을 결정한다. 단순한 약한 학습기도 반복적으로 성능을 보완하면 강력한 예측 모델로 발전시킬 수 있다고 설명한다.<br/>

## Boosting

&ensp;Boosting은 약한 학습기가 잘못 분류한 훈련 샘플을 다음 약한 학습기가 학습하여 앙상블 성능을 향상시키는 방식이다.<br/>

&ensp;흐름<br/>
```
이전 단계 학습기
       ↓
잘못 분류한 샘플
       ↓
다음 학습기가 집중 학습
       ↓
더 나은 예측 결과
```

&ensp;Boosting 과정<br/>

&ensp;첫 번째 단계<br/>
&ensp;훈련 데이터셋 D에서 중복을 허용하지 않고 랜덤한 부분 집합 $d_1$을 뽑아 약한 학습기 $C_1$ 을 훈련한다.<br/>

&ensp;두 번째 단계<br/>
&ensp;또 다른 부분 집합 $d_2$ 를 뽑고, 이전에 잘못 분류된 샘플의 50%를 더하여 $C_2$를 훈련한다.<br/>

&ensp;세 번째 단계<br/>
&ensp;$C_1$ 과 $C_2$에서 잘못 분류된 훈련 샘플 $d_3$ 를 찾아 $C_3$ 를 훈련한다.<br/>

&ensp;마지막<br/>
&ensp;약한 학습기 $C_1 , C_2 , C_3$ 을 다수결 투표로 연결한다.<br/>

&ensp;Boosting의 특징<br/>
&ensp;일반적으로 배깅 모델에 비해 분산 감소, 편향 감소 효과가 있다.<br/>
&ensp;또한 각 단계에서 이전 학습기가 놓친 부분 즉 샘플에 집중하기 때문에 모델의 분산을 줄이는 것뿐 아니라 편향까지도 효과적으로 줄여줄 수 있다.<br/>

----

&ensp;AdaBoost의 특징<br/>
&ensp;AdaBoost에서는 이전 학습기의 전체 훈련 데이터셋을 사용한다. 훈련 샘플은 반복마다 가중치가 다시 부여되고 이전 학습기가 실수한 샘플에 집중하도록 한다.<br/>
&ensp;단일 모델로 감지하기 어려운 결정 경계 근처의 복잡한 패턴을 포착하여 강력한 예측 모델을 만들 수 있다고 설명한다. 하지만 학습 데이터에 노이즈가 많거나 잘못된 레이블이 포함된 경우 분산이 커지고 과대적합 가능성이 있다. 또한 배깅과 달리 모델들이 순차적으로 의존하며 학습하기 때문에 병렬 처리가 어렵고 계산량이 더 많다.<br/>

&ensp;AdaBoost 알고리즘<br/>
&ensp;초기 가중치 설정<br/>
&ensp;각 샘플의 초기 가중치는 동일한다. $\sum_{i}{w_i} = 1$ . $w_i = \frac{1}{n}$ 여기서 n은 훈련 샘플의 개수이다.<br/>

&ensp;반복 과정<br/>
&ensp;m번째 부스팅 반복에서 다음을 수행한다.<br/>
&ensp;a. 약한 학습기 훈련. $C_j = train(X, y, w)$ <br/>
&ensp;b. 클래스 레이블 예측. $\hat{y} = predict(C_j, X)$ <br/>
&ensp;c. 가중치가 적용된 에러 계산. $\epsilon = w\cdot(\hat{y}\neq y)$ <br/>
&ensp;d. 학습기 가중치 계산.l $\alpha _j = 0.5\log \frac{1 - \epsilon}{\epsilon}$ <br/>
&ensp;e. 샘플 가중치 업데이트.l $w := w \times exp(-\alpha _j \times \hat{y} \times y)$ <br/>
&ensp;f. 가중치 정규화. $w := \frac{w}{\sum _i w_i}$ <br/>

&ensp;학습기 가중치 $\alpha_j$ <br/>
$\alpha _j = 0.5 \log \frac{1-\epsilon}{\epsilon}$ <br/>

> 오류율 $\epsilon$ 을 바탕으로 학습기의 신뢰도 또는 영향력을 나타내는 $\alpha_j$ 를 계산

&ensp;샘플 가중치 업데이트<br/>
* 올바르게 분류한 경우 → 가중치 감소
* 잘못 분류한 경우 → 가중치 증가

&ensp;가 되도록 업데이트한다. 마지막에는 전체 가중치 합이 1이 되도록 정규화하여 다음 학습기에서 오분류된 샘플에 더 집중하게 한다.<br/>

&ensp;최종 예측<br/>
&ensp;최종 예측은 각 학습기의 예측 결과에 학습기 가중치 $\alpha_j$ 를 적용하여 계산한다.<br/>

$$\hat{y} = (\sum\limits_{j=1}^{m}{\alpha _j \times predict (C_j, X) > 0}$$

# 그레디언트 부스팅 Gradient Boosting

&ensp;Gradient Boosting은 이전 모델의 예측 오차를 기반으로 다음 트리를 학습하며 손실 함수의 Gradient를 이용하여 모델을 점진적으로 개선하는 방법이다.<br/>
&ensp;오차 자체를 다음 학습의 target 값으로 사용하는 방식이다.<br/>

---

&ensp;AdaBoost와 Gradient Boosting 비교<br/>
&ensp;AdaBoost<br/>
* 이전 트리의 오차를 기반으로 깊이가 1인 결정 트리를 훈련
* 각 반복에서 오차를 사용하여 샘플 가중치와 개별 트리를 앙상블로 합칠 때의 결정 트리 분류기 가중치를 계산
* 최대 반복 횟수에 도달하면 훈련을 멈춤

&ensp;Gradient Boosting<br/>
* 예측 오차를 사용하여 반복적으로 스타일을 유지하며 결정 트리를 훈련
* 일반적으로 깊이가 3~6인 트리를 사용
* 샘플 가중치를 할당하지 않고 다음 트리를 훈련
* 모든 트리에 적용되는 학습률을 사용

<p align="center"><img src="/assets/img/사물기계학습/4주차/4-14.png" width="600"></p>

---

&ensp;Gradient Boosting의 의미<br/>
&ensp;여러 개의 결정 트리 또는 약한 학습기를 순차적으로 만들어 가는 방식의 앙상블 학습 기법이다. 각 트리는 이전의 오차, 즉 예측값과 실제값 사이의 차이에서 훈련된다. 반복마다 각 트리를 올바른 방향으로 조금씩 업데이트하기 때문에 트리 앙상블이 향상된다. 손실 Gradient를 기반으로 하므로 Gradient Boosting이라고 부른다.<br/>

> 각각의 트리는 비교적 약한 성능을 가질 수 있지만 Gradient를 따라가며 격차를 줄이도록 훈련된 트리들이 순차적으로 결합하면서 정교하고 강력해진다.

&ensp;Gradient Boosting의 특징<br/>
&ensp;각 단계에서 이전 모델의 오차를 기반으로 다음 모델을 학습한다.
> 학습이 병렬화되기 어렵고 계산량이 많음

---

&ensp;Gradient Boosting 주요 단계<br/>
&ensp;1. 상수 예측값을 반환하는 모델 초기화<br/>
&ensp;하나의 리프 노드만 가지는 트리를 사용한다. 트리가 반환하는 값을 모든 표시값에 대해 정의할 때 가능한 손실함수를 최소화하는 값을 찾는다.<br/>
$$F_0 (x) = arg\underset{\hat{y}}{min}\sum\limits_{i=1}^{n}{(y_i, \hat{y})}$$

&ensp;n은 데이터셋에 존재하는 훈련 샘플의 개수이다.<br/>

&ensp;2-a. 의사 잔차 계산<br/>
&ensp;예측값 $F(x_i) = \hat{y_i}$ 와 클래스 레이블 $y_i$ 사이의 차이를 계산한다.<br/>
&ensp;이 값을 의사 응답, 의사 잔차 Residual 라고 부른다.<br/>
&ensp;손실 함수의 음의 Gradient를 사용한다.<br/>
<p align="center"><img src="/assets/img/사물기계학습/4주차/4-15.png" width="600"></p>

&ensp;2-b. 의사 잔차로 트리 훈련<br/>
&ensp;의사 잔차 $r_{min}$ 에서 트리를 훈련한다. $R_{jm​}$ 은 반복 m에서 j번째 리프 노드이며 $j = 1, ..., J_m$ 으로 표현한다.<br/>

&ensp;2-c. 각 리프 노드의 출력값 계산<br/>
<p align="center"><img src="/assets/img/사물기계학습/4주차/4-16.png" width="600"></p>

&ensp;출력값은 해당 리프 노드에 포함된 샘플들의 손실 함수를 최소화하는 값을 선택한다. 즉 각 리프 노드에서 속한 샘플의 손실을 줄이는 방향으로 정해진 값을 출력한다.<br/>

&ensp;2-d. 모델 업데이트<br/>
$$F_m(x) = F_{m-1}(x) + \eta\gamma_m$$

&ensp;η 는 학습률이며 점진적인 업데이트를 위해 사용한다.<br/>

---

&ensp;분류를 위한 Gradient Boosting<br/>
&ensp;Logistic Loss<br/>
&ensp;하나의 훈련 샘플에 대한 Logistic Loss는 $L_i = -[y_i \log p_i + (1 - y_i)\log (1-p_i)]$ 이다.<br/>

&ensp;Log Odds<br/>
&ensp;하나의 훈련 샘플에 대한 Log Odds는 $\hat{y_i} = \log \frac{p_i}{1-p_i}$ 이다. 따라서 $\log (p_i) = \hat{y_i} + \log (1-p_i)$ 로 변형한다.<br/>

&ensp;Logistic Loss의 편미분<br/>
&ensp;Loss를 변형한 뒤 편미분하면 $\frac{∂ L_i}{∂ \hat{y_i}} = p_i - y_i$ 가 되는 과정을 보여준다. 그러므로 음의 편미분은 $-\frac{∂ L_i}{∂ \hat{y_i}} = y_i - p_i$ 가 된다. 즉 분류 Gradient Boosting에서는 $r_i = y_i - p_i$ 를 의사 잔차로 사용한다.<br/>
> 현재 모델이 얼마나 잘못 예측했는지를 나타내며 다음 트리의 학습 대상

---

&ensp;분류 Gradient Boosting의 주요 단계<br/>
&ensp;첫 번째: Logistic Loss를 최소화하는 Root Node를 만든다. 초기 모델은 모든 샘플에 대해 동일한 값을 예측하고, 이 값은 Logistic Loss를 최소화하는 값이다.<br/>
&ensp;두 번째: Log Odds를 Logistic 함수에 넣어 확률로 변환한다. $p = \frac{1}{1 + e^{-\hat{y}}}$ 그리고 r = y - p를 계산한다.<br/>
&ensp;세 번째: 의사 잔차로 새로운 트리를 훈련한다.<br/>
&ensp;네 번째: 각 리프 노드에서 Logistic Loss를 최소화하는 $\gamma_{jm}$ 를 계산한다.<br/>
> 해당 리프 노드에서 모델의 예측을 얼마나 어떤 방향으로 조정할지를 나타내는 보정값

&ensp;다섯 번째: 학습률을 적용하여 모델을 업데이트한다.<br/>

$$F_m(x) = F_{m-1}(x) + η \gamma_{m}$$
