# Unit 01. 사물인터넷과 기계학습의 융합

&ensp;1. 왜 IoT와 기계학습을 함께 사용해야 할까?<br/>
&ensp;IoT와 기계학습은 각각 담당하는 역할이 다르다.<br/>

&ensp;IoT의 역할<br/>
* 데이터 수집 기술
* 실시간으로 데이터 수집
* 데이터 자체를 이해하거나 결정을 내리지는 못함

&ensp;즉, IoT는 현실 세계에서 데이터를 얻어오는 역할을 담당한다.<br/>

&ensp;기계학습 모델의 역할<br/>
* 데이터를 분석하고 예측
* 학습된 패턴이나 사용자 습관에 따라 정교한 결정 가능

&ensp;즉, IoT가 데이터를 모으면 기계학습이 그 데이터를 이용해 판단한다.<br/>

&ensp;예시: 스마트홈<br/>
&ensp;온도 센서가 방의 온도를 감지한다.<br/>
&ensp;→ IoT 센서가 데이터를 수집<br/>
&ensp;→ 기계학습 모델이 데이터를 분석<br/>
&ensp;→ 냉·난방 장치를 자동으로 작동<br/>

> IoT = 감지 및 데이터 수집
> Machine Learning = 분석 및 판단
> IoT + ML = 감지 → 판단 → 자동 대응

---

&ensp;2. 데이터 수집과 데이터 활용의 차이<br/>

&ensp;데이터 수집<br/>
&ensp;센서가 실제 환경에서 발생하는 정보를 얻는 것<br/>
&ensp;예: 온도, 압력, 위치, 습도<br/>

&ensp;데이터 활용<br/>
&ensp;수집한 데이터를 이용하여 그 안의 정보를 찾아내는 것<br/>
> 수집 = 데이터를 얻는 단계
> 활용 = 데이터를 분석해서 의미를 얻는 단계

&ensp;IoT만으로는 데이터 수집까지 가능하지만, 기계학습을 결합하면 데이터에서 패턴을 찾고 자동으로 판단할 수 있다.<br/>

---

&ensp;3. IoT + 기계학습 결합의 중요성<br/>
&ensp;① 데이터를 활용한 자동화의 중요성 증가<br/>
&ensp;수집된 데이터를 사람이 직접 분석하지 않고 시스템이 분석하여 자동으로 행동할 수 있다.<br/>

&ensp;② 단순한 현실을 넘어 예측·제어까지 확장<br/>
&ensp;단순히 현재 상태를 파악하는 것에서 끝나지 않고 미래 상태 예측, 이상 상황 탐지, 시스템 제어까지 가능해진다.<br/>

&ensp;지능화: 센서 데이터를 기반으로 시스템이 스스로 판단하고 대응하는 것<br/>

---

# Unit 02. IoT 데이터의 특성과 기계학습 처리 과정

&ensp;1. IoT 데이터의 정의<br/>
&ensp;IoT 데이터는 센서, 디바이스, 장비 등 실제 사물에서 수집되어 전송되는 데이터를 의미한다.<br/>
&ensp;IoT 시스템에서 생성되는 모든 디지털 정보를 IoT 데이터라고 볼 수 있다.<br/>

---

&ensp;2. IoT 데이터의 주요 구성 요소<br/>

| 종류        | 예                     |
| --------- | --------------------- |
| 센서 측정값    | 온도, 습도, 압력, 조도 등      |
| 이벤트 로그    | 작동/오류 발생 시간, 상태 변경 기록 |
| 통신 데이터    | 패킷 흐름, 연결 품질, 전송량     |
| 위치 정보     | GPS 좌표, 이동 경로, 지역 정보  |
| 멀티미디어 데이터 | 이미지, 영상, 음성           |

&ensp;핵심<br/>
&ensp;IoT 데이터가 단순히 센서 숫자만 의미하는 것은 아니다.<br/>
&ensp;예를 들어 하나의 자율 시스템에서도 센서값, GPS, 카메라 영상, 시스템 로그, 네트워크 정보가 동시에 생성될 수 있다.<br/>

---

&ensp;3. IoT 데이터의 데이터 형식<br/>
&ensp;IoT 데이터는 크게 정형, 비정형, 반정형 데이터로 나눌 수 있다.<br/>

&ensp;① 정형 데이터 Structured Data<br/>
&ensp;일정한 형식이 정해져 있는 데이터<br/>

&ensp;예<br/>
* 수치
* 시간
* 상태값
* CSV
* Database

&ensp;② 비정형 데이터 Unstructured Data<br/>
&ensp;고정된 구조 없이 저장되는 데이터<br/>

&ensp;예<br/>
* 이미지
* 영상
* 로그파일
* 텍스트

&ensp;③ 반정형 데이터 Semi-structured Data<br/>
&ensp;일정한 구조는 존재하지만, 정형 데이터처럼 완전히 고정된 표 형태는 아니다.<br/>

&ensp;예<br/>
* JSON
* XML

&ensp;정리<br/>
> 정형 → 표처럼 구조가 고정됨
> 반정형 → 구조는 있지만 유연함
> 비정형 → 고정된 구조가 없음

---

&ensp;4. IoT 데이터의 생성 방식과 시간 특성<br/>
&ensp;IoT 데이터에서 매우 중요한 특징은 시간이다.<br/>

&ensp;① 시계열 데이터 중심<br/>
&ensp;대부분 시간 축을 기준으로 연속적으로 생성된다.<br/>
&ensp;예: 매 초마다 기록되는 온도 센서 값<br/>
&ensp;즉 $x_1, x_2, x_3, ... , x_t$ 처럼 시간 순서가 존재한다.<br/>

&ensp;② 스트리밍 특성<br/>
&ensp;데이터가 한 번에 모두 주어지는 것이 아니라 초당 수백~수천 건 단위로 실시간 전송 될 수 있다. 따라서 기존의 정적인 데이터 처리와 달리 계속 들어오는 데이터를 처리해야 한다.<br/>

&ensp;③ 이벤트 기반 데이터<br/>
&ensp;특정 조건이 발생했을 때만 데이터가 생성될 수 있다.<br/>
&ensp;예: 문이 열릴 때 센서가 작동하여 기록<br/>
* 지속적으로 값이 생성되는 센서 데이터
* 특정 사건이 발생할 때만 생성되는 이벤트 데이터<br/>
&ensp;가 함께 존재할 수 있다.<br/>

---

&ensp;5. IoT 데이터의 주요 특성<br/>
&ensp;① 복잡도 Complexity<br/>
&ensp;다양한 센서와 디바이스에서 서로 다른 데이터가 생성된다.<br/>
&ensp;따라서 수치형, 범주형, 시계열, 멀티미디어 등 다양한 데이터 구조가 공존한다.<br/>

&ensp;② 비정규성 Irregularity<br/>
&ensp;IoT 데이터는 항상 일정하게 생성되는 것이 아니다.<br/>
&ensp;예<br/>
* 시간 간격이 일정하지 않음
* 센서별 데이터 생성 속도가 다름
* 누락 발생
* 중복 발생
* 이상치 발생

&ensp;따라서 전처리가 매우 중요하다.<br/>

&ensp;③ 스트리밍 특성 Streaming nature<br/>
&ensp;지속적으로 데이터가 생성된다.<br/>
&ensp;따라서 실시간 처리, 근실시간 처리가 필요하다.<br/>

&ensp;④ 고차원성 High dimensionality<br/>
&ensp;IoT에서는 동시에 여러 종류의 변수를 수집할 수 있다.<br/>
&ensp;예<br/>
* 위치
* 시간
* 센서 상태
* 주변 환경

&ensp;따라서 변수의 개수가 많아질 수 있다.<br/>
&ensp;고차원 데이터의 경우 차원 축소 또는 피처 선택이 필요할 수 있다.<br/>

---

&ensp;6. IoT 데이터의 특성으로 인해 발생하는 문제<br/>
1. 데이터 통합의 어려움
2. 실시간 처리 요구
3. 데이터 품질 문제
4. 고차원 데이터 해석의 어려움
5. 시스템 자원의 제약

&ensp;연결해서 이해하기<br/>
&ensp;IoT 데이터가 여러 센서에서 발생<br/>
&ensp;↓<br/>
&ensp;형태와 시간 간격이 다름<br/>
&ensp;↓<br/>
&ensp;누락·중복·이상치 발생<br/>
&ensp;↓<br/>
&ensp;동시에 엄청난 양의 데이터가 실시간으로 유입<br/>
&ensp;↓<br/>
&ensp;따라서 데이터 통합과 전처리가 중요<br/>

---

&ensp;7. IoT 데이터가 가지는 기회와 가치<br/>
1. 실시간 모니터링 가능성
2. 예측 기반 의사결정 지원
3. 자동화 시스템 구현 가능
4. 데이터 기반 가치 창출
5. 환경 및 사회 문제 해결에 기여 

&ensp;즉 IoT 데이터의 단점이 복잡성과 처리 난이도라면, 장점은 현실 세계의 상태를 지속적으로 관찰하고 이를 기반으로 예측·자동화할 수 있다는 것이다.<br/>

---

&ensp;8. IoT에 적합한 기계학습 기술군<br/>
&ensp;① 시계열 예측 모델<br/>
&ensp;시간 흐름을 가진 데이터를 바탕으로 미래값을 예측<br/>
&ensp;예:<br/>
* 미래 온도 예측
* 전력 사용량 예측

&ensp;② 이상 탐지 모델<br/>
&ensp;정상적인 패턴과 다른 데이터를 찾아냄<br/>
&ensp;예:<br/>
* 장비 고장 탐지
* 이상 센서값 탐지

&ensp;③ 경량화 기계학습 모델<br/>
&ensp;IoT 장치는 컴퓨팅 자원이 제한될 수 있기 때문에 가벼운 모델이 필요할 수 있다.<br/>

---

&ensp;9. IoT 데이터 처리의 전체 흐름<br/>
&ensp;데이터 수집 → 전처리 → 특성 추출 → 학습 및 검증 → 추론 및 활용<br/>
&ensp;① 데이터 수집: 센서 및 장치로부터 데이터를 얻는다.<br/>
&ensp;↓<br/>
&ensp;② 전처리: 학습에 적합하도록 데이터를 정리한다.<br/>
&ensp;↓<br/>
&ensp;③ 특성 추출: 원본 데이터에서 학습에 필요한 특징을 만든다.<br/>
&ensp;↓<br/>
&ensp;④ 학습 및 검증: 기계학습 모델을 학습하고 성능을 확인한다.<br/>
&ensp;↓<br/>
&ensp;⑤ 추론 및 활용: 학습된 모델을 실제 IoT 환경에 적용한다.<br/>

---

&ensp;10. 전처리의 주요 작업<br/>
&ensp;① 결측치 처리 Missing Value Handling<br/>
&ensp;센서가 값을 제대로 기록하지 못했을 때 발생하는 빈 데이터를 처리한다.<br/>

&ensp;② 스케일 조정 Scaling / Normalization<br/>
&ensp;센서마다 값의 크기가 다를 수 있기 때문에 값의 범위를 조정한다.<br/>
&ensp;예<br/>
* 온도: 20~30
* 압력: 900~1100
* 특정 센서값: 0~10000

&ensp;이렇게 스케일 차이가 큰 데이터를 일정한 범위로 맞출 수 있다.<br/>

&ensp;③ 시간 정렬 Time Alignment<br/>
&ensp;센서마다 데이터가 기록되는 시간이 다를 수 있기 때문에 시간축을 맞춘다.<br/>
&ensp;예<br/>
&ensp;센서 A: `10:00:00, 10:00:01, 10:00:02` <br/>
&ensp;센서 B: `10:00:00.5, 10:00:01.5, 10:00:02.5` <br/>
&ensp;→ 서로 같은 시간 기준으로 맞추는 작업이 필요할 수 있다.<br/>

---

&ensp;11. IoT 데이터 특성 추출 방식<br/>
* 통계 기반 특성 추출: 데이터의 통계적 특징 이용
* 주파수 기반 특성 추출: 데이터를 주파수 관점에서 분석
* 딥러닝 기반 자동 특성 추출: 딥러닝 모델이 직접 유용한 특징을 학습

---

&ensp;12. 학습 데이터셋 구성 방식<br/>
&ensp;Sliding Window 방식<br/>
&ensp;연속적인 시계열 데이터를 일정 길이의 입력-출력 쌍으로 나누는 방식이다.<br/>
&ensp;예시: 과거 10분간의 센서 데이터를 입력으로 사용하고 이후 1분간의 값을 예측하도록 출력으로 설정<br/>
&ensp;개념적으로 $[x_{t-9}, x_{t-8}, ... , x_{t}] -> x_{t+1}$ 처럼 볼 수 있다. 그리고 다시 한 칸 이동해서 $[x_{t-8}, x_{t-7}, ..., x_{t+1}] -> x_{t+2}$ 를 만드는 방식이다.<br/>
&ensp;그래서 Sliding Window, 즉 창(window)을 조금씩 이동시키면서 학습 데이터를 만든다고 한다.<br/>

---

&ensp;13. 입력 시퀀스와 출력값<br/>
&ensp;입력 시퀀스<br/>
&ensp;시간 순서를 유지한 상태로 고정된 길이의 시퀀스를 구성한다.<br/>

&ensp;출력값<br/>
&ensp;문제에 따라 단일 시점 값, 다단계 시퀀스 모두 가능하다.<br/>

---

&ensp;14. 라벨링 기준<br/>
&ensp;IoT 데이터를 지도학습에 사용할 경우 정답을 지정해야 한다.<br/>
&ensp;이벤트 발생 여부: 특정 상태 변화가 발생했는지<br/>
&ensp;임계치 초과 여부: 설정된 기준값을 넘었는지<br/>
&ensp;범주형 클래스: 다중 분류 문제로 구성<br/>

---

&ensp;15. 학습 모델 선택 기준<br/>
&ensp;기계학습 모델을 선택할 때 다음을 고려한다.<br/>
1. 데이터의 양
2. 실시간성
3. 계산 자원
4. 클라우드 vs 엣지 배치 전략
5. 하이브리드 구조

&ensp;특히 IoT에서는 단순히 정확도가 가장 높은 모델을 쓰는 것이 아니라 **실제로 그 장치에서 실행할 수 있는가?** 도 중요하다.<br/>

---

&ensp;16. 기계학습 모델 학습 방식<br/>
&ensp;① 지도학습 Supervised Learning<br/>
&ensp;입력 데이터에 대한 정답(label)이 존재한다.<br/>
&ensp;주요 알고리즘:<br/>
* 결정 트리
* SVM
* 신경망
* KNN
* Random Forest

&ensp;② 비지도학습 Unsupervised Learning<br/>
&ensp;정답 없이 데이터 내부의 패턴이나 군집을 찾는다.<br/>
&ensp;주요 알고리즘:<br/>
* K-means
* PCA
* Auto-Encoder

&ensp;③ 준지도학습 Semi-supervised Learning<br/>
&ensp;일부 데이터에만 라벨이 있고 나머지 데이터에는 라벨이 없는 경우 사용한다.<br/>

&ensp;④ 강화학습 Reinforcement Learning<br/>
&ensp;환경과 상호작용하며 보상을 최대화하는 방향으로 의사결정을 학습한다.<br/>

&ensp;⑤ 온라인 학습 Online Learning<br/>

&ensp;17. 처리 성능 평가 기준<br/>
&ensp;IoT ML에서는 단순 정확도뿐 아니라 시스템 성능도 함께 본다.<br/>

&ensp;모델 성능<br/>
* Accuracy
* Precision
* Recall
* F1-score

&ensp;시스템 성능<br/>
* Latency
* Throughput
* Resource utilization

&ensp;구분해야 하는 것<br/>
* Latency: 하나의 요청이나 데이터가 처리되는 데 걸리는 시간
* Throughput: 일정 시간 동안 얼마나 많은 데이터를 처리할 수 있는가

&ensp;예를 들어,<br/>
* Latency가 낮다 → 하나의 예측이 빠름
* Throughput이 높다 → 많은 데이터를 처리 가능
