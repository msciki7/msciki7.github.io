# BoW 모델 

&ensp;1. 감성 분석과 텍스트 데이터 표현<br/>
&ensp;감정 분석은 사람의 감정을 자동으로 인식하고 분류하는 기술이다.<br/>
&ensp;분석 대상<br/>
* 텍스트
* 음성
* 이미지

&ensp;텍스트, 음성, 이미지에서 사람의 감정을 자동으로 인식하여 긍정, 부정 등으로 분류한다.<br/>
&ensp;이러한 감성 분석에는 나이브 베이즈, 서포트 벡터 머신(SVM), 딥러닝 모델(RNN, LSTM, BERT)  등이 사용될 수 있다. 하지만 이런 모델이 동작하려면 텍스트 데이터를 컴퓨터가 이해할 수 있는 숫자 형태의 벡터로 변환해야 한다.<br/>
&ensp;단어의 의미를 숫자로 표현하는 대표적인 방법으로 BoW, TF-IDF, 워드 임베딩이 있다.<br/>

---

&ensp;2. BoW(Bag-of-Words) 모델<br/>
&ensp;BoW의 핵심 아이디어<br/>
&ensp;BoW는 문서 안의 단어 순서나 문맥을 고려하지 않고, 어떤 단어가 얼마나 자주 등장했는지에 집중하는 방법이다. 문서를 하나의 '단어 가방'처럼 생각한다.<br/>

&ensp;고유한 토큰 생성<br/>
&ensp;전체 문서에서 등장하는 단어를 모아 고유한 토큰 집합을 만든다.<br/>

&ensp;단어 사전(Vocabulary) 생성<br/>
&ensp;모든 고유한 단어를 포함하는 사전을 만든다. 각 단어에는 고유한 인덱스가 부여된다.<br/>

&ensp;문서를 특성 벡터로 변환<br/>
&ensp;문서마다 각 단어가 몇 번 등장했는지를 기록한다. 따라서 각 문서는 고정 길이의 수치 벡터로 변환된다.<br/>

&ensp;문서 안에 존재하지 않는 단어의 값은 0이 되기 때문에 BoW 벡터는 매우 희소한 구조를 갖는다.<br/>

---

&ensp;3. CountVectorizer를 이용한 단어 특성 벡터 변환<br/>
&ensp;사이킷런 `CountVectorizer` 를 사용한다.<br/>
```python 
from sklearn.feature_extraction.text import CountVectorizer

count = CountVectorizer()
```

&ensp;예제 문서는 다음과 같다.<br/>
```python
docs = np.array([
    'The sun is shining',
    'The weather is sweet',
    'The sun is shining, the weather is sweet, and one and one is two'
])
```

&ensp;다음 코드로 BoW 벡터로 변환한다.<br/>
```python
bag = count.fit_transform(docs)
```

```python
print(count.vocabulary_)
```

&ensp;를 사용하면 각 단어에 할당된 단어 인덱스를 확인할 수 있다.<br/>

```python
print(bag.toarray())
```

&ensp;는 변환된 BoW 벡터를 확인한다.<br/>

&ensp;행과 열의 의미는 다음과 같다.<br/>
* 행 → 문서
* 열 → 단어
* 값 → 해당 단어가 문서에서 등장한 횟수
ㅗ
&ensp;BoW에서 값은 단어 빈도를 의미한다.<br/>

---

&ensp;4. 단어 빈도와 특성 벡터<br/>
&ensp;특성 벡터: 텍스트 데이터를 숫자로 표현한 벡터이다.<br/>

&ensp;단어빈도: 문서 d에서 단어 t가 등장한 횟수를 tf(t, d)로 표현한다. BoW에서 벡터의 각 위치는 하나의 단어를 의미하며 그 위치의 값에는 해당 단어의 등장 횟수가 기록된다.<br/>

&ensp;BoW 벡터 생성 순서<br/>
&ensp;전체 문서에서 등장한 고유 단어 수집 -> 단어의 순서를 위해 사전의 알파벳 순서 생성 -> 각 문서를 사전에 따라 고정된 위치의 벡터로 표현 -> 각 위치에 해당 단어의 빈도 기록<br/>

> 문서 → 단어 사전 → 단어 위치 고정 → 단어 등장 횟수 기록

---

&ensp;5. TF-IDF<br/>
&ensp;BoW의 문제<br/>
&ensp;BoW에서는 단순히 단어의 등장 빈도를 사용한다.<br/>
&ensp;그런데 the, is, a 처럼 대부분의 문서에 자주 등장하는 단어는 문서를 구별하는 데 큰 도움이 되지 않는다.<br/>
&ensp;즉 자주 등장한다고 해서 항상 중요한 단어는 아니다.<br/>
&ensp;그래서 TF-IDF에서는 흔하게 등장하는 단어의 중요도는 낮추고 특정 문서에 특징적으로 등장하는 단어의 중요도는 높인다.<br/>

&ensp;TF-IDF 정의<br/>
&ensp;TF-IDF는 Term Frequency-Inverse Document Frequency의 약자이다.<br/>

&ensp;기본 식: $tf-idf(t, d) = tf(t, d) \times idf(t, d)$ <br/>
&ensp;IDF는 $idf(t, d) = \log{\frac{n_d}{1 + df(d, t)}}$ 로 제시된다.<br/>

* $n_d$ : 전체 문서 개수
* df(d, t): 단어 t가 포함된 문서의 개수

&ensp;분모에 1을 추가하는 이유는 훈련 샘플에 한 번도 등장하지 않은 단어가 있는 경우 분모가 0이 되는 것을 막기 위해서이다.<br/>
&ensp;또한 log를 사용해 문서 빈도의 영향을 줄인다.<br/>

---

&ensp;6. TfidfTransformer <br/>
&ensp;BoW 벡터를 TF-IDF 벡터로 변환할 때 TfidfTransformer를 사용한다.<br/>
```python
tfidf = TfidfTransformer(
    use_idf=True,
    norm='l2',
    smooth_idf=True
)
```

&ensp;1단계: CountVectorizer로 문서를 BoW 벡터로 변환<br/>
&ensp;2단계: BoW 벡터를 TfidfTransformer에 입력<br/>
&ensp;3단계: TF-IDF 가중치 벡터로 변환<br/>

---

&ensp;7. 사이킷런 TF-IDF의 특징<br/>
&ensp;사이킷런 TfidfTransformer가 앞에서 정의한 기본 TF-IDF 식과 다르다.<br/>

&ensp;사이킷런에서는 $idf(t, d) = \log{\frac{1+n_d}{a+df(d, t)}}$ 를 사용한다.<br/>

&ensp;그리고 TF-IDF는 $tf-idf(d, f) = tf(t, d) \times (idf(t, d) + 1)$ 형태이다.<br/>

&ensp;스무딩(Smoothing)<br/>
&ensp;문서 빈도의 분자와 분모에 1을 더한다. 모든 문서에 등장하는 단어의 가중치가 0 되는 것을 막기 위해서이다.<br/>

&ensp;정규화<br/>
&ensp;TF-IDF를 계산한 뒤 정규화를 적용한다.<br/>
&ensp;정규화의 효과를 문서마다 길이가 달라도 벡터 비교 가능, 문서 길이에 의한 왜곡 방지로 설명한다.<br/>

---

&ensp;8. 텍스트 데이터 정제<br/>
&ensp;BoW 모델을 만들기 전에 중요한 단계는 불필요한 문자를 제거하여 텍스트를 정제하는 것이다.<br/>
&ensp;강의의 preprocessor() 함수는 다음 작업을 수행한다.<br/>
```python
def preprocessor(text):
    text = re.sub(r'<[^>]*>', '', text)
```

&ensp;-> HTML 태그 제거<br/>

```python
emoticons = re.findall(
    r'(?::|;|=)(?:-)?(?:\)|\(|D|P)', text
)
```

&ensp;→ 이모티콘 추출<br/>

```python
text = (
    re.sub(r'[\W]+', ' ', text.lower()) +
    ' '.join(emoticons).replace('-', '')
)
```

&ensp;소문자 변환, 특수문자 제거, 이모티콘 다시 추가 이후 `df['review'] = df['review'].apply(preprocessor)` 를 통해 전체 리뷰에 전처리를 적용한다.<br/>

&ensp;9. 토큰화(Tokenization)<br/>
&ensp;텍스트 정제 후에는 텍스트 문장을 토큰(Token) 으로 나눈다. 토큰은 단어 단위를 의미한다. 가장 기본적인 방법은 공백을 기준으로 나누는 것이다.<br/>
```python
def tokenizer(text):
    return text.split()
```

---

&ensp;10. 어간 추출(Stemming)<br/>
&ensp;어간 추출은 단어를 변하지 않는 기본 형태인 어간으로 변환하는 방법이다.<br/>

&ensp;NLTK의 PorterStemmer를 사용<br/>
```python
from nltk.stem.porter import PorterStemmer

porter = PorterStemmer()

def tokenizer(text):
  return text.split()

def tokenizer_porter(text):
  return [porter.stem(word) for word in text.split()]

print(tokenizer('runners like running and thus they run'))
print(tokenizer_porter('runners like running and thus they run'))
```

&ensp;예를 들어 runners, running, runs, ran 등과 같이 같은 의미를 가진 단어들을 기본 형태로 처리한다.<br/>

&ensp;11. 불용어(Stopwords) 제거<br/>
&ensp;불용어는 문장 구성에는 필요하지만 의미 분석에는 큰 도움이 되지 않은 단어이다.<br/>
&ensp;예: the, is, a, and, in 불용어를 너무 많이 제거하면 정보 손실이 생길 수 있다. 또한 TF-IDF나 기타 단어 빈도 기반 모델에서는 불용어 제거가 필요하지 않을 수 있다. 그 이유는 TF-IDF 자체가 자주 등장하는 단어의 가중치를 낮추기 때문이다.<br/>

&ensp;NLTK 불용어 제거<br/>
```python
import nltk
from nltk.corpus import stopwords
from nltk.stem.porter import PorterStemmer 

porter = PorterStemmer()
def tokenizer_porter(text):
  return [porter.stem(word) for word in text.split()]

nltk.download('stopwords')

stop = stopwords.words('english')
v = [w for w in tokenizer_porter('a runner likes running and runs a lot')[-10:]
if w not in stop]

print(v)
```

# 문서 분류를 위한 로지스틱 회귀

&ensp;1. 로지스틱 회귀<br/>
&ensp;입력 피처에 시그모이드 함수를 적용하여ㅕ 0과 1 사이의 확률 값을 출력하는 이진 분류 모델이다.<br/>
&ensp;영화 리뷰에서는 감성이 긍정일 확률을 예측한다.<br/>
&ensp;시그모이드 함수는 $\hat{y} = \frac{1}{1 + e^{-(W^T x + b)}}$ 이다.<br/>
&ensp;판정 기준은  $\hat{y}\ge0.5$ 이면 긍정이고 $\hat{y}<0.5$ 이면 부정이다.<br/>

---

&ensp;2. 영화 리뷰 분류 전체 흐름<br/>
&ensp;영화 리뷰 데이터 -> 텍스트 전처리<br/>
* HTML 태그 제거
* 특수문자 제거
* 소문자 통일
* 숫자 제거

&ensp;-> 불용어 제거 -> 어간 추출/표제어 추출 -> BoW 또는 TF-IDF 벡터화 -> 로지스틱 회귀 -> 긍정 / 부정 분류<br/>

---

&ensp;3. 피처 벡터화<br/>
&ensp;BoW : 각 단어의 등장 빈도를 기반으로 벡터화한다.<br/>
&ensp;예시<br/>
&ensp;`["good", "bad", "boring", "great"]`에 대해 `[2, 0, 1, 1]` 처럼 표현한다.<br/>

&ensp;TF-IDF<br/>
&ensp;TF-IDF는 자주 등장하지만 중요도가 낮은 단어에는 낮은 가중치, 문서 간 구분에 기여하는 단어에는 높은 가중치를 부여한다.<br/>

---

&ensp;4. 로지스틱 회귀 모델 학습<br/>
&ensp;학습 데이터<br/>
&ensp;IMDb 데이터셋을 사용한다.<br/>
* 별 6개 이상 → 긍정
* 별 4개 이하 → 부정

&ensp;총 50,000개 영화 리뷰이다.<br/>

&ensp;손실 함수<br/>
&ensp;로그 손실(Log loss) 을 사용한다.<br/>
$$L = -y\log{\hat{y}} - (1-y)\log{1-\hat{y}}$$

&ensp;여기서 y: 정답레이블, $\hat{y}$ : 모델의 예측값 이다.<br/>

&ensp;최적화<br/>
&ensp;경사하강법(Gradient Descent) 을 이용해 손실 함수가 최소가 되도록 학습한다.<br/>

---

&ensp;5. 성능 평가<br/>
* 정확도(Accuracy): 전체 데이터 중 정답을 맞힌 비율
* 정밀도(Precision): 긍정이라고 예측한 것 중 실제로 긍정인 비율
* 재현율(Recall): 실제 긍정인 것 중 긍정으로 예측한 비율
* F1-score: 정밀도와 재현율의 조화 평균

&ensp;혼동 행렬(Confusion Matrix)<br/>
&ensp;실제 레이블과 예측 값의 관계를 2×2 행렬로 표현한다. 정확도, 정밀도, 재현율, F1-score를 혼동 행렬의 원소로 표현할 수 있다.<br/>

&ensp;6. 로지스틱 회귀의 장점과 한계<br/>
&ensp;장점<br/>
* 학습이 빠름
* 해석 용이- 가중치로 단어 영향 파악 가능
* 과적합이 적음

&ensp;한계<br/>
* 단어 간 관계, 즉 문맥 고려 불가
* "not good"과 "good"을 제대로 구별하지 못할 수 있음
* 비선형 분리 문제에 취약

---

&ensp;7. 로지스틱 회귀 분류기 구현<br/>

&ensp;9. KoNLPy를 이용한 한국어 감성 분석<br/>
&ensp;데이터는 학습 데이터 15만 개, 테스트 데이터 5만 개로 구성된다.<br/>
&ensp;데이터의 주요 컬럼은 document → 리뷰 텍스트, label → 감정 레이블 이다.<br/>
&ensp;레이블은 0 → 부정, 1 → 긍정이다.<br/>

&ensp;Okt 형태소 분석기<br/>
&ensp;KoNLPy의 Okt 형태소 분석기를 사용한다.<br/>
```python
from konlpy.tag import Okt

okt = Okt()
```

&ensp;TF-IDF 벡터화 과정에서 `tokenizer=okt.morphs` 를 지정해 형태소 단위로 텍스트를 분석한다.<br/>

```python
tfidf = TfidfVectorizer(
    ngram_range=(1, 2),
    min_df=3,
    max_df=0.9,
    tokenizer=okt.morphs,
    token_pattern=None
)
```

&ensp;주요 설정<br/>
* ngram_range=(1, 2)
  - 단어 하나 또는 두 단어 조합까지 고려
* min_df=3
  - 최소 등장 문서 수 3
* max_df=0.9- 최대 문서 비율 90%
  - tokenizer=okt.morphs- 형태소 분석기로 토큰화

```python
param_dist = {
```

&ensp;범위에서 탐색한다.<br/>
&ensp;RandomizedSearchCV를 사용한다.<br/>
```python
rsv_okt = RandomizedSearchCV(
```

# 토픽 모델링(Topic Modeling)

&ensp;토픽 모델링은 **대량의 문서에서 사람이 미리 정해놓은 레이블 없이 문서에 내재된 숨겨진 주제를 자동으로 추출하는 비지도 학습 기법** 이다.<br/>

&ensp;레이블이 없는 상태에서 문서 집합을 주제별로 나누는 것이다.<br/>
&ensp;예를 들어 대량의 뉴스 기사 데이터셋을<br/>
* 스포츠
* 금융
* 세계 뉴스
* 정치
* 지역 뉴스

---

&ensp;1. 토픽 모델링의 주요 목적<br/>

* - 문서 집합의 전체 구조를 한눈에 파악
* 여러 문서를 주요 주제로 요약
* 주제별 분류 결과를 활용해 검색·추천 효율화
* 시기별 주제 변화를 분석해 트렌드 추적
* 데이터 속 예상치 못한 패턴과 관계 발견

---

&ensp;2.일반 데이터 압축과 토픽 모델링의 차이

&ensp;일반 데이터 압축
목적:
* 저장 공간 절약
* 원본 복원

&ensp;방식:<br/>
* 비트
* 픽셀

&ensp;같은 물리적 데이터 단위 처리<br/>
&ensp;예:<br/>
* ZIP
* JPEG

&ensp;토픽 모델링<br/>
&ensp;목적:<br/>
* 의미 구조 추출
* 분석 용이성

&ensp;결과:<br/>
* 원문을 복원하는 것이 아니라
* 의미 구조만 남김

&ensp;방식:
* 단어와 문서 간 확률적 관계 파악

&ensp;예:
* LDA
* NMF
* HDP

&ensp;강의자료의 비유는<br/>
* 데이터 압축 → 사진 파일 용량 줄이기
* 토픽 모델링 → 사진 여러 장을 바다, 여행, 가족처럼 주제로 분류하고 그룹화

&ensp;3. 키워드 추출과 토픽 모델링의 차이<br/>
&ensp;키워드 추출<br/>
&ensp;목적:<br/>
* 문서 요약

&ensp;결과:<br/>
* 문서의 핵심 단어 목록

&ensp;대상:<br/>
* 개별 문서

&ensp;예:<br/>
&ensp;뉴스 기사에서 대통령, 정상회담, 무역협정 등을 뽑는 것.<br/>

&ensp;토픽 모델링<br/>
&ensp;목적:
* 문서 집합의 주제별 분류·그룹화

&ensp;결과:<br/>
* 주제별 핵심 단어
* 문서별 주제 비율

&ensp;대상:<br/>
* 문서 집합 전체

&ensp;예: 전체 뉴스를 정치, 경제, 스포츠 등으로 주제별로 분류하는 것이다.<br/>

&ensp;4. 잠재 디리클레 할당(LDA)<br/>
&ensp;LDA는 **Latent Dirichlet Allocation** 의 약자이다.<br/>

> 텍스트 데이터에서 숨겨진 주제를 추출하기 위해 사용되는 대표적인 확률 기반 토픽 모델링 알고리즘

&ensp;이름의 의미<br/>
&ensp;Latent: 겉으로 드러나지 않고 숨겨져 있다는 의미.<br/>
&ensp;즉, 문서 속에 직접적으로 표시되지 않은 주제.<br/>

&ensp;Dirichlet: 통계학에서 사용하는 확률 분포의 한 종류.<br/>
&ensp;여러 범주에 대한 확률을 동시에 모델링할 때 사용한다.<br/>

&ensp;Allocation: 각 단어가 어떤 주제에 속하는지를 확률적으로 배정하는 과정.<br/>

&ensp;핵심 가정: 문서 집합이 여러 주제의 혼합으로 구성되어 있으며, 각 주제는 특정 단어의 확률 분포를 따른다고 가정한다.<br/>

----

&ensp;5. LDA의 핵심 아이디어<br/>
&ensp;문서마다 여러 주제가 섞여 있다.<br/>
&ensp;예: 잡지(정치, 경제, 문화 주제마다 특정 단어가 자주 등장한다.)<br/>
&ensp;경제 주제라면 주가, 환율, 금리 등이 자주 등장한다.<br/>
&ensp;문서의 단어 분포를 보고 주제의 확률 분포를 역으로 추정한다.<br/>
&ensp;입력으로 BoW, TF-IDF 와 같이 문서-단어 행렬을 사용하고 각 문서의 주제 분포와 각 주제의 단어 분포를 추론한다.<br/>

---

&ensp;6. LDA 기반 토픽 모델링 과정<br/>
&ensp;데이터 전처리<br/>
* 특수문자 제거
* 불용어 제거
* 단어 표준화
  - 소문자 변환
  - 어간 추출
  - 표제어 추출

&ensp;한국어의 경우 자료에서는 명사, 형용사 등 핵심 품사를 추출한다고 설명한다.<br/>
* 명사
* 형용사

&ensp;등 핵심 품사를 추출한다고 설명한다.<br/>
&ensp;목적은 **모델이 의미 있는 단어만 학습하도록 노이즈를 줄이는 것**이다.<br/>

&ensp;문서-단어 행렬 생성<br/>
&ensp;모든 문서에서 등장하는 단어를 목록으로 만들고 각 문서의 단어 빈도를 계산한다.<br/>
&ensp;문서-단어 행렬에서는<br/>
* - 행 → 문서
* 열 → 단어
* 값 → 해당 문서에서 단어가 등장한 횟수

&ensp;이 행렬이 LDA가 주제 분포를 추정하는 기본 데이터 구조이다.<br/>

&ensp;LDA 모델 적용<br/>
&ensp;각 문서는 여러 주제의 혼합이라고 가정한다. 또 각 주제는 특정 단어들의 확률 분포로 표현된다. LDA는 문서-단어 행렬을 기반으로 문서별 토픽 분포, 토픽별 단어 분포를 추정한다.<br/>

&ensp;토픽 해석<br/>
&ensp;토픽별로 확률이 높은 상위 단어를 추출한다. 그리고 사람이 해당 단어 목록을 보고 토픽의 의미를 해석하여 이름을 부여한다.<br/>

&ensp;예: 전쟁, 군인, 전투, 폭격 → 전쟁 영화 토픽<br/>

&ensp;결과 활용<br/>
* 문서별 토픽 비율을 이용한 분류
* 검색
* 추천 시스템
* 시각화를 통한 토픽 구조와 관계 파악

---

&ensp;7. LDA의 입력과 출력<br/>
&ensp;입력: 문서 집합에서 추출한 단어 정보이며 일반적으로 문서-단어 행렬 형태이다.<br/>
&ensp;예<br/>
* 문서 1: 경제 성장률이 증가했다
* 문서 2: 금리 인상이 발표되었다

&ensp;출력<br/>
&ensp;각 문서가 어떤 주제로 구성되어 있는지에 대한 확률 분포<br/>

&ensp;예:<br/>
&ensp;문서 1<br/>
* 주제 1: 80%
* 주제 2: 20%

&ensp;문서 2<br/>
* 주제 1: 70%
* 주제 2: 30%

&ensp;각 주제에 많이 등장하는 단어도 구할 수 있다.<br/>
&ensp;예<br/>
* 주제 1 → 경제, 성장, 금리, 인상
* 주제 2 → 정치, 선거, 후보, 투표

---

&ensp;8. 문서와 BoW의 관계<br/>
&ensp;BoW에서는 문서를 단어의 빈도 수만 고려하여 벡터로 표현한다.<br/>
&ensp;특징<br/>
* 문서 길이에 따라 순서와 문맥 무시
* 고정된 단어 사전을 기준으로 벡터화

&ensp;전체 문서들를 모으면 문서-단어 행렬(Document-Term Matrix, DTM) 또는 BoW 행렬이 된다.<br/>

&ensp;BoW 행렬을 이용한 LDA 문서 분해<br/>
&ensp;LDA는 입력으로 BoW 행렬을 두 개의 행렬로 분해한다.<br/>
* 문서-토픽 행렬
* 단어-토픽 행렬

&ensp;그리고 두 행렬을 다시 곱하면 원래 BoW 입력 행렬에 가까운 행렬을 재구성할 수 있다.<br/>
