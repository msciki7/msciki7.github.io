# 데이터 다루기

&ensp;누락된 데이터(Missing Data)<br/>
&ensp;센서 이상, 설문 미응답 등으로 특정 값이 존재하지 않은 경우이다.<br/>
&ensp;Pandas에서는 일반적으로 NaN 형태로 나타난다.<br/>
&ensp;결측치가 존재하면<br/>
* 수치 계산이 어려워지고
* 학습 과정에서 오류가 발생하거나
* 예측 성능이 저하될 수 있다.

&ensp;결측치 확인<br/>
&ensp;`df.isnull().sum()`  각 열에 존재하는 결측치의 개수를 확인할 수 있다. 또한 `df.values` 를 이용하면 DataFrame을 NumPy 배열로 변환할 수 있다.<br/>

&ensp;결측치 삭제<br/>
&ensp;Pandas의 dropna()를 사용한다.<br/>

&ensp;결측치가 있는 행 삭제<br/>
&ensp;`df.dropna(axis=0)` <br/>

&ensp;결측치가 있는 열 삭제<br/>
&ensp;`df.dropna(axis=1)` <br/>

&ensp;모든 값이 NaN인 행 삭제<br/>
&ensp;`df.dropna(how='all')`<br/>

&ensp;NaN이 아닌 값이 일정 개수보다 적으면 삭제<br/>
&ensp;`df.dropna(subset=['C'])` <br/>

> dropna() = 결측치가 포함된 데이터 자체를 제거

&ensp;하지만 데이터를 많이 삭제하면 학습에 사용할 정보 자체가 줄어들 수 있다는 문제가 있다.<br/>

&ensp;4. 결측치 대체 — KNNImputer<br/>
&ensp;데이터를 삭제하지 않고 주변 데이터로 결측치를 추정할 수도 있다.<br/>
&ensp;강의에서는 KNNImputer를 사용한다.<br/>

```python
from sklearn.impute import KNNImputer

kimr = KNNImputer()
imputed_data = kimr.fit_transform(df.values)
```

&ensp;KNNImputer의 원리<br/>
&ensp;결측치가 있는 샘플과 비슷한 주변 샘플들을 찾고, 그 값들을 이용하여 결측값을 추정한다. 강의 자료에서는 기본적으로 5개의 이웃을 사용한다고 설명한다.<br/>

> 비슷한 데이터들의 값을 이용해 빈 값을 채운다.

&ensp;5. Scikit-learn의 fit()과 transform()<br/>
&ensp;데이터 전처리에서 아주 중요한 API 이다.<br/>

&ensp;`fit()` <br/>
&ensp;훈련 데이터에서 필요한 파라미터를 학습한다.<br/>
&ensp;예<br/>
* 평균
* 표준편차
* 최소값
* 최대값

&ensp;`scaler.fit(X_train)` <br/>

&ensp;`transform()` <br/>
&ensp;`fit()` 에서 학습한 값을 이용하여 데이터를 변환한다.<br/>

```python
X_train = scaler.transform(X_train)
X_test = scaler.transform(X_test)
```

&ensp;`fit_transform()` <br/>
&ensp;`fit()` + `transform()`을 한 번에 수행한다. <br/>

```python
X_train = scaler.fit_transform(X_train)
```

&ensp;훈련 데이터에는 `fit_transfor()`, 테스트 데이터에는 `transform()`만 사용<br/>

&ensp;6. 범주형 데이터(Categorical Data)<br/>
&ensp;범주형 데이터란 숫자가 아니라 특정 그룹을 나타내는 데이터이다.<br/>
&ensp;예<br/>
* 색상: red, blue, green
* 옷 크기: M, L, XL

&ensp;범주형 데이터는 크게 두 종류로 구분된다.<br/>

&ensp;순서가 있는 범주형 데이터<br/>
&ensp;예: `M < L < XL` 크기처럼 범주 사이에 순서가 존재한다.<br/>
&ensp;직접 Mapping<br/>
```python
size_mapping = {
    'XL': 3,
    'L': 2,
    'M': 1
}

df['size'] = df['size'].map(size_mapping)
```

&ensp;결과:<br/>
* M  → 1
* L  → 2
* XL → 3

&ensp;역변환도 가능하다.<br/>
```python
inv_size_mapping = {v:k for k,v in size_mapping.items()}
```

&ensp;7. 클래스 레이블 인코딩<br/>
&ensp;기계학습 모델은 일반적으로 문자열 클래스 레이블을 직접 처리하지 못한다.<br/>
&ensp;예<br/>
* class1
* class2

&ensp;이를 정수로 변환한다.<br/>
* class1 → 0
* class2 → 1

&ensp;Mapping 사용<br/>
```python
class_mapping = {
    label: idx
    for idx, label in enumerate(np.unique(df['classlabel']))
}
```

&ensp;LabelEncoder 사용<br/>
&ensp;Scikit-learn의 LabelEncoder도 사용할 수 있다.<br/>
```python
from sklearn.preprocessing import LabelEncoder

class_le = LabelEncoder()
y = class_le.fit_transform(df['classlabel'])
```

&ensp;복원:<br/>
```python
class_le.inverse_transform(y)
```

&ensp;예를 들어<br/>

&ensp;Pandas: `pd.get_dummies(..., drop_first=True)`<br/>

&ensp;Scikit-learn: `OneHotEncoder(drop='first')` <br/>

&ensp;14. 특성 스케일링(Feature Scaling)<br/>
&ensp;특성마다 값의 범위가 크게 다르면 모델이 큰 값의 특성을 더 중요하게 판단할 수 있다.<br/>
&ensp;예:<br/>
* 특성 1: 1 ~ 10
* 특성 2: 1 ~ 100,000

&ensp;거리 기반 모델이나 최적화 기반 모델에서는 특히 문제가 된다.<br/>
&ensp;영향을 많이 받는 모델:<br/>
* Logistic Regression
* KNN
* SVM
* 경사하강법 기반 모델

&ensp;반면 결정 트리나 랜덤 포레스트는 상대적으로 스케일의 영향을 적게 받는다.<br/>

&ensp;15. 정규화(Normalization)<br/>
&ensp;강의에서는 Min-Max Scaling을 정규화로 설명한다. 값을 일반적으로 [0,1] 범위로 변환한다.<br/>

$$x^{(i)}_{norm} = \frac{x^{(i)} - x_{min}}{x_{max} - x_{min}}$$

&ensp;특징<br/>
&ensp;최소값: 0, 최대값 1<br/>
&ensp;단점은 이상치에 민감하다는 것이다.<br/>


&ensp;16. 표준화(Standardization)<br/>
&ensp;각 특성의 평균 = 0, 표준편차 = 1 이 되도록 변환한다.<br/>

$$x^{(i)}_{std} = \frac{x^{(i)} - \mu _{x}}{\sigma _x}$$

&ensp;여기서 $\mu _x = 평균, \sigma _x = 표준편차$ <br/>
&ensp;표준화가 최소-최대 스케일링보다 이상치에 덜 민감하다.<br/>

&ensp;Scikit-learn: `from sklearn.preprocessing import StandardScaler` <br/>
```python
sc = StandardScaler()

X_train_std = sc.fit_transform(X_train)
X_test_std = sc.transform(X_test)
```

# 유용한 특성 다루기

&ensp;1. 특성 선택의 목적<br/>
&ensp;특성이 많다고 반드시 좋은 것은 아니다.<br/>
&ensp;불필요한 특성이 많으면 모델 복잡도 증가, 과적합 가능성 증가, 계산량 증가 등의 문제가 발생한다.<br/>
&ensp;따라서 의미 있는 특성만 선택한다.<br/>
1. L1/L2 규제
2. 순차적 특성 선택
3. Random Forest 특성 중요도

&ensp;2. L1 규제와 L2 규제<br/>
&ensp;규제(Regularization)는 손실 함수에 Penalty term을 추가하여 모델이 지나치게 복잡해지는 것을 막는 방법이다.<br/>

&ensp;Loss + Penalty 형태로 학습한다.<br/>

&ensp;3. L2 규제<br/>
$$L2 = ||w|| ^{2}_{2} = \sum _{j=1}^{m}w^2_j$$

&ensp;가중치의 제곱합을 패널티로 사용한다.<br/>
&ensp;특징<br/>
&ensp;가중치를 전체적으로 작게 만든다.<br/>
&ensp;그러나 일반적으로 **가중치를 정확히 0으로 만들지는 않는다.** <br/>
&ensp;따라서 모든 특성을 어느 정도 유지하면서 모델 복잡도를 제한한다.<br/>

&ensp;4. L1 규제<br/>
$$L1 = ||w||_{1} = \sum _{j=1}^{m}|w_j|$$

&ensp;가중치의 절댓값 합을 패널티로 사용한다.<br/>
&ensp;핵심 특징<br/>
&ensp;일부 가중치를 0으로 만들 수 있다. 따라서 중요하지 않은 특성을 자동으로 제거하는 효과가 있다.<br/>
> L1 규제는 특성 선택 효과를 낼 수 있다.

&ensp;L1과 L2 비교<br/>

| L1                  | L2          |
| ------------------- | ----------- |
| 절댓값 사용              | 제곱 사용       |
| 일부 가중치를 0으로 만들 수 있음 | 가중치를 작게 만듦  |
| 희소성(Sparsity) 발생    | 전체 특성 유지 경향 |
| 특성 선택 효과            | 모델 복잡도 제한   |

<p align="center"><img src="/assets/img/사물기계학습/3주차/3-1.png" width="600"></p>

&ensp;L1 제약 영역은 모서리가 있기 때문에 최적점이 축과 만나면서 특정 가중치가 정확히 0이 되기 쉽다.<br/>

&ensp;5. 규제 강도와 C<br/>
&ensp;Logistic Regression에서는 C를 통해 규제 강도를 조절한다.<br/>
&ensp;중요: $C = \frac{1}{규제강도}$ <br/>
* C ↑ → 규제 약해짐
* C ↓ → 규제 강해짐

&ensp;이 부분은 방향을 반대로 외우기 쉬워서 시험에서 특히 조심해야 한다.


<p align="center"><img src="/assets/img/사물기계학습/3주차/3-2.png" width="600"></p>

&ensp;C 변화 그래프에서도 C가 작을 때 대부분의 가중치가 0 근처에 모이고, C가 커질수록 가중치 절댓값이 커지는 모습을 보여준다.<br/>

&ensp;6. 차원 축소(Dimensionality Reduction)<br/>
&ensp;차원 축소 방법은 크게 두 가지다.<br/>

&ensp;Feature Selection<br/>
&ensp;기존 특성 중 일부만 선택한다.<br/>
&ensp;예<br/>
```
x1, x2, x3, x4
↓
x1, x3
```

&ensp;Feature Extraction<br/>
&ensp;기존 특성을 조합해서 새로운 특성을 만든다.<br/>
&ensp;예<br/>
```
x1, x2, x3, x4
↓
z1, z2
```

&ensp;PCA, LDA가 대표적인 Feature Extraction 방법이다.<br/>

&ensp;7. Sequential Backward Selection(SBS)<br/>
&ensp;모든 특성으로 시작해서 하나씩 제거한다.<br/>
```
13개 특성
↓
12개
↓
11개
↓
...
↓
원하는 특성 개수
```

&ensp;SBS 수행 과정<br/>
&ensp;① 전체 특성으로 시작 $X_d$ ​<br/>
&ensp;② 하나의 특성을 제거했을 때 성능 평가<br/>
&ensp;각 특성을 하나씩 제거해 본다.<br/>
&ensp;③ 성능 감소가 가장 작은 특성을 제거<br/>
> 없어도 모델 성능에 영향이 가장 적은 특성을 제거한다.

&ensp;④ 원하는 특성 개수가 될 때까지 반복<br/>

&ensp;SBS 코드의 핵심<br/>
```python
for p in combinations(self.indices_, r=dim - 1):
```

&ensp;현재 특성 중 하나를 제거한 모든 조합을 만든다.<br/>
&ensp;각 조합에 대해<br/>
```python
self.estimator.fit(...)
```

&ensp;모델을 학습하고<br/>
```python
accuracy_score(...)
```

&ensp;성능을 계산한다.<br/>
&ensp;가장 좋은 조합을 선택한다.<br/>
```python
best = np.argmax(scores)
```

&ensp;8. Random Forest의 Feature Importance<br/>
&ensp;Random Forest는 여러 Decision Tree를 조합한 모델이다. 각 특성이 분류 과정에서 얼마나 많이 기여했는지를 이용해 Feature Importance를 계산할 수 있다.<br/>
```python
forest.feature_importances_
```

&ensp;Random Forest Feature Importance의 주의점<br/>
&ensp;두 개 이상의 특성이 강한 상관관계를 가지면 한 특성이 높은 중요도를 가져가고 다른 특성은 상대적으로 낮게 평가될 수 있다.<br/>
> Feature Importance가 낮다고 반드시 그 특성이 의미 없다는 뜻은 아니다.

# 데이터 압축

&ensp;1. 차원 축소 기법<br/>
* PCA(Principal Component Analysis) → 데이터의 분산이 큰 방향을 찾는다.
* LDA(Linear Discriminant Analysis) → 클래스 분리가 잘 되는 방향을 찾는다.
* t-SNE → 고차원 데이터의 구조를 2D/3D 공간으로 표현하는 비선형 시각화 기법

&ensp;2. Feature Extraction<br/>
&ensp;기존 특성을 선택하는 Feature Selection과 달리, Feature Extraction은 기존 특성을 조합하여 새로운 특성을 만든다.<br/>

&ensp;목적<br/>
* 저장 공간 절약
* 계산 효율 향상
* 차원의 저주 감소
* 중요한 정보 유지

&ensp;2. PCA — Principal Component Analysis<br/>
&ensp;PCA는 비지도 선형 변환 기법이다. 클래스 레이블을 사용하지 않고 데이터의 분산을 최대한 보존한다.<br/>
> 데이터가 가장 많이 퍼져 있는 방향을 찾는다.

&ensp;Principal Component<br/>
<p align="center"><img src="/assets/img/사물기계학습/3주차/3-3.png" width="600"></p>

* PC1 = 데이터가 가장 많이 분산된 방향
* PC2 = PC1과 직교하면서 두 번째로 많이 분산된 방향

&ensp;따라서 데이터의 주요 구조를 유지하면서 더 작은 차원으로 표현할 수 있다.<br/>

&ensp;3. PCA의 차원 변환<br/>
&ensp;기존 데이터: $x=[x_1​, x_2​, … ,x_d​]$ , $x ∈ R^d$ <br/>
&ensp;변환 행렬: W 를 이용하여 $xW = z$ 로 변환한다. <br/>
&ensp;새로운 데이터: $z=[z_1​, z_2 ​, … ,z_k​]$ , $z ∈ R^k$ 이며 k < d 이다.<br/>

&ensp;4. PCA 알고리즘 단계<br/>
&ensp;1단계 - 주성분 추출<br/>
1. 데이터를 표준화
2. 공분산 행렬 계산
3. 공분산 행렬의 고유값(Eigenvalue)과 고유벡터(Eigenvector) 계산
4. 고유값을 내림차순으로 정렬
5. 상위 k개의 고유벡터 선택

&ensp;2단계 — 데이터 변환<br/>
&ensp;선택한 고유벡터로 변환행렬 W 를 만들고 XW 를 이용하여 새로운 k차원 공간으로 변환한다.<br/>

&ensp;5. Scikit-learn PCA<br/>

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=2) # 2차원으로 축소

X_train_pca = pca.fit_transform(X_train_std)
X_test_pca = pca.transform(X_test_std)
```

* Train → fit_transform()
* Test  → transform()

&ensp;6. PCA Loading<br/>
&ensp;Loading은 **원래 특성이 특정 주성분에 얼마나 기여하는가** 를 나타낸다.<br/>
&ensp;강의 코드<br/>
```python
loadings = pca.components_.T * np.sqrt(pca.explained_variance_)
```

&ensp;이를 통해 PC1을 만드는 데 어떤 원래 특성이 크게 기여했는지 분석할 수 있다.<br/>

&ensp;7. LDA — Linear Discriminant Analysis<br/>
&ensp;DA는 지도학습 기반 특성 추출 기법이다. 핵심 목적은 **클래스 간 분리를 최대화하는 방향을 찾는 것** 이다. 즉, PCA와 목적이 다르다.<br/>

&ensp;PCA와 LDA 비교<br/>

| PCA           | LDA           |
| ------------- | ------------- |
| 비지도 학습        | 지도 학습         |
| 클래스 정보 사용 X   | 클래스 정보 사용 O   |
| 전체 데이터 분산 최대화 | 클래스 간 분산 최대화  |
| 데이터 구조 요약     | 분류에 유리한 공간 생성 |

&ensp;LDA의 핵심 개념<br/>
&ensp;예를 들어 두 클래스가 있을 때, LDA는 두 클래스가 투영된 공간에서 최대한 멀리 떨어지게 만드는 방향을 찾는다. <br/>
<p align="center"><img src="/assets/img/사물기계학습/3주차/3-5.png" width="600"></p>

&ensp;원래 2차원 공간에서 클래스가 퍼져 있어도 적절한 LD1 방향으로 투영하면 두 클래스가 잘 분리될 수 있다.<br/>

&ensp;LDA 내부 동작<br/>
* 클래스 간 산포 행렬 $S_B$ → 클래스 중심들이 서로 얼마나 떨어져 있는지 나타낸다.
* 클래스 내 산포 행렬 $S_W$ → 같은 클래스 내부 데이터가 얼마나 퍼져 있는지 나타낸다.

&ensp;LDA의 목표: 클래스 간 거리는 크게 만들고 클래스 내부의 분산은 작게 만드는 방향을 찾는다.<br/>

&ensp;8. Scikit-learn LDA<br/>
```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis as LDA

lda = LDA(n_components=2)

X_train_lda = lda.fit_transform(
    X_train_std,
    y_train
)
```

&ensp;PCA와 중요한 차이: `PCA.fit_transform(X)` <br/>
&ensp;하지만 LDA는 `LDA.fit_transform(X, y)` 이다. 왜냐하면 클래스 정보 y가 필요하기 때문이다.<br/>

&ensp;9. 비선형 차원 축소가 필요한 이유<br/>
&ensp;PCA와 LDA는 기본적으로 선형적인 관계를 기반으로 한다.<br/>
&ensp;하지만 실제 데이터는 원형, 나선형, 복잡한 곡선 구조 처럼 비선형 형태를 가질 수 있다. 이런 경우 PCA나 LDA만으로는 데이터 구조를 제대로 표현하기 어렵다. 따라서 비선형 차원 축소 방법을 사용한다.<br/>

&ensp;10. t-SNE<br/>
&ensp;t-distributed Stochastic Neighbor Embedding<br/>
&ensp;고차원 데이터의 구조를 저차원 공간에 시각화하는 대표적인 비선형 차원 축소 방법이다. 특히 고차원 데이터를 2D 또는 3D 로 시각화 할 때 많이 사용한다.<br/>

&ensp;t-SNE 기본 아이디어<br/>
&ensp;① 원본 고차원 데이터에서 샘플 간 거리 계산<br/>
&ensp;② 고차원 공간에서 확률 분포 구성: 가까운 데이터일수록 높은 확률을 부여한다.<br/>
&ensp;③ 저차원 공간에서도 확률 분포 계산<br/>
&ensp;④ 두 확률 분포의 차이를 최소화하도록 배치<br/>

> 고차원에서 가까웠던 데이터는 저차원에서도 최대한 가깝게 배치한다.

&ensp;PCA / LDA / t-SNE 비교<br/>

| 방법    | 지도/비지도 | 목적            | 주요 사용       |
| ----- | ------ | ------------- | ----------- |
| PCA   | 비지도    | 데이터 분산 최대 보존  | 차원 축소       |
| LDA   | 지도     | 클래스 분리 최대화    | 분류용 차원 축소   |
| t-SNE | 비지도    | 지역적 데이터 구조 보존 | 고차원 데이터 시각화 |

* PCA = 많이 퍼지는 방향
* LDA = 클래스가 잘 갈라지는 방향
* t-SNE = 비슷한 것끼리 모아서 그림

&ensp;11. Feature Selection과 Feature Extraction 비교<br/>
* Feature Selection: 기존 특성 중 중요한 특성만 남긴다.
* Feature Extraction: 기존 특성을 조합하여 새로운 특성을 만든다.
