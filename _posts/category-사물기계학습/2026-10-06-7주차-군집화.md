# Unit 01. 유사한 객체 그룹핑

&ensp;1. 군집화의 주요 학습 내용<br/>
&ensp;이번 단원에서는 유사한 데이터를 그룹으로 묶는 군집화 방법을 다룬다.<br/>

* k-평균 군집화
* k-평균++ 군집화
* 간접 군집화
* 엘보우 방법
* 실루엣 그래프

---

&ensp;2. 프로토타입 기반 군집 Prototype-based clustering<br/>
&ensp;각 군집을 대표하는 프로토타입을 정하고, 각 데이터 포인트를 가장 가까운 프로토타입에 할당한 뒤 프로토타입을 반복적으로 갱신하여 군집을 형성하는 방법이다.<br/>

&ensp;센트로이드 Centroid<br/>
&ensp;한 군집에 속한 모든 점의 평균 좌표이다.<br/>

&ensp;메도이드 Medoid<br/>
&ensp;군집 내에서 다른 모든 점들과 총 거리가 가장 작은 실제 데이터 포인트이다.<br/>

&ensp;대표 알고리즘<br/>
* k-평균 K-means → 프로토타입 = Centroid
* K-medoids → 프로토타입 = Medoid
* K-medoids는 이상치에 강한 특성을 보임

> K-means = 평균 좌표인 Centroid 사용
> K-medoids = 실제 데이터인 Medoid 사용

---

&ensp;3. k-평균 군집화 K-means clustering<br/>
&ensp;k-평균은 군집의 중심점을 반복적으로 갱신하며 데이터를 분할하는 대표적인 프로토타입 기반 군집 알고리즘이다.<br/>

&ensp;데이터가 다음과 같이 주어진다.<br/>

$$
X=\{x_1,x_2,\ldots,x_n\}, \quad x_i \in \mathbb{R}^d
$$

&ensp;목표는 데이터 $X$를 $k$개의 군집 $C_1,C_2,\ldots,C_k$로 분할하고 각 군집의 중심점 $μ_1,μ_2,\ldots,μ_k$를 찾는 것이다.<br/>

---

&ensp;4. k-평균의 목적 함수<br/>
&ensp;k-평균은 군집 내 제곱 오차의 합을 최소화하는 것을 목표로 한다.<br/>

$$
J=
\sum_{j=1}^{k}
\sum_{x_i\in C_j}
\|x_i-\mu_j\|^2
$$

&ensp;$\|x_i-\mu_j\|^2$는 데이터 포인트 $x_i$와 해당 군집 중심점 $\mu_j$ 사이의 유클리드 거리 제곱이다.<br/>

&ensp;$J$가 작을수록 데이터들이 각 군집의 중심점 주변에 잘 모여 있다는 의미이다.<br/>

> k-평균의 핵심 목표 = 군집 내 제곱 오차 $J$ 최소화

---

&ensp;5. k-평균 알고리즘의 단계<br/>

&ensp;① 초기화<br/>
&ensp;$\mu_1,\mu_2,\ldots,\mu_k$를 무작위로 선택한다.<br/>

&ensp;② 할당 단계<br/>
&ensp;각 데이터 포인트를 가장 가까운 군집 중심점에 할당한다.<br/>

$$
C_j=
\left\{
x_i \mid
\|x_i-\mu_j\|^2
\le
\|x_i-\mu_l\|^2,
\forall l\in\{1,\ldots,k\}
\right\}
$$

&ensp;③ 갱신 단계<br/>
&ensp;각 군집의 중심을 해당 군집에 속한 데이터들의 평균으로 갱신한다.<br/>

$$
\mu_j=
\frac{1}{|C_j|}
\sum_{x_i\in C_j}x_i
$$

&ensp;④ 수렴 조건<br/>
&ensp;군집 할당이 변하지 않거나 목적함수 $J$의 변화가 기준 이하가 되면 종료한다.<br/>

> 초기화 → 할당 → 갱신 → 수렴 여부 확인

---

&ensp;6. 사이킷런을 이용한 k-평균 군집화<br/>

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

X, y = make_blobs(
    n_samples=150,
    n_features=2,
    centers=3,
    cluster_std=0.5,
    shuffle=True,
    random_state=0
)

km = KMeans(
    n_clusters=3,
    init='random',
    n_init=10,
    max_iter=300,
    tol=1e-04,
    random_state=0
)

y_km = km.fit_predict(X)
```

&ensp;주요 파라미터<br/>
* `n_clusters=3`: 군집 개수
* `init='random'`: 초기 중심점을 무작위로 선택
* `n_init=10`: 서로 다른 초기 중심점으로 여러 번 실행
* `max_iter=300`: 최대 반복 횟수
* `tol=1e-04`: 수렴 판단 기준
* `fit_predict(X)`: 모델을 학습하고 각 데이터가 속한 군집 번호를 반환

---

&ensp;7. k-평균++ K-means++<br/>
&ensp;일반 k-평균은 초기 중심점을 무작위로 선택하기 때문에 나쁜 초기값으로 인해 지역 최적해에 빠질 수 있다.<br/>

&ensp;k-평균++는 초기 중심점들을 데이터 공간에 잘 퍼지도록 선택하여 수렴 속도와 군집 품질을 개선한다.<br/>

&ensp;초기화만 개선하며, 중심점 선택 이후의 할당과 갱신 과정은 일반 k-평균과 동일하다.<br/>

---

&ensp;8. k-평균++ 알고리즘의 단계<br/>

&ensp;① 첫 번째 중심 선택<br/>
&ensp;데이터 포인트 중 하나를 균등 확률로 무작위 선택하여 $\mu_1$로 설정한다.<br/>

&ensp;② 나머지 중심 선택<br/>
&ensp;각 데이터 $x_i$에 대해 이미 선택된 가장 가까운 중심점까지의 거리 제곱을 계산한다.<br/>

$$
D(x_i)=
\min_{j\in\{1,\ldots,m\}}
\|x_i-\mu_j\|^2
$$

&ensp;거리 제곱 $D(x_i)$를 확률 가중치로 사용하여 다음 중심점을 선택한다.<br/>

$$
P(x_i)=
\frac{D(x_i)}
{\sum_{l=1}^{n}D(x_l)}
$$

&ensp;따라서 기존 중심점에서 멀리 떨어진 데이터일수록 다음 중심점으로 선택될 확률이 높다.<br/>

&ensp;③ $k$개의 중심점이 모두 선택될 때까지 반복<br/>

&ensp;④ 이후 과정은 일반 k-평균과 동일<br/>
&ensp;할당 → 중심 갱신 → 수렴할 때까지 반복한다.<br/>

> K-means++ = 초기 중심점을 서로 멀리 분산시켜 선택하는 방법

---

&ensp;9. k-평균과 k-평균++ 비교<br/>

| 구분 | k-평균 | k-평균++ |
| --- | --- | --- |
| 초기 중심점 | 무작위 선택 | 기존 중심에서 먼 점이 선택될 확률이 높음 |
| 초기값 영향 | 큼 | 상대적으로 작음 |
| 수렴 및 결과 | 초기값에 따라 불안정할 수 있음 | 더 안정적인 결과를 얻을 수 있음 |
| 이후 과정 | 할당 → 갱신 반복 | 일반 k-평균과 동일 |

---

&ensp;10. 직접 군집 Hard clustering<br/>
&ensp;데이터의 각 샘플을 정확히 하나의 클래스에 할당하는 군집 방식이다.<br/>

&ensp;직접 군집은 결과가 명확하지만, 실제 데이터가 여러 개의 특징을 함께 가지는 경우 애매한 경계를 표현하기 어렵다.<br/>

> Hard clustering = 하나의 데이터는 하나의 군집에만 소속

---

&ensp;11. 간접 군집 Soft clustering<br/>
&ensp;데이터의 샘플을 하나 이상의 클래스에 할당하는 군집 방식이다.<br/>

&ensp;음악 추천에서 한 곡이 여러 특징을 가질 수 있는 경우나 의료 데이터에서 증상이 복합적인 경우처럼, 데이터가 여러 군집에 동시에 어느 정도 속할 수 있는 상황을 표현할 수 있다.<br/>

&ensp;대표적인 퍼지 C-평균 Fuzzy C-Means, FCM 알고리즘이 있다.<br/>

* Soft k-means
* Fuzzy k-means
* Fuzzy C-Means

> Hard clustering = 단일 소속
> Soft clustering = 경계가 모호하거나 여러 특성을 함께 다루는 경우

---

&ensp;12. Fuzzy C-Means FCM의 문제 설정<br/>
&ensp;FCM은 k-평균처럼 데이터를 $c$개의 군집으로 나누지만, 각 데이터가 여러 군집에 속할 수 있도록 소속도 Membership를 부여한다.<br/>

&ensp;각 군집에 얼마나 속하는지를 0과 1 사이의 값으로 표현한다.<br/>

$$
0 \le u_{ij} \le 1
$$

&ensp;한 데이터의 모든 군집에 대한 소속도 합은 항상 1이다.<br/>

$$
\sum_{j=1}^{c}u_{ij}=1
$$

---

&ensp;13. FCM 목적함수<br/>
&ensp;FCM은 다음 목적함수를 최소화한다.<br/>

$$
J_m=
\sum_{i=1}^{n}
\sum_{j=1}^{c}
u_{ij}^{m}\cdot\|x_i-c_j\|^2
$$

&ensp;기호의 의미<br/>
* $n$: 데이터 포인트 개수
* $c$: 군집 개수
* $x_i$: $i$번째 데이터
* $c_j$: $j$번째 군집 중심 Centroid
* $u_{ij}$: 데이터 $i$의 군집 $j$에 대한 소속도
* $m>1$: 퍼지화 계수, 값이 클수록 소속도가 더 균일하게 분배됨

&ensp;가까운 군집에는 높은 소속도를, 먼 군집에는 낮은 소속도를 부여한다.<br/>

&ensp;군집 중심은 각 군집에 속한 데이터의 좌표를 소속도에 따라 가중 평균하여 갱신한다.<br/>

---

&ensp;14. FCM 알고리즘 단계<br/>

&ensp;① 초기화<br/>
&ensp;$u_{ij}$를 무작위로 초기화하되 다음 조건을 만족하도록 한다.<br/>

$$
\sum_{j=1}^{c}u_{ij}=1
$$

&ensp;② 군집 중심 갱신<br/>

$$
c_j=
\frac{
\sum_{i=1}^{n}u_{ij}^{m}x_i
}{
\sum_{i=1}^{n}u_{ij}^{m}
}
$$

&ensp;③ 소속도 갱신<br/>

$$
u_{ij}=
\frac{1}{
\sum_{k=1}^{c}
\left(
\frac{\|x_i-c_j\|}
{\|x_i-c_k\|}
\right)^{\frac{2}{m-1}}
}
$$

&ensp;④ 반복<br/>
&ensp;군집 중심과 소속도 갱신을 반복하고 $u_{ij}$의 변화량이 임계값 이하가 되면 종료한다.<br/>

> 소속도 초기화 → 군집 중심 계산 → 소속도 갱신 → 반복

---

&ensp;15. FCM의 목적과 특징<br/>
* 데이터-군집 거리와 소속도를 기반으로 가중된 오차 합을 최소화
* 군집 중심과 소속도를 번갈아 갱신
* 소속도는 0과 1 사이이며 한 데이터의 소속도 합은 1
* 군집 경계가 모호하거나 중첩된 데이터의 불확실성을 표현 가능
* 해석의 유연성이 높음
* 가장 큰 소속도를 기준으로 최종 라벨링 가능
* 소속도 자체를 활용해 후속 분석, 시각화, 추천 모델 등에 적용 가능

---

&ensp;16. 엘보우 방법 Elbow Method<br/>
&ensp;k-평균에서는 군집 개수 $k$를 미리 지정해야 한다.<br/>
&ensp;엘보우 방법은 적절한 군집 개수를 찾기 위한 방법이다.<br/>

&ensp;여러 $k$값에 대해 k-평균을 수행하고 왜곡 Distortion을 계산한다.<br/>

```python
distortions = []

for i in range(1, 11):
    km = KMeans(
        n_clusters=i,
        init='k-means++',
        n_init=10,
        max_iter=300,
        random_state=0
    )
    km.fit(X)
    distortions.append(km.inertia_)
```

&ensp;군집 개수가 증가할수록 왜곡은 감소하지만, 어느 시점부터 감소 폭이 작아진다.<br/>

&ensp;그래프가 팔꿈치처럼 꺾이는 지점을 엘보우 포인트 Elbow Point라고 하며, 이 지점의 군집 개수를 적절한 $k$로 선택한다.<br/>

> Elbow Method = 왜곡 감소 폭이 급격히 작아지는 지점에서 k 선택

&ensp;17. 실루엣 분석 Silhouette Analysis<br/>
&ensp;실루엣 분석은 클러스터 내 샘플들이 얼마나 조밀하게 모여 있는지와 다른 클러스터와 얼마나 잘 분리되어 있는지를 측정하는 방법이다.<br/>

&ensp;① 같은 클러스터 내 평균 거리, 클러스터 응집력 $a(i)$<br/>
&ensp;샘플 $i$와 같은 클러스터에 속한 다른 모든 샘플과의 평균 거리이다.<br/>

$$
a(i)=
\frac{1}{|C_A|-1}
\sum_{x_j\in C_A,j\ne i}
d(x_i,x_j)
$$

&ensp;② 가장 가까운 다른 클러스터와의 평균 거리, 클러스터 분리도 $b(i)$<br/>
&ensp;샘플 $i$가 속하지 않은 다른 모든 클러스터에 대해 평균 거리를 계산하고 그중 최소값을 선택한다.<br/>

$$
b(i)=
\min_{B\ne A}
\frac{1}{|C_B|}
\sum_{x_j\in C_B}
d(x_i,x_j)
$$

&ensp;③ 실루엣 계수<br/>

$$
s(i)=
\frac{b(i)-a(i)}
{\max(a(i),b(i))}
$$

---

&ensp;18. 실루엣 계수 해석<br/>
&ensp;실루엣 계수의 값 범위는 -1부터 1까지이다.<br/>

* 1에 가까움 → 현재 클러스터에 잘 배정됨
* 0에 가까움 → 클러스터 경계에 위치
* 음수 → 다른 클러스터에 더 가까워 잘못 배정되었을 가능성

&ensp;좋은 클러스터는 실루엣 계수가 높고, 각 클러스터가 막대 길이를 비교적 균일하게 가지는 형태를 보인다.<br/>

&ensp;엘보우 방법만으로 부족할 때 실루엣 분석을 보조 지표로 사용하여 클러스터 경계와 품질을 확인할 수 있다.<br/>

> 응집력 $a(i)$는 작을수록 좋음
> 분리도 $b(i)$는 클수록 좋음
> 실루엣 계수 $s(i)$는 1에 가까울수록 좋음

# Unit 02. 클러스터 조직화

&ensp;1. 계층 군집화 Hierarchical clustering<br/>
&ensp;유사도 기반의 트리 구조를 형성하는 군집화 방법이다.<br/>

&ensp;계층 군집에서는 사전에 정확한 클러스터 개수를 지정하지 않아도 되며, 덴드로그램 Dendrogram을 자르는 위치에 따라 원하는 개수의 군집을 선택할 수 있다.<br/>

&ensp;데이터 간 거리 또는 유사도를 반복적으로 계산하여 상위·하위 구조가 명확한 군집 트리를 생성한다.<br/>

---

&ensp;2. 계층 군집의 두 가지 방법<br/>

&ensp;① 병합 계층 군집 Agglomerative hierarchical clustering<br/>
&ensp;가까운 군집들을 반복적으로 병합하여 상위 군집 구조를 만든다.<br/>
&ensp;덴드로그램에서 아래에서 위로 병합하는 방식이다.<br/>

&ensp;② 분할 계층 군집 Divisive hierarchical clustering<br/>
&ensp;전체 데이터를 하나의 군집으로 보고 점진적으로 분할하여 계층적 구조를 찾는다.<br/>
&ensp;덴드로그램에서 위에서 아래로 분할하는 방식이다.<br/>

> Agglomerative = 아래 → 위, 병합
> Divisive = 위 → 아래, 분할

---

&ensp;3. 계층 군집의 특징<br/>
&ensp;다양한 형태와 크기의 군집을 탐지할 수 있으며, 단일 연결, 완전 연결, 평균 연결, Ward 방법 등 거리 계산 방식에 따라 결과가 달라질 수 있다.<br/>

&ensp;장점<br/>
* 군집 개수를 유연하게 선택 가능
* 덴드로그램을 통해 군집 구조를 직관적으로 이해 가능
* 거리와 유사도 정의에 따라 다양한 형태에 적용 가능

&ensp;단점<br/>
* 데이터 수가 많아질수록 거리 계산과 병합/분할 과정의 계산량이 급격히 증가
* 노이즈나 이상치에 민감할 수 있음

---

&ensp;4. 병합 계층 군집 Agglomerative hierarchical clustering<br/>
&ensp;개별 데이터 포인트를 각각 하나의 군집으로 시작하여 가까운 두 군집을 점진적으로 병합하며 상위 군집을 형성한다.<br/>

&ensp;모든 데이터가 하나의 군집이 될 때까지 병합을 반복할 수 있다.<br/>

> 초기화 → 거리 계산 → 병합 → 거리 갱신 → 종료 조건

---

&ensp;5. 병합 계층 군집의 장단점<br/>

&ensp;장점<br/>
* 구현이 간단함
* 군집 개수를 사전에 지정하지 않아도 됨
* 덴드로그램으로 군집 구조를 시각적으로 분석 가능
* 데이터 구조 탐색과 최적 군집 개수 결정에 유용

&ensp;단점<br/>
* 데이터가 많으면 계산량이 많아짐, $O(n^2)$ 이상
* 한 번 병합된 군집은 다시 분리할 수 없기 때문에 초기 병합 오류가 최종 결과에 영향을 줄 수 있음

---

&ensp;6. 분할 계층 군집 Divisive hierarchical clustering<br/>
&ensp;모든 데이터를 하나의 군집으로 시작하여 군집을 점진적으로 분할하면서 하위 군집을 형성한다.<br/>

> 초기화 → 분할 기준 결정 → 분할 수행 → 반복 → 종료 조건

&ensp;장점<br/>
* 전역적으로 전체 데이터 구조를 고려하면서 분할
* 특정 대규모 군집을 세부적으로 분석 가능

&ensp;단점<br/>
* 구현이 병합 방식보다 복잡하고 계산량이 더 많을 수 있음
* 초기 분할이 잘못되면 이후 구조 전체에 영향을 미침

---

&ensp;7. 병합 계층 군집의 연결 방식<br/>

&ensp;① 단일 연결 Single linkage<br/>
&ensp;두 군집에서 가장 가까운 점의 거리를 기준으로 병합 여부를 결정한다.<br/>

$$
D(A,B)=
\min_{a\in A,b\in B} d(a,b)
$$

&ensp;장점<br/>
&ensp;복잡하게 휘어진 모양의 군집을 잘 찾을 수 있다.<br/>

&ensp;단점<br/>
&ensp;외곽점이나 노이즈에 취약하며 군집이 사슬처럼 늘어질 수 있다.<br/>

&ensp;② 완전 연결 Complete linkage<br/>
&ensp;두 군집에서 가장 먼 점의 거리를 기준으로 병합 여부를 결정한다.<br/>

$$
D(A,B)=
\max_{a\in A,b\in B} d(a,b)
$$

&ensp;장점<br/>
&ensp;군집 내부가 조밀하고 균일하게 유지된다.<br/>

&ensp;단점<br/>
&ensp;복잡한 형태보다는 둥글고 뭉친 형태의 군집에 적합하다.<br/>

> Single linkage = 가장 가까운 점
> Complete linkage = 가장 먼 점

---

&ensp;8. 거리 행렬에서 계층 군집 수행<br/>

```python
import pandas as pd
import numpy as np
from scipy.spatial.distance import pdist, squareform
from scipy.cluster.hierarchy import linkage
from scipy.cluster.hierarchy import dendrogram
import matplotlib.pyplot as plt

np.random.seed(123)

variables = ['X', 'Y', 'Z']
labels = ['ID_0', 'ID_1', 'ID_2', 'ID_3', 'ID_4']

X = np.random.random_sample([5, 3]) * 10
df = pd.DataFrame(X, columns=variables, index=labels)

row_dist = pd.DataFrame(
    squareform(pdist(df, metric='euclidean')),
    columns=labels,
    index=labels
)

row_clusters = linkage(
    df.values,
    method='complete',
    metric='euclidean'
)

row_dendr = dendrogram(row_clusters, labels=labels)

plt.tight_layout()
plt.ylabel('Euclidean distance')
plt.show()
```

&ensp;`pdist`는 데이터 간 거리를 계산하고, `squareform`은 이를 거리 행렬 형태로 변환한다.<br/>
&ensp;`linkage(..., method='complete')`는 완전 연결 기반 계층 군집을 수행한다.<br/>
&ensp;덴드로그램은 군집이 어떤 순서와 거리에서 병합되었는지 보여준다.<br/>

---

&ensp;9. 히트맵에 덴드로그램 연결<br/>
&ensp;덴드로그램을 히트맵과 연결하면 샘플 간 유사도를 색으로 표현하면서 동시에 계층적인 군집 구조를 확인할 수 있다.<br/>

&ensp;군집 구조가 반영된 순서로 데이터를 재정렬하여 시각적으로 확인한다.<br/>

---

&ensp;10. 사이킷런에서 병합 군집 적용<br/>

```python
from sklearn.cluster import AgglomerativeClustering

    linkage='complete'

```

&ensp;주요 설정<br/>

* `metric='euclidean'`: 유클리드 거리
* `linkage='complete'`: 완전 연결 방식 사용

# Unit 03. 밀집도가 높은 지역 찾기

&ensp;1. 밀도 기반 군집화 알고리즘의 종류<br/>

&ensp;DBSCAN<br/>
* 밀도 기반으로 군집 정의
* 비선형 경계와 이상치 탐지에 효과적

&ensp;OPTICS와 HDBSCAN<br/>
* 서로 다른 밀도 구조에도 적용 가능
* 고정 반경 파라미터의 한계를 보완

&ensp;SNN Clustering<br/>
* 공통 최근접 이웃 기반 유사도 활용
* 고차원, 이상치가 많은 환경에서도 군집화 가능

---

&ensp;2. DBSCAN<br/>
&ensp;DBSCAN의 전체 이름은 Density-Based Spatial Clustering of Applications with Noise이다.<br/>

&ensp;목적<br/>
* 밀도가 높은 영역은 군집으로 정의
* 밀도가 낮은 영역은 Noise로 처리
* 군집 개수를 사전에 지정할 필요 없음
* $\varepsilon$과 MinPts 두 개의 파라미터로 동작
* 직선·곡선 등 임의 모양의 군집 탐지 가능
* 비선형 경계도 식별 가능

---

&ensp;3. DBSCAN의 핵심 아이디어<br/>

&ensp;핵심점 Core point<br/>
&ensp;$\varepsilon$ 반경 내에 MinPts 이상의 점이 있는 경우 핵심점으로 판단한다.<br/>

&ensp;핵심점들 사이에 밀도도달성 Density-reachability 조건을 만족하면 같은 군집으로 묶는다.<br/>

&ensp;경계점 Border point<br/>
&ensp;핵심점의 이웃에 포함되는 점이다.<br/>

&ensp;잡음점 Noise<br/>
&ensp;핵심점과 경계점 어디에도 속하지 않는 점이다.<br/>

> DBSCAN = Core point + Border point + Noise point

---

&ensp;4. DBSCAN 핵심 파라미터<br/>

&ensp;① $\varepsilon$ Eps<br/>
&ensp;각 점 주변을 탐색하는 반경 Neighborhood radius이다.<br/>
&ensp;한 점 주변을 둘러보는 거리 범위를 의미한다.<br/>

&ensp;② MinPts<br/>
&ensp;밀도가 높다고 판단하기 위한 최소 이웃 점 개수이다.<br/>
&ensp;$\varepsilon$ 반경 안에 MinPts개 이상의 점이 있으면 밀도가 높다고 판단한다.<br/>

---

&ensp;5. DBSCAN의 점 분류<br/>

| 종류 | 정의 |
| --- | --- |
| Core point | $\varepsilon$ 반경 내에 최소 MinPts 이상의 점이 있는 점 |
| Border point | 핵심점에는 속하지 않지만 어떤 핵심점의 $\varepsilon$ 반경 안에 속하는 점 |
| Noise point | 어떤 군집에도 속하지 않는 점 |

---

&ensp;6. DBSCAN 알고리즘 절차<br/>
&ensp;모든 점을 방문하지 않은 상태에서 시작한다.<br/>

&ensp;① 임의의 점 $p$를 선택하고 $\varepsilon$ 반경 내 이웃을 탐색한다.<br/>

&ensp;② 이웃 수가 MinPts 이상이면 $p$를 핵심점으로 분류하고 새로운 군집을 생성한다.<br/>

&ensp;③ 핵심점 주변의 이웃 점을 계속 처리하며 군집을 확장한다.<br/>

&ensp;④ 이웃 수가 MinPts보다 적으면, $p$가 다른 핵심점의 $\varepsilon$ 반경 안에 있는지 확인한다.<br/>

* 다른 핵심점의 영역 안에 있음 → Border point
* 다른 핵심점의 영역에도 포함되지 않음 → Noise point

&ensp;⑤ 모든 점이 처리될 때까지 반복한다.<br/>

&ensp;한번 잡음점으로 분류되더라도 이후 다른 핵심점의 영역에 포함되면 경계점이 될 수 있다.<br/>

> 임의의 점 선택 → ε 이웃 탐색 → Core 여부 판단 → 군집 확장 → Border/Noise 판단 → 반복

---

&ensp;7. DBSCAN 구현<br/>

```python
from sklearn.datasets import make_moons
from sklearn.cluster import DBSCAN

X, y = make_moons(
    n_samples=200,
    noise=0.05,
    random_state=0
)

db = DBSCAN(
    eps=0.2,
    min_samples=5,
    metric='euclidean'
)

y_db = db.fit_predict(X)
```

&ensp;`eps=0.2`는 이웃을 탐색하는 반경이고 `min_samples=5`는 최소 이웃 수를 의미한다.<br/>

---

&ensp;8. 비선형 데이터에서 군집화 비교<br/>
&ensp;강의자료에서는 두 개의 반달 모양 데이터에 k-평균, 병합 계층 군집, DBSCAN을 적용하여 결과를 비교한다.<br/>

&ensp;k-평균은 중심점을 기준으로 데이터를 나누기 때문에 반달 형태와 같은 복잡한 비선형 구조를 제대로 표현하기 어렵다.<br/>

&ensp;병합 계층 군집도 사용한 거리와 연결 기준에 따라 실제 비선형 구조를 잘 분리하지 못할 수 있다.<br/>

&ensp;DBSCAN은 거리 기반 중심점이 아니라 데이터의 밀도와 연결 관계를 사용하므로 반달 모양과 같은 비선형 군집도 탐지할 수 있다.<br/>

---

&ensp;9. DBSCAN의 장점<br/>

&ensp;① 군집 개수 사전 지정 불필요<br/>
&ensp;k-평균과 달리 군집 개수를 미리 입력하지 않아도 되며 데이터 밀도에 따라 자동으로 결정한다.<br/>

&ensp;② 임의 모양 군집 탐지 가능<br/>
&ensp;원형, 타원형, 비선형 경계 등 복잡한 모양의 군집도 탐지할 수 있다.<br/>

&ensp;③ 노이즈 및 이상치 처리 능력<br/>
&ensp;밀도가 낮은 점은 자동으로 Noise로 분류되기 때문에 별도의 이상치 탐지 과정 없이 이상치를 처리할 수 있다.<br/>

&ensp;④ 적은 파라미터<br/>
&ensp;핵심 파라미터는 $\varepsilon$과 MinPts 두 가지이므로 구조가 비교적 단순하다.<br/>

---

&ensp;10. DBSCAN의 단점<br/>

&ensp;① 파라미터 설정에 민감<br/>
&ensp;$\varepsilon$과 MinPts 설정에 따라 결과가 크게 달라질 수 있다.<br/>
&ensp;특히 $\varepsilon$은 데이터 스케일과 분포에 매우 민감하다.<br/>

&ensp;② 밀도 차이가 큰 군집 처리 어려움<br/>
&ensp;일부 군집이 합쳐지거나 쪼개지는 등 의도하지 않은 결과가 발생할 수 있다.<br/>

&ensp;③ 고차원 데이터에서 성능 저하<br/>
&ensp;차원이 증가하면 거리 계산이 무의미해지고 밀도 기반 판단이 어려워질 수 있다.<br/>

&ensp;④ 대규모 데이터에서 계산 비용 증가<br/>
&ensp;모든 점 쌍의 거리 계산으로 인해 $O(n^2)$ 이상의 복잡도가 발생할 수 있다.<br/>
&ensp;데이터 규모가 커질수록 계산량이 급증하며, 최적화를 위해 k-d tree나 ball tree 등의 인덱싱 기법이 필요할 수 있다.<br/>

---

&ensp;11. OPTICS<br/>
&ensp;OPTICS의 전체 이름은 Ordering Points To Identify the Clustering Structure이다.<br/>

&ensp;특징<br/>
* DBSCAN과 같이 $\varepsilon$, MinPts 개념을 사용
* 단일 $\varepsilon$ 값에 고정되지 않음
* 다양한 스케일의 군집 파악 가능
* 고저밀도 혼합 데이터에서 군집 경계 탐지 가능

&ensp;핵심 아이디어<br/>
&ensp;모든 점을 밀도 도달 순서로 나열하고 각 점의 도달 가능 거리 Reachability distance를 계산한다.<br/>

&ensp;Reachability Plot에서 계곡 모양을 군집으로 판별한다.<br/>

&ensp;장점<br/>
* 임의 모양 군집과 노이즈 식별 가능
* 서로 다른 밀도의 군집도 안정적으로 탐지
* 유연한 파라미터 설정
* 복잡한 경계와 다양한 밀도 구조에서도 성능이 뛰어남

---

&ensp;12. HDBSCAN<br/>
&ensp;HDBSCAN은 Hierarchical DBSCAN으로 DBSCAN을 계층적 방식으로 확장한 방법이다.<br/>

&ensp;특징<br/>
* 단일 $\varepsilon$ 값에 의존하지 않음
* 다양한 스케일에서 군집 구조 탐색
* 데이터 특성에 따라 군집 개수 및 형태를 자동으로 결정

&ensp;핵심 아이디어<br/>
&ensp;여러 $\varepsilon$ 값에 대해 DBSCAN을 반복 실행한 것처럼 군집 병합·분할 과정을 계층적 트리 형태로 생성하고, 안정성이 높은 군집을 선택하여 최종 결과를 만든다.<br/>

&ensp;안정성 Stability<br/>
&ensp;특정 군집이 다양한 $\varepsilon$ 값 범위에서 얼마나 오래 유지되는지를 수치화한 지표이다.<br/>

> HDBSCAN = DBSCAN의 장점 유지 + 단일 ε 의존성 감소 + 다양한 밀도 구조 처리

---

&ensp;13. DENCLUE<br/>
&ensp;DENCLUE는 DENsity-based CLUstEring의 약자이다.<br/>

&ensp;특징<br/>
* 밀도 함수를 수학적으로 모델링하여 군집 정의
* 커널 밀도 추정 Kernel Density Estimation, KDE를 이용해 밀도 계산
* 확률 밀도 함수 관점에서 군집 개념을 정립
* 이론적으로 명확하고 해석 가능성이 높음

&ensp;핵심 아이디어<br/>
&ensp;각 데이터 포인트 주변의 밀도를 커널 함수로 계산하고, 데이터 포인트를 밀도 흡인점 Density attractor으로 반복 이동한다.<br/>

&ensp;동일한 흡인점에 수렴하는 데이터 포인트들을 하나의 군집으로 정의하며, 저밀도 영역은 군집 경계 역할을 한다.<br/>

&ensp;특징 정리<br/>
* 수학적 엄밀성과 확률적 해석 가능
* 고밀도 중심 기반의 안정적인 군집 형성
* 임의 모양 군집 탐지 및 노이즈·이상치 분리에 효과적
* 커널 폭 조절을 통해 군집 경계 민감도를 유연하게 조정

---

&ensp;14. SNN Clustering<br/>
&ensp;SNN은 Shared Nearest Neighbor Clustering의 약자이다.<br/>

&ensp;두 점이 얼마나 많은 공통 최근접 이웃 Shared Nearest Neighbors를 가지는지를 유사도로 사용한다.<br/>

&ensp;고차원 및 거리 기반 측정이 왜곡되기 쉬운 데이터에서 강한 성능을 보인다.<br/>

&ensp;핵심 아이디어<br/>
&ensp;① 각 데이터 포인트에 대해 $k$-최근접 이웃 k-NN 집합을 계산한다.<br/>
&ensp;② 두 점 $p$와 $q$가 공통으로 갖는 이웃 수를 유사도로 정의한다.<br/>
&ensp;③ 일정 임계값 이상이면 두 점을 연결하여 그래프 형태로 판단한다.<br/>
&ensp;④ 공통 이웃 수가 많은 핵심점 중심으로 군집을 형성한다.<br/>
&ensp;⑤ DBSCAN과 유사하게 핵심점, 경계점, 잡음점을 분류한다.<br/>

&ensp;특징<br/>
* 거리 이상치에 대한 민감도 감소
* 차원의 저주 상황에서도 안정적인 군집 형성
* 비선형 경계 및 임의 모양 군집 탐지 가능

---

# 중간고사 대비 핵심 정리

&ensp;1. k-평균에서 반드시 기억할 것<br/>

> 프로토타입 = Centroid
> 목적함수 = 군집 내 제곱 오차의 합 최소화
> 순서 = 초기화 → 할당 → 갱신 → 수렴
> 중심점 = 군집에 속한 데이터들의 평균

---

&ensp;2. k-평균++에서 반드시 기억할 것<br/>

> 일반 k-평균의 초기 중심점 선택 문제를 개선
> 기존 중심에서 멀리 떨어진 데이터일수록 다음 중심으로 선택될 확률이 높음
> 중심점 선택 후 과정은 일반 k-평균과 동일

---

&ensp;3. FCM에서 반드시 기억할 것<br/>

> Soft clustering
> 하나의 데이터가 여러 군집에 소속 가능
> 소속도 $0 \le u_{ij} \le 1$
> 한 데이터의 모든 군집 소속도 합 = 1
> 군집 중심은 소속도를 이용한 가중 평균

---

&ensp;4. 엘보우와 실루엣<br/>

> Elbow Method = 적절한 군집 개수 k를 찾는 방법
> Silhouette = 군집의 응집력과 분리도를 함께 평가
> $a(i)$ = 같은 군집과의 평균 거리
> $b(i)$ = 가장 가까운 다른 군집과의 평균 거리
> $s(i)$가 1에 가까울수록 좋은 군집

---

&ensp;5. 계층 군집에서 반드시 기억할 것<br/>

> Agglomerative = 아래에서 위로 병합
> Divisive = 위에서 아래로 분할
> Dendrogram = 계층적인 군집 구조 시각화
> Single linkage = 가장 가까운 점
> Complete linkage = 가장 먼 점

---

&ensp;6. DBSCAN에서 반드시 기억할 것<br/>

> 핵심 파라미터 = ε, MinPts
> Core point = ε 반경 내 이웃 수가 MinPts 이상
> Border point = Core는 아니지만 Core의 ε 반경 안에 위치
> Noise point = 어떤 군집에도 속하지 않음
> 군집 개수 k를 미리 지정할 필요 없음
> 임의 모양의 비선형 군집 탐지 가능
> 노이즈와 이상치 처리 가능

---

&ensp;7. 밀도 기반 군집 방법 비교<br/>

| 알고리즘 | 핵심 특징 |
| --- | --- |
| DBSCAN | ε와 MinPts를 이용한 대표적인 밀도 기반 군집 |
| OPTICS | 서로 다른 밀도 구조를 탐색하기 위해 도달 가능 거리 사용 |
| HDBSCAN | DBSCAN을 계층적으로 확장하고 안정적인 군집 선택 |
| DENCLUE | 커널 밀도 함수와 Density Attractor 사용 |
| SNN | 공통 최근접 이웃 수를 유사도로 사용 |

---

# 중간고사 예상 확인 문제

&ensp;1. k-평균에서 군집을 대표하는 평균 좌표를 무엇이라고 하는가?<br/>
> Centroid

&ensp;2. k-평균의 반복 순서를 쓰시오.<br/>
> 초기화 → 할당 → 갱신 → 수렴

&ensp;3. k-평균++가 일반 k-평균과 다른 부분은 무엇인가?<br/>
> 초기 중심점을 선택하는 방법

&ensp;4. FCM에서 하나의 데이터에 대한 모든 군집 소속도의 합은 얼마인가?<br/>
> 1

&ensp;5. 적절한 군집 개수 $k$를 찾기 위해 왜곡 그래프의 꺾이는 지점을 사용하는 방법은 무엇인가?<br/>
> Elbow Method

&ensp;6. 실루엣 계수가 1에 가까울수록 무엇을 의미하는가?<br/>
> 현재 군집에 잘 배정되어 있고 다른 군집과 잘 분리되어 있음을 의미

&ensp;7. 아래에서 위로 군집을 합치는 계층 군집 방식은 무엇인가?<br/>
> Agglomerative hierarchical clustering

&ensp;8. 두 군집의 가장 가까운 두 점을 기준으로 거리를 정의하는 방식은 무엇인가?<br/>
> Single linkage

&ensp;9. 두 군집의 가장 먼 두 점을 기준으로 거리를 정의하는 방식은 무엇인가?<br/>
> Complete linkage

&ensp;10. DBSCAN의 두 핵심 파라미터는 무엇인가?<br/>
> ε(Eps), MinPts

&ensp;11. DBSCAN에서 ε 반경 안에 MinPts 이상의 점이 존재하는 점을 무엇이라고 하는가?<br/>
> Core point

&ensp;12. DBSCAN에서 어떤 군집에도 속하지 않는 점을 무엇이라고 하는가?<br/>
> Noise point

&ensp;13. DBSCAN을 계층적인 방법으로 확장한 알고리즘은 무엇인가?<br/>
> HDBSCAN

&ensp;14. 공통 최근접 이웃을 이용하여 유사도를 계산하는 군집화 방법은 무엇인가?<br/>
> SNN Clustering
