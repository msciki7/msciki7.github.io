# 특징과 표현 공간 개념

&ensp;1. 특징(Feature)이란?<br/>
&ensp;특징은 **데이터를 설명하는 핵심 변수**이며, AI 모델이 입력으로 사용하는 정보이다.<br/>
&ensp;IoT 환경에서는 온도, 습도, 진동, 전류, 전력 사용량, 압력, 소음처럼 센서가 직접 측정한 값뿐 아니라 평균값, 변화량, 표준편차처럼 가공한 값도 특징으로 사용할 수 있다.<br/>

&ensp;원본 데이터와 특징의 차이<br/>
* 원본 데이터: 센서가 측정한 값 전체
* 특징: 모델의 학습과 판단에 사용하기 위해 선택하거나 가공한 값

> 특징 = AI 모델이 상태를 판단하기 위해 실제로 사용하는 입력 변수

---

&ensp;2. 특징 벡터(Feature Vector)<br/>
&ensp;여러 개의 특징을 하나로 묶은 벡터를 **특징 벡터**라고 한다.<br/>

&ensp;예를 들어 모터의 상태를 온도, 진동, 전류로 표현하면<br/>

$$
x=(35,\;0.03,\;2.1)
$$

&ensp;으로 나타낼 수 있다.<br/>

| 특징 | 값 |
| --- | ---: |
| 온도 | 35 |
| 진동 | 0.03 |
| 전류 | 2.1 |

&ensp;이 특징 벡터는 **특정 시점의 모터 상태 하나**를 나타낸다.<br/>

> 여러 특징을 묶으면 하나의 상태를 수학적인 벡터로 표현할 수 있다.

---

&ensp;3. 표현(Representation)<br/>
&ensp;표현은 **원본 데이터를 모델이 이해하기 쉬운 수학적 형태로 바꾼 것**이다.<br/>

| 원본 데이터 | 표현 |
| --- | --- |
| 센서 로그 | 특징 벡터 |
| 이미지 | 픽셀 텐서 |
| 텍스트 | 임베딩 벡터 |
| 그래프 | 노드 특징과 인접행렬 |

&ensp;같은 데이터라도 어떻게 표현하느냐에 따라 모델의 성능이 달라질 수 있다.<br/>
&ensp;좋은 표현은 정상과 이상을 잘 구분하게 하고, 나쁜 표현은 중요한 패턴을 숨길 수 있다.<br/>

> 좋은 표현 = 모델이 데이터의 차이와 패턴을 더 쉽게 파악할 수 있게 만드는 표현

---

&ensp;4. 표현 공간(Representation Space)<br/>
&ensp;표현 공간은 **특징 벡터들이 위치하는 공간**이다.<br/>
&ensp;예를 들어 특징 벡터가 $x=(온도, 진동)$ 이라면 각 데이터는 2차원 공간의 하나의 점으로 표현된다.<br/>

&ensp;표현 공간에서 점들의 의미<br/>
* 가까운 점 → 비슷한 상태
* 먼 점 → 서로 다른 상태
* 특정 영역에 모여 있는 점 → 비슷한 패턴을 가진 그룹

&ensp;따라서 정상 모터 데이터들이 서로 가까이 모이고 이상 데이터가 멀리 떨어져 있다면, 정상 상태들은 서로 유사한 센서 패턴을 가지지만 이상 상태는 정상 상태와 다른 패턴을 가진다고 해석할 수 있다.<br/>

---

&ensp;5. 특징 공간에서의 거리<br/>
&ensp;특징 공간에서는 데이터 사이의 거리를 계산하여 두 상태의 유사성을 판단할 수 있다.<br/>
&ensp;강의자료에서는 **유클리드 거리(Euclidean Distance)** 를 사용한다.<br/>

$$
d(x,y)=\sqrt{\sum_{i=1}^{D}(x_i-y_i)^2}
$$

&ensp;해석<br/>
* 거리가 작다 → 두 상태가 유사하다.
* 거리가 크다 → 두 상태가 서로 다르다.

&ensp;IoT 예시에서는 정상 모터 상태들이 특징 공간에서 가까이 모이고, 과열이나 고진동 상태는 정상 중심에서 멀리 떨어질 수 있다.<br/>

---

&ensp;6. 좋은 특징과 나쁜 특징<br/>

| 좋은 특징 | 나쁜 특징 |
| --- | --- |
| 상태 차이를 잘 드러냄 | 상태 차이와 관계가 약함 |
| 정상과 이상을 잘 구분함 | 정상과 이상을 구분하지 못함 |
| 노이즈에 덜 민감함 | 노이즈가 큼 |
| 해석 가능성이 있음 | 중복 정보가 많음 |
| 모델 성능 향상에 도움 | 단위 차이로 특정 값이 과도하게 영향 |

&ensp;특징을 선택할 때 단순히 값이 존재하는지가 아니라 **상태의 차이를 잘 설명할 수 있는가**가 중요하다.<br/>

---

&ensp;7. 원본 특징과 가공 특징<br/>

&ensp;원본 특징<br/>
&ensp;센서가 직접 측정한 값이다.<br/>
* 현재 온도
* 현재 진동
* 현재 전류

&ensp;가공 특징<br/>
&ensp;원본 데이터에서 계산하여 새롭게 만든 특징이다.<br/>
* 최근 5분 평균 온도
* 최근 5분 진동 표준편차
* 현재값과 이전값의 차이
* 전력 사용량 증가율
* 정상 평균과의 거리

&ensp;가공 특징을 사용하면 원본 값만으로는 보이지 않았던 패턴을 드러낼 수 있다.<br/>

---

&ensp;8. 특징 공간과 AI 모델<br/>

| 모델/방법 | 특징 공간에서 하는 일 |
| --- | --- |
| 회귀 모델 | 입력과 연속값 출력의 관계 학습 |
| 분류 모델 | 클래스를 나누는 결정경계 학습 |
| 군집화 | 가까운 데이터끼리 그룹화 |
| 이상 탐지 | 정상 데이터가 모인 영역에서 멀리 떨어진 데이터를 이상으로 판단 |
| 표현학습 | 모델이 더 좋은 특징 공간을 자동으로 학습 |

---

&ensp;9. 스마트팩토리 모터 상태 예시<br/>

&ensp;정상 상태<br/>

| 상태 | 온도 | 진동 | 전류 |
| --- | ---: | ---: | ---: |
| 정상 1 | 35 | 0.03 | 2.1 |
| 정상 2 | 36 | 0.04 | 2.2 |
| 정상 3 | 35 | 0.03 | 2.0 |
| 정상 4 | 36 | 0.05 | 2.3 |

&ensp;이상 상태<br/>

| 상태 | 온도 | 진동 | 전류 |
| --- | ---: | ---: | ---: |
| 이상 1 | 45 | 0.20 | 4.0 |
| 이상 2 | 48 | 0.25 | 4.5 |

&ensp;정상 데이터는 온도, 진동, 전류 값이 서로 비슷하기 때문에 특징 공간에서도 가까이 모일 가능성이 크다.<br/>
&ensp;반대로 이상 데이터는 정상보다 세 특징이 모두 높기 때문에 정상 그룹과 멀리 떨어질 가능성이 크다.<br/>

---

&ensp;10. 정규화와 PCA를 이용한 특징 공간 시각화<br/>
&ensp;강의 실습에서는 온도, 진동, 전류를 특징으로 사용하고 다음 순서로 특징 공간을 확인한다.<br/>

1. 온도, 진동, 전류를 입력 특징으로 선택한다.
2. `StandardScaler`로 정규화한다.
3. PCA를 이용해 3차원 특징 공간을 2차원으로 축소한다.
4. 정상 데이터와 이상 데이터의 위치를 시각화한다.

&ensp;정규화의 목적<br/>
* 온도, 진동, 전류의 단위 차이를 줄인다.
* 특정 센서의 값 크기가 지나치게 커서 과도하게 영향을 주는 문제를 완화한다.

&ensp;PCA의 역할<br/>
* 3차원 특징 공간을 2차원으로 축소한다.
* 시각화를 통해 데이터의 구조를 확인할 수 있다.

&ensp;결과 해석<br/>
* 정상 데이터는 서로 가까이 모일 가능성이 크다.
* 이상 데이터는 정상 데이터와 떨어진 위치에 나타날 가능성이 크다.

> 특징 공간에서는 데이터 간 유사성과 차이를 **거리와 위치**로 해석한다.

# 비선형 변환과 표현학습

&ensp;1. 선형 표현(Linear Representation)<br/>
&ensp;선형 표현은 원본 특징을 그대로 사용하거나 가중합으로 표현하는 방식이다.<br/>

$$
z=w_1x_1+w_2x_2+b
$$

&ensp;장점<br/>
* 해석이 쉽다.
* 계산이 간단하다.
* 작은 데이터에서도 안정적일 수 있다.

&ensp;한계<br/>
* 복잡한 관계를 표현하기 어렵다.
* 곡선형 패턴을 설명하기 어렵다.
* 정상과 이상이 하나의 직선으로 나뉘지 않는 경우 성능이 낮을 수 있다.

---

&ensp;2. 비선형 관계(Nonlinear Relationship)<br/>
&ensp;비선형 관계는 **입력과 출력의 관계가 직선으로 표현되지 않는 경우**를 의미한다.<br/>

&ensp;IoT 예시<br/>
* 모터 속도가 너무 낮거나 너무 높을 때 진동이 증가한다.
* 온도가 일정 수준을 넘으면 전력 사용량이 급격히 증가한다.
* 습도와 온도의 조합이 작물 생육에 비선형적으로 영향을 준다.
* 전류와 진동이 동시에 증가할 때만 이상 가능성이 증가한다.

&ensp;즉 센서 하나만 보면 정상처럼 보이지만, 여러 센서의 조합을 보면 이상일 수 있다.<br/>

---

&ensp;3. 비선형 특징(Nonlinear Feature)<br/>
&ensp;비선형 특징은 **원본 특징을 변환하여 만든 새로운 특징**이다.<br/>

&ensp;강의자료의 예<br/>

$$
x_1^2,\;x_2^2,\;x_1x_2,\;\log(x),\;\sqrt{x}
$$

&ensp;IoT 예시<br/>
* 온도 제곱
* 진동 제곱
* 온도 × 전류
* 전류 × 진동
* 현재값과 평균의 제곱 차이

&ensp;비선형 특징을 추가하면 원본 공간에서 보이지 않던 데이터의 구조가 새로운 표현 공간에서 드러날 수 있다.<br/>

> 제곱항이나 곱항을 추가하면 선형적으로 잘 구분되지 않던 데이터가 더 쉽게 구분될 수 있다.

---

&ensp;4. 입력 공간과 표현 공간<br/>

| 구분 | 입력 공간 | 표현 공간 |
| --- | --- | --- |
| 구성 | 원본 특징 | 변환된 특징 |
| 목적 | 측정값 표현 | 학습하기 쉬운 구조 제공 |
| 예시 | 온도, 진동 | 온도×진동, 진동² |
| 장점 | 해석이 쉬움 | 복잡한 패턴 표현 가능 |

&ensp;입력 공간은 원본 데이터가 놓인 공간이고, 표현 공간은 원본 데이터를 변환한 뒤의 공간이다.<br/>

---

&ensp;5. 표현학습(Representation Learning)<br/>
&ensp;표현학습은 **모델이 데이터에서 유용한 표현을 자동으로 학습하는 과정**이다.<br/>

&ensp;사람이 직접 특징을 만드는 방식<br/>
* 평균
* 분산
* 변화량
* 곱항
* 제곱항

&ensp;모델이 특징을 학습하는 방식<br/>
* 신경망의 은닉층
* CNN의 특징맵
* Autoencoder의 잠재벡터
* Transformer의 임베딩

&ensp;표현학습의 핵심은 원본 데이터를 그대로 사용하는 것이 아니라 **목적에 맞는 더 좋은 표현으로 변환하는 것**이다.<br/>

---

&ensp;6. 신경망과 비선형 표현<br/>
&ensp;신경망은 여러 층을 통과하면서 입력을 점진적으로 변환한다.<br/>

$$
h_1=\phi(W_1x+b_1)
$$

$$
h_2=\phi(W_2h_1+b_2)
$$

| 기호 | 의미 |
| --- | --- |
| $x$ | 원본 입력 |
| $h_1, h_2$ | 은닉 표현 |
| $\phi$ | 비선형 활성화 함수 |

&ensp;비선형 활성화 함수를 사용하면 단순한 입력을 더 유용한 표현으로 변환할 수 있고, 복잡한 데이터 구조를 학습할 수 있다.<br/>

---

&ensp;7. 이미지에서의 표현학습<br/>
&ensp;이미지의 입력은 픽셀값이며 CNN은 층이 깊어질수록 더 복잡한 특징을 학습한다.<br/>

| CNN 층 | 학습되는 표현 |
| --- | --- |
| 초기 층 | 선, 엣지 |
| 중간 층 | 질감, 패턴 |
| 깊은 층 | 객체, 결함, 구조 |

&ensp;제품 표면 이미지의 경우 원본 픽셀만으로는 흠집을 직접 설명하기 어렵지만, CNN은 흠집을 구분하는 특징맵을 자동으로 학습할 수 있다.<br/>

---

&ensp;8. IoT 센서에서의 표현학습<br/>

| 단계 | 예시 |
| --- | --- |
| 원본 센서값 | 온도, 진동, 전류 |
| 수작업 특징 | 평균 온도, 진동 표준편차, 전류 변화량, 온도×진동 |
| 학습된 표현 | 신경망 은닉층 벡터, 오토인코더 잠재벡터, 시계열 모델 hidden state |

&ensp;이러한 표현은 상태 분류, 이상 탐지, 예측, 군집화에 활용할 수 있다.<br/>

---

&ensp;9. 온도와 진동의 조합으로 나타나는 이상 상태<br/>
&ensp;강의자료에서는 온도와 진동을 이용해 모터 상태를 판단하는 예를 제시한다.<br/>

| 온도 | 진동 | 상태 |
| ---: | ---: | --- |
| 35 | 0.03 | 정상 |
| 36 | 0.04 | 정상 |
| 37 | 0.05 | 정상 |
| 40 | 0.06 | 정상 |
| 42 | 0.08 | 주의 |
| 44 | 0.10 | 이상 |
| 45 | 0.12 | 이상 |

&ensp;온도만 보면 정상 범위이고 진동만 봐도 정상 범위일 수 있지만, **두 값이 동시에 높아지면 이상 가능성이 증가할 수 있다.**<br/>
&ensp;이처럼 표현 공간을 바꾸면 정상과 이상을 더 쉽게 구분할 수 있다.<br/>

---

&ensp;10. 비선형 특징 추가 전후 비교<br/>
&ensp;강의 실습에서는 로지스틱 회귀에 원본 특징과 비선형 특징을 각각 사용하여 분류 결과를 비교한다.<br/>

&ensp;원본 특징<br/>
* 온도
* 진동

&ensp;추가한 비선형 특징<br/>

$$
온도\times진동
$$

&ensp;이 특징은 온도와 진동이 동시에 커지는 상황을 더 명확하게 표현한다.<br/>
&ensp;원본 특징만으로도 분류가 가능할 수 있지만, 비선형 특징을 추가하면 결정 경계가 더 명확해질 수 있으며 실제 데이터에서는 성능 향상에 도움이 될 수 있다.<br/>

> 좋은 표현은 모델이 데이터를 더 쉽게 구분하도록 도와준다.

# 표현 기반 이상 탐지

&ensp;1. 표현 기반 이상 탐지란?<br/>
&ensp;표현 기반 이상 탐지는 **원본 데이터가 아니라 변환된 표현 공간에서 이상 여부를 판단하는 방법**이다.<br/>

&ensp;기본 아이디어<br/>
* 정상 데이터는 표현 공간에서 일정한 구조를 가진다.
* 이상 데이터는 그 구조에서 벗어난다.

&ensp;예를 들어 정상 설비 데이터가 특정 영역에 모여 있다면, 그 영역에서 멀리 떨어진 데이터를 이상 데이터로 볼 수 있다.<br/>

---

&ensp;2. 원본 공간 이상 탐지의 한계<br/>
&ensp;원본 공간은 온도, 진동, 전류 같은 센서값을 그대로 사용하는 공간이다.<br/>

&ensp;한계<br/>
* 센서 수가 많으면 해석이 어렵다.
* 센서마다 단위 차이가 크다.
* 센서 간 상관관계가 복잡하다.
* 각각의 센서는 정상처럼 보여도 센서들의 조합은 이상일 수 있다.

&ensp;예를 들어 온도, 진동, 전류가 각각 정상 범위에 있어도 세 값의 조합이 평소와 다르면 이상 상태일 수 있다.<br/>

---

&ensp;3. 표현 공간에서의 이상 탐지<br/>
&ensp;표현 공간은 원본 데이터를 변환한 공간이다.<br/>

&ensp;사용할 수 있는 방법<br/>
* PCA
* Autoencoder
* 신경망 은닉층
* 임베딩 벡터

&ensp;장점<br/>
* 중요한 구조를 요약할 수 있다.
* 차원을 줄일 수 있다.
* 정상 패턴을 더 명확히 표현할 수 있다.
* 이상 데이터를 정상 구조에서 벗어난 점으로 볼 수 있다.

---

&ensp;4. 정상 중심 기반 이상 탐지<br/>
&ensp;정상 데이터의 표현 벡터 평균을 **정상 중심**으로 설정한다.<br/>

$$
c=\frac{1}{n}\sum_{i=1}^{n}z_i
$$

| 기호 | 의미 |
| --- | --- |
| $z_i$ | 표현 공간에서의 정상 데이터 벡터 |
| $c$ | 정상 데이터의 중심 |
| $z_{current}$ | 현재 데이터의 표현 벡터 |

&ensp;현재 데이터와 정상 중심 사이의 거리는 다음과 같이 계산한다.<br/>

$$
d=\lVert z_{current}-c\rVert
$$

&ensp;판단<br/>
* 거리가 작다 → 정상일 가능성이 높다.
* 거리가 크다 → 이상일 가능성이 높다.

---

&ensp;5. PCA 기반 이상 탐지<br/>
&ensp;PCA는 정상 데이터의 주요 변화 방향을 찾고, 고차원 데이터를 더 낮은 차원의 표현으로 변환한다.<br/>

&ensp;과정<br/>
1. 정상 데이터를 수집한다.
2. 데이터를 정규화한다.
3. PCA를 학습한다.
4. 정상 데이터의 표현 공간 중심을 계산한다.
5. 현재 데이터를 같은 PCA 공간으로 변환한다.
6. 현재 데이터와 정상 중심 사이의 거리를 계산한다.

&ensp;장점<br/>
* 시각화가 가능하다.
* 계산이 비교적 간단하다.
* 정상 패턴에서 벗어난 데이터를 확인할 수 있다.

---

&ensp;6. 재구성 오차 기반 이상 탐지<br/>
&ensp;재구성은 **압축된 표현에서 다시 원본 데이터를 복원하는 과정**이다.<br/>
&ensp;정상 데이터만 학습한 모델은 정상 패턴은 잘 복원하지만, 정상과 다른 이상 패턴은 잘 복원하지 못할 수 있다.<br/>

&ensp;재구성 오차<br/>

$$
E=\lVert x-\hat{x}\rVert^2
$$

| 기호 | 의미 |
| --- | --- |
| $x$ | 원본 입력 |
| $\hat{x}$ | 복원된 입력 |
| $E$ | 재구성 오차 |

&ensp;판단<br/>
* 재구성 오차가 작다 → 정상
* 재구성 오차가 크다 → 이상 가능성이 높음

---

&ensp;7. 표현 기반 이상 탐지 활용<br/>

| 분야 | 활용 예시 |
| --- | --- |
| 스마트팩토리 | 설비 이상 탐지, 진동 패턴 변화 탐지, 제품 불량 패턴 탐지 |
| 스마트빌딩 | 에너지 사용 이상 탐지, 비정상 점유 패턴 탐지 |
| 스마트팜 | 환경 조건 이상 탐지, 작물 생육 패턴 이상 탐지 |
| 스마트시티 | 교통 흐름 이상 탐지, 센서 네트워크 이상 탐지 |

---

&ensp;8. 표현 기반 이상 탐지의 주의점<br/>

&ensp;표현 공간이 항상 좋은 것은 아니다.<br/>
* 잘못된 표현은 오히려 이상을 숨길 수 있다.

&ensp;정상 데이터 품질이 중요하다.<br/>
* 정상 데이터에 이상 데이터가 섞이면 정상 기준 자체가 왜곡될 수 있다.

&ensp;임계값 설정이 필요하다.<br/>
* 거리 또는 재구성 오차가 어느 정도 이상일 때 이상으로 판단할지 기준을 정해야 한다.

&ensp;도메인 해석이 필요하다.<br/>
* 표현 공간에서 정상 중심과 멀다고 해서 항상 실제 고장을 의미하지는 않는다.
* 센서 오류, 운전 조건 변화, 일시적 이벤트도 고려해야 한다.

---

&ensp;9. PCA 표현 공간을 이용한 설비 이상 탐지 예시<br/>
&ensp;스마트팩토리에서 모터의 온도, 진동, 전류, 압력, 소음을 수집한다고 가정한다.<br/>

&ensp;정상 데이터<br/>

| 온도 | 진동 | 전류 | 압력 | 소음 |
| ---: | ---: | ---: | ---: | ---: |
| 35 | 0.03 | 2.1 | 100 | 40 |
| 36 | 0.04 | 2.2 | 102 | 42 |
| 35 | 0.03 | 2.0 | 101 | 41 |
| 37 | 0.05 | 2.3 | 103 | 43 |

&ensp;현재 데이터<br/>

| 온도 | 진동 | 전류 | 압력 | 소음 |
| ---: | ---: | ---: | ---: | ---: |
| 50 | 0.25 | 4.8 | 122 | 75 |

&ensp;현재 데이터는 모든 센서값이 정상 데이터보다 높은 편이다.<br/>
&ensp;원본 공간에서는 5개의 특징을 동시에 비교해야 하지만, PCA를 사용하면 5차원 데이터를 2차원 표현 공간으로 축소할 수 있다.<br/>
&ensp;정상 데이터는 PCA 표현 공간에서 가까이 모이고, 현재 데이터는 정상 중심에서 멀어질 가능성이 크다.<br/>

---

&ensp;10. PCA 표현 공간에서 이상 탐지 실습 흐름<br/>
&ensp;강의 실습의 흐름은 다음과 같다.<br/>

1. 정상 설비 데이터를 준비한다.
2. 현재 상태 데이터를 준비한다.
3. `StandardScaler`를 정상 데이터에 `fit_transform()`하고 현재 데이터에는 `transform()`만 적용한다.
4. `PCA(n_components=2)`를 정상 데이터에 학습한다.
5. 정상 데이터와 현재 데이터를 같은 PCA 표현 공간으로 변환한다.
6. 정상 데이터의 PCA 표현 평균으로 정상 중심을 계산한다.
7. 현재 상태와 정상 중심 사이의 유클리드 거리를 계산한다.
8. 거리가 임계값보다 크면 이상 의심으로 판단한다.

&ensp;강의 예제에서는 임계값을 다음과 같이 설정한다.<br/>

```python
threshold = 3.0

if distance > threshold:
    print("판단 결과: 이상 의심")
else:
    print("판단 결과: 정상 범위")
```

> 표현 공간에서 정상 구조와 멀리 떨어진 데이터는 이상일 가능성이 있다.

# 시험 직전 핵심 정리

&ensp;1. 특징 · 특징 벡터 · 표현 · 표현 공간<br/>

| 개념 | 반드시 기억할 정의 |
| --- | --- |
| 특징 | 데이터를 설명하며 AI 모델이 입력으로 사용하는 핵심 변수 |
| 특징 벡터 | 여러 특징을 하나로 묶은 벡터 |
| 표현 | 원본 데이터를 모델이 이해하기 쉬운 수학적 형태로 바꾼 것 |
| 표현 공간 | 특징 벡터들이 위치하는 공간 |

---

&ensp;2. 입력 공간과 표현 공간<br/>

> 입력 공간 = 원본 특징이 놓인 공간<br/>
> 표현 공간 = 원본 특징을 변환한 뒤의 특징이 놓인 공간

---

&ensp;3. 표현학습<br/>

> 표현학습 = 모델이 데이터에서 유용한 특징 또는 표현을 자동으로 학습하는 과정

&ensp;대표 예<br/>
* 신경망 은닉층 벡터
* CNN 특징맵
* Autoencoder 잠재벡터
* Transformer 임베딩

---

&ensp;4. 비선형 특징이 필요한 이유<br/>
&ensp;선형 표현만으로는 복잡한 관계나 곡선형 패턴을 충분히 표현하기 어려울 수 있다.<br/>
&ensp;제곱항이나 곱항 같은 비선형 특징을 추가하면 원본 특징에서는 보이지 않던 구조를 드러낼 수 있다.<br/>

---

&ensp;5. 이상 탐지에서 가장 중요한 두 가지 기준<br/>

&ensp;정상 중심과의 거리<br/>

$$
c=\frac{1}{n}\sum_{i=1}^{n}z_i
$$

$$
d=\lVert z_{current}-c\rVert
$$

&ensp;재구성 오차<br/>

$$
E=\lVert x-\hat{x}\rVert^2
$$

&ensp;공통 해석<br/>
* 거리 또는 오차가 작다 → 정상 가능성이 높다.
* 거리 또는 오차가 크다 → 이상 가능성이 높다.

---

&ensp;6. PCA 기반 이상 탐지 순서<br/>

> 정상 데이터 수집 → 정규화 → PCA 학습 → 정상 중심 계산 → 현재 데이터를 같은 PCA 공간으로 변환 → 정상 중심과 거리 계산 → 임계값과 비교

---

&ensp;7. 꼭 구분해야 하는 포인트<br/>

| 구분 | 핵심 |
| --- | --- |
| 원본 특징 | 센서가 직접 측정한 값 |
| 가공 특징 | 원본 데이터에서 계산한 값 |
| 선형 표현 | 원본 특징 또는 가중합 중심 |
| 비선형 표현 | 제곱항, 곱항 등으로 복잡한 관계 표현 |
| 거리 기반 이상 탐지 | 정상 중심에서 얼마나 떨어졌는지 확인 |
| 재구성 오차 기반 이상 탐지 | 원본을 얼마나 잘 복원했는지 확인 |

---

&ensp;8. 강의자료 기준 핵심 문장<br/>
* 특징 공간에서는 데이터의 **유사성과 차이를 거리와 위치로 해석**할 수 있다.
* 좋은 표현은 모델이 데이터를 **더 쉽게 구분하도록** 도와준다.
* 표현학습은 사람이 모든 특징을 직접 설계하지 않고 모델이 **유용한 표현을 자동으로 학습**하도록 한다.
* 표현 기반 이상 탐지는 원본 데이터가 아니라 **변환된 표현 공간에서 정상 구조로부터 벗어났는지**를 판단한다.
* PCA 기반 이상 탐지에서는 **정규화, 정상 중심, 거리, 임계값**의 흐름을 기억해야 한다.
* 정상 데이터의 품질이 나쁘거나 임계값을 잘못 설정하면 이상 탐지 기준도 왜곡될 수 있다.
