# 손실함수와 학습 목표

&ensp;학습의 의미<br/>
&ensp;AI 모델의 학습은 입력 데이터와 정답 사이의 관계를 찾고, 모델의 예측값이 실제값에 가까워지도록 파라미터를 조정하는 과정이다.<br/>
&ensp;기본적인 모델 표현은 $\hat{y} = f(x; \theta)$ <br/>
* x: 입력 데이터
* f: 예측 모델
* $\theta$ : 모델 파라미터
* $\hat{y}$: 모델의 예측값

&ensp;학습의 목표<br/>
$$\hat{y} -> y$$

&ensp;예측값 $\hat{y}$ 가 실제값 y에 가까워지도록 만드는 것이다.<br/>

&ensp;오차(Error)<br/>
&ensp;오차는 실제값과 예측값의 차이이다.<br/>
$$e=y-\hat{y}$$

&ensp;예를 들어 실제 전력 사용량 y = 200, 예측 전력 사용량 $\hat{y} = 180$ 이면 $
e=200-180=20$ 이다. 모델이 실제값보다 20만큼 낮게 예측했다는 의미이다. 오차가 작을수록 예측이 정확하다.<br/>

----

&ensp;손실함수(Loss Function)<br/>

> 모델이 얼마나 틀렸는지를 숫자로 표현하는 함수

$$Loss = L(y, \hat{y})$$

&ensp;손실함수는 다음 역할을 한다.<br/>
* 학습 중 모델 성능 평가
* 파라미터를 어느 방향으로 수정할지 결정
* 학습 목표를 수학적으로 정의

&ensp;즉 손실이 작을수록 모델의 예측이 실제값에 가까운 것이다.<br/>

----

&ensp;회귀 문제의 손실함수<br/>
&ensp;회귀(Regression): 연속적인 숫자값을 예측하는 문제<br/>
&ensp;대표적인 손실함수는 MSE(Mean Squared Error) 평균제곱오차이다.<br/>

&ensp;MSE의 핵심 특징<br/>
&ensp;오차를 제곱하기 때문에 큰 오차에는 더 큰 패널티를 부여한다. 따라서 예측값이 실제값에 가까울수록 MSE가 작아진다.<br/>

&ensp;MSE 계산 예제<br/>

| 실제값 | 예측값 | 오차 |
|---:|---:|---:|
| 100 | 105 | -5 |
| 120 | 125 | -5 |
| 150 | 145 | 5 |
| 180 | 170 | 10 |
| 210 | 200 | 10 |

&ensp;오차를 제곱하면 25, 25, 25, 100, 100<br/>
&ensp;따라서 평균은 $\frac{25 + 25 + 25 + 100 + 100}{5} = 55$ 이다.<br/>
&ensp;error ** 2로 제곱오차를 구한 뒤 np.mean()으로 평균을 계산한다.<br/>

> 학습은 MSE와 같은 손실을 줄이는 방향으로 진행된다.

---

&ensp;분류 문제의 손실함수<br/>
&ensp;분류(Classification): 정해진 범주 중 하나를 예측하는 문제<br/>

&ensp;예:<br/>
* 정상 / 이상
* 고장 / 정상
* 위험 / 안전
* 저부하 / 중부하 / 고부하

&ensp;분류 모델은<br/>
* 예측 클래스
* 또는 각 클래스에 속할 확률

&ensp;을 출력할 수 있다.<br/>
&ensp;대표 손실함수는 Cross-Entropy Loss 이다.<br/>

---

&ensp;교차엔트로피 손실<br/>
&ensp;이진 분류에서<br/>
* y=1: 이상
* y=0: 정상
* $\hat{p}$ : 모델이 이상이라고 예측한 확률

&ensp;일 때 $L = -[y\log{(\hat{p})} + (1-y)\log{(1-\hat{p})}]$ 이다.<br/>

&ensp;Cross Entropy는 단순히 맞았다 / 틀렸다 만 보는 것이 아니다. 예측 확률의 신뢰도까지 반영한다.<br/>
* 정답 클래스에 낮은 확률 → 큰 손실
* 정답 클래스에 높은 확률 → 작은 손실

&ensp;따라서 분류 모델은 **정답 클래스의 확률을 높이는 방향** 으로 학습한다.<br/>
&ensp;**Cross Entropy는 단순 오분류뿐 아니라 예측 확률의 신뢰도까지 반영한다.** <br/>

---

&ensp;손실함수와 학습 목표<br/>
&ensp;모델 학습의 최종 목표는 **손실함수를 최소화하는 파라미터를 찾는 것** 이다.<br/>

$$\theta ^{*} = arg\underset{\theta}{min} L(y, \hat{y})$$

* $\theta^*$ : 가장 좋은 파라미터
* L: 손실함수

&ensp;학습 과정은 **모델 예측 → 실제값과 비교 → 손실 계산 → 손실이 줄어들도록 파라미터 수정** 순서로 진행된다.<br/>

# 경사하강법과 파라미터 업데이트

&ensp;파라미터(Parameter)<br/>
> 모델 내부에서 학습을 통해 조정되는 값

&ensp;선형회귀 모델을 예로 들면 $\hat{y} = wx + b$ <br/>
* w: 가중치(weight)
* b: 편향(bias)
* x: 입력
* $\hat{y}$ : 예측값

&ensp;학습의 목표는 좋은 w와 b를 찾는 것이다.<br/>

---

&ensp;파라미터가 예측에 미치는 영향<br/>
&ensp;모델이 $\hat{y} = wx$ 이고 x = 10이라면<br/> 
* w = 2 -> $\hat{y} = 2 \times 10 = 20$
* w=5 -> $\hat{y} = 5 \times 10 = 50$ 
&ensp;같은 입력이라도 **가중치가 달라지면 예측값도 달라진다.** <br/>
&ensp;따라서 학습은 적절한 가중치를 찾는 과정이다.<br/>

---

&ensp;최적화(Optimization)<br/>
&ensp;최적화는 **손실함수를 가장 작게 만드는 파라미터를 찾는 과정** 이다.<br/>

$$\underset{\theta}{min} L(\theta)$$

<p align="center"><img src="/assets/img/인공지능수학/5주차/5-1.png" width="600"></p>

&ensp;현재 파라미터 위치에서 어느 방향으로 이동해야 손실이 줄어드는가? 를 판단하는 과정이다.<br/>

&ensp;기울기(Gradient)<br/>
&ensp;기울기는 **손실함수가 파라미터 변화에 따라 얼마나 변하는지를 나타내는 값** 이다.<br/>
&ensp;가중치 w에 대해서는 $\frac{\partial L}{\partial w}$ 로 표현한다.<br/>

&ensp;기울기가 양수<br/>
$$\frac{\partial L}{\partial w}>0$$

&ensp;이면 w를 줄이는 방향으로 이동한다.<br/>

&ensp;기울기가 음수<br/>
$$\frac{\partial L}{\partial w}<0$$

&ensp;이면 w를 키우는 방향으로 이동한다.<br/>

> 기울기는 결국 파라미터를 어느 방향으로 수정해야 손실이 감소하는가? 를 알려준다.

---

&ensp;경사하강법(Gradient Descent)<br/>
&ensp;경사하강법은 **손실함수의 기울기를 이용해 파라미터를 반복적으로 수정하는 방법** 이다.<br/>

$$w_{\text{new}} = w_{\text{old}} -\eta\frac{\partial L}{\partial w}$$

* $w_{\text{old}}$ : 현재 가중치
* $w_{\text{new}}$ : 수정된 가중치
* $\eta$ : 학습률
* $\frac{\partial L}{\partial w}$ : 손실함수의 기울기

&ensp;경사하강법은 **기울기의 반대 방향** 으로 움직인다. 기울기가 손실이 증가하는 방향을 나타내기 때문에 그 반대로 이동해야 손실이 줄어든다.<br/>

<p align="center"><img src="/assets/img/인공지능수학/5주차/5-2.png" width="600"></p>

---

&ensp;학습률(Learning Rate)<br/>

&ensp;학습률 $\eta$ 는 **한 번 업데이트할 때 얼마나 크게 이동할지를 결정하는 값** 이다.<br/>

&ensp;학습률이 너무 작음<br/>
* 학습이 매우 느림
* 최적점까지 오래 걸림

&ensp;학습률이 너무 큼<br/>
* 최적점을 지나칠 수 있음
* 손실이 불안정하게 증가할 수 있음
* 학습이 발산할 수 있음

&ensp;적절한 학습률<br/>
* 손실을 안정적으로 감소
* 너무 느리지 않음
* 너무 불안정하지 않음

> 학습률이 크다고 무조건 학습이 빨리 잘 되는 것은 아니다.

<p align="center"><img src="/assets/img/인공지능수학/5주차/5-3.png" width="600"></p>

---

&ensp;경사하강법 계산 예제<br/>

&ensp;손실함수: $L(w) = (w - 3)^2$ <br/>
&ensp;이 함수는 $w=3$ 일 때 손실이 0으로 최소가 된다.<br/>

&ensp;기울기: $\frac{\partial L}{\partial w} = 2(w-3)$

&ensp;초기값 w = 0 이면 -6<br/>
&ensp;학습률 $\eta=0.1$ 이면 $w_{new} =w-\eta\frac{\partial L}{\partial w} =0-0.1(-6) = 0.6$ 이다.<br/>
&ensp;0 -> 0.6 으로 이동하면서 최적값 3에 가까워진다.<br/>

&ensp;반복 업데이트<br/>
&ensp;경사하강법은 한 번만 수행하는 것이 아니라 반복한다.<br/>
> 반복적인 파라미터 업데이트를 통해 모델은 점점 더 작은 손실을 가지는 방향으로 학습된다.

# 일반화와 실시간 학습

&ensp;일반화(Generalization)<br/>
&ensp;일반화는 **학습에 사용하지 않은 새로운 데이터에서도 잘 예측하는 능력** 이다.<br/>
&ensp;좋은 모델은<br/>
* 학습 데이터에서도 잘 맞고
* 새로운 데이터에서도 잘 맞아야 한다.

&ensp;특정 날짜의 전력 사용량만 잘 예측해서는 부족하며, 다른 날짜·계절·사용 패턴에서도 잘 예측해야 한다.<br/>

---

&ensp;훈련 데이터와 테스트 데이터<br/>
* 훈련 데이터: 모델이 학습할 때 사용하는 데이터
* 테스트 데이터: 학습에는 사용하지 않고 성능 평가에 사용하는 데이터

&ensp;데이터를 나누는 이유는 **모델이 새로운 데이터에서도 잘 작동하는지 확인하기 위해서** 이다.<br/>
&ensp;학습 데이터만 가지고 평가하면 실제 성능을 과대평가할 수 있다.<br/>
&ensp;전체 데이터 -> 훈련 데이터 + 테스트 데이터<br/>

---

&ensp;과소적합(Underfitting)<br/>
&ensp;과소적합은 **모델이 데이터의 기본 패턴도 충분히 학습하지 못한 상태** 이다.<br/>

&ensp;특징<br/>
* 훈련 데이터 성능 낮음
* 테스트 데이터 성능 낮음

&ensp;원인<br/>
* 모델이 너무 단순함
* 특징이 부족함
* 학습이 충분하지 않음

&ensp;IoT 예: 전력 사용량이 외부 온도, 사람 수, 시간대 등에 따라 달라지는데 온도 하나만 사용하는 경우가 있다.<br/>

---

&ensp;과적합(Overfitting)<br/>
&ensp;과적합은 **모델이 훈련 데이터에 지나치게 맞춰진 상태** 이다.<br/>
&ensp;학습 데이터의 노이즈까지 외운 상태라고도 볼 수 있다.<br/>

&ensp;특징<br/>
* 훈련 데이터 성능 → 매우 좋음
* 테스트 데이터 성능 → 낮음

&ensp;원인<br/>
* 모델이 너무 복잡함
* 데이터가 적음
* 노이즈가 많은 데이터를 그대로 학습

&ensp;IoT 예:<br/>
* 특정 날짜의 센서 오류까지 패턴으로 학습
* 특정 장비의 특수한 운전 조건만 외움

---

&ensp;과소적합 vs 과적합 vs 적절한 일반화<br/>

| 모델 상태 | 훈련 성능 | 테스트 성능 |
|---|---|---|
| **과소적합** | 낮음 | 낮음 |
| **과적합** | 높음 | 낮음 |
| **적절한 일반화** | 높음 | 높음 |

&ensp;적절한 일반화 모델<br/>
* 너무 단순하지 않음
* 너무 복잡하지 않음
* 핵심 패턴을 학습
* 노이즈는 지나치게 외우지 않음

> 훈련 데이터 손실과 테스트 데이터 손실이 모두 낮은 것

---

&ensp;데이터 분포 변화<br/>
&ensp;IoT 환경에서는 시간이 지나면서 데이터의 분포가 달라질 수 있다.<br/>
&ensp;예<br/>
* 여름 ↔ 겨울의 전력 사용 패턴 변화
* 새 장비 도입으로 센서값 범위 변화
* 설비 노후화로 진동 패턴 변화
* 사용자 행동 변화
* 제어 정책 변경

> 과거 데이터로 학습한 모델이 현재 환경에 맞지 않을 수 있다.

&ensp;해결방법<br/>
* 모델 성능 모니터링
* 주기적 재학습
* 실시간 업데이트
* 이상 분포 감지

---

&ensp;실시간 학습<br/>
&ensp;실시간 학습은 **새로운 데이터가 들어올 때 모델을 지속적으로 업데이트하는 방식** 이다.<br/>

&ensp;필요한 상황<br/>
* 데이터가 빠르게 변하는 환경
* 계절 변화
* 설비 상태 변화
* 사용자 패턴 변화
* 최신 데이터 반영이 중요한 시스템

&ensp;IoT 예시<br/>
* 스마트빌딩 에너지 관리
* 공장 설비 예지보전
* 교통량 예측
* 스마트팜 환경 제어

&ensp;실시간 학습의 장점과 주의점<br/>
&ensp;장점<br/>
* 최신 패턴 반영 가능
* 환경 변화에 빠르게 대응
* 장기적인 성능 저하 방지

&ensp;주의점<br/>
* 잘못된 데이터가 들어오면 모델이 오염될 수 있음
* 이상값이나 센서 오류를 그대로 학습할 수 있음
* 너무 자주 업데이트하면 모델이 불안정해질 수 있음
* 기존에 잘 학습한 패턴을 잊을 수 있음

&ensp;따라서 필요한 요소는 데이터 품질 확인, 성능 모니터링, 재학습 기준, 안전한 모델 배포 절차이다.<br/>
