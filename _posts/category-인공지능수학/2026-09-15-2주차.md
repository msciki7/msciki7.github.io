# 벡터와 행렬 기반 데이터 구조

&ensp;여기서br/>
* 1. AI 모델과 데이터 표현<br/>
&ensp;AI 모델은 현실의 상태를 그대로 이해하는 것이 아니라, 기본적으로 숫자로 표현된 데이터를 입력으로 사용한다.<br/>
&ensp;예를 들어 스마트팩토리에서<br/>
* “모터가 뜨거워지고 있다”
* “진동이 커졌다”

&ensp;라는 상태가 있다면 AI에는 다음과 같이 숫자로 바꾸어 입력해야 한다.<br/>
* 모터 온도 = 82.5
* 진동 RMS = 0.18

&ensp;따라서 IoT 데이터가 AI 모델에 들어가는 과정은 **현실 상태 → 센서 측정 → 숫자 데이터 → 벡터/행렬 → AI 모델 → 예측/판단** 의 구조를 가진다.<br/>

&ensp;핵심<br/>
&ensp;AI에서 중요한 것은 단순히 값을 측정하는 것이 아니라, 현실의 상태를 숫자로 바꾸고 일정한 구조로 정리하는 것이다.<br/>

---

&ensp;2. 벡터로 한 시점의 상태 표현하기<br/>

&ensp;2-1. 상태 벡터<br/>
&ensp;한 시점에서 여러 센서가 측정한 값을 하나로 묶으면 **벡터(Vector)** 가 된다.<br/>
&ensp;예를 들어 한 시점의 스마트온실 상태가<br/>
* 온도 = 24
* 습도 = 60
* 조도 = 300
* CO₂ = 700

&ensp;이라면<br/>

&ensp;이 벡터 하나가 특정 시점의 시스템 상태를 나타낸다.<br/>

&ensp;2-2. 벡터와 샘플<br/>
&ensp;AI 모델에서 보통 **벡터 하나 = 샘플 하나** 로 생각할 수 있다.<br/>
&ensp;예를 들어 설비 상태가<br/>
<p align="center"><img src="/assets/img/인공지능수학/2주차/2-2.png" width="600"></p>

&ensp;이고 해당 설비가 정상이라면<br/>
$$y_1 = 정상$$

&ensp;이 된다.<br/>
&ensp;지도학습 데이터는 일반적으로 $(x_1​, y_1​), (x_2​, y_2​), … , (x_n​, y_n​)$ 형태로 구성된다.<br/>

* $x_i$ : 입력 벡터
* $y_i$ : 정답

&ensp;핵심: x -> y라는 관계를 학습하는 것이 지도학습의 기본 구조다.<br/>

&ensp;3. 행렬로 여러 데이터를 표현하기<br/>
&ensp;3-1. 센서 로그와 행렬<br/>
&ensp;IoT 센서는 한 번만 값을 측정하는 것이 아니라 시간에 따라 계속 값을 수집한다.<br/>
&ensp;예를 들어<br/>

| ----- | ---: | ---: | --: | ----: |
| 10:00 | 35.2 | 0.04 | 2.1 | 100.5 |
| 10:01 | 35.5 | 0.04 | 2.2 | 101.0 |
| 10:02 | 36.0 | 0.05 | 2.3 | 101.5 |
| 10:03 | 42.0 | 0.12 | 3.5 | 115.0 |

&ensp;이 데이터를 행렬로 나타내면<br/>
<p align="center"><img src="/assets/img/인공지능수학/2주차/2-3.png" width="600"></p>

&ensp;이 된다.<br/>
&ensp;여기서는<br/>

* 열(column) = 센서 종류

> 여러 시점의 상태 벡터를 쌓으면 하나의 행렬이 된다.

---

&ensp;5. 텐서를 이용한 복잡한 데이터 표현<br/>
&ensp;시간, 장비, 센서가 모두 존재하면 행렬만으로 표현하기 어려워진다.<br/>
&ensp;예를 들어<br/>
* 시간 = 100개
* 장비 = 10개
* 센서 = 3개

&ensp;라면 $X \in \mathbb{R}^{100 \times 10 \times 3}$ 으로 표현할 수 있다.<br/>

&ensp;각 축은 1. 시간 2. 장비 3. 센서 특징을 의미한다.<br/>
&ensp;이처럼 3개 이상의 축을 가지는 데이터를 텐서(Tensor) 라고 한다.<br/>

&ensp;구조 정리<br/>
* 숫자 하나 → Scalar
* 숫자들의 1차원 배열 → Vector
* 2차원 배열 → Matrix
* 3차원 이상 → Tensor

# 평균과 분산으로 상태 이해

&ensp;1. 평균<br/>
&ensp;평균은 데이터의 대표적인 수준을 나타낸다.<br/>

$$\mu = \frac{1}{n}\sum ^{n}_{i=1} x_i$$

&ensp;예를 들어 모터 온도의 평균이 높아졌다면 모터가 전반적으로 높은 온도에서 동작하고 있다. 라고 해석할 수 있다.<br/>
&ensp;평균으로 알 수 있는 것: 시스템이 대체로 어느 수준에 있는가<br/>

---

&ensp;2. 분산<br/>
&ensp;분산은 값이 평균을 중심으로 얼마나 흔들리는지를 나타낸다.<br/>

$$\sigma ^2 = \frac{1}{n}\sum ^{n}_{i=1}(x_i - \mu )^2$$

&ensp;분산이 작다.<br/>
* 값들이 평균 주변에 모여 있음. → 상대적으로 안정적인 상태

&ensp;분산이 크다.<br/>
* 값들이 평균으로부터 크게 떨어져 있음. → 변동성이 큰 상태

---

&ensp;3. 평균과 분산은 함께 봐야 한다.<br/>

&ensp;예를 들어<br/>
<p align="center"><img src="/assets/img/인공지능수학/2주차/2-7.png" width="600"></p>

&ensp;둘 다 평균은 40도이다.<br/>
* Motor A → 39~41도
* Motor B → 32~50도
&ensp;-> 상태는 완전히 다르다.<br/>

&ensp;해석<br/>
* Motor A는 안정적
* Motor B는 제어 불안정, 부하 변화, 센서 문제, 고장 징후 등이 있을 가능성이 있다.

> 평균이 같다고 해서 데이터의 상태까지 같은 것은 아니다.

&ensp;4. 평균과 분산의 동시 해석<br/>

| 평균 | 분산 | 해석           |
| -- | -- | ------------ |
| 낮음 | 낮음 | 안정적인 낮은 상태   |
| 높음 | 낮음 | 안정적으로 높은 상태  |
| 낮음 | 높음 | 평균은 낮지만 변동 큼 |
| 높음 | 높음 | 높은 수준에서 불안정  |

&ensp;5. 표준편차<br/>
&ensp;표준편차는 분산의 제곱근이다.<br/>
$$\sigma = \sqrt{\sigma ^2}$$

&ensp;분산은 값의 단위가 제곱되기 때문에 직관적으로 해석하기 어렵다. 표준편차는 다시 원래 데이터와 동일한 단위를 가지므로 **센서값이 평균을 중심으로 어느 정도 흔들리는지를 직관적으로 해석** 할 수 있다.<br/>

---

&ensp;6. 이동평균과 이동분산<br/>
&ensp;전체 평균은 전체 기간을 하나의 값으로 요약하기 때문에 최근 변화에 약하다. 그래서 일정한 최근 구간만 계산하는 방법을 사용한다.<br/>

&ensp;이동평균: 최근 일정 구간의 평균을 계속 계산한다. 예를 들어 최근 3개 값의 평균을 계속 구한다.<br/>
&ensp;목적: 최근 추세를 부드럽게 파악<br/>

&ensp;이동분산: 최근 일정 구간의 분산을 계산한다.<br/>
&ensp;목적: 최근에 변동성이 갑자기 증가했는지 파악<br/>
* 이동평균 → 최근 수준 변화
* 이동분산 → 최근 안정성 변화

&ensp;7. 평균·분산과 정규화<br/>

&ensp;센서마다 데이터 범위는 매우 다르다.<br/>
&ensp;예<br/>

| 센서 | 값의 범위     |
| -- | --------- |
| 온도 | 20~35     |
| 습도 | 30~90     |
| 전력 | 0~5000    |
| 진동 | 0.01~0.30 |

&ensp;이 상태에서 모델을 학습하면 값이 큰 센서가 과도한 영향을 줄 수 있다. 이를 해결하기 위해 표준화(stardardization)를 사용한다.<br/>

$$z = \frac{x - \mu}{\sigma }$$

&ensp;결과<br/>
&ensp;표준화 후 데이터는 평균 = 0, 표준편차 = 1 에 맞춰진다. 따라서 서로 다른 크기의 센서값을 비교하기 쉬워진다.<br/>

# 공분산과 상관계수로 관계 분석

&ensp;1. 센서 관계의 세 가지 유형<br/>
&ensp;양의 관계: 두 값이 같은 방향으로 움직인다.<br/>
&ensp;예:<br/>
* 외부 온도 ↑ → 냉방 전력 ↑
* 조도 ↑ → 온실 온도 ↑
* 생산 속도 ↑ → 전류 ↑

&ensp;음의 관계: 두 값이 반대 방향으로 움직인다.<br/>
&ensp;예:<br/>
* 냉방 세기 ↑ → 실내 온도 ↓
* 온도 ↑ → 상대 습도 ↓
* 배터리 사용량 ↑ → 잔여 배터리 ↓

&ensp;관계가 약한 경우: 한 센서의 변화와 다른 센서의 변화가 뚜렷하게 연결되지 않는다.<br/>

---

&ensp;2. 공분산<br/>
> 두 변수가 평균을 기준으로 함께 어느 방향으로 움직이는지를 나타낸다.

$$Cov(X, Y) = \frac{1}{n}\sum ^{n}_{i=1}(x_i - \mu_X)(y_i - \mu _Y)$$

&ensp;핵심: $(x_i - \mu_X)(y_i - \mu _Y)$ <br/>
&ensp;둘 다 평균보다 높음: (+)(+) = +<br/>
&ensp;둘 다 평균보다 낮음: (−)(−) = +<br/>
&ensp;→ 공분산이 양수가 된다.<br/>

&ensp;반대로 한쪽은 높고 한쪽은 낮으면 (+)(−)=−<br/>
&ensp;→ 공분산이 음수가 된다.<br/>

&ensp;공분산 부호 해석<br/>
* Cov(X,Y) > 0 → 같은 방향
* Cov(X,Y) < 0 → 반대 방향
* Cov(X,Y) ≈ 0 → 선형 관계가 약함

&ensp;3. 공분산 계산 예제<br/>
<p align="center"><img src="/assets/img/인공지능수학/2주차/2-8.png" width="600"></p>

&ensp;평균:<br/>
* $μ_X = 26$
* $μ_Y = 120$

&ensp;편차:<br/>
* $X - \mu _X = (-2, 0, 2)$
* $X - \mu _Y = (-20, 0, 20)$ 

&ensp;편차 곱:<br/>
&ensp;(−2)(−20), 0(0) , 2(20) = 40, 0, 40<br/>

&ensp;따라서<br/>
$$Cov(X, Y) = \frac{40 + 0 40}{3} = \frac{80}{3} \approx 26.67$$

&ensp;양수이므로 외부 온도와 전력 사용량은 같은 방향으로 움직이는 경향이 있다.<br/>

---

&ensp;4. 공분산의 한계<br/>
&ensp;공분산의 가장 큰 문제는 **관계의 방향은 알 수 있지만 강도를 비교하기 어렵다.** <br/>
&ensp;이유는 공분산이 단위와 값의 범위에 영향을 받기 때문이다.<br/>
&ensp;예를 들어 온도, 전력, 진동은 단위와 값의 크기가 전혀 다르다. 따라서 Cov = 100 이라고 해서 무조건 강한 관계라고 할 수 없다.
&ensp;이를 해결하기 위해 **상관계수**를 사용한다.<br/>

---

&ensp;5. 상관계수<br/>
&ensp;상관계수는 공분산을 표준화한 값이다.<br/>
$$r_{XY} = \frac{Cov(X, Y)}{\sigma _X, \sigma _Y}$$

&ensp;값의 범위는 -1 ≤ r ≤ 1 이다.<br/>

&ensp;상관계수 해석<br/>
<p align="center"><img src="/assets/img/인공지능수학/2주차/2-9.png" width="600"></p>

&ensp;6. 공분산 vs 상관계수<br/>

| 구분      | 공분산        | 상관계수    |
| ------- | ---------- | ------- |
| 목적      | 함께 움직이는 방향 | 방향 + 강도 |
| 범위      | 제한 없음      | -1 ~ 1  |
| 단위 영향   | 있음         | 없음      |
| 센서 간 비교 | 어려움        | 쉬움      |

> 상관계수 = 공분산을 표준화한 값

&ensp;7. 상관행렬<br/>
&ensp;센서가 여러 개라면 센서 쌍마다 상관계수를 계산할 수 있다. 이를 하나의 행렬로 정리한 것이 **상관행렬(Correlation Matrix)** 이다.<br/>
&ensp;예를 들어 강의자료의 상관행렬에서<br/>
* 온도–습도 = -0.90
* 온도–조도 = 0.85
* 온도–CO₂ = 0.20

&ensp;이라면<br/>
* 온도 ↔ 습도: 강한 음의 상관
* 온도 ↔ 조도: 강한 양의 상관
* 온도 ↔ CO₂: 상대적으로 약한 관계

&ensp;중요한 특징: 대각선은 자기 자신과의 상관이므로 항상 1 이다.<br/>

---

&ensp;8. 상관계수와 입력 변수 선택<br/>
&ensp;AI 모델에 센서를 많이 넣는다고 반드시 좋은 것은 아니다. 관련이 거의 없는 센서는 오히려 노이즈가 될 수 있다. 따라서 상관계수를 이용해 **예측 대상과 관련성이 높은 센서를 입력 후보로 선정** 할 수 있다.<br/>
&ensp;전력 사용량 예측 예:<br/>

| 입력 후보 | 전력 사용량과 상관계수 |
| ----- | -----------: |
| 외부 온도 |         0.88 |
| 사람 수  |         0.72 |
| 실내 온도 |         0.65 |
| 습도    |         0.20 |
| 조도    |         0.05 |

&ensp;따라서 외부 온도나 사람 수가 상대적으로 중요한 입력 후보가 될 수 있다. 하지만 **상관계수만으로 최종 입력 변수를 결정해서는 안 된다.** <br/>

---

&ensp;9. 상관관계 해석 시 주의사항<br/>
&ensp;① 상관관계 ≠ 인과관계<br/>
&ensp;두 데이터가 같이 움직인다고 해서 A가 B를 발생시킨다 고 단정할 수 없다. 제 3의 요ㅇ이  인 둘 모두에게 영향을 줄 수도 있다.<br/>

&ensp;② 비선형 관계를 놓칠 수 있다<br/>
&ensp;상관계수는 주로 선형 관계를 측정한다. 따라서 곡선형 관계가 있어도 r ≈ 0으로 나타날 수 있다.<br/>

&ensp;③ 이상값에 민감하다<br/>
&ensp;센서 오류 등 하나의 큰 이상값이 상관계수를 크게 왜곡할 수 있다.<br/>

&ensp;④ 시간 지연 관계<br/>
&ensp;예를 들어 조도가 증가하고 30분 후 온도가 증가 할 수도 있다. 같은 시점끼라만 비교하면 상관이 약하게 나타날 수 있다.<br/>

&ensp;⑤ 운영 조건에 따라 관계가 변할 수 있음<br/>
&ensp;예:<br/>
* 여름 vs 겨울
* 신규 설비 vs 노후 설비

&ensp;등의 조건에 따라 센서 관계가 달라질 수 있다.<br/>
