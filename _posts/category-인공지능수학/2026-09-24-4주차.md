# 회귀 기반 연속값 예측

&ensp;회귀(Regression): 회귀는 연속적인 숫자값을 예측하는 문제이다.<br/>
&ensp;IoT 환경에서는 다음과 같은 값을 예측할 수 있다.<br/>
* 전력 사용량 → 1320W
* 온도 → 27.5℃
* 진동 크기 → 0.12g
* 잔여 수명 → 120시간
* 생산량 → 530개

> 회귀 = 숫자를 예측

&ensp;반면 분류는 정상/이상처럼 미리 정해진 범주를 예측한다.<br/>

| 구분     | 회귀           | 분류       |
| ------ | ------------ | -------- |
| 예측 대상  | 연속값          | 범주       |
| 예시     | 1320W        | 정상/이상    |
| IoT 예시 | 다음 전력 사용량 예측 | 설비 상태 분류 |

---

&ensp;예측모델의 기본 구조<br/>
&ensp;예측모델은 주어진 데이터를 이용해 아직 모르는 값을 추정하는 모델이다. 입력 데이터와 출력값 사이의 관계를 학습한다. $\hat{y} = f(x)$ <br/>
* x: 입력 데이터
* f: 예측모델
* $\hat{y}$ : 모델이 예측한 값

## 선형회귀(Linear Regression)

&ensp;선형회귀: 입력과 출력 사이의 관계를 직선 또는 평면으로 표현하는 모델<br/>
&ensp;입력 변수가 하나라면: $\hat{y} = wx + b$ <br/>
* x: 입력 변수
* w: 가중치
* b: 편향
* $\hat{y}$ : 예측값

&ensp;가중치 w의 의미<br/>
&ensp;가중치는 입력 변수가 예측값에 미치는 영향을 나타낸다. 단순히 w가 크다고 해서 무조건 영향력이 크다고 해석해서는 안 된다. 왜냐하면 입력 변수의 단위와 스케일에 따라 가중치 크기의 해석이 달라질 수 있기 때문이다. 따라서 변수의 영향력을 해석하기 전에 정규화 여부를 확인해야 한다.<br/> 

---

&ensp;다중 선형회귀<br/>
&ensp;실제 IoT 문제에서는 입력 변수가 하나가 아니라 여러 개인 경우가 많다.<br/>
&ensp;예를 들어 스마트빌딩의 전력 사용량을 예측한다면:<br/>
* 외부 온도
* 실내 온도
* 사람 수
* 습도
* 현재 전력 사용량

&ensp;등을 입력으로 사용할 수 있다.<br/>

&ensp;수식은 다음과 같다.<br/>
$$\hat{y} = w_1x_1 + w_2x_2 + ... + w_dw_d + b$$

* $x_1, x_2, ..., x_d$ : 입력 변수
* $w_1, w_2, ..., w_d$: 각 입력 변수의 가중치
* b: 편향
* $\hat{y}$ : 예측값

&ensp;**여러 입력 변수의 가중합 + 편향 → 예측값** <br/>

---

&ensp;예측 오차<br/>
&ensp;모델의 예측값이 실제값과 항상 같지는 않다.<br/>
$$오차 = y - \hat{y}$$

* y: 실제값
* $\hat{y}$ : 예측값

&ensp;예를 들어 실제 전력 사용량 = 1200W, 예측 전력 사용량 = 1150W 라면 1200−1150=50. <br/>
&ensp;따라서 모델은 실제보다 50W 낮게 예측한 것이다.<br/>
&ensp;기본적으로 오차가 작을수록 좋은 모델이다.<br/>

---

&ensp;평균제곱오차(MSE)<br/>
&ensp;MSE: 회귀 모델에서 많이 사용하는 성능 기준이다.<br/>

$$MSE = \farc{1}{n}\sum\limits_{i=1}^{n}{(y_i - \hat{y}_i)^2}$$

&ensp;제곱하는 이유<br/>
1. 양수 오차와 음수 오차가 서로 상쇄되는 것을 방지
2. 큰 오차에 더 큰 패널티를 부여

> MSE가 작을수록 예측값이 실제값에 가까운 것

&ensp;**MSE가 작다 → 예측값과 실제값의 차이가 작다** <br/>

---

&ensp;선형회귀 실습 코드 흐름<br/>

&ensp;데이터 생성<br/>
```python
data = {
    "outside_temp": [...],
    "indoor_temp": [...],
    "people_count": [...],
    "power_usage": [...]
}
```

&ensp;입력 X와 정답 y 구성<br/>
```python
X = df[["outside_temp", "indoor_temp", "people_count"]]
y = df["power_usage"]
```

* X → 입력 변수
* y → 정답값

&ensp;학습/테스트 데이터 분리<br/>
```python
X_train = X.iloc[:-2]
y_train = y.iloc[:-2]

X_test = X.iloc[-2:]
y_test = y.iloc[-2:]
```

&ensp;모델 생성 및 학습<br/>
```python
model = LinearRegression()
model.fit(X_train, y_train)
```

&ensp;예측<br/>
```python
y_pred = model.predict(X_test)
```

&ensp;MSE 계산<br/>
```python
model.coef_
model.intercept_
```

&ensp;가중치와 편향 확인<br/>
```python
model.coef_
model.intercept_
```

&ensp;새로운 데이터 예측<br/>
```python
new_pred = model.predict(new_data)
```

&ensp;데이터 생성 → X/y 분리 → 학습/테스트 분리 → 모델 생성 → fit() 학습 → predict() 예측 → MSE 계산<br/>


# 분류와 결정경계 이해

&ensp;분류(Classification): 분류는 데이터를 미리 정해진 범주 중 하나로 나누는 문제이다.<br/>
&ensp;예<br/>
* 정상 / 이상
* 고장 / 정상
* 위험 / 안전
* 저부하 / 중부하 / 고부하
* 사람 있음 / 없음

> 회귀 = 숫자 예측, 분류 = 범주 예측

---

&ensp;이진 분류(Binary Classification): 클래스가 두 개인 분류 문제이다.<br/>
&ensp;예<br/>
* 정상 / 이상
* 침입 / 비침입
* 불량 / 정상
* 고장 / 정상

---

&ensp;다중 분류(Multi-class Classification)<br/>
&ensp;클래스가 3개 이상인 분류 문제이다.<br/>
&ensp;예<br/>
* 정상 / 주의 / 위험
* 저부하 / 중부하 / 고부하
* 대기 / 동작 / 오류 / 정지
* 고장 유형 A / B / C

---

&ensp;결정경계(Decision Boundary)<br/>
&ensp;결정경계는 서로 다른 클래스를 나누는 기준이다.<br/>
&ensp;차원에 따라 다음과 같이 표현된다.<br/>
* 2차원 → 선
* 3차원 → 평면
* 고차원 → 초평면

&ensp;온도 $x_1$ , 진동 $x_2$ 를 사용한다면 결정경계의 식: $w_1x_1 + w_2x_2 + b = 0$ <br/>
&ensp;결정경계를 기준으로 한쪽 영역은 정상, 다른 영역은 이상으로 판단할 수 있다.<br/>
> 결정경계 = 서로 다른 클래스를 구분하는 기준

## 로지스틱 회귀(Logistic Regression)

&ensp;로지스틱 회귀는 이진 분류에서 자주 사용하는 기본 모델이다.<br/>
&ensp;입력 변수의 선형 점수를 먼저 계산한다.<br/>

$$z = w^Tx + b$$

&ensp;그리고 이 값을 sigmoid 함수에 넣는다.<br/>
&ensp;최종 출력: $\hat{y} = \sigma (z)$ 이다.<br/>
&ensp;출력값의 의미: $\hat{y}$ 는 클래스 1일 확률이다. 예를 들어 설비 이상 탐지라면 $\hat{y} = 이상일 확률$ 로 해석할 수 있다.<br/>

&ensp;확률 기준값<br/>
&ensp;로지스틱 회귀의 출력은 0~1 사이의 확률값이다.<br/>

&ensp;기준값을 낮추는 경우<br/>
&ensp;고장을 놓치면 위험한 경우:<br/>
* 기준값을 낮춤
* 이상을 더 민감하게 탐지
* 대신 오탐이 증가할 수 있음

&ensp;기준값을 높이는 경우<br/>
&ensp;오탐 비용이 큰 경우:<br/>
* 기준값을 높임
* 더 확실한 경우에만 이상 판단

&ensp;기준값은 안전성, 비용, 오탐·미탐 위험 등을 고려하여 조정할 수 있다.<br/>

---

&ensp;오탐과 미탐<br/>
&ensp;분류에서는 두 가지 오류가 중요하다.<br/>
&ensp;오탐: 정상인데 이상이라고 판단 → 불필요한 경고, 점검 비용 증가<br/>
&ensp;미탐: 이상인데 정상이라고 판단  → 실제 고장을 놓침 → 안전 문제 발생 가능<br/>

---

&ensp;로지스틱 회귀 실습 코드 흐름<br/>
&ensp;입력과 정답<br/>
```python
X = df[["temperature", "vibration"]]
y = df["label"]
```

* X → 온도, 진동
* y → 정상/이상 라벨

&ensp;모델 생성 및 학습<br/>
```python
model = LogisticRegression()
model.fit(X, y)
```

&ensp;이상확률<br/>
```python
prob = model.predict_proba(X)[:, 1]
```

&ensp;→ 정상 또는 이상<br/>

&ensp;새로운 모터 상태<br/>
```python
new_prob = model.predict_proba(new_state)[:, 1]
new_pred = model.predict(new_state)
```

&ensp;→ 새로운 센서값에 대해 이상 확률과 예측 클래스를 구한다.<br/>

# PCA, 군집화로 구조 분석

&ensp;PCA·군집화로 구조 분석<br/>
&ensp;스마트팩토리 모터의 상태를 다음과 같이 표현할 수 있다.<br/>
$$x = (온도, 진동, 전류, 압력, 소음)$$

&ensp;즉 하나의 장비 상태가 5차원 벡터로 표현된다.<br/>
&ensp;센서 수가 많아지면:<br/>
* 시각화가 어려움
* 중요한 패턴을 직관적으로 보기 어려움
* 센서 간 중복 정보가 포함될 수 있음
* 정상·고부하·이상 상태가 섞일 수 있음

&ensp;따라서 **중요한 정보가 담긴 축을 찾거나 비슷한 상태끼리 묶는 방법** 이 필요하다.<br/>

---

&ensp;PCA(Principal Component Analysis)<br/>
&ensp;PCA는 고차원 데이터를 더 적은 차원으로 줄이는 방법이다.<br/>
> 데이터가 가장 많이 퍼져 있는 방향을 찾고, 그 방향을 새로운 축으로 사용하는 것

&ensp;주성분<br/>
* PC1: 데이터의 분산이 가장 큰 방향
* PC2: PC1과 직교하면서 남은 분산이 가장 큰 방향

<p align="center"><img src="/assets/img/인공지능수학/4주차/4-2.png" width="600"></p>

> PC1 → 가장 많은 분산, PC2 → 그다음으로 많은 분산

&ensp;PCA와 공분산행렬<br/>
&ensp;PCA는 데이터의 퍼짐을 분석한다.<br/>
* 변수 하나의 퍼짐 → 분산
* 두 변수의 함께 움직임 → 공분산

&ensp;이를 행렬로 표현한 것이 공분산행렬이다.<br/>

<p align="center"><img src="/assets/img/인공지능수학/4주차/4-1.png" width="600"></p>

&ensp;행렬의 의미<br/>
* 대각선 원소 → 각 변수의 분산
* 비대각선 원소 → 변수 간 공분산

&ensp;공분산행렬에는 데이터가 어떤 방향으로 퍼져 있는지가 담겨 있으며, PCA는 이를 이용해 중요한 방향을 찾는다.<br/>

&ensp;고유값과 고유벡터<br/>
&ensp;PCA는 수학적으로 고유값(Eigenvalue)과 고유벡터(Eigenvector)와 연결된다.<br/>
$$\sum v = \lambda v$$

* Σ: 공분산행렬
* v: 고유벡터
* $\lambda$ : 고유값

&ensp;고유벡터 → 데이터가 퍼진 주요 방향<br/>
&ensp;고유값 → 해당 방향으로 데이터가 얼마나 많이 퍼져 있는지<br/>

> 고유값이 큰 주성분일수록 더 많은 정보를 담고 있다.

---

&ensp;PCA 차원축소<br/>
&ensp;예를 들어 5차원 센서 데이터를 2차원으로 줄일 수 있다. 이때 중요한 정보는 최대한 유지하면서 차원을 줄인다.<br/>
* 시각화가 쉬워짐
* 군집 분석이 쉬워짐

&ensp;PCA 변환 과정<br/>
&ensp;원본 데이터 준비: $X \in R^{n \times D}$ <br/>
&ensp;평균 중심화: $X_c = X - \mu$ <br/>
&ensp;공분산행렬 계산: $\sum = \frac{1}{n}X^T_cX_c$ <br/>
&ensp;고유값, 고유벡터 계산: $\sum v= \lambda v$ <br/>

&ensp;큰 고유값의 고유벡터 선택<br/>
&ensp;새로운 축으로 데이터 투영: $Z = X_cW$ <br/>
* X: 원본 센서 데이터
* $X_c$ : 평균을 뺀 데이터
* W: 선택된 주성분 방향
* Z: PCA로 변환된 저차원 데이터

&ensp;**평균 중심화 → 공분산행렬 → 고유값·고유벡터 → 큰 고유값 선택 → 데이터 투영** <br/>

---

&ensp;PCA의 IoT 해석<br/>
&ensp;예를 들어 센서가 x=(온도,진동,전류,압력,소음) 이라면 PCA 이후 z=(PC1, PC2) 로 표현할 수 있다. <br/>

&ensp;PC1<br/>
&ensp;설비 부하 수준을 나타내는 축일 수 있음<br/>
* 온도, 전류, 압력 등이 함께 증가하는 방향

&ensp;PC2<br/>
&ensp;진동이나 소음 중심의 불안정성을 나타내는 축일 수 있음<br/>
* 고장 전조와 관련될 수 있음

&ensp;PCA 결과는 도메인 지식과 함께 해석해야 한다.<br/>

---

&ensp;군집화(Clustering)<br/>
&ensp;군집화는 정답 라벨 없이 비슷한 데이터끼리 묶는 방법이다.<br/>
> 비지도 학습

&ensp;학습 아이디어:<br/>
* 서로 가까운 데이터 → 같은 상태일 가능성이 높음
* 서로 멀리 떨어진 데이터 → 다른 상태일 가능성이 높음

&ensp;IoT에서는:<br/>
* 설비 운전 상태 그룹화
* 센서 패턴 유형 발견
* 사용자 에너지 사용 패턴 분석
* 교통 흐름 패턴 분류

---

&ensp;K-means<br/>
&ensp;데이터를 K개의 군집으로 나누는 대표적인 군집화 알고리즘이다. 각 군집은 중심점 $c_k$ 를 갖는다. 각 데이터는 가장 가까운 중심에 할당된다.<br/>

&ensp;K-means 기본 과정<br/>
1. 군집 개수 K 설정
2. 초기 중심점 선택
3. 각 데이터를 가장 가까운 중심에 할당
4. 각 군집의 평균으로 중심점 갱신
5. 중심이 거의 변하지 않을 때까지 반복

> 중심 선택 → 데이터 할당 → 중심 갱신 → 반복

&ensp;K-means 목적함수<br/>
&ensp;K-means는 각 데이터가 자기 군집 중심과 최대한 가까워지도록 군집을 구성한다.<br/>
&ensp;목적함수<br/>
$$J = \sum\limits_{k=1}^{K}\sum\limits_{x_i \in C_k}{||x_i - c_k||^2}$$

* J: 전체 군집화 오차
* $C_k$ : k번째 군집
* $c_k$ : k번째 군집 중심
* $x_i$ : 데이터 샘플

&ensp;군집 중심은 해당 군집 데이터의 평균으로 계산한다.<br/>
$$c_k = \frac{1}{|C_k|} \sum\limits_{x_i \in C_k}{x_i}$$

&ensp;따라서 K-means는 군집 내부 거리를 줄이는 방향으로 반복 학습한다.<br/>

---

&ensp;PCA + K-means<br/>
&ensp;전체 흐름<br/>
&ensp;고차원 센서 데이터 -> PCA로 2차원 축소 ->  K-means 군집화 -> 상태 그룹 해석<br/>

&ensp;이렇게 하면:<br/>
* 고차원 데이터를 2차원으로 시각화
* 군집 구조를 눈으로 확인
* 정상 / 고부하 / 이상 후보 그룹 발견

&ensp;등이 가능하다.<br/>

&ensp;PCA와 K-means가 자동으로 의미를 붙여주는 것은 아니다. **센서 평균값과 도메인 지식을 이용해 군집의 의미를 해석해야 한다.** <br/>

&ensp;PCA + K-means 실습 코드 흐름<br/>

&ensp;데이터 생성<br/>
```python
df = pd.DataFrame(data)
```

&ensp;정규화<br/>
```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)
```

&ensp;PCA로 2차원 축소<br/>
```python
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
```

&ensp;설명 분산 비율 확인<br/>
```python
pca.explained_variance_ratio_
```

&ensp;K-means<br/>
```python
kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

clusters = kmeans.fit_predict(X_pca)
```

&ensp;결과 확인<br/>
```python
df["cluster"] = clusters
```

&ensp;그리고 PCA 결과를 시각화하고 군집별 평균 센서값을 확인한다.<br/>
