# 데이터 구조와 센서 로그 이해

&ensp;1. 데이터란?<br/>
&ensp;데이터는 현실 세계의 상태, 사건, 변화를 기록한 정보다. 예를 들어 현실의 현상을 데이터로 바꾸면 다음처럼 볼 수 있다.<br/>

| 현실 현상          | 데이터 표현      |
| -------------- | ----------- |
| 강의실이 덥다        | 온도 29℃      |
| 공장 모터가 많이 흔들린다 | 진동 0.25g    |
| 전력 사용량이 증가한다   | 전력 1,800W   |
| 사람이 빠르게 이동한다   | 속도 1.5m/s   |
| CCTV에 차량이 보인다  | 이미지 픽셀 배열   |
| 장비에 오류가 발생했다   | 오류 코드 E-102 |

&ensp;핵심<br/>
&ensp;**데이터 = 현실 그 자체가 아니다.**<br/>
&ensp;현실을 측정하거나 기록한 표현일 뿐이다. 따라서 인공지능은 현실 자체를 이해하는 것이 아니라 데이터로 표현된 현실을 학습한다.<br/>

---

&ensp;2. IoT 데이터<br/>
&ensp;IoT(Internet of Things)는 다양한 사물이나 장치가 인터넷에 연결되어 데이터를 수집하고 주고받는 환경이다. IoT 데이터는 사람이 직접 입력하지 않아도 자동으로 생성되고 시간에 따라 계속 쌓인다. 대표적인 특징은 **자동 생성, 지속적인 누적, 여러 센서의 동시 측정, 실제 시스템 상태와의 직접 연결, 결측값, 노이지, 통신 지연 발생 가능성** 이다.<br/>
&ensp;예를 들어 스마트팩토리에서는 온도, 진동, 전류, 압력, 생산량, 장비 로그 등을 수집할 수 있다.<br/>
&ensp;단순히 숫자 몇 개가 있는 것이 아니라, 시간에 따라 시스템 상태가 어떻게 변하는지 보여주는 데이터라고 이해해야 한다.<br/>

---

&ensp;3. 센서 로그<br/>
&ensp;센서 로그는 센서가 시간 순서에 따라 기록한 데이터이다. IoT 데이터를 분석할 때 가장 기본적인 형태다. 센서 로그에는 일반적으로 다음 정보가 포함된다.<br/>

| 구성 요소 | 의미          | 예시         |
| ----- | ----------- | ---------- |
| 시간    | 데이터가 측정된 시점 | 10:00      |
| 장치 ID | 측정 장치 또는 설비 | Motor_01   |
| 센서 종류 | 측정 항목       | 온도, 진동, 전류 |
| 측정값   | 실제 측정된 숫자   | 35.2       |
| 상태 라벨 | 정상/주의/이상    | 정상         |

---

&ensp;4. 센서 로그의 중요한 특징<br/>
&ensp;시간 순서<br/>
&ensp;센서 데이터는 시간에 따라 연속적으로 쌓이기 때문에 시계열 데이터가 된다.<br/>
&ensp;예를 들어 23.1→23.2→23.4→24.0 처럼 온도가 변화한다면 단순히 네 개의 숫자가 있는 게 아니라 시간에 따른 변화 패턴이 존재한다. 따라서 시간 순서가 뒤섞이면 패턴을 잘못 해석할 수 있다.<br/>
&ensp;여러 센서 동시 측정<br/>
&ensp;하나의 시스템에 여러 센서가 존재할 수 있다. 예를 들어 한 시점에 (23.1, 60, 1.2)라는 데이터가 있다면 이것은 (온도, 습도, 전력) 을 동시에 나타낸다. 이렇게 한 시점의 여러 센서값을 하나의 벡터로 볼 수 있다.<br/>
&ensp;예를 들어<br/>
| 시간    |    온도 |
| ----- | ----: |
| 10:00 |  23.1 |
| 10:01 |  23.2 |
| 10:02 | 999.0 |
| 10:03 |  23.3 |

&ensp;여기서 999.0은 실제 온도가 아니라 센서 오류일 가능성이 높다. 따라서 AI 모델을 적용하기 전에 **데이터 구조와 품질을 확인하고 전처리하는 과정** 이 중요하다.<br/>

---

&ensp;5. 데이터 유형<br/>

| 종류      | 특징                  | 예시               |
| ------- | ------------------- | ---------------- |
| 정형 데이터  | 행과 열이 명확함           | 센서 로그, 표         |
| 반정형 데이터 | 구조는 있지만 고정된 행·열이 아님 | JSON, XML        |
| 비정형 데이터 | 고정된 표 구조가 없음        | 이미지, 영상, 음성, 텍스트 |

&ensp;정형 데이터<br/>
&ensp;행과 열이 명확한 표 형태다. 예를 들어 센서로그는 대표적인 정형 데이터이다. 데이터베이스에 저장하기 쉽고 통계 분석이나 머신러닝 모델에 사용하기 좋다.<br/>

&ensp;반정형 데이터<br/>
&ensp;JSON처럼 일정한 구조는 있지만 표 형태는 아니다.<br/>

```json
{
  "device_id": "sensor_01",
  "time": "09:00",
  "temperature": 25,
  "humidity": 60
}
```

&ensp;IoT 장비가 서버에 데이터를 보낼 때 많이 사용한다.<br/>

&ensp;비정형 데이터<br/>
&ensp;표와 같은 고정된 구조가 없다. CCTV 영상은 픽셀 배열이고, 음성은 시간에 따른 파형이며, 텍스트는 단어의 순서와 의미를 가진다.<br/>

---

&ensp;6. 데이터 구조에 따라 AI 모델도 달라진다<br/>

| 데이터 유형  | 예시            | 주요 모델            |
| ------- | ------------- | ---------------- |
| 테이블 데이터 | 센서 로그, 고객 정보  | 회귀, 분류, 트리 모델    |
| 이미지 데이터 | CCTV, 비전 센서   | CNN              |
| 그래프 데이터 | 센서 네트워크, 전력망  | GNN              |
| 시계열 데이터 | 온도 변화, 전력 사용량 | RNN, Transformer |
| 생성 데이터  | 시뮬레이션, 복원     | VAE, Diffusion   |

> 데이터의 구조에 따라 적절한 수학적 표현과 AI 모델이 달라진다.

# 스칼라·벡터·행렬·텐서 표현

&ensp;1. 스칼라 Scalar<br/>
&ensp;스칼라는 숫자 하나다. 예를 들어 x = 25.3 은 현재 온도 하나를 나타낼 수 있다. 수학적으로는 x ∈ R 이라고 표현한다.<br/>
> x는 실수 하나다.

&ensp;예: 온도 25, 습도 60, 전력 1200, 진동 0.03 각각은 모두 스칼라다.<br/>

---

&ensp;2. 벡터 Vector<br/>
&ensp;벡터는 여러 개의 숫자를 순서 있게 묶은 것이다.<br/>
&ensp;예를 들어 한 시점에 온도=25, 습도=60, 전력=1200 이라면 x = (25, 60, 1200) 으로 표현할 수 있다. 일반적으로 $x = (x_1, x_2, ... , x_n)$  이라고 표현한다. 각 원소는 하나의 특징(feature)을 의미한다. 센서가 100개 있다면 한 시점의 데이터는 100차원 벡터가 된다.<br/>

---

&ensp;3. 벡터의 기하학적 의미<br/>
&ensp;벡터는 단순히 숫자를 묶은 것이 아니라 공간의 한 점으로 생각할 수도 있다. <br/>
&ensp;예를 들어 A=(25, 60), B=(26, 62) 라면 두 점이 공간상 가까이 있으므로 두 상태가 비슷하다고 볼 수 있다. 반면 C=(80, 10)은 훨씬 멀리 떨어져 있으므로 다른 상태라고 볼 수 있다.<br/>

---

&ensp;4. 행렬 Matrix<br/>
&ensp;행렬은 숫자를 행과 열로 배열한 2차원 구조다. 여러 시점의 벡터를 모으면 행렬이 된다.<br/>
&ensp;예를 들어<br/>

<p align="center"><img src="/assets/img/인공지능수학/1주차/1-1.png" width="600"></p>

* 행 = 시간 또는 샘플
* 열 = 센서 또는 특징

&ensp;행 기준<br/>
&ensp;첫 번째 행 [25, 60, 1200] 은 특정 시점은 전체 상태를 의미한다.<br/>
> 행 = 하나의 샘플 또는 한 시점의 상태

&ensp;열 기준<br/>
&ensp;첫 번째 열 [25, 26, 25]은 온도가 시간에 따라 어떻게 변했는지를 의미한다.<br/>
> 열 = 하나의 특징이 여러 샘플에서 어떻게 변하는지

---

&ensp;5. 텐서 Tensor<br/>
&ensp;텐서는 행렬보다 더 많은 축을 가진 배열이다.<br/>
&ensp;흑백 이미지<br/>
&ensp;높이 H, 너비 W를 가지므로 $X ∈ R^{H \times W}$ <br/>

&ensp;컬러 이미지<br/>
&ensp;RGB 세 개의 채널이 있기 때문에 $X ∈ R^{H\times W \times 3}$ <br/>

&ensp;영상<br/>
&ensp;영상은 시간에 따라 여러 이미지가 이어진 것이다. 따라서 시간 축 T가 추가되어 $X ∈ R^{T \times H \times W \times 3}$ 가 된다.<br/>
> 영상 = 시간에 따라 변하는 이미지들의 모음

----

&ensp;스칼라·벡터·행렬·텐서 한 번에 정리<br/>

| 구조  | 의미              | 예시             |
| --- | --------------- | -------------- |
| 스칼라 | 숫자 하나           | 현재 온도          |
| 벡터  | 여러 특징           | 한 시점의 온도·습도·전력 |
| 행렬  | 여러 벡터           | 여러 시간의 센서 로그   |
| 텐서  | 여러 축을 가진 고차원 배열 | 이미지, CCTV 영상   |

---

# 데이터에서 예측까지 전체 흐름

&ensp;1. 데이터 수집<br/>
&ensp;센서, 로그, 이미지, 영상 등으로부터 데이터를 얻는다.<br/>
&ensp;예를 들어 스마트팩토리에서는 온도, 진동, 전류 등을 시간과 함께 수집한다.<br/>

---

&ensp;2. 데이터 전처리<br/>
&ensp;수집된 데이터를 AI 모델이 사용할 수 있도록 정리한다.<br/>

| 문제       | 처리 방법            |
| -------- | ---------------- |
| 결측값      | 평균값 대체, 보간, 제거   |
| 이상값      | 확인 후 제거 또는 별도 표시 |
| 센서 단위 차이 | 정규화              |
| 노이즈      | 필터링              |
| 중복 기록    | 중복 제거            |
| 시간 불일치   | 시간 정렬            |

&ensp;특히 중요한 것: 정규화<br/>
&ensp;예를 들어 전력=1200, 진동=0.03 처럼 숫자의 크기가 크게 다르면 큰 값을 가진 특징이 과도하게 영향을 줄 수 있다. 따라서 단위나 값의 범위를 맞추기 위해 정규화가 필요할 수 있다.<br/>

---

&ensp;3. 특징 표현 Feature Representation<br/>
&ensp;전처리된 데이터를 모델이 사용할 수 있는 형태로 만든다. 기본적으로 x = (온도, 진동, 전류) 처럼 구성할 수 있다. 하지만 최근 변화가 중요하다면 x = (현재 온도, 평균 온도, 온도변화량, 진동, 전류)처럼 새로운 특징을 만들 수 있다. <br/>

> 좋은 특징 → 모델이 패턴을 쉽게 학습

---

&ensp;4. 모델 입력과 예측<br/>
&ensp;AI 모델의 기본 표현은 $\hat{y} = f(x; \theta )$ 이다.<br/>
&ensp;각 기호의 의미<br/>

| 기호         | 의미      |
| ---------- | ------- |
| $x$      | 입력 데이터  |
| $f$      | 모델      |
| $\theta$ | 모델 파라미터 |
| $\hat y$ | 모델의 예측값 |

&ensp;예를 들어 x = (온도, 진동, 전류) 를 모델에 넣으면 $\hat{y} = 정상$ 또는 $\hat{y} = 이상$ 을 출력할 수 있다.<br/>

---

&ensp;5. 회귀 Regression<br/>
&ensp;회귀는 **연속적인 숫자값을 예측하는 문제**이다.<br/>
&ensp;예를 들어 다음을 예측한다. 30분 후 전력 사용량, 다음 시간의 온도, 설비 잔여 수명, 배터리 잔량, 생산량 등 예측 결과가 숫자라면 대표적으로 회귀문제라고 볼 수 있다.<br/>

---

&ensp;6. 분류 Classification<br/>
&ensp;분류는 미리 정해진 범주 중 하나를 예측하는 문제 이다.<br/>
&ensp;예<br/>
* 정상/이상
* 고장/정상 
* 위험/안전 
* 저부하/중부하/고부하

&ensp;출력이 범주라는 것이 회귀와의 가장 큰 차이다.<br/>

---

&ensp;7. 시계열 예측<br/>
&ensp;시계열 예측은 **과거 여러 시점의 데이터를 이용해 미래 값을 예측하는 문제** 이다.<br/>
&ensp;예시<br/>
<p align="center"><img src="/assets/img/인공지능수학/1주차/1-2.png" width="600"></p>

&ensp;가 과거 3시간 데이터이고 y = 28이 다음 시간의 온도이다. 즉 과거 데이터 x -> 미래 값 y 형태이다.<br/>

---

&ensp;8. 이상 탐지 Anomaly Detection<br/>
&ensp;이상 탐지는 **현재 데이터가 정상 패턴에서 얼마나 벗어났는지를 판단하는 문제** 이다.<br/>
&ensp;예시<br/>
<p align="center"><img src="/assets/img/인공지능수학/1주차/1-3.png" width="600"></p>

&ensp;온도, 진동, 전류가 모두 정상 상태보다 크게 증가했기 때문에 설비 이상 가능성이 있다고 판단할 수 있다.<br/>

---

&ensp;회귀 vs 분류 vs 시계열 vs 이상 탐지<br/>

| 문제     | 핵심 질문         | 출력 예시        |
| ------ | ------------- | ------------ |
| 회귀     | 숫자가 얼마일까?     | 전력 1250W     |
| 분류     | 어느 범주일까?      | 정상 / 이상      |
| 시계열 예측 | 미래 값은 얼마일까?   | 다음 시간 온도 28℃ |
| 이상 탐지  | 정상 패턴에서 벗어났나? | 정상 / 이상 가능성  |

---

&ensp;9. 평가<br/>
&ensp;실제값과 예측값을 비교해야 한다.<br/>

&ensp;회귀<br/>
&ensp;실제값이 1200이고 예측값이 1150이라면 오차=50이다. 강의에서는 기본적으로 오차가 작을수록 좋은 모델이라고 설명한다.<br/>

&ensp;분류<br/>
&ensp;분류에서는 실제 상태와 예측 상태를 비교한다.<br/>

| 실제 | 예측 | 의미      |
| -- | -- | ------- |
| 정상 | 정상 | 정답      |
| 이상 | 정상 | 위험한 오류  |
| 이상 | 이상 | 정답      |
| 정상 | 이상 | 불필요한 경고 |

&ensp;특히 실제는 이상인데 정상이라고 판단하는 경우는 위험한 오류가 될 수 있다.<br/>

&ensp;10. 예측에서 제어까지<br/>
&ensp;IoT 시스템에서는 예측 자체가 최종 목표가 아니다 예측 결과를 이용해 실제 시스템을 제어할 수 있다. 예를 들어 10분 후 모터 온도 $90^∘C$ 라고 예측했다면 냉각 장치를 작동하거나, 설비 속도를 줄이거나, 유지보수 알림을 보내거나, 긴급 정지를 수행할 수 있다.<br/>
&ensp;따라서 데이터 -> 예측 -> 의사결정 -> 제어 까지 연결된다.<br/>
&ensp;다만 강의에서는 예측 결과를 무조건 바로 제어에 사용하는 것은 위험할 수 있다고 강조한다. 예측 오류가 실제 설비 제어 오류로 이어질 수 있기 때문에 예측 신뢰도, 안전 기준, 사람의 확인, 제어 정책 등을 함께 고려해야 한다.<br/>
