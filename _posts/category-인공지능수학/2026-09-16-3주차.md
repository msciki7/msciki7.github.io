# 상관성과 독립성 이해

&ensp: 1. 데이터 관계<br/>
&ensp;데이터 관계: 한 변수의 변화가 다른 변수의 변화와 함께 나타나는 정도를 의미한다.<br/>
&ensp;예를 들어<br/>
* 외부 온도 ↑ → 냉방 전력 ↑
* 조도 ↑ → 온실 온도 ↑
* 모터 진동 ↑ → 모터 온도 ↑
* 냉방 세기 ↑ → 실내 온도 ↓

&ensp;관계를 분석하는 이유<br/>
&ensp;IoT 환경에서는 관계 분석을 통해<br/>
* 예측에 중요한 센서를 찾고
* 시스템 상태 변화의 원인 후보를 찾고
* 센서 오류나 운영 조건 변화를 감지하고
* 이상 탐지에 사용할 정상 패턴을 파악할 수 있다.

---

&ensp;2. 상관성 Correlation<br/>
&ensp;개념<br/>
&ensp;두 변수가 함께 변하는 정도를 의미한다.<br/>
&ensp;일반적으로 상관계수 r로 표현한다.<br/>

$$r_{XY} = \frac{Cov(X, Y)}{\sigma _X \sigma _Y}$$

&ensp;개념<br/>
&ensp;두 변수가 함께 변하는 정도를 의미한다. 일반적인 상관계수 r로 표현한다.<br/>
> 두 변수가 얼마나 비슷한 방향으로 움직이는지를 하나의 숫자로 표현한 것.

&ensp;상관계수 해석<br/>

| 상관계수             | 의미          |
| ---------------- | ----------- |
| $r \approx 1$  | 강한 양의 선형 관계 |
| $r \approx -1$ | 강한 음의 선형 관계 |
| $r \approx 0$  | 선형 관계가 약함   |

&ensp;양의 상관<br/>
&ensp;한 변수가 증가할 때 다른 변수도 증가.<br/>

&ensp;예<br/>
* 외부 온도 ↑ → 냉방 전력 ↑
* 생산량 ↑ → 전류 ↑

&ensp;음의 상관<br/>
&ensp;한 변수가 증가할 때 다른 변수는 감소.<br/>
&ensp;예<br/>
* 냉방 세기 ↑ → 실내 온도 ↓
* 온도 ↑ → 상대습도 ↓

---

&ensp;3. 상관관계와 인과관계<br/>
&ensp;상관관계: 두 변수가 함께 움직이는 현상<br/>
&ensp;인과관계: 한 변수가 다른 변수의 원인이 되는 관계<br/>

&ensp;따라서 상관관계 ≠ 인과관계<br/>

&ensp;대표 예시<br/>
&ensp;여름철<br/>
* 아이스크림 판매량 ↑
* 냉방 전력 사용량 ↑

&ensp;잘못된 해석: 아이스크림을 많이 팔아서 냉방 전력이 증가했다.<br/>
&ensp;더 타당한 해석: 더운 날씨 때문에 아이스크림 판매량과 냉방 전력이 동시에 증가했을 수 있다.<br/>

&ensp;즉, 제3의 변수가 두 변수에 동시에 영향을 줄 수 있다. IoT에서도 마찬가지다. 진동과 전류가 함께 증가했다고 해서 "진동 증가가 전류 증가의 원인이다." 라고 바로 말할 수 없다. 실제로는 생산 속도 증가가 진동과 전류를 모두 증가시켰을 수도 있다.<br/>

---

&ensp;4. 독립성 Independence<br/>
&ensp;개념<br/>
&ensp;한 변수의 정보를 알아도 다른 변수에 대한 정보가 변하지 않는 상태<br/>
&ensp;수학적으로 $P(X, Y) = P(X)P(Y)$ <br/>
&ensp;또는 P(Y | X) = P(Y) 이다.<br/>

> X를 알아도 Y가 발생할 확률이 바뀌지 않는다.

&ensp;예시<br/>
&ensp;동전 던지기와 주사위 던지기를 생각해보자 동전이 앞면이 나왔다고 해서 주사위에서 6이 나올 확률이 바뀌는 것은 아니다. 따라서 두 사건은 독립적이다.<br/>

&ensp;IoT에서는?<br/>
&ensp;완전히 독립적인 센서를 찾기 어려운 경우가 많다.<br/>
&ensp;왜냐하면<br/>
* 온도
* 습도
* 전력
* 진동

&ensp;등이 같은 시스템 안에서 작동하기 때문이다.<br/>

&ensp;5. 상관성과 독립성의 차이<br/>

| 구분 | 상관성              | 독립성                      |
| -- | ---------------- | ------------------------ |
| 기준 | 선형 관계            | 확률분포 관계                  |
| 표현 | $r_{XY}$          |  $P(X,Y)=P(X)P(Y)$      |
| 의미 | 같이 증가·감소하는가      | 한 변수의 정보가 다른 변수에 정보를 주는가 |
| 주의 | $r=0$ 이어도 관계 가능 | 독립이면 상관계수는 0             |

&ensp;핵심은 독립 => 상관 없음. <br/>
&ensp;하지만 상관없음 ⇏ 독립 이라는 것이다.<br/>
&ensp;왜냐하면 상관계수는 주로 선형 관계를 측정하기 때문이다.<br/>

---

&ensp;6. 비선형 관계<br/>
&ensp;상관계수의 가장 중요한 한계다.<br/>
&ensp;대표 예시<br/>
$$Y = X^2$$

&ensp;X = [-2, -1, 0, 1, 2] 이면 Y = [4, 1, 0, 1, 4]이다. 분명히 $Y = X^2$ 라는 확실한 관계가 존재한다. 그런데 X가 증가한다고 Y가 계속 증가하거나 감소하는 것이 아니다. 그래서 선형 상관계수는 r ≈ 0 으로 나올 수 있다.<br/>

&ensp;하지만 r = 0 이라고 해서 관계까 없는 것은 아니다.<br/>

&ensp;IoT 예시<br/>
&ensp;모터 속도와 진동 관계가<br/>
* 너무 낮은 속도 → 진동 큼
* 중간 속도 → 안정
* 너무 높은 속도 → 진동 큼

&ensp;이라면 U자 형태가 된다. <= 비선형 관계이다.<br/>

---

&ensp;7. 산점도 Scatter Plot<br/>
&ensp;그래서 상관계수만 계산해서는 안 된다. 산점도를 이용하면 두 변수의 관계를 눈으로 확인할 수 있다.<br/>
&ensp;확인할 수 있는 패턴:<br/>
* 직선형 증가
* 직선형 감소
* U자형
* 군집 구조
* 이상점
* 관계 없음

&ensp;따라서 IoT 데이터 분석에서는 **산점도 -> 상관계수 -> 도메인 지식** 순으로 함께 해석하는 것이 중요하다.<br/>

---

&ensp;8. 센서 간 관계 변화<br/>
&ensp;센서 간 관계 자체가 시간에 따라 변할 수 있다. 예를 들어 정상 설비에서 r = 0.85 였던 진동과 온도의 상관관계가 센서 고장 이후 r = 0.10 으로 바뀌었다고 하자.<br/>
&ensp;가능한 원인<br/>
* 센서 오류
* 운전 조건 변화
* 제어 정책 변경
* 데이터 수집 문제

> 값 자체가 정상이어도 센서 간 관계 구조가 바뀌는 것이 이상 징후일 수 있다.

---

&ensp;9. IoT 관계 분석 절차<br/>
1. 분석할 센서 쌍 선택
2. 산점도 확인
3. 상관계수 계산
4. 상관관계 방향 해석
5. 비선형 관계 가능성 확인
6. 도메인 지식으로 해석 보완
7. 이상 상태 또는 운영 조건 변화 여부 판단

# 거리·유사도 기반 상태 비교

&ensp;1. 센서 데이터를 벡터로 표현하기<br/>
&ensp;여러 센서 값을 하나의 벡터로 표현할 수 있다.<br/>
&ensp;예: x = (온도, 진동, 전류)<br/>
&ensp;정상상태: A = (35, 0.03, 2.1)<br/>
&ensp;현재 상태: B = (36, 0.04, 2.2)<br/>
&ensp;이상 의심 상태: C=(45, 0.30, 5.0)<br/>
&ensp;벡터 공간에서 생각하면<br/>
* A와 B는 가까움
* A와 C는 멂

&ensp;따라서 가까우면 비슷한 상태, 멀면 다른 상태 라고 볼 수 있다.<br/>

---

&ensp;2. 유클리드 거리 Euclidean Distance<br/>
&ensp;2차원<br/>
$$d(x, y) = \sqrt{(x_1 - y_1)^2 + (x_2 - y_2)^2}$$

&ensp;D차원<br/>
$$d(x, y) = \sqrt{\sum _{i=1}^{D}(x_i - y_i)^2}$$

&ensp;의미<br/>
* 거리 작음 → 두 상태가 비슷함
* 거리 큼 → 두 상태가 다름

&ensp;우리가 일반적으로 생각하는 직선 거리이다.<br/>

&ensp;3. 맨해튼 거리 Manhattan Distance<br/>
&ensp;각 좌표의 차이를 절댓값으로 구해서 더한다.<br/>

$$d(x, y) = \sum ^{D}_{i = 1}|x_i - y_i|$$

&ensp;예를 들어 도시의 격자형 도로를 이동하는 것처럼 생각하면 된다.<br/>
&ensp;차이<br/>
&ensp;유클리드 거리: 직선으로 바로 이동<br/>
&ensp;맨해튼 거리: 가로, 세로 축을 따라 이동<br/>

----

&ensp;4. 코사인 유사도 Cosine Similarity<br/>
&ensp;거리와 조금 다른 개념이다.  두 벡터의 방향이 얼마나 비슷한지 측정한다.<br/>

$$cos(\theta ) = \frac{x \cdot y}{||x|| ||y||}$$

&ensp;해석<br/>

| 값  | 의미       |
| -- | -------- |
| 1  | 거의 같은 방향 |
| 0  | 방향 관계 약함 |
| -1 | 반대 방향    |

---

&ensp;5. 유클리드 거리 vs 코사인 유사도<br/>
&ensp;x = (1, 2, 3) , y = (2, 4, 6) 를 생각해보자<br/>
&ensp;y는 x의 2배이다.<br/>
&ensp;유클리드 거리<br/>
$$d(x, y) = \sqrt{1^2 + 2^2 + 3^ 2} \approx 3.74$$

&ensp;따라서 크기가 다르다고 판단.<br/>

&ensp;코사인 유사도 cos(θ) = 1 <br/>

> 방향 또는 패턴은 완전히 같다고 판단.

&ensp;거리 = 크기 차이<br/>
&ensp;코사인 유사도 = 방향/패턴 차이<br/>

---

&ensp;6. 거리와 유사도 비교<br/>

| 방법      | 무엇을 비교?   | 해석      |
| ------- | --------- | ------- |
| 유클리드 거리 | 직선 거리     | 작을수록 비슷 |
| 맨해튼 거리  | 좌표별 차이의 합 | 작을수록 비슷 |
| 코사인 유사도 | 방향        | 클수록 비슷  |

&ensp;IoT에서는<br/>
* 절대 온도 차이 → 유클리드 거리
* 센서별 누적 차이 → 맨해튼 거리
* 하루 전력 사용 패턴 → 코사인 유사도

---

&ensp;7. 정상 중심 기반 상태 비교<br/>
&ensp;정상 데이터 여러 개가 있다면 평균을 구해 정상 중심을 만들 수 있다.<br/>
$$c = (평균온도, 평균 진동, 평균 전류)$$

&ensp;현재 상태를 x = (현재온도, 현재 진동, 현재전류) 라고 하면 d(x, c)를 계산한다.<br/>

&ensp;판단<br/>
* d(x, c) 작음 -> 정상과 유사
* d(x, c) 큼 -> 이상 가능성 증가

---

&ensp;8. 정규화가 필요한 이유<br/>
&ensp;예를 들어 (온도, 진동, 전류)<br/>
&ensp;데이터가 온도 = 35, 진동 = 0.03, 전류 = 2.1 이라고 하자. 숫자의 크기가 완전히 다르다. 그대로 유클리드 거리를 계산하면 온도처럼 숫자가 큰 변수가 거리 계산을 거의 지배할 수 있다. 따라서 **센서 단위와 범위가 다르면 정규화 또는 표준화가 필요하다.** <br/>

---

# 정적 패턴 기반 이상 탐지

&ensp;1. 이상치 Outlier<br/>
&ensp;일반적인 데이터 패턴에서 크게 벗어난 값<br/>
&ensp;예: 23,24,24,25,23,24,90 에서 90은 이상치로 볼 수 있다. 하지만 중요한 것은 이상치 = 반드시 오류가 아니라는 것이다.<br/>
&ensp;90이 센서 오류일 수도 있고 실제 과열 상황일 수도 있다. 따라서 단순 삭제하면 안 되고 원인을 확인해야 한다.<br/>

---

&ensp;2. 이상 탐지 Anomaly Detection<br/>
&ensp;정상 패턴에서 벗어난 데이터를 찾는 과정<br/>
&ensp;IoT에서 활용:<br/>
* 고장 사전 예방
* 안전 사고 예방
* 에너지 낭비 방지
* 유지보수 비용 절감
* 서비스 중단 방지

&ensp;예<br/>
* 모터 진동 급증
* 냉장고 온도 상승
* 전력 사용량 급증
* 네트워크 트래픽 폭증
* 배터리 전압 급락

---

&ensp;3. 정적 이상 탐지<br/>
&ensp;현재 값 또는 현재 상태 벡터를 기준으로 판단한다.<br/>
> 지금 이 값이 정상 범위에 있는가? 를 보는 것

&ensp;예<br/>
* 현재 온도 = 90℃
* 진동 = 0.35
* 전류 = 5.0

&ensp;또는 x = (온도, 진동, 전류) 라는 현재 벡터가 정상 중심에서 얼마나 떨어져 있는지를 본다.<br/>

---

&ensp;4. 시간 기반 이상 탐지<br/>
&ensp;반대로 시간 기반 이상 탐지는 현재 값 자체보다 시간에 따른 변화를 본다.<br/>
&ensp;예<br/>
* 5분 동안 온도가 급상승
* 진동이 짧은 시간에 급격히 증가
* 일정하던 전류 패턴이 갑자기 변함

&ensp;시간 구간을 $x_{t-k}, ... , x_{t-1}, x_t$ 처럼 본다.<br/>

---

&ensp;5. 정적 이상 탐지 vs 시간 기반 이상 탐지<br/>

| 구분    | 정적 이상 탐지     | 시간 기반 이상 탐지  |
| ----- | ------------ | ------------ |
| 기준    | 현재 값/벡터      | 시간에 따른 변화    |
| 예     | 현재 온도 90℃    | 5분 동안 온도 급상승 |
| 주요 도구 | 평균, 표준편차, 거리 | 자기상관, 예측 오차  |
| 초점    | 현재 상태 위치     | 변화 패턴        |

---

&ensp;6. 정적 이상 탐지 방법<br/>
&ensp;정적 이상 탐지는 다시 두 가지로 나뉜다.<br/>
&ensp;단일 센서: 하나의 센서만 본다.<br/>
&ensp;예: 온도 하나만 보고 이상 판단<br/>

&ensp;대표 방법:<br/>
* 평균
* 표준편차
* Z-score

&ensp;다중 센서: 여러 센서를 하나의 벡터로 본다.( x=(온도, 진동, 전류) )<br/>
&ensp;대표 방법:<br/>
* 정상 중심과의 거리
* 거리 기반 이상 탐지

---

&ensp;7. Z-score<br/>
&ensp;단일 센서 이상 탐지의 핵심<br/>

$$z = \frac{x - \mu }{\sigma }$$

&ensp;여기서<br/>
* x: 현재 값
* $\mu$ : 정상 평균
* $sigma$: 정상 표준편차

&ensp;예제<br/>
* 정상 평균: μ = 25
* 표준편차: σ = 2
* 현재값: x = 31

$$z = \frac{31 - 25}{2} = 3$$

> 현재 값은 평균보다 표준편차 3배만큼 떨어져 있다.

&ensp;일반적으로 |z| > 2 또는 |z| > 3. <br/>
&ensp;같은 기준을 이용해 이상치를 판단할 수 있다.<br/>

&ensp;8. 다중 센서 기반 이상 탐지<br/>
&ensp;현재 상태: x=(42, 0.20, 4.0)<br/>
&ensp;정상 중심: c=(35.5, 0.0375, 2.15)<br/>

&ensp;그러면 d(x, c)를 계산한다. 거리가 클수록 현재 상태가 정상 상태와 멀리 떨어져 있으므로 이상 가능성이 커진다.<br/>
&ensp;장점<br/>
&ensp;한 센서만 보는 것이 아니라 온도, 진동, 전류 조합 자체를 볼 수 있다.<br/>

&ensp;9. 마할라노비스 거리<br/>
&ensp;유클리드 거리의 문제<br/>
&ensp;유클리드 거리는 센서별 스케일 차이, 센서 간 상관관계 를 제대로 반영하기 어렵다. 그래서 사용하는 것이 마할라노비스 거리다. 
$$D_{M}(x) = \sqrt{(x - \mu )^{T \sum^{-1}}(x - \mu )}$$

&ensp;여기서<br/>
* x: 현재 상태 벡터
* $\mu$: 정상 데이터 평균 벡터
* $\Sigma$ : 정상 데이터 공분산 행렬
* $\Sigma^{-1}$ : 공분산 행렬의 역행렬

&ensp;핵심 아이디어<br/>
&ensp;마할라노비스 거리는 단순히 얼마나 떨어졌는가? 만 보는 것이 아니라 **정상 데이터가 원래 어떤 방향으로 분포하고 있는가?** 까지 고려한다.<br/>

&ensp;예시<br/>
&ensp;정상 상태에서 온도 ↑ + 전류 ↑ 가 자주 같이 나타난다면 이 변화는 크게 이상하지 않을 수 있다. 하지만 온도는 낮은데 진동만 갑자기 크게 증가하는 조합은 정상 데이터에서 잘 나타나지 않는다면 이상하게 볼 수 있다. 즉 **센서 간 관계까지 고려한 거리** 가 마할라노비스 거리다.<br/>

&ensp;10. Z-score / 유클리드 / 마할라노비스 비교<br/>

| 방법        | 대상    | 특징             |
| --------- | ----- | -------------- |
| Z-score   | 단일 센서 | 평균에서 얼마나 벗어났는가 |
| 유클리드 거리   | 다중 센서 | 정상 중심과의 단순 거리  |
| 마할라노비스 거리 | 다중 센서 | 센서 간 상관관계까지 고려 |

&ensp;11. 정상 패턴이 하나가 아닐 수도 있다<br/>
&ensp;설비가 저부하 정상, 중부하 정상, 고부하 정상 상태를 모두 가질 수 있다. 그런데 모든 데이터를 하나로 평균내면 실제로 존재하지 않은  애매한 평균 상태가 만들어질 수 있다. 그래서 정상 상태가 여러 종류라면 군집화, 운전 모드별 정상 기준 등을 이용해야 한다.<br/>

&ensp;12. 오탐과 미탐<br/>
&ensp;오탐 False Positive<br/>
&ensp;실제로 정상인데 이상이라고 판단 하는 것<br/>

&ensp;미탐 False Negative<br/>
&ensp;실제로는 이상인데 정상이라고 판단<br/>

&ensp;설비 고장 탐지<br/>
&ensp;미탐이 특히 위험할 수 있다. 실제 고장을 놓칠 수 있기 때문이다.<br/>

&ensp;에너지 관리<br/>
&ensp;오탐이 많으면 불필요한 제어가 발생해 비용이 증가할 수 있다.<br/>

&ensp;따라서 문제 특성에 따라 이상 판단 기준값을 조절해야 한다.<br/>
