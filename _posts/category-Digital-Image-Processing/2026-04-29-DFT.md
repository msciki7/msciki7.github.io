# DFT

&ensp;1. 전체 흐름: FT → DTFT → DFT<br/>
```txt
연속 신호 f(x)
   ↓ 샘플링
이산 신호 f(n)
   ↓ 주파수도 샘플링
DFT F(k)
```

&ensp;처음에는 연속 신호 f(x) <br/>
&ensp;예를 들어 이미지에서는 밝기가 연속적으로 변하는 어떤 신호라고 생각하면 된다. 이 연속 신호를 푸리에 변환하면 F(u) or F(jw) 가 나온다. (여기서 중요한 점은 **시간/공간도 연속이고 주파수도 연속**)<br/>
&ensp;그런데 컴퓨터는 연속값을 그대로 다룰 수 없다. 그래서 신호를 일정 간격으로 찍어서 저장한다.<br/>

$$f(x) \rightarrow f(n)$$

&ensp;이게 sampling. 이제 신호는 연속이 아니라 숫자 배열이 됐다.<br/>

&ensp;2. DTFT?<br/>
&ensp;샘플링된 이산 신호 f(n)에 대해 푸리에 변환을 하면 DTFT가 나온다.<br/>

$$f(n) \rightarrow \tilde{F}(e^{j\hat{w}})$$

&ensp;DFTF는 입력 신호는 이산인데 주파수 축은 아직 연속이다.<br/>
&ensp;즉 n은 0, 1, 2, 3 처럼 딱딱 끊어진 값인데 $hat{w}$ 는 연속적으로 움직인다. 그리고 DTFT는 중요한 특징이 있다. 2π periodic. 즉 주파수측에서 2π마다 같은 모양이 반복된다.<br/>

```txt
시간축: 이산적
주파수축: 연속적
주파수 모양: 2π마다 반복
```

&ensp;3. 그런데 컴퓨터는 DTFT도 그대로 못 씀<br/>
&ensp;DTFT는 주파수축이 연속이기 때문에 컴퓨터가 무한히 많은 주파수 값을 다 계산할 수 없다. 그래서 주파수축도 샘플링해야 한다. DTFT의 한 주기는 2π 길이이다. 이 한 주기를 N 등분해서 딱 N개의 주파수만 뽑는다.<br/>

$$\hat{w} = \frac{2\pi k}{N}$$

&ensp;여기서 k = 0, 1, 2, ... , N-1<br/>
&ensp;이게 바로 DFT의 주파수 인덱스이다.<br/>

```txt
DTFT: F(e^{jω})처럼 ω가 연속
DFT: F(k)처럼 k = 0,1,2,...,N-1만 계산
```

&ensp;= DFT는 DTFT의 한 주기에서 N개 지점을 뽑은 것이다.<br/>

&ensp;4. DFT 공식<br/>

&ensp;Forward DFT<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-1.png" width="600"></p>

&ensp;**원래 신호 f(n) 안에 주파수 k번 성분이 얼마나 들어 있는지 검사하는 식**<br/>
&ensp;즉 k = 0이면 0번 주파수 성분을 검사하고 k = 1이면 1번 주파수 성분을 검사하고 k = 2이면 2번 주파수 성분을 검사하는 것이다.<br/>

&ensp;5. 왜 cos와 sin이 나오냐?<br/>
&ensp;오일러 공식 때문에<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-2.png" width="600"></p>

&ensp;즉 DFT는 실제로는 신호를 cos 성분, sin 성분 과 비교하는 계산<br/>

&ensp;6. basis 그림 이해<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-3.png" width="600"></p>

&ensp;여기서 k는 wave number, 즉 몇 번 진동하는 주파수인지<br/>
```txt
k = 0 : 변화 없음
k = 1 : 한 주기 동안 1번 진동
k = 2 : 한 주기 동안 2번 진동
k = 3 : 한 주기 동안 3번 진동
...
k = 15
```

&ensp;오른쪽은 consine basis, 왼쪽은 sine basis<br/>
&ensp;DFT는 신호 f(n)을 각각의 basis와 곱해서 더한다.<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-4.png" width="600"></p>

&ensp;즉 이런 질문을 하는 것<br/>
```txt
내 신호 f(n)이 k=0 모양과 얼마나 닮았나?
내 신호 f(n)이 k=1 모양과 얼마나 닮았나?
내 신호 f(n)이 k=2 모양과 얼마나 닮았나?
...
```

&ensp;닮았으면 F(k) 값이 크게 나오고 안 닮았으면 작게 나온다.<br/>

&ensp;DFT는 **길이 N짜리 이산 신호 f(n)를 N개의 주파수 성분 F(k)로 분해하는 것** 이다.<br/>

```txt
f(n) : 시간/공간에서 본 신호
F(k) : 주파수에서 본 신호
```

&ensp;예를 들어 이미지에서 밝기가 천천히 변하면 낮은 주파수 k 성분이 크고, 경계선이나 노이즈처럼 급격히 변하면 높은 주파수 k 성분이 커진다.<br/>

&ensp;7. Inverse DFT는 반대로 조립하는 것<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-5.png" width="600"></p>

&ensp;DFT가 분해라면 IDFT는 조립이다.<br/>

```txt
DFT  : f(n) → F(k)
IDFT : F(k) → f(n)
```

&ensp;즉 F(k)라는 주파수 재료들을 다시 합치면 원래 신호 f(n)이 복원된다. 여기서 $frac{1}{N}$ 이 붙는 이유는 DFT에서 합을 많이 해서 크기가 N배처럼 커지기 때문에 다시 평균처럼 나누어 주는 거라고 이해하면 된다.<br/>

# FFT

&ensp;1. 왜 FFT를 하는가 (문제의 시작)<br/>
&ensp;DFT 정의<br/>

$$X(k) = \sum_{n=0}^{N-1}x(n)e^{-j\frac{2\pi}{N}kn}$$

&ensp;이걸 그대로 계산하면 연산량이 얼마나 될까?<br/>

```txt
곱셈: N × N = N²
덧셈: (N-1)N ≈ N²
```

&ensp;복잡도 = O(N²)<br/>

&ensp;문제점<br/>
* N이 1024 → 약 100만 연산
* 이미지(2D) → 훨씬 더 큼

&ensp;그래서 등장한 게 **FFT (Fast Fourier Transform)**<br/>

&ensp;2. FFT의 핵심 아이디어<br/>
&ensp;**"DFT를 쪼개서 계산하자"**<br/>
&ensp;그 방법이 바로 짝수 / 홀수 분리 (even / odd)<br/>

&ensp;3. 핵심 유도: even / odd 분리<br/>
&ensp;원래 식<br/>

$$X(k) = \sum_{n=0}^{N-1}x(n)e^{-j\frac{2\pi}{N}kn}$$

&ensp;여기서 n을 두 그룹으로 나눈다.<br/>
```txt
짝수: n = 0,2,4,...
홀수: n = 1,3,5,...
```

&ensp;그래서 식을 쪼개면<br/>

$$X(k) = \sum x(2n)e^{-j\frac{2\pi}{N}k(2n)} + \sum x(2n+1)e^{-j\frac{2\pi}{N}k(2n+1)}$$

&ensp;4. 여기서 핵심 트릭<br/>
&ensp;지금 지수 부분을 자세히 보면<br/>
&ensp;(1) 짝수 부분<br/>

$$e^{-j\frac{2\pi}{N}k(2n)} = e^{-j\frac{2\pi}{N/2}kn}$$

&ensp;(2) 홀수 부분<br/>

$$e^{-j\frac{2\pi}{N}k(2n+1)} = e^{-j\frac{2\pi}{N}k}\cdot e^{-j\frac{2\pi}{N/2}kn}$$

&ensp;앞에 하나 튀어나옴: $W^{k}_N = e^{-j\frac{2\pi}{N}k}$ <br/>

&ensp;5. 그래서 최종 형태<br/>
&ensp;이걸 정리하면<br/>

$$X(k) = G(k) + W^{k}_{N}H(k)$$

&ensp;여기서<br/>
* G(k): 짝수 신호 DFT
* H(k): 홀수 신호 DFT

&ensp;N-point DFT → N/2-point DFT 두 개로 쪼개짐<br/>

&ensp;6. 구조적으로 보면<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-6.png" width="600"></p>

&ensp;입력:<br/>
```txt
x[0], x[2], x[4], x[6] → 짝수
x[1], x[3], x[5], x[7] → 홀수
```

&ensp;각각을 따로 DFT 계산<br/>
```txt
G(k): 짝수 DFT
H(k): 홀수 DFT
```

&ensp;그 다음 결합<br/>
&ensp;`X(k) = G(k) + W_N^k H(k)`<br/>

&ensp;그리고 또 하나 중요한 관계:<br/>
&ensp;`X(k+N/2) = G(k) - W_N^k H(k)`<br/>
&ensp;이게 그림에서 위/아래로 갈라지는 이유<br/>

&ensp;7. 왜 k가 반복되냐<br/>
&ensp;`If N=8, G(0)=G(4), G(1)=G(5), G(2)=G(6), G(3)=G(7)`<br/>
&ensp;DFT는 주파수도 주기적 F(k+N) = F(k)<br/>

&ensp;8. FFT의 핵심 구조<br/>
```txt
N-point DFT
→ 2개의 N/2 DFT
→ 4개의 N/4 DFT
→ 8개의 N/8 DFT
...
→ 2-point DFT까지 쪼갬
```

&ensp;9. 더 쪼개기 (recursive 구조)<br/>

$$G(k) = \sum g(n)W^{nk}_{N/2}$$

&ensp;여기서 또 `g(2l), g(2l+1)` 로 쪼갬 → 또 even / odd<br/>

&ensp;결과<br/>
$$G(k) = (짝수) + W^{k}_{N/2}(홀수)$$

&ensp;이 구조가 계속 반복된다.<br/>

&ensp;10. 복잡도 감소<br/>
&ensp;이 구조 덕분에:<br/>
```txt
기존: O(N²)
FFT: O(N log N)
```

&ensp;왜냐하면<br/>
```txt
쪼개는 단계: log N 단계
각 단계 연산: N
```

&ensp;11. 직관적으로 이해<br/>
&ensp;DFT는 원래 이런 느낌: `전체 신호 × 모든 주파수 → 계산` <br/>
&ensp;FFT는:<br/>
```txt
신호를 반으로 나누고
→ 또 반으로 나누고
→ 또 나누고
→ 작은 문제들만 풀어서 합침
```

&ensp;-> Divide & Conquer<br/>

&ensp;12. 예시<br/>
&ensp;N=8이면<br/>
&ensp;`8 → 4 → 2 → 1` <br/>
&ensp;즉 2-point DFT까지 쪼개짐<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-7.png" width="600"></p>

<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-12.jpg" width="600"></p>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-13.jpg" width="600"></p>

&ensp;2-point DFT가 진짜 핵심<br/>

$$F(0) = x(0)+ x(1)$$

$$F(1) = x(0) - x(1)$$

&ensp;`모든 FFT는 결국 "덧셈 + 뺄셈"으로 끝난다.`<br/>

&ensp;butterfly 구조<br/>
```math
X(k) = G(k) + W_N^k H(k)
```

```math
X(k+N/2) = G(k) - W_N^k H(k)
```

&ensp;이걸 그림으로 그리면<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-8.png" width="600"></p>

&ensp;이게 butterfly(나비 모양)<br/>

&ensp;의미<br/>
&ensp;한 번의 butterfly 연산<br/>
&ensp;연산<br/>
```txt
덧셈 1번
뺄셈 1번
곱셈 1번 (W)
```

<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-9.png" width="600"></p>

&ensp;$W^{N/2}_{N} = e^{-j\pi } = -1$ <br/>
&ensp;-> $ W^{N/2+k}_{N} = W^{N/2}_{N}\cdot W^{k}_{N} = -W^{k}_{N}$ <br/>

```math
윗줄: +W_N^k
아랫줄: -W_N^k
```

&ensp;연산량이 줄어드는 이유<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-10.png" width="600"></p>

&ensp;$2 × (N/2)^2$ -> 이건 두 개의 N/2 DFT<br/>
&ensp;반복하면 N → N/2 → N/4 → ... -> 단계 수: $log_{2}N$ <br/>

&ensp;각 단계 연산<br/>
* 곱셈: N/2
* 덧셈: N

&ensp;최종<br/>
```
곱셈: (N/2) log₂N
덧셈: N log₂N
```

&ensp;결론<br/>
&ensp;`O(N²) → O(N log N)` <br/>

&ensp;13. stage 개념<br/>
&ensp;`log₂N = stage 수` <br/>
&ensp;예<br/>
```
stage 1
stage 2
stage 3
```

&ensp;총 3단계<br/>

&ensp;각 stage에서 butterfly 연산 반복<br/>
&ensp;핵심 이해: FFT는 "여러 stage의 butterfly 반복"<br/>

&ensp;14. bit reversal<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-11.png" width="600"></p>

&ensp;index를 binary로 표현한 것<br/>
&ensp;bit reversal이란?<br/>
```
000 → 000 (0)
001 → 100 (4)
010 → 010 (2)
011 → 110 (6)
100 → 001 (1)
101 → 101 (5)
110 → 011 (3)
111 → 111 (7)
```

&ensp;필요한 이유<br/>
&ensp;FFT는 계산 순서가 자연 순서가 아니라 쪼개진 순서로 진행됨<br/>
&ensp;그래서 입력을 미리 재배열해야 함<br/>
&ensp;FFT는 입력을 bit-reversal 순서로 정렬해야 버터플라이 계산이 깔끔하게 된다.<br/>

&ensp;15. 전체 흐름<br/>
```txt
1. DFT는 O(N²)라서 느림

2. FFT는
   → even/odd로 나눔
   → N → N/2 → N/4 → ... 분해

3. 마지막은 2-point DFT (덧셈/뺄셈)

4. 각 단계는 butterfly 구조

5. 총 단계 수 = log₂N

6. 연산량 = N log N

7. 입력은 bit reversal로 재정렬 필요
```

# 2D DFT

&ensp;1. 정의<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-19.png" width="600"></p>

&ensp;2D DFT는 1D DFT 두 번이다.<br/>

&ensp;계산 방법<br/>
1. 모든 행(row)에 대해 1D DFT
2. 결과에 대해 모든 열(column)에 대해 1D DFT

&ensp;2D FFT = row FFT + column FFT<br/>

&ensp;이미지 생각하면: 가로 방향 주파수 분석 + 세로 방향 주파수 분석<br/>

&ensp;Separability<br/>
&ensp;2D DFT는 1D DFT 두 번이다”<br/>

&ensp;수식<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-20.png" width="600"></p>

&ensp;계산과정<br/>
1. 각 row에 대해 1D DFT → F(x,v)
2. 각 column에 대해 1D DFT → F(u,v)

<p align="center"><img src="/assets/img/Digital Image Processing/DFT/1-20.png" width="600"></p>

```txt
f(x,y)
  ↓ (row FFT)
F(x,v)
  ↓ (column FFT)
F(u,v)
```

&ensp;2D FFT = row FFT + column FFT<br/>

&ensp;직접 2D DFT → O(N² × N²)<br/>
&ensp;분리하면 → O(N² log N)<br/>

&ensp;2. Translation (이동 성질)<br/>
&ensp;공간에서 이동<br/>

$$f(m-m_0 , n-n_0)$$

&ensp;이미지가 오른쪽/위로 이동<br/>

&ensp;주파수에서 변화<br/>

$$F(u, v)e^{-2\pi (um_0 / N + vn_0 / N)}$$

&ensp;핵심 해석: 공간 이동 → 주파수에서 phase 변화(magnitude는 그대로)<br/>

&ensp;3. 반대로<br/>

$$f(m, n)e^{j2\pi (u_0 m/N + v_0 n/N)}\leftrightarrow F(u-u_0, v-v_0)$$

&ensp;의미: 공간에서 exponential 곱 → 주파수 이동<br/>

```txt
공간 이동 ↔ 주파수 phase 변화
주파수 이동 ↔ 공간 modulation
```

&ensp;4. Conjugate Symmetry (대칭성)<br/>

$$F^{*}(u, v) = F(-u, -v)$$

&ensp;의미: 입력이 real이면 주파수는 대칭 구조<br/>
&ensp;결과: Magnitude는 180도 회전해도 동일<br/>
&ensp;그래서 이미지 magnitude 보면: 가운데 기준으로 좌우/상하 대칭<br/>

&ensp;5. Magnitude vs Phase<br/>
&ensp;Magnitude: 밝기 정보 (어떤 주파수가 얼마나 있는지)<br/>
&ensp;Phase: 위치 / 구조 정보<br/>

&ensp;6. Spatial Filtering in Frequency Domain<br/>
&ensp;기본 개념<br/>
```txt
공간에서 filtering (convolution)
↔
주파수에서 곱셈
```

&ensp;핵심 공식<br/>
```txt
f(x,y) * h(x,y)
↔
F(u,v) × H(u,v)
```

&ensp;의미: 이미지 필터링을 주파수 영역에서 곱셈으로 처리 가능<br/>

# Frequency Domain Filtering 전체 절차

&ensp;전체 과정<br/>
1. f(m,n) × (-1)^(m+n)
2. DFT → F(u,v)
3. 필터 곱 → F(u,v) × H(u,v)
4. IDFT
5. real part 취함
6. 다시 × (-1)^(m+n)

&ensp;각 단계 의미<br/>

&ensp;1. (-1)^(m+n)<br/>
&ensp;주파수 중심 이동(centering)<br/>
&ensp;원래 DC는 (0,0)에 있음 -> 이걸 중앙으로 이동<br/>

&ensp;2. DFT<br/>
&ensp;이미지를 주파수 영역으로 변환<br/>

&ensp;3. 필터 적용<br/>
&ensp;`F(u,v) × H(u,v)` <br/>
&ensp;여기서 모든 이미지 처리 발생<br/>
* 저주파 통과 → blur
* 고주파 통과 → edge
* 특정 방향 제거 → 노이즈 제거

&ensp;4. IDFT<br/>
&ensp;다시 이미지로 복원<br/>

&ensp;5. real part<br/>
&ensp;복소수 결과 → 실제 이미지<br/>

&ensp;6. 다시 (-1)^(m+n)<br/>
&ensp;원래 위치로 복원<br/>
