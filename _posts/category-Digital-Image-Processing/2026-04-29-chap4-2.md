# Fast algorithm for convolution

&ensp;이걸 배우는 이유<br/>
&ensp;Convolution을 빠르게 계산하기 위해 FFT 사용<br/>
&ensp;원래 convolution은 시간 영역: 연산량 = O(N²) (겁나 느림). 하지만 FFT 쓰면: 주파수 영역: 연산량 = O(N log N) (훨씬 빠름)<br/>

&ensp;전체 흐름<br/>
&ensp;Convolution을 FFT로 계산하는 과정<br/>
```txt
f(n), g(n)
   ↓ (Zero padding → 길이 2N)
F'(k) = FFT(f')
G'(k) = FFT(g')
   ↓ (주파수 영역 곱)
H'(k) = F'(k) · G'(k)
   ↓ (Inverse FFT)
h(n) = IFFT(H'(k))
```

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-1.png" width="600"></p>

&ensp;DFT 2번 + 곱셈 1번 + IDFT 1번이 필요<br/>

&ensp;왜 길이를 2N으로 맞추는가?<br/>
&ensp;**of samples should be 2ⁿ to apply fast DFT**<br/>
&ensp;(1) FFT는 2ⁿ일 때 가장 빠름 -> radix-2 FFT 때문<br/>
&ensp;(2) Linear convolution을 위해 -> zero padding 안 하면 circular convolution 됨<br/>

&ensp;연산량 계산 흐름<br/>
&ensp;FFT의 multiplicaton 복잡도: $ \frac{N}{2}log_{2}N$ <br/>

&ensp;그런데 길이가 2N인 FFT를 사용하니까  $\frac{2N}{2}log_{2}2N$ 이 된다.<br/>
&ensp;정리하면 $N log_{2}2N$ <br/>

&ensp;1) f' 에 대한 FFT<br/>
&ensp;$N log_{2}2N$ <br/>

&ensp;2)F'와 G' 사이의 주파수 영역 곱셈<br/>
&ensp;두 주파수 성분을 위치별로 곱해야 하니까 샘플 개수만큼 곱셈이 필요<br/>
&ensp;길이가 2N이므로 2N<br/>
&ensp;그래서 $N log_{2}2N + 2N$ <br/>

&ensp;3) inverse DFT<br/>
&ensp;다시 공간 영역으로 돌아와야 하니까 IDFT도 필요: $N log_{2}2N$ <br/>

&ensp;따라서 전체는 $N log_{2}(2N) + {N log_{2}(2N) + 2N} + N log_{2}(2N)$ <br/>
&ensp;그래서 $3N log_{2}(2N) + 2N$ <br/>
&ensp;이제 $log_{2}(2N) = log_{2}2 + log_{2}N = 1 + log_{2}N$ 이니끼<br/>

# Smoothing Frequency-Domain Filters

&ensp;noise와 sharp transition이 high-frequency인 이유<br/>
&ensp;이미지에서 픽셀 값이 천천히 변하면 저주파.<br/>
&ensp;예를 들어 하늘, 벽, 피부처럼 부드러운 영역은 픽셀 값 변화가 작다.<br/>
&ensp;반대로 픽셀 값이 갑자기 확 바뀌면 고주파이다.<br/>

&ensp;LPF가 smoothing을 만드는 이유<br/>
&ensp;LPF는 Low-Pass Filter이다.<br/>
```txt
Low frequency는 통과
High frequency는 제거 또는 감소
```

&ensp;이미지에서 high frequency는 노이즈와 날카로운 경계 성분이니까, 이것을 줄이면 이미지가 부드러워진다.<br/>
&ensp;그래서 LPF 결과는 보통 흐릿해진다.<br/>

&ensp;기본식<br/>
&ensp;주파수 영역 filtering의 기본 모델은<br/>

$$G(u, v) = H(u, v)F(u, v)$$

| 기호       | 의미          |
| -------- | ----------- |
| (F(u,v)) | 원본 이미지의 DFT |
| (H(u,v)) | 주파수 영역 필터   |
| (G(u,v)) | 필터링된 주파수 결과 |
| (g(x,y)) | 최종 결과 이미지   |


&ensp;공간 영역에서는<br/>

$$g(x, y) = h(x, y) \ast f(x, y)$$

&ensp;주파수 영역에서는<br/>

$$G(u, v) = H(u, v)F(u, v)$$

&ensp;다시 공간 영역으로 오면<br/>

$$g(x, y) = DFT^{-1}[H(u, v)F(u, v)]$$

&ensp;LPF 세 종류<br/>
&ensp;1) Ideal Low Pass Filter<br/>
&ensp;중심에서 일정 거리 안쪽은 완전히 통과시키고 바깥은 완전히 제거한다.<br/>
```txt
안쪽: 1
바깥쪽: 0
```

&ensp;장점은 개념이 단순하다.<br/>
&ensp;단점은 너무 급격하게 자르기 때문에 공간 영역에서 ringing 현상이 생길 수 있다.<br/>

&ensp;2) Butterworth Low Pass Filter<br/>
&ensp;Ideal처럼 갑자기 끊지 않고 부드럽게 감소한다. 차수 n이 커질수록 Ideal filter에 가까워진다.<br/>
```txt
n 작음 → 완만한 필터
n 큼 → 급격한 필터
```

&ensp;3) Gaussian Low Pass Filter<br/>
&ensp;가장 부드럽게 감소하는 필터다.<br/>
&ensp;중심이 가장 크고 중심에서 멀어질수록 자연스럽게 작아진다. Gaussian은 급격한 절단이 없어서 ringing이 거의 없다. 그래서 smoothing에서 많이 쓰인다.<br/>

# Ideal Low Pass Filter (ILPF)

&ensp;1. 정의<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-3.png" width="600"></p>

&ensp;중심에서 D0 안쪽 주파수는 100% 통과<br/>
&ensp;중심에서 D0 바깥쪽 주파수는 100% 제거<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-4.png" width="600"></p>

&ensp;흰 원 안쪽만 살리고 바깥 검은 부분은 다 버린다. 여기서 중심 근처는 저주파고 중심에서 멀수록 고주파이다.<br/>
&ensp;그래서 $D_0$ 가 작으면 아주 조금의 저주파만 남아서 이미지가 많이 흐려지고 $D_0$ 가 크면 더 많은 주파수가 살아남아서 원본에 가까워진다.<br/>

&ensp;원 모양으로 자르는 이유<br/>
&ensp;2D 이미지의 주파수는 u, v 두 방향이 있다.<br/>
* u: 세로 방향 변화와 관련된 주파수
* v: 가로 방향 변화와 관련된 주파수

&ensp;어떤 주파수가 높은지 낮은지는 중심에서 얼마나 멀리 떨어져 있는지로 판단한다. 그래서 거리 D(u, v)를 사용한다.<br/>

$$D(u, v) = \sqrt{(u-center_u)^2 + (v - center_v)^2}$$

&ensp;중심에서 반지름 $D_0$ 안쪽이면 통과, 바깥이면 제거이다.<br/>
&ensp;그래서 필터 모양이 네모가 아니라 원이 되는 거다. 원은 "모든 방향에 대해 같은 기준 거리"를 적용한다는 뜻이다.<br/>

&ensp;2. 그런데 Ideal LPF는 왜 문제가 생길까?<br/>
&ensp;Ideal LPF는 주파수 영역에서 갑자기 자른다.<br/>
```txt
안쪽은 1
바깥쪽은 0
경계에서 갑자기 뚝 끊김
```

&ensp;이렇게 급격하게 끊기는 필터는 공간 영역으로 돌아왔을 때 부작용이 생긴다. 왜냐하면 주파수 영역에서의 필터 H(u, v)는 공간 영역에서는 어떤 함수 h(x, y)와 연결돼 있다.<br/>

$$h(x, y) = DFT^{-1}[H(u, v)]$$

&ensp;즉 주파수 영역에서 필터를 만든다는 건 사실 공간 영역에서 어떤 convolution kernel을 만드는 것과 같다. Ideal LPF처럼 주파수 영역에서 뚝 끊긴 모양은 공간 영역에서 sinc 함수처럼 출렁이는 모양이 된다.<br/>
&ensp;sinc 함수는 가운데는 크고 양옆으로 물결처럼 진동한다. 그래서 이미지에 적용하면 경계 주변에 물결무늬가 생긴다. 이걸 ringing artifact라고 한다.<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-5.png" width="600"></p>

&ensp;3. Power/Energy conservation은 왜 여기서 나올까?<br/>
&ensp;Fourier transform을 해도 이미지가 가진 전체 에너지는 사라지지 않는다는 걸 설명하기 위해서<br/>
&ensp;즉 공간 영역의 픽셀 값 에너지와 주파수 영역의 에너지는 대응된다.<br/>

&ensp;$\sum \begin{vmatrix}f(x, y)\end{vmatrix}^{2}$ 와 $\sum \begin{vmatrix}F(u, v)\end{vmatrix}^{2}$ <br/>

&ensp;는 정규화방식에 따라 같은 의미로 볼 수 있다<br/>
&ensp;그래서 Fourier spectrum에서 중심 원 안에 포함된 에너지가 크면 그 만큼 원본 이미지의 중요한 성분이 많이 남아 있다는 뜻이다.<br/>
&ensp;작은 원 안에도 에너지가 꽤 많다. → 이미지의 주요 구조는 저주파에 많이 있다. → 하지만 세부 정보와 경계는 고주파 쪽에 있다.<br/>
&ensp;그래서 LPF는 큰 구조는 남기고 세부 정보는 줄이는 거다.<br/>

# Butterworth Lowpass Filter(BLPF)

&ensp;Ideal LPF의 문제는 너무 갑자기 자르는 것이였다.<br/>
&ensp;Butterworth LPF는 이렇게 하지 않는다.<br/>

$$H(u, v) = \frac{1}{1 + (\frac{D(u, v)}{D_{0}})^{2n}}$$

&ensp;중심 근처에서는 값이 1에 가까움. 멀어질수록 점점 0에 가까워짐.<br/>
&ensp;즉 고주파를 갑자기 없애는 게 아니라 부드럽게 줄인다. 그래서 공간 영역에서 sinc처럼 심하게 출령이는 현상이 줄어든다.<br/>

&ensp;n은 Butterworth 필터의 성격을 결정한다.<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-6.png" width="600"></p>

&ensp;Butterworth에서 n은 order이다.<br/>
&ensp;n이 작으면 필터가 부드럽게 감소한다.<br/>
&ensp;`n 작음 → 완만하게 감소 → 부드러운 필터` <br/>

&ensp;n이 커지면 Ideal LPF처럼 갑자기 떨어진다.<br/>
&ensp;`n 큼 → 급격하게 감소 → Ideal LPF에 가까움` <br/>

&ensp;예<br/>
* n=1: 아주 부드러움
* n=2: 적당히 부드러움
* n=5: 점점 Ideal 느낌
* n=20: 거의 Ideal LPF

&ensp;그런데 n이 커지면 다시 ringing이 커진다. 왜냐하면 필터 모양이 점점 "뚝 끊기는 모양"에 가까워지기 때문이다.<br/>

# Gaussian LPF

&ensp;`Gaussian LPF = 주파수를 "부드럽게 자연스럽게 줄이는 필터"` <br/>
* Ideal: 뚝 자름
* Butterworth: 완만하게 자름
* Gaussian: 가장 자연스럽게 줄임

&ensp;1. 수식<br/>

$$H(u, v) = e^{-D^{2}(u, v)/2D^{2}_{0}}$$

```txt
중심 (D=0) → e^0 = 1 → 완전 통과
멀어질수록 → 지수적으로 감소
아주 멀리 → 거의 0
```

* D(u,v): 중심에서 거리
* $D_0$ : 얼마나 넓게 퍼질지 결정 (blur 강도)

&ensp;2. 그림<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-7.png" width="600"></p>

&ensp;중심 → 중요한 정보 (저주파) → 많이 살림<br/>
&ensp;바깥 → 디테일/노이즈 (고주파) → 자연스럽게 줄임<br/>

&ensp;3.Ideal / Butterworth / Gaussian 차이<br/>
&ensp;Ideal LPF<br/>
* 갑자기 끊음 → ringing 발생

&ensp;Butterworth LPF<br/>
* 조금 부드럽게 끊음 → ringing 줄어듦

&ensp;Gaussian LPF<br/>
* 끊는 개념이 없음 → 그냥 자연스럽게 감소 → ringing 거의 없음

&ensp;4. Gaussian이 왜 좋을까?<br/>
&ensp;Gaussian은 frequency에서도 Gaussian, spatial에서도 Gaussian이다.<br/>
&ensp;결과 진동 없음, ringing 없음.<br/>

&ensp;다른 필터들: frequency에서 sharp → spatial에서 sinc → ringing 발생<br/>

&ensp;Gaussian = 자연스럽게 퍼지는 형태 → 어떤 domain에서도 "부드러움 유지"<br/>

&ensp;Lowpass filters 정리<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-8.png" width="600"></p> 

&ensp;흐름<br/>
&ensp;이미지 → Fourier Transform → 주파수 분석<br/>
* 저주파 → 큰 구조
* 고주파 → 디테일 / 노이즈

&ensp;LPF → 고주파 줄임 → 이미지 부드러워짐<br/>

&ensp;필터 차이<br/>
```txt
Ideal → sharp cutoff → ringing 발생
Butterworth → 완만 → 타협
Gaussian → 자연스러움 → 가장 안정
```
