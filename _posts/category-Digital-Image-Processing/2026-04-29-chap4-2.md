# Fast algorithm for convolution

&ensp;이걸 배우는 이유<br/>
&ensp;Convolution을 빠르게 계산하기 위해 FFT 사용<br/>
&ensp;원래 convolution은 시간 영역: 연산량 = O(N²) (겁나 느림). 하지만 FFT 쓰면: 주파수 영역: 연산량 = O(N log N) (훨씬 빠름)<br/>

&ensp;전체 흐름<br/>
&ensp;Convolution을 FFT로 계산하는 과정<br/>
```txt
f(n), g(n)
   ↓ (Zero padding → 길이 2N)
F'(k) = FFT(f')
G'(k) = FFT(g')
   ↓ (주파수 영역 곱)
H'(k) = F'(k) · G'(k)
   ↓ (Inverse FFT)
h(n) = IFFT(H'(k))
```

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-1.png" width="600"></p>

&ensp;DFT 2번 + 곱셈 1번 + IDFT 1번이 필요<br/>

&ensp;왜 길이를 2N으로 맞추는가?<br/>
&ensp;**of samples should be 2ⁿ to apply fast DFT**<br/>
&ensp;(1) FFT는 2ⁿ일 때 가장 빠름 -> radix-2 FFT 때문<br/>
&ensp;(2) Linear convolution을 위해 -> zero padding 안 하면 circular convolution 됨<br/>

&ensp;연산량 계산 흐름<br/>
&ensp;FFT의 multiplicaton 복잡도: $ \frac{N}{2}log_{2}N$ <br/>

&ensp;그런데 길이가 2N인 FFT를 사용하니까  $\frac{2N}{2}log_{2}2N$ 이 된다.<br/>
&ensp;정리하면 $N log_{2}2N$ <br/>

&ensp;1) f' 에 대한 FFT<br/>
&ensp;$N log_{2}2N$ <br/>

&ensp;2)F'와 G' 사이의 주파수 영역 곱셈<br/>
&ensp;두 주파수 성분을 위치별로 곱해야 하니까 샘플 개수만큼 곱셈이 필요<br/>
&ensp;길이가 2N이므로 2N<br/>
&ensp;그래서 $N log_{2}2N + 2N$ <br/>

&ensp;3) inverse DFT<br/>
&ensp;다시 공간 영역으로 돌아와야 하니까 IDFT도 필요: $N log_{2}2N$ <br/>

&ensp;따라서 전체는 $N log_{2}(2N) + {N log_{2}(2N) + 2N} + N log_{2}(2N)$ <br/>
&ensp;그래서 $3N log_{2}(2N) + 2N$ <br/>
&ensp;이제 $log_{2}(2N) = log_{2}2 + log_{2}N = 1 + log_{2}N$ 이니끼<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-2.png" width="600"></p>

# Smoothing Frequency-Domain Filters

&ensp;noise와 sharp transition이 high-frequency인 이유<br/>
&ensp;이미지에서 픽셀 값이 천천히 변하면 저주파.<br/>
&ensp;예를 들어 하늘, 벽, 피부처럼 부드러운 영역은 픽셀 값 변화가 작다.<br/>
&ensp;반대로 픽셀 값이 갑자기 확 바뀌면 고주파이다.<br/>

&ensp;LPF가 smoothing을 만드는 이유<br/>
&ensp;LPF는 Low-Pass Filter이다.<br/>
```txt
Low frequency는 통과
High frequency는 제거 또는 감소
```

&ensp;이미지에서 high frequency는 노이즈와 날카로운 경계 성분이니까, 이것을 줄이면 이미지가 부드러워진다.<br/>
&ensp;그래서 LPF 결과는 보통 흐릿해진다.<br/>

&ensp;기본식<br/>
&ensp;주파수 영역 filtering의 기본 모델은<br/>

$$G(u, v) = H(u, v)F(u, v)$$

| 기호       | 의미          |
| -------- | ----------- |
| (F(u,v)) | 원본 이미지의 DFT |
| (H(u,v)) | 주파수 영역 필터   |
| (G(u,v)) | 필터링된 주파수 결과 |
| (g(x,y)) | 최종 결과 이미지   |


&ensp;공간 영역에서는<br/>

$$g(x, y) = h(x, y) \ast f(x, y)$$

&ensp;주파수 영역에서는<br/>

$$G(u, v) = H(u, v)F(u, v)$$

&ensp;다시 공간 영역으로 오면<br/>

$$g(x, y) = DFT^{-1}[H(u, v)F(u, v)]$$

&ensp;LPF 세 종류<br/>
&ensp;1) Ideal Low Pass Filter<br/>
&ensp;중심에서 일정 거리 안쪽은 완전히 통과시키고 바깥은 완전히 제거한다.<br/>
```txt
안쪽: 1
바깥쪽: 0
```

&ensp;장점은 개념이 단순하다.<br/>
&ensp;단점은 너무 급격하게 자르기 때문에 공간 영역에서 ringing 현상이 생길 수 있다.<br/>

&ensp;2) Butterworth Low Pass Filter<br/>
&ensp;Ideal처럼 갑자기 끊지 않고 부드럽게 감소한다. 차수 n이 커질수록 Ideal filter에 가까워진다.<br/>
```txt
n 작음 → 완만한 필터
n 큼 → 급격한 필터
```

&ensp;3) Gaussian Low Pass Filter<br/>
&ensp;가장 부드럽게 감소하는 필터다.<br/>
&ensp;중심이 가장 크고 중심에서 멀어질수록 자연스럽게 작아진다. Gaussian은 급격한 절단이 없어서 ringing이 거의 없다. 그래서 smoothing에서 많이 쓰인다.<br/>

# Ideal Low Pass Filter (ILPF)

&ensp;1. 정의<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-3.png" width="600"></p>

&ensp;중심에서 D0 안쪽 주파수는 100% 통과<br/>
&ensp;중심에서 D0 바깥쪽 주파수는 100% 제거<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-4.png" width="600"></p>

&ensp;흰 원 안쪽만 살리고 바깥 검은 부분은 다 버린다. 여기서 중심 근처는 저주파고 중심에서 멀수록 고주파이다.<br/>
&ensp;그래서 $D_0$ 가 작으면 아주 조금의 저주파만 남아서 이미지가 많이 흐려지고 $D_0$ 가 크면 더 많은 주파수가 살아남아서 원본에 가까워진다.<br/>

&ensp;원 모양으로 자르는 이유<br/>
&ensp;2D 이미지의 주파수는 u, v 두 방향이 있다.<br/>
* u: 세로 방향 변화와 관련된 주파수
* v: 가로 방향 변화와 관련된 주파수

&ensp;어떤 주파수가 높은지 낮은지는 중심에서 얼마나 멀리 떨어져 있는지로 판단한다. 그래서 거리 D(u, v)를 사용한다.<br/>

$$D(u, v) = \sqrt{(u-center_u)^2 + (v - center_v)^2}$$

&ensp;중심에서 반지름 $D_0$ 안쪽이면 통과, 바깥이면 제거이다.<br/>
&ensp;그래서 필터 모양이 네모가 아니라 원이 되는 거다. 원은 "모든 방향에 대해 같은 기준 거리"를 적용한다는 뜻이다.<br/>

&ensp;2. 그런데 Ideal LPF는 왜 문제가 생길까?<br/>
&ensp;Ideal LPF는 주파수 영역에서 갑자기 자른다.<br/>
```txt
안쪽은 1
바깥쪽은 0
경계에서 갑자기 뚝 끊김
```

&ensp;이렇게 급격하게 끊기는 필터는 공간 영역으로 돌아왔을 때 부작용이 생긴다. 왜냐하면 주파수 영역에서의 필터 H(u, v)는 공간 영역에서는 어떤 함수 h(x, y)와 연결돼 있다.<br/>

$$h(x, y) = DFT^{-1}[H(u, v)]$$

&ensp;즉 주파수 영역에서 필터를 만든다는 건 사실 공간 영역에서 어떤 convolution kernel을 만드는 것과 같다. Ideal LPF처럼 주파수 영역에서 뚝 끊긴 모양은 공간 영역에서 sinc 함수처럼 출렁이는 모양이 된다.<br/>
&ensp;sinc 함수는 가운데는 크고 양옆으로 물결처럼 진동한다. 그래서 이미지에 적용하면 경계 주변에 물결무늬가 생긴다. 이걸 ringing artifact라고 한다.<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-5.png" width="600"></p>

&ensp;3. Power/Energy conservation은 왜 여기서 나올까?<br/>
&ensp;Fourier transform을 해도 이미지가 가진 전체 에너지는 사라지지 않는다는 걸 설명하기 위해서<br/>
&ensp;즉 공간 영역의 픽셀 값 에너지와 주파수 영역의 에너지는 대응된다.<br/>

&ensp;$\sum \begin{vmatrix}f(x, y)\end{vmatrix}^{2}$ 와 $\sum \begin{vmatrix}F(u, v)\end{vmatrix}^{2}$ <br/>

&ensp;는 정규화방식에 따라 같은 의미로 볼 수 있다<br/>
&ensp;그래서 Fourier spectrum에서 중심 원 안에 포함된 에너지가 크면 그 만큼 원본 이미지의 중요한 성분이 많이 남아 있다는 뜻이다.<br/>
&ensp;작은 원 안에도 에너지가 꽤 많다. → 이미지의 주요 구조는 저주파에 많이 있다. → 하지만 세부 정보와 경계는 고주파 쪽에 있다.<br/>
&ensp;그래서 LPF는 큰 구조는 남기고 세부 정보는 줄이는 거다.<br/>

# Butterworth Lowpass Filter(BLPF)

&ensp;Ideal LPF의 문제는 너무 갑자기 자르는 것이였다.<br/>
&ensp;Butterworth LPF는 이렇게 하지 않는다.<br/>

$$H(u, v) = \frac{1}{1 + (\frac{D(u, v)}{D_{0}})^{2n}}$$

&ensp;중심 근처에서는 값이 1에 가까움. 멀어질수록 점점 0에 가까워짐.<br/>
&ensp;즉 고주파를 갑자기 없애는 게 아니라 부드럽게 줄인다. 그래서 공간 영역에서 sinc처럼 심하게 출령이는 현상이 줄어든다.<br/>

&ensp;n은 Butterworth 필터의 성격을 결정한다.<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-6.png" width="600"></p>

&ensp;Butterworth에서 n은 order이다.<br/>
&ensp;n이 작으면 필터가 부드럽게 감소한다.<br/>
&ensp;`n 작음 → 완만하게 감소 → 부드러운 필터` <br/>

&ensp;n이 커지면 Ideal LPF처럼 갑자기 떨어진다.<br/>
&ensp;`n 큼 → 급격하게 감소 → Ideal LPF에 가까움` <br/>

&ensp;예<br/>
* n=1: 아주 부드러움
* n=2: 적당히 부드러움
* n=5: 점점 Ideal 느낌
* n=20: 거의 Ideal LPF

&ensp;그런데 n이 커지면 다시 ringing이 커진다. 왜냐하면 필터 모양이 점점 "뚝 끊기는 모양"에 가까워지기 때문이다.<br/>

# Gaussian LPF

&ensp;`Gaussian LPF = 주파수를 "부드럽게 자연스럽게 줄이는 필터"` <br/>
* Ideal: 뚝 자름
* Butterworth: 완만하게 자름
* Gaussian: 가장 자연스럽게 줄임

&ensp;1. 수식<br/>

$$H(u, v) = e^{-D^{2}(u, v)/2D^{2}_{0}}$$

```txt
중심 (D=0) → e^0 = 1 → 완전 통과
멀어질수록 → 지수적으로 감소
아주 멀리 → 거의 0
```

* D(u,v): 중심에서 거리
* $D_0$ : 얼마나 넓게 퍼질지 결정 (blur 강도)

&ensp;2. 그림<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-7.png" width="600"></p>

&ensp;중심 → 중요한 정보 (저주파) → 많이 살림<br/>
&ensp;바깥 → 디테일/노이즈 (고주파) → 자연스럽게 줄임<br/>

&ensp;3.Ideal / Butterworth / Gaussian 차이<br/>
&ensp;Ideal LPF<br/>
* 갑자기 끊음 → ringing 발생

&ensp;Butterworth LPF<br/>
* 조금 부드럽게 끊음 → ringing 줄어듦

&ensp;Gaussian LPF<br/>
* 끊는 개념이 없음 → 그냥 자연스럽게 감소 → ringing 거의 없음

&ensp;4. Gaussian이 왜 좋을까?<br/>
&ensp;Gaussian은 frequency에서도 Gaussian, spatial에서도 Gaussian이다.<br/>
&ensp;결과 진동 없음, ringing 없음.<br/>

&ensp;다른 필터들: frequency에서 sharp → spatial에서 sinc → ringing 발생<br/>

&ensp;Gaussian = 자연스럽게 퍼지는 형태 → 어떤 domain에서도 "부드러움 유지"<br/>

&ensp;Lowpass filters 정리<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-8.png" width="600"></p> 

&ensp;흐름<br/>
&ensp;이미지 → Fourier Transform → 주파수 분석<br/>
* 저주파 → 큰 구조
* 고주파 → 디테일 / 노이즈

&ensp;LPF → 고주파 줄임 → 이미지 부드러워짐<br/>

&ensp;필터 차이<br/>
```txt
Ideal → sharp cutoff → ringing 발생
Butterworth → 완만 → 타협
Gaussian → 자연스러움 → 가장 안정
```

# High-pass Filter

&ensp;고주파를 살리면 이미지가 선명해진다.<br/>
&ensp;저주파(배경)를 줄인다.<br/>

```txt
Low-pass → 부드럽게 (blur)
High-pass → 날카롭게 (sharpen)
```

&ensp;고주파 = 경계(edge), 디테일<br/>
&ensp;저주파 = 배경, 큰 구조<br/>

&ensp;High-pass = 경계만 살린다 → 선명해짐<br/>

&ensp;수식<br/>

$$H_{hp}(u, v) = 1 - H_{lp}(u, v)$$

&ensp;의미<br/>
&ensp;LPF가 통과시키던 걸 막고 LPF가 막던 걸 통과시킨다.<br/>
&ensp;Low frequency → 제거<br/>
&ensp;High frequency → 통과<br/>

&ensp;그림<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-9.png" width="600"></p>

&ensp;1. Ideal HPF<br/>
* 가운데 (저주파) = 0
* 바깥 (고주파) = 1

&ensp;Butterworth / Gaussian HPF<br/>
&ensp;가운데가 점점 어두워짐 (부드럽게 제거)<br/>

&ensp;spatial domain 해석<br/>

$$h(x, y) = DFT^{-1}[H(u, v)]$$

&ensp;frequency filter → spatial kernel로 변환됨<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-10.png" width="600"></p>

&ensp;(a) Ideal HPF<br/>
&ensp;sinc처럼 진동 (ringing)<br/>
&ensp;`sharp cutoff → spatial에서 출렁임` <br/>

&ensp;(b) Butterworth HPF<br/>
&ensp;덜 진동<br/>

&ensp;(c) Gaussian HPF<br/>
&ensp;가장 부드러움(거의 진동 없음)<br/>

&ensp;frequency에서 급격하면 → spatial에서 진동<br/>
&ensp;frequency에서 부드러우면 → spatial에서도 부드러움<br/>

&ensp;Ideal High-pass 실제 결과<br/>
&ensp;수식<br/>

$$H(u, v) = \left\{\begin{matrix}
0 & D(u, v) \leq D_{0} \\
1 & D(u, v) > D_{0} \\
\end{matrix}\right.$$

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-11.png" width="600"></p>

&ensp;배경 제거됨, 경계만 강조됨<br/>

&ensp;D0 영향<br/>
&ensp;D0 작음 → 많은 고주파 포함 → 더 많은 edge<br/>
&ensp;D0 큼 → 일부만 → 덜 sharp<br/>

&ensp;2. Butterworth High-pass<br/>

&ensp;수식<br/>

$$H_{hp}(u, v) = 1 - \frac{1}{1+(D(u,v)/D_{0})^{2n}}$$

&ensp;특징<br/>
&ensp;Ideal보다 부드럽게 제거 → ringing 감소<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-12.png" width="600"></p>

&ensp;이미지 해석<br/>
* Ideal보다 자연스러움
* noise는 조금 덜 강조됨
* edge는 잘 보임

&ensp;`Butterworth HPF = sharp + 안정성 균형` <br/>

&ensp;3. Gaussian High-pass<br/>
&ensp;수식<br/>

$$H(u, v) = 1 - e^{-D^{2}(u, v)/2D^{2}_{0}}$$

&ensp;의미<br/>
&ensp;`Gaussian LPF의 반대 → 중심 제거 + 바깥 자연스럽게 통과` <br/>

&ensp;특징<br/>
* ringing 거의 없음
* 가장 자연스러운 sharpening

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-13.png" width="600"></p>

&ensp;이미지 해석<br/>
* noise는 덜 거칠게 보임
* edge 강조는 부드럽게 됨

&ensp;LPF vs HPF 정리<br/>
| 구분    | LPF  | HPF     |
| ----- | ---- | ------- |
| 목적    | blur | sharpen |
| 남기는 것 | 저주파  | 고주파     |
| 제거    | 고주파  | 저주파     |
| 결과    | 부드러움 | 선명함     |

# Laplacian

&ensp;1. Laplacian은 원래 공간 영역의 “2차 미분”이다.<br/>
&ensp;먼저 Laplacian은 이미지 f(x,y)에 대해 이렇게 정의된다.<br/>

$$\bigtriangledown ^{2}f(x, y) = \frac{\partial ^{2}f}{\partial x^{2}} + \frac{\partial ^{2}f}{\partial y^{2}}$$

&ensp;이미지를 픽셀 값의 표면이라고 생각해보자<br/>
&ensp;밝기가 거의 일정한 부분은 변화가 작다.<br/>
```txt
평평한 배경, 하늘, 벽, 달 표면의 넓은 회색 영역
→ 값이 천천히 변함
→ 미분값이 작음
```

&ensp;반대로 경계선이나 무늬가 있는 부분은 픽셀 값이 갑자기 변한다.<br/>
```txt
달의 크레이터 경계
글자 테두리
선
점 노이즈
밝고 어두운 부분의 경계
→ 값이 급격히 변함
→ 미분값이 큼
```

&ensp;Laplacian은 2차 미분이기 때문에 이런 급격한 변화 지점에 강하게 반응한다. 그래서 Laplacian은 공간 영역에서 보면 edge, detail, sharp transition을 잡아내는 연산자이다.<br/>

&ensp;2. 그러면 왜 frequency domain에서 Laplacian을 다룰까?<br/>
&ensp;푸리에 변환의 아주 중요한 성질이 있다. 공간 영역에서 미분을 하면 주파ㅏ수 영역에서는 주파수를 곱하는 형태가 된다.<br/>
&ensp;1차원에서 보면, $f(x) \leftrightarrow F(u)$ 일 때<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-14.png" width="600"></p>

&ensp;즉 한 번 미분하면 주파수 영역에서 $j2\pi u$ 가 곱해진다.<br/>
&ensp;두 번 미분하면<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-19.png" width="600"></p>

&ensp;그런데 $j^2 = -1$ 이므로 $(j2\pi u)^{2} = -4\pi ^{2}u^{2}$ <br/>
&ensp;그래서 2차 미분은 주파수 영역에서 $-4\pi ^{2}u^{2}F(u)$ 가 된다.<br/>

&ensp;3. 2D 이미지에서는 x, y 방향을 둘 다 본다<br/>
&ensp;이미지는 2D니까 x 방향과 y 방향이 있다. Laplacian은 **x 방향 2차 미분 + y 방향 2차 미분** 이였다. 따라서 주파수 영역에서는 각각 이렇게 바뀐다.<br/>

<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-15.png" width="600"></p>

&ensp;둘을 더하면 $\Im \{\bigtriangledown ^{2}f(x, y) \} = -4\pi ^{2}(u^{2} + v^{2})F(u, v)$ <br/>

&ensp;4. 이 식이 왜 High-pass 성질을 가질까?<br/>
&ensp;Laplacian 필터의 frequency response는<br/>

$$H(u, v) = -4\pi ^{2} (u^{2} + v^{2})$$ 

&ensp;여기서 중요한 건 크기. $u^{2} + v^{2}$ 는 중심에서 멀어질수록 커진다.<br/>
&ensp;주파수 영역에서 중심 근처는 저주파고 중심에서 멀수록 고주파였다. 그러면 Laplacian 필터는 이렇게 동작한다.<br/>
```txt
중심 근처 저주파 → u²+v² 작음 → 거의 0에 가까움
중심에서 먼 고주파 → u²+v² 큼 → 크게 강조됨
```

&ensp;즉, Laplacian은 저주파는 약하게 만들고 고주파는 크게 만든다.<br/>
&ensp;그래서 Laplacian은 본질적으로 high-pass filter이다.<br/>

&ensp;5. 중심이 이동된 경우 왜 (u−M/2),(v−N/2)가 나올까?<br/>
&ensp;앞에서 frequency domain filtering할 때 저주파를 가운데로 옮기려고 $(-1)^{x+y}$ 를 곱했다.<br/>
&ensp;그러면 DFT 결과에서 원점, 즉 저주파 중심이 배열의 왼쪽 위가 아니라 중앙에 온다.<br/>
&ensp;이미지 크기가 M×N이면 중심 좌표는 대략 (M/2,N/2) 이다.<br/>
&ensp;그래서 중심 기준 거리를 써야 한다. $u^{2} + v^{2}$ 가 아니라 <br/>
$H(u, v) = -4\pi ^{2}[(u - M/2)^{2} + (v - N/2)^{2}]$

&ensp;이렇게 된다. 이건 원점이 중앙으로 이동했으니까 거리도 중앙 기준으로 계산하자 라는 뜻이다.<br/>

&ensp;6. Laplacian으로 이미지를 선명하게 만드는 법<br/>
&ensp;Laplacian 자체를 적용하면 edge 성분만 나온다. 그런데 우리가 원하는 건 edge만 남은 이미지가 아니라 원본이 선명해진 이미지이다. 그래서 원본에 Laplacian 결과를 더하거나 빼서 sharpening을 한다.<br/>

$$g(x, y) = f(x, y) + c\bigtriangledown ^{2}f(x, y)$$

&ensp;여기서 c = -1.<br/>

$$g(x, y) = f(x, y) - \bigtriangledown ^{2}f(x, y)$$

&ensp;왜 더하거나 빼는 부호가 달라질까?<br/>
&ensp;이건 Laplacian mask의 중심 계수 부호 때문.<br/>

&ensp;Laplacian mask를 어떤 형태로 정의하느냐에 따라 결과의 부호가 반대로 나온다. 예를 들어 중심이 음수인 마스크:<br/>

&ensp;이걸 쓰면 sharpening은 보통 $g = f - \bigtriangledown ^{2}f$ 를 사용한다. <br/>

&ensp;7. frequency domain에서는 어떻게 sharpening할까?<br/>
&ensp;공간 영역에서는 $g(x, y) = f(x, y) + c\bigtriangledown ^{2}f$ <br/>
&ensp;푸리에 변환하면,<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-20.png" width="600"></p>

&ensp;즉 frequency domain에서 Laplacian sharpening은 원본 스펙트럼 F(u,v)에 새로운 필터를 곱하는 것과 같다. 그 필터는 1 + cH(u, v) 이다. <br/>

&ensp;그냥 HPF만 하면 edge만 남아서 이미지가 어둡고 이상해지는데, Laplacian sharpening은 원본을 유지하면서 edge를 강조하니까 선명해진다.<br/>

# Unsharp masking

&ensp;1. Unsharp masking<br/>
&ensp;Unsharp masking은 말 그대로 “unsharp image”, 즉 흐릿한 이미지를 이용해서 mask를 만드는 방법이다.<br/>

&ensp;원본 이미지를 f(x,y)라고 하자. 먼저 원본에 LPF를 적용해서 흐릿한 이미지를 만든다. $f_{LP}(x, y)$ 이건 원본에서 고주파가 제거된 이미지이다. 즉 부드러운 배경이나 큰 구조만 남은 이미지라고 보면 된다.<br/>
&ensp;그 다음 원본에서 흐릿한 이미지를 뺀다.<br/>
&ensp;$g_{mask}(x, y) = f(x, y) - f_{LP}(x, y)$ <br/>
&ensp;원본 - 흐릿한 이미지 = 흐릿한 부분을 제거한 나머지 = edge, detail, 고주파 성분<br/>
&ensp;즉 $g_{mask}(x, y)$ 는 이미지의 선, 경계, 디테일만 모아놓은 이미지이다.<br/>

&ensp;2. 왜 원본에서 LPF 결과를 빼면 고주파가 남을까?<br/>
&ensp;`원본 이미지 = 저주파 성분 + 고주파 성분` <br/>
&ensp;f = low + high<br/>
&ensp;LPF를 적용하면 저주파만 남는다. 그러면 원본에서 LPF 결과를 빼면 $f - f_{LP} = (low + high) - low = high$ <br/>
&ensp;그래서 mask는 고주파 성분이 되는 것이다.<br/>
&ensp;이게 unsharp masking의 핵심: 흐릿한 이미지를 빼서, 흐릿하지 않은 부분만 뽑는다.<br/>

&ensp;3. 그다음 원본에 mask를 더한다<br/>
&ensp;고주파 mask를 만들었으면, 이제 원본에 더한다.<br/>
$$g(x, y) = f(x, y) + kg_{mask}(x, y)$$ 

&ensp;여기서 k는 고주파를 얼마나 강하게 더할지 조절하는 값이다.<br/>

$$g(x, y) = f(x, y) + k[f(x, y) - f_{LP}(x, y)]$$ 

&ensp;이 식을 말로 풀면 `최종 이미지 = 원본 + k × 고주파 성분` <br/>
&ensp;즉, 원본은 그대로 유지하면서 edge와 detail만 더 강조하는 것이다.<br/>

&ensp;4. k=1과 k>1의 차이<br/>

```txt
Unsharp masking when k = 1
Highboost filtering when k > 1
```

&ensp;k = 1 -> $g = f + g_{mask}$ <br/>
&ensp;고주파 성분을 원본에 한 번 더한다. 이걸 unsharp masking.<br/>

&ensp;k > 1 -> $g = f + kg_{mask}$ <br/>
&ensp;고주파 성분을 더 강하게 더한다.<br/>
&ensp;이걸 high-boost filtering이라고 한다. 예를 들어 k = 2라면 edge와 detail을 두 배로 강조하는 느낌이다.<br/>
```txt
k가 커질수록 선명함 증가
하지만 너무 크면 noise도 같이 커짐
```

&ensp;고주파에는 edge만 있는 게 아니라 noise도 있다. 그래서 k를 너무 크게 하면 이미지가 거칠어질 수 있다.<br/>

&ensp;5. 이걸 frequency domain에서 쓰면 어떻게 될까?<br/>
&ensp;공간 영역에서는 $g = f + k(f - f_{LP})$ 였다. 이걸 주파수 영역으로 바꿔보면<br/>
&ensp;원본 이미지의 Fourier transform은 F(u, v)<br/>
&ensp;LPF 결과는 $F_{LP}(u, v) = H_{LP}(u, v)F(u, v)$ 이다.<br/>
&ensp;그래서 frequency domain에서 최종 결과는<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap4-2/4-21.png" width="600"></p>

&ensp;왜냐하면 high-pass filter는 low-pass filter의 반대<br/>
&ensp;그래서 최종적으로<br/>
$$G(u, v) = [1 + kH_{HP}(u, v)]F(u, v)$$

&ensp;6. 이 식이 진짜 의미하는 것<br/>
&ensp;$G(u, v) = [1 + kH_{HP}(u, v)]F(u, v)$ <br/>
&ensp;여기서 필터 부분은 $1 + kH_{HP}(u, v)$ <br/>
&ensp;이걸 그냥 HPF와 비교해보면<br/>
&ensp;일반 HPF는 $H_{HP}(u, v)F(u, v)$ 이니까 저주파가 거의 제거된다. 그래서 결과 이미지가 전체적으로 어둡고 edge만 남는다. 그런데 high-frequency emphasis filter는<br/>

$$[1 + kH_{HP}(u, v)]F(u, v)$$

&ensp;1이 의미하는 건 원본 이미지 성분을 기본적으로 유지한다.<br/>
&ensp;그리고 $kH_{HP}$ 는 고주파 성분을 추가로 강조한다.<br/>

&ensp;그래서 이 방식은 HPF만 적용하는 것보다 훨씬 자연스러진다.<br/>
```txt
HPF만 적용 → edge만 남음
원본 + HPF → 원본은 유지하고 edge만 강조됨
```

&ensp;7. 왜 이것을 High-frequency emphasis filter라고 부를까?<br/>
&ensp;emphasis는 “강조”라는 뜻<br/>
&ensp;High-frequency emphasis filter는 고주파를 제거하거나 단독으로 뽑는 게 아니라, **원본에 고주파를 더해서 강조하는 필터**<br/>

&ensp;`High-frequency emphasis filter = high frequency를 강조하는 필터` <br/>

&ensp;일반 HPF와 다르게 저주파를 완전히 없애지 않는다. 저주파는 이미지의 밝기, 배경, 전체적인 구조를 담당한다. 이걸 없애면 이미지가 어두워지고 이상해진다.<br/>

&ensp;8. DC term이 뭔데 왜 없애면 안 될까?<br/>
&ensp;DC term은 주파수 영역의 중심 성분<br/>
&ensp;이미지에서는 대략적으로 말하면 전체 평균 밝기, 전체적인 배경 톤에 해당된다.<br/>
&ensp;HPF는 중심의 저주파를 제거하니까 DC term도 제거해버린다. 그러면 이미지의 평균 밝기가 사라지고 결과가 어둡게 보일 수 있다. 그래서 high-frequency emphasis filter에서는 offset을 더한다.<br/>

$$g(x, y) = \Im ^{-1}{k_{1} + k_{2}H_{HP}(u, v)F(u, v)}$$ 

* $k_{1}$ : 원본/저주파/DC 성분을 얼마나 유지할지
* $k_{2}$ : 고주파 성분을 얼마나 강조할지

&ensp;9. Laplacian sharpening과의 차이<br/>
&ensp;Laplacian sharpening: `2차 미분으로 edge/detail을 뽑는다.` <br/>

$$g = f + c\bigtriangledown ^{2}f$$

&ensp;Unsharp masking / high-boost: `원본에서 흐린 이미지를 빼서 edge/detail을 뽑는다.` <br/>

$$g = f + k(f - f_{LP})$$

&ensp;Laplacian: 미분 기반<br/>
&ensp;Unsharp masking: blur 차이 기반<br/>
