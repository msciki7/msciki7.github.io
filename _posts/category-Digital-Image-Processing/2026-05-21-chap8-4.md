# Fourier Series와 Fourier Transform의 차이

&ensp;복잡한 신호도 여러 개의 사인파/코사인파를 섞어서 표현할 수 있다.<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap8-4/8-1.png" width="600"></p>

&ensp;위 그림을 보면 위에 작은 파형들이 여러 개 있고, 아래에 복잡한 파형이 있지? 이 말은 아래의 복잡한 신호가 사실은 위쪽의 여러 단순한 파형을 더해서 만들어질 수 있다는 뜻이다.<br/>

&ensp;복잡한 신호 = 저주파 성분 + 고주파 성분 + ... <br/>
&ensp;이미지는 2D 신호니까, 이미지도 여러 주파수 성분의 조합으로 표현할 수 있다.<br/>

&ensp;Fourier Series<br/>
&ensp;Fourier Series는 주기적인 신호를 다룰 때 사용<br/>
&ensp;반복되는 신호는 여러 주파수의 사인파/코사인파 합으로 표현할 수 있다.<br/>

&ensp;수식<br/>
$$f(x) = \sum_{k = -\infty }^{\infty }F[k]e^{jkw_{0}x}$$

&ensp;또는 시간 신호에서는<br/>

$$x(t) = \sum_{k = -\infty }^{\infty }X[k]e^{jkw_{0}t}$$

&ensp;Fourier Transform<br/>
&ensp;Fourier Transform은 비주기 신호를 다룰 때 사용한다.<br/>
&ensp;비주기 신호는 반복 주기가 없기 때문에, 주파수 성분이 연속적으로 퍼져 있다고 본다.<br/>

&ensp;수식<br/>
$$f(x) = \int_{-\infty }^{\infty }F(u)e^{j2\pi ux}du$$

&ensp;여기서 F(u)는 주파수 u 성분이 얼마나 들어 있는지를 나타내는 가중치이다.<br/>

&ensp;시험용 차이 정리<br/>

| 구분    | Fourier Series | Fourier Transform |
| ----- | -------------- | ----------------- |
| 대상    | 주기 신호          | 비주기 신호            |
| 표현 방식 | 사인/코사인의 합      | 사인/코사인의 적분        |
| 주파수   | 이산적            | 연속적               |
| 수식 핵심 | $\sum$         | $\int$            |
| 계수    | $F[k]$, $X[k]$ | $F(u)$            |

&ensp;이게 이미지 처리에서 중요한 이유<br/>
&ensp;이미지는 픽셀값으로 되어 있다. 예를 들어 이미지 블록이 있으면 공간 영역에서는 f(x, y)로 보인다.(x, y 는 위치)<br/>
&ensp;그런데 푸리에 변환이나 DCT를 하면 이미지를 주파수 영역으로 바꿀 수 있다.<br/>
$$f(x, y) -> F(u, v)$$

&ensp;u, v는 주파수 위치<br/>
&ensp;공간 영역에서는 "어느 위치의 픽셀값이 얼마인가?"를 보지만, 주파수 영역에서는 "밝기가 얼마나 천천히 또는 빠르게 변하는가?"를 본다.<br/>

&ensp;예를 들어 부드러운 하늘 사진은 대부분 저주파 성분이 많는다.<br/>
&ensp;부드러운 영역 -> 저주파 성분 많음<br/>

&ensp;반대로 글자, 경계선, 머리카락 같은 부분은 고주파 성분이 많다.<br/>
&ensp;급격한 변화/경계 -> 고주파 성분 많음<br/>

&ensp;압축에서는 이 성질을 이용한다. 사람 눈은 보통 고주파의 세밀한 변화에 상대적으로 덜 민감하니까, 고주파 계수를 더 많이 양자화하거나 버린다. 이게 JPEG에서 DCT를 쓰는 이유와 이어진다.<br/>

&ensp;Linear Independence와 Span<br/>
&ensp;선형결합<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap8-4/8-2.png" width="600"></p>

&ensp;벡터 여러 개가 있다.<br/>

$$v_{1}, v_{2}, ..., v_{n}$$

&ensp;이 벡터들에 어떤 숫자 $a_{1}, a_{2}, ..., a_{n}$ 을 곱해서 더하는 걸 선형결합이라고 한다.<br/>

$$a_{1}v_{1} + a_{2}v_{2} + ... + a_{n}v_{n}$$

&ensp;선형독립<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap8-4/8-3.png" width="600"></p>

&ensp;어떤 벡터도 다른 벡터들의 조합으로 만들 수 없는 상태<br/>
&ensp;수식으로는 $a_{1}v_{1} + a_{2}v_{2} + ... + a_{n}v_{n} = 0$ 을 만족하는 방법이 $a_{1} = a_{2} = ... = a_{n} = 0$ 뿐이면 선형독립이다.<br/>

&ensp;서로 중복되지 않는 방향들이라는 뜻<br/>

&ensp;예를 들어 2차원 평면에서 [1, 0], [0, 1]은 선형독립이다. 왜냐하면 x축 방향과 y축 방향은 서로 다른 방향이고, 하나로 다른 하나를 만들 수 없다.<br/>
&ensp;반대로 [1, 0],[2, 0]은 선형종속이다. 둘 다 x축 방향이기 때문에 하나는 다른 하나의 배수이다.<br/>

&ensp;Span<br/>
&ensp;Span은 어떤 벡터들의 선형결합으로 만들 수 있는 전체 공간이다. 예를 들어 [1, 0], [0, 1]이 두 벡터가 있으면 2차원 평면의 모든 벡터를 만들 수 있다. <br/>
&ensp;[3, 5] = 3[1, 0] + 5[0, 1]<br/>
&ensp;그래서 이 두 벡터는 2차원 공간을 span한다고 말한다.<br/>

&ensp;DFT에서 basis vector의 의미<br/>
&ensp;DFT도 같은 원리<br/>
&ensp;길이가 N인 신호가 있다고 해보자. $x = [x_{0}, x_{1}, ..., x_{N-1}]$ <br/>
&ensp;DFT는 이 신호를 N개의 basis vector 조합으로 표현한다. 각 basis vector는 서로 다른 주파수의 복소 지수파이다. <br/>
$$원래 신호 = 저주파 기저 × 계수 + 고주파 기저×  계수+⋯$$

&ensp;Video Compression Standard<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap8-4/8-4.png" width="600"></p>

&ensp;영상 압축은 예측으로 만든 차이 블록(residual block)을 DCT하고, 양자화하고, 엔트로피 코딩한다.<br/>

&ensp;전체 흐름<br/>
1. 현재 블록을 예측한다.
2. 실제 블록과 예측 블록의 차이인 residual block을 만든다.
3. residual block에 DCT를 한다.
4. DCT 계수를 양자화한다.
5. 가변 길이 부호화로 더 압축한다.
6. encoded block을 만든다.

&ensp;VVC/H.266 Standard<br/>
<p align="center"><img src="/assets/img/Digital Image Processing/chap8-4/8-5.png" width="600"></p>

&ensp;H.266, 즉 VVC는 HEVC/H.265 다음 세대의 영상 압축 표준이다.<br/>
&ensp;흐름: 예측 → 잔차 계산 → 변환 → 양자화 → 엔트로피 코딩<br/>
&ensp;디코더 흐름: 역양자화 → 역변환 → 복원 → 필터 → 다음 예측에 사용<br/>
