## 0. Chapter 6에서 배우는 것

&ensp;PVT는 다음 세 가지를 의미한다.<br/>

* **P — Position**
* **V — Velocity**
* **T — Time**

&ensp;GPS receiver는 satellite에서 신호를 받아 최종적으로 사용자의 **Position, Velocity, Time**을 계산한다.<br/>
&ensp;Chapter 6의 전체 흐름은 다음과 같다.<br/>

&ensp;**Pseudorange 측정**<br/>
&ensp;→ 여러 measurement error 보정<br/>
&ensp;→ **Position + Receiver clock bias estimation**<br/>
&ensp;→ Least-Squares를 이용한 위치 계산<br/>
&ensp;→ Position estimation error 분석<br/>
&ensp;→ **DOP을 이용한 satellite geometry 평가**<br/>
&ensp;→ Pseudorange rate를 이용한 **Velocity estimation**<br/>
&ensp;→ Receiver clock bias를 이용한 **Time transfer**<br/>

---

# 1. Position Estimation with Pseudoranges

## 1.1 Pseudorange measurement

&ensp;k번째 satellite에서 측정한 pseudorange는<br/>

$$\rho^{(k)}(t) = r^{(k)}(t,t-\tau) + c[\delta t_u(t)-\delta t^{(k)}(t-\tau)] + I^{(k)}(t) + T^{(k)}(t) + \epsilon_\rho^{(k)}(t)$$

&ensp;로 표현된다.<br/>
&ensp;각 항의 의미는 다음과 같다.<br/>
* $r^{(k)}$: user와 satellite 사이의 실제 **geometric range**
* $\delta t_u$: receiver clock offset
* $\delta t^{(k)}$: satellite clock offset
* $I^{(k)}$: ionospheric delay
* $T^{(k)}$: tropospheric delay
* $\epsilon_\rho^{(k)}$: 그 밖의 measurement error
* c: speed of light

> **Pseudorange = geometric range + clock error + atmospheric error + measurement error**

&ensp;GPS receiver는 정확한 geometric range를 직접 측정하는 것이 아니라 여러 오차가 포함된 **pseudorange**를 측정한다.<br/>

---

## 1.2 Pseudorange error correction

&ensp;Navigation message를 이용하여 주로 다음과 같은 항목을 보정한다.<br/>
* Satellite clock offset
* Relativity effect
* Ionospheric delay

&ensp;더 높은 accuracy가 필요한 경우 추가적인 방법을 사용할 수 있다.<br/>

### Multipath

&ensp;Multipath에 의해 code measurement error가 발생할 수 있다.<br/>
&ensp;이를 줄이기 위해 **Carrier-smoothing of code measurements** 를 사용할 수 있다. Carrier phase는 code measurement보다 상대적으로 noise가 작기 때문에 code measurement를 smoothing하는 데 활용할 수 있다.<br/>

### Ionospheric delay

&ensp;L1/L2 dual-frequency receiver를 이용하면 frequency에 따른 ionospheric delay 특성을 이용하여 ionospheric error를 줄일 수 있다.<br/>

### Tropospheric delay

&ensp;Tropospheric delay는 별도의 **model**을 이용하여 보정한다.<br/>

### Satellite position / clock error

&ensp;Satellite position과 clock error, signal propagation error 등은 Local-area DGPS, Wide-area DGPS 등의 correction service를 이용해 추가적으로 보정할 수 있다.<br/>

---

# 2. Corrected Pseudorange

&ensp;여러 error를 최대한 보정한 후 pseudorange를 다음과 같이 단순화할 수 있다.<br/>

$$\rho_c^{(k)} = r^{(k)} + c\delta t_u + \tilde{\epsilon}_\rho^{(k)}$$

&ensp;Receiver clock bias를 meter 단위로 $b=c\delta t_u$ 라고 정의하면

$\rho_c^{(k)} = |x^{(k)}-x| + b + \tilde{\epsilon}_\rho^{(k)}$

&ensp;가 된다.<br/>

&ensp;여기서 $x^{(k)} = (x^{(k)},y^{(k)},z^{(k)})$ 는 kth satellite의 position이고, $x=(x,y,z)$ 는 user position이다.<br/>

&ensp;Geometric range는<br/>

$$r^{(k)} = \sqrt{(x^{(k)}-x)^2+(y^{(k)}-y)^2+(z^{(k)}-z)^2}$$

&ensp;이다.<br/>

---

# 3. 왜 GPS에서 Satellite가 최소 4개 필요한가?

&ensp;Receiver가 구해야 할 unknown은 $x,\qquad y,\qquad z,\qquad b$ 이다.<br/>
* x position
* y position
* z position
* receiver clock bias

&ensp;총 **4개의 unknown**이 존재한다.<br/>
&ensp;따라서 최소 4개의 independent pseudorange measurement가 필요하다.<br/>

$$\text{4 unknowns} \Rightarrow \text{minimum 4 satellites}$$

&ensp;GPS에서 satellite가 최소 4개 필요한 이유는 단순히 3-D position만 구하는 것이 아니라 **receiver clock bias까지 함께 estimation하기 때문**이다.<br/>

---

# 4. Earth Rotation Correction

&ensp;Satellite에서 signal이 전송된 시각과 receiver에 도착하는 시각은 다르다.<br/>
&ensp;Satellite가 signal을 송신한 시각: $t-\tau$ <br/>
&ensp;Receiver가 signal을 수신한 시각: t<br/>
&ensp;Signal이 이동하는 동안 Earth도 회전한다.<br/>
&ensp;따라서 transmission time에서의 satellite ECEF position을 그대로 사용할 수 없으며 Earth rotation을 보정해야 한다.<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-1.png" width="600"></p>

* $\omega_E$ : Earth rotation rate
* $\tau$ : signal transit time
* $\tilde{x}^{(k)}$ : transmission time에서의 satellite position

> Signal이 이동하는 동안 Earth가 회전하기 때문에 satellite position의 coordinate frame을 receiver measurement epoch에 맞춰줘야 한다.

---

# 5. Position Equation은 Nonlinear

&ensp;Corrected pseudorange equation은<br/>

$$\rho_c^{(k)} = \sqrt{(x^{(k)}-x)^2+(y^{(k)}-y)^2+(z^{(k)}-z)^2}+b$$

&ensp;이다.<br/>
&ensp;Unknown (x,y,z)가 square root 내부에 존재하므로 **nonlinear equation**이다. 따라서 바로 matrix equation으로 만들어 inverse를 계산하기 어렵다. 이를 해결하기 위해 **linearization**을 수행한다.<br/>

---

# 6. Initial Guess

&ensp;먼저 user position과 clock bias의 initial guess를 설정한다.<br/>

$$x_0=(x_0,y_0,z_0)$$

&ensp;$b_0$ Initial guess를 이용해 예상 pseudorange를 계산하면<br/>

$$\rho_0^{(k)} = |x^{(k)}-x_0|+b_0$$

&ensp;이다.<br/>
&ensp;실제 position과 initial position의 차이를 $\delta x=x-x_0$ 라고 정의한다. Clock bias correction도 $\delta b=b-b_0$ 로 정의한다.<br/>

* $x_0$: 현재 예상 position
* $\delta x$: 예상 position에서 실제 position 방향으로 이동해야 하는 correction

---

# 7. Taylor Expansion을 이용한 Linearization

거리항 $\|x^{(k)}-x_0-\delta x\|$ 을 $x_0$ 주변에서 first-order Taylor expansion하면

$$|x^{(k)}-x_0-\delta x| \approx |x^{(k)}-x_0| - \frac{x^{(k)}-x_0}{|x^{(k)}-x_0|} \cdot\delta x$$

&ensp;가 된다.<br/>
&ensp;여기서<br/>

$$(-1)^{(k)} = \frac{x^{(k)}-x_0}{|x^{(k)}-x_0|}$$

&ensp;를 정의한다.<br/>

&ensp;$(-1)^{(k)}$ 는 **Line-of-Sight(LOS) unit vector**이다.<br/>

> User의 initial position에서 kth satellite 방향을 나타내는 길이 1의 vector

---

# 8. Pseudorange Residual

&ensp;실제 corrected pseudorange와 initial guess에서 계산한 pseudorange의 차이를 $\delta\rho^{(k)} = \rho_c^{(k)}-\rho_0^{(k)}$ 라고 한다.<br/>

&ensp;Linearization 결과를 적용하면<br/>

$$\delta\rho^{(k)} \approx ((-1)^{(k)})^T\delta x + \delta b + \tilde{\epsilon}_\rho^{(k)}$$

&ensp;가 된다.<br/>

&ensp;원래 pseudorange equation은 nonlinear이었지만 $\delta x,\delta b$ 에 대해서는 **linear equation**으로 표현할 수 있게 된다.<br/>

---

&ensp;Satellite가 K개 존재하면 각각에 대해 위의 equation을 만들 수 있다.<br/>
&ensp;이를 matrix 형태로 표현하면<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-2.png" width="600"></p>

&ensp;Geometry matrix (G)는<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-3.png" width="600"></p>

&ensp;각 satellite에 대한 row는 $[-1_x, -1_y, -1_z,1]$ 의 형태가 된다.<br/>

### Geometry Matrix의 의미

&ensp;(G)에는 단순히 satellite의 개수만 포함되는 것이 아니라, **User를 기준으로 satellite들이 어느 방향에 위치해 있는가** 라는 geometry 정보가 들어 있다. 따라서 이후의 positioning accuracy와 DOP도 (G)에 의해 결정된다.<br/>

---

# 10. Iterative Position Estimation

&ensp;Linearization은 현재 initial guess 주변에서만 정확하기 때문에 correction을 반복적으로 계산해야 한다.<br/>

### Step 1

&ensp;Initial guess 설정 $x_0,\quad b_0$ <br/>

### Step 2

&ensp;현재 position에서 Geometry matrix와 pseudorange residual 계산<br/>

### Step 3

&ensp;$\delta x,\quad\delta b$ 계산<br/>

### Step 4

&ensp;Position update<br/>

$$x_1=x_0+\delta x$$

$$b_1=b_0+\delta b$$

### Step 5

&ensp;새로운 (x_1,b_1)를 initial guess로 사용하여 다시 계산<br/>
&ensp;이 과정을 correction이 충분히 작아질 때까지 반복한다.<br/>

$$x_0 \rightarrow x_1 \rightarrow x_2 \rightarrow \cdots \rightarrow \hat{x}$$

&ensp;의 형태로 solution에 접근한다.<br/>

&ensp;강의록에서는 일반적으로 $x_0=0, b_0=0$ 으로 시작해도 **2~4 iterations 정도면 convergence**한다고 설명한다.<br/>

---

# 11. Satellite가 정확히 4개인 경우

&ensp;Unknown이 4개이고 satellite measurement도 4개라면 (G)는 4×4 matrix가 된다.<br/>
&ensp;Inverse가 존재한다면<br/>

$$\begin{bmatrix} \delta x\ \delta b \end{bmatrix} = G^{-1}\delta\rho$$

&ensp;로 correction을 계산할 수 있다.<br/>

---

# 12. Satellite가 4개보다 많은 경우

&ensp;실제 GNSS receiver에서는 4개 이상의 satellite를 이용하는 경우가 많다. 예를 들어 satellite가 8개라면<br/>
* Measurement = 8개
* Unknown = 4개

&ensp;가 된다.<br/>
&ensp;이런 system을 **over-determined system**이라고 한다. Measurement error가 존재하기 때문에 모든 equation을 정확하게 만족하는 solution은 일반적으로 존재하지 않는다. 따라서 **Least-Squares**를 이용한다.<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-4.png" width="600"></p>

$$\hat{x}=x_0+\delta \hat{x}$$

$$\hat{b}=b_0+\delta \hat{b}$$

&ensp;로 새로운 estimate를 계산한다.<br/>

---

# 13. Least-Squares

&ensp;일반적인 linear measurement equation을 $y_{\text{meas}}=Ax+\text{error}$ 라고 하자.<br/>
&ensp;Residual을 $r=Ax-y_{\text{meas}}$ 라고 정의한다. Least-Squares에서는 residual의 squared magnitude $|r|^2$ 를 최소화한다.<br/>

$$|r|^2 = (Ax-y)^T(Ax-y)$$

&ensp;을 최소화하는 x를 찾는다. 이를 x에 대해 differentiate하고 0으로 놓으면 $A^TAx=A^Ty$ 이고, $x_{\text{opt}} = (A^TA)^{-1}A^Ty$ 를 얻는다.<br/>

&ensp;GPS에서는 $A\rightarrow G$ 가 되므로 pseudorange position estimation의 Least-Squares solution이 만들어진다.<br/>

---

# 14. Weighted Least-Squares

&ensp;Ordinary Least-Squares는 모든 measurement가 동일한 quality를 가지고 있다고 가정한다. 하지만 GPS에서는 satellite마다 measurement quality가 다를 수 있다.특히 **low-elevation satellite**는 일반적으로<br/>
* atmosphere를 통과하는 경로가 길고
* multipath에 취약하며
* obstruction 영향을 받을 가능성이 크기 때문에

&ensp;measurement error가 더 커질 수 있다.<br/>
&ensp;따라서 satellite마다 서로 다른 weight를 적용한다.<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-5.png" width="600"></p>

> Accuracy가 좋은 measurement에는 큰 weight를 주고, error가 클 것으로 예상되는 measurement에는 작은 weight를 준다.

---

# 15. Satellite Geometry의 중요성

&ensp;Position accuracy는 measurement quality뿐만 아니라 **satellite geometry**의 영향을 크게 받는다. 두 satellite가 user를 기준으로 비슷한 방향에 존재하면 range measurements가 비슷한 방향에서 교차한다. → Position uncertainty 영역이 커진다.<br/>
&ensp;반대로 satellite들이 서로 다른 방향에 넓게 분포하면 range measurements가 좋은 각도로 교차한다. → Position uncertainty 영역이 작아진다.<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-6.png" width="600"></p>

&ensp;따라서 $\text{Satellite number} \neq \text{Position accuracy}$ 이며 satellite가 몇 개 존재하는지만큼이나 **어떤 geometry로 배치되어 있는지**가 중요하다.<br/>

---

# 16. Measurement Error Model

&ensp;Corrected pseudorange의 residual error를 $\tilde{\epsilon}_\rho$ 라고 하자. 강의에서는 단순화를 위해 다음을 가정한다.<br/>

### Zero Mean

$E(\tilde{\varepsilon}_\rho)=0$

### Uncorrelated

&ensp;각 satellite의 measurement error가 서로 correlation이 없다고 가정한다.<br/>

### Identically Distributed

&ensp;모든 satellite measurement가 동일한 variance를 가진다고 가정한다.<br/>

$$Cov(\tilde{\varepsilon}_\rho) = \sigma_{\text{URE}}^2 I$$

&ensp;여기서 URE는 **User Range Error**이다.<br/>

---

# 17. Position Estimate Error

&ensp;Position estimation error를 $\Delta x=\hat{x}-x$ , clock bias estimation error를 $\Delta b=\hat{b}-b$ 라고 정의한다. Measurement error가 zero mean이라고 가정하면<br/>

$$E[\Delta x]=0$$

$$E[\Delta b]=0$$

&ensp;이 된다.<br/>
&ensp;Estimate error covariance는<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-7.png" width="600"></p>

&ensp;이다.<br/>
&ensp;여기서 $H=(G^TG)^{-1}$ 라고 정의하면 $Cov=\sigma^2H$ 로 표현할 수 있다.<br/>

---

# 18. 이 식이 중요한 이유

&ensp;$Cov=\sigma^2(G^TG)^{-1}$ 에서 positioning uncertainty는 크게 두 요소로 나뉜다.<br/>

### Measurement quality

$$\sigma$$

### Satellite geometry

$$(G^TG)^{-1}$$

&ensp;따라서 GPS positioning error는<br/>

$$\text{Position Error} \approx \text{Range Measurement Error} \times \text{Satellite Geometry}$$

&ensp;라는 구조로 이해할 수 있다.<br/>
&ensp;이 satellite geometry의 영향을 숫자로 표현한 것이 **DOP**이다.<br/>

---

# 19. RMS Positioning Error

&ensp;$H=(G^TG)^{-1}$ 라고 할 때

$$\sigma_x^2=\sigma^2H_{11}$$

$$\sigma_y^2=\sigma^2H_{22}$$

$$\sigma_z^2=\sigma^2H_{33}$$

$$\sigma_b^2=\sigma^2H_{44}$$

&ensp;이다.<br/>
&ensp;3-D RMS position error는 $\sqrt{\sigma_x^2 + \sigma_y^2 + \sigma_z^2}$ 이므로 $3D\ RMS = \sigma \sqrt{H_{11}+H_{22}+H_{33}}$ 가 된다.<br/>

---

# 20. Dilution of Precision — DOP

&ensp;DOP은 **satellite geometry가 measurement error를 얼마나 증폭시키는지** 나타내는 값이다.<br/>

## PDOP — Position Dilution of Precision

$$PDOP= \sqrt{H_{11}+H_{22}+H_{33}}$$

&ensp;3-D position geometry를 나타낸다.<br/>
&ensp;따라서 $3D\ position\ error \approx \sigma\times PDOP$ 이다.<br/>

---

## TDOP — Time Dilution of Precision

$$TDOP=\sqrt{H_{44}}$$

&ensp;Clock bias error와 관련된다.<br/>

$$Clock\ bias\ error \approx \sigma\times TDOP$$

---

## GDOP — Geometric Dilution of Precision

&ensp;Position과 Time을 모두 포함한다.<br/>

$$GDOP = \sqrt{H_{11}+H_{22}+H_{33}+H_{44}}$$

&ensp;따라서 $GDOP^2 = PDOP^2 + TDOP^2$ 이다.<br/>

---

# 21. DOP의 의미

&ensp;예를 들어 pseudorange measurement error가 $\sigma=2m$ 라고 하자.<br/>

### PDOP = 1

$$3D\ RMS\approx2m$$

### PDOP = 5

$$3D\ RMS\approx10m$$

&ensp;즉, measurement quality가 동일해도 satellite geometry가 나쁘면 position error가 크게 증가할 수 있다.<br/>
&ensp;따라서 DOP가 작을수록 좋은 satellite geometry 라고 볼 수 있다.<br/>

# 25. HDOP와 VDOP

&ensp;Horizontal direction은 East와 North를 포함하므로 $HDOP = \sqrt{\tilde H_{11}+\tilde H_{22}}$ 이다.<br/>

&ensp;Vertical direction은 $VDOP=\sqrt{\tilde H_{33}}$ 이다.<br/>


$$Horizontal\ RMS\ error = \sigma\times HDOP$$

$$Vertical\ RMS\ error = \sigma\times VDOP$$

$$3D\ RMS\ error = \sigma\times PDOP$$

&ensp;으로 표현할 수 있다.<br/>

# 26. 왜 VDOP가 HDOP보다 큰 경우가 많은가?

&ensp;Horizontal 방향에서는 satellite가<br/>
* East
* West
* North
* South

&ensp;등 여러 방향으로 분포할 수 있다.<br/>
&ensp;반면 vertical 방향에서는 모든 satellite가 user의 **위쪽 하늘**에 존재한다. Receiver 아래쪽에서는 satellite signal을 받을 수 없다. 따라서 vertical direction의 geometry가 horizontal direction보다 상대적으로 불리하다. 그 결과 일반적으로 $VDOP>HDOP$ 가 되는 경우가 많다.<br/>
&ensp;이것은 GPS에서 **vertical position accuracy가 horizontal position accuracy보다 좋지 않은 이유 중 하나**이다.<br/>

# 27. Distribution of DOP

&ensp;Satellite의 위치는 시간에 따라 변하기 때문에<br/>
* Visible satellite number
* Satellite geometry
* DOP

&ensp;도 계속 변한다.<br/>
&ensp;여기서 중요한 점은 **Satellite 개수가 많다고 반드시 DOP가 좋은 것은 아니다.** Satellite가 여러 개 있더라도 모두 한쪽 방향에 몰려 있다면 geometry가 좋지 않을 수 있다.반대로 satellite 수가 조금 적더라도 sky에 넓게 분포되어 있으면 좋은 geometry를 만들 수 있다.<br/>

&ensp;강의록의 simulation 결과에서는 대체로<br/>
* HDOP ≈ 1 근처
* TDOP ≈ 1 근처
* 일반적으로 2를 크게 넘지 않음
* VDOP가 HDOP보다 큰 경향

&ensp;을 보여준다.<br/>

# 28. Price of an Inexpensive Receiver Clock

&ensp;GPS receiver에는 satellite에 사용되는 atomic clock만큼 정밀한 clock을 사용할 수 없다. 따라서 receiver clock bias를 unknown으로 포함해야 한다. 결국 GPS position solution의 unknown은 x, y, z, b가 되고 최소 satellite 4개가 필요하다. 만약 receiver clock bias를 정확하게 알고 있다면 unknown은 x, y, z 3개만 남게 된다.<br/>

# 33. Velocity Estimation

&ensp;Position estimation에서는 **pseudorange**를 이용했다. Velocity estimation에서는 pseudorange를 시간에 대해 differentiate한 **pseudorange rate**를 이용한다. $\rho^{(k)}$ 를 시간에 대해 differentiate하면 $\dot{\rho}^{(k)}$ 가 된다.<br/>

&ensp;Geometric range rate는<br/>

$$\dot r^{(k)} = (v^{(k)}-v)\cdot 1^{(k)}$$

* $v^{(k)}$ : satellite velocity
* v: user velocity
* $1^{(k)}$ : LOS unit vector

&ensp;Geometric Range Rate 유도<br/>
&ensp;Position estimation에서는 pseudorange를 이용했다면, Velocity estimation에서는 pseudorange를 시간에 대해 differentiate한 pseudorange rate를 이용한다.<br/>
&ensp;이때 왜 다음과 같은 식이 나오는지 과정을 살펴본다.<br/>

$$\left(v^{(k)}-v\right)\cdot 1^{(k)}$$

&ensp;1. Geometric Range<br/>
&ensp;k번째 satellite와 user 사이의 geometric range는<br/>

$$\sqrt{\left(x^{(k)}-x\right)^2 + \left(y^{(k)}-y\right)^2 + \left(z^{(k)}-z\right)^2}$$

&ensp;Vector 형태로 간단하게 표현하면<br/>

$$\left|x^{(k)}-x\right|$$

&ensp;2. Range를 시간에 대해 Differentiate<br/>
&ensp;위 식을 시간에 대해 differentiate하면<br/>

$$\frac{x^{(k)}-x}{r^{(k)}} \left(v_x^{(k)}-v_x\right) + \frac{y^{(k)}-y}{r^{(k)}} \left(v_y^{(k)}-v_y\right) + \frac{z^{(k)}-z}{r^{(k)}} \left(v_z^{(k)}-v_z\right)$$

&ensp;가 된다.<br/>
&ensp;Position의 time derivative는 velocity이므로 $\dot{x}^{(k)}=v_x^{(k)}, \qquad \dot{x}=v_x$ 와 같이 표현할 수 있다.<br/>

&ensp;3. LOS Unit Vector와 연결<br/>
&ensp;Satellite 방향의 LOS(Line-of-Sight) unit vector는 $\frac{x^{(k)}-x}{\left|x^{(k)}-x\right|}$ 이다.<br/>

&ensp;Component 형태로 쓰면<br/>

$$\begin{bmatrix} \dfrac{x^{(k)}-x}{r^{(k)}} , \dfrac{y^{(k)}-y}{r^{(k)}} , \dfrac{z^{(k)}-z}{r^{(k)}} \end{bmatrix}$$

&ensp;따라서 range rate는 $\left(v^{(k)}-v\right)^T l^{(k)}$ 또는 $\left(v^{(k)}-v\right)\cdot 1^{(k)}$ 로 표현할 수 있다.<br/>

&ensp;핵심 의미<br/>
&ensp;$v^{(k)}-v$ 는 satellite와 user 사이의 relative velocity이다. 하지만 relative velocity 전체가 satellite-user distance를 변화시키는 것은 아니다. Relative velocity 중에서 LOS 방향 component만 range를 변화시킨다.<br/>

> Range rate = Relative velocity를 LOS 방향으로 projection한 값

---

# 34. 왜 Dot Product를 사용하는가?

&ensp;Satellite와 user 사이의 relative velocity는 $v^{(k)}-v$ 이다. 하지만 relative velocity 전체가 satellite-user distance를 변화시키는 것은 아니다. LOS 방향의 velocity component만 range를 변화시킨다.<br/>

&ensp;$(v^{(k)}-v)\cdot 1^{(k)}$ 라는 dot product를 사용한다.<br/>

> Relative velocity를 satellite-user LOS 방향으로 projection한 값이 range rate이다.

---

# 35. Receiver Clock Drift

&ensp;Position estimation에서는 receiver clock **bias** b를 unknown으로 계산했다. Velocity estimation에서는 이를 시간에 대해 differentiate한 $\dot{b}$ 즉, **receiver clock drift**가 unknown으로 등장한다.<br/>
&ensp;따라서 velocity estimation의 unknown도 $v_x,\quad v_y,\quad v_z,\quad \dot b$ 총 4개이다.<br/>

---

# 36. Velocity Linear Equation

&ensp;Satellite velocity와 LOS 관련 known term을 정리하면<br/>

$$\tilde{\dot\rho}^{(k)} =  -1^{(k)}\cdot v + \dot b + \epsilon_{\dot\phi}^{(k)}$$

&ensp;가 된다.<br/>
&ensp;전체 satellite에 대해 matrix 형태로 표현하면<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-18.png" width="600"></p>

&ensp;가 된다.<br/>
&ensp;Position estimation과 동일한 **Geometry matrix (G)**를 이용할 수 있다.<br/>
* Least-Squares
* Weighted Least-Squares
* Covariance
* DOP

&ensp;등의 개념도 velocity estimation에 유사하게 적용할 수 있다.<br/>

&ensp;Position estimation과 Velocity estimation의 식을 비교하면 두 estimation 구조가 거의 동일하다는 것을 알 수 있다.<br/>
&ensp;Position Estimation<br/>
&ensp;Measurement는 pseudorange이다. $c$. Unknown은 $x,\quad y,\quad z,\quad b$ 이다. Linearized equation은 $G \begin{bmatrix} \delta x\ \delta b \end{bmatrix} + \epsilon$ 이다.<br/>

&ensp;Velocity Estimation<br/>
&ensp;Measurement는 pseudorange rate / Doppler이다. $\dot{\rho}$ <br/>
&ensp;Unknown은 $v_x,\quad v_y,\quad v_z,\quad \dot{b}$ 이다.<br/>
&ensp;Linear equation은 $G \begin{bmatrix} v\ \dot{b} \end{bmatrix} + \epsilon$ 이다.<br/>

> Position은 range를 이용하고, Velocity는 range의 변화율을 이용하지만 estimation의 수학적 구조는 매우 유사하다.

---

# 37. Doppler와 Velocity Estimation

&ensp;Pseudorange rate는 **Doppler frequency measurement**와 연결된다. Satellite와 receiver 사이에 relative radial velocity가 존재하면 received carrier frequency가 Doppler shift를 가진다. 따라서 GPS receiver는 Doppler measurement를 이용하여 user velocity를 계산할 수 있다.<br/>

# 38. Velocity Estimation의 Error Source

&ensp;Moderate user speed에서는 주요 error가<br/>
* Predicted satellite position error
* Predicted satellite velocity error

&ensp;이다.<br/>
&ensp;Satellite position에 error가 있으면 LOS vector $1^{(k)}$ 가 잘못 계산된다.Satellite velocity에 error가 있으면 $v^{(k)}$ 자체가 잘못되기 때문에 predicted range rate에도 error가 발생한다.<br/>

---

# 39. High Dynamics User

&ensp;Acceleration과 jerk가 큰 high-dynamics user에서는 velocity estimation이 더 어려워진다. 그 이유는 delta range가 measurement interval 동안의 변화량을 이용하므로 기본적으로 **Measurement interval 동안의 average velocity** 를 나타내기 때문이다. 따라서 measurement interval 동안 velocity가 빠르게 변하면 instantaneous velocity와 차이가 발생할 수 있다. 또한 high dynamics는 receiver clock phase noise에도 영향을 줄 수 있다.<br/>

---

# 40. Relative Velocity

&ensp;두 receiver가 가까운 지역에서 동일한 satellite들을 이용하면 satellite 관련 error가 두 receiver에 비슷하게 포함된다.<br/>
&ensp;예를 들어<br/>
* Satellite position error
* Satellite velocity error

&ensp;등이다.<br/>
&ensp;두 receiver의 velocity를 difference하면 이러한 **common error가 상당 부분 cancel**될 수 있다. 따라서 absolute velocity보다 relative velocity에서 훨씬 높은 accuracy를 얻을 수 있다.<br/>

# 41. Time Transfer

&ensp;GPS는 Position과 Velocity뿐 아니라 매우 정확한 **Time synchronization**에도 사용된다. 목표 중 하나는 UTC(USNO)에 synchronization된 **1PPS(One Pulse Per Second)** signal 생성이다.<br/>
&ensp;이를 위해 여러 time scale 사이의 관계를 알아야 한다.<br/>

&ensp;GPS의 Time Transfer에서는 1PPS(One Pulse Per Second)​가 중요한 역할을 한다. 1PPS는 이름 그대로 1초마다 한 번 발생하는 timing pulse이다. 중요한 것은 pulse의 모양이나 크기가 아니라 pulse가 발생하는 정확한 순간이다. Receiver clock에 offset이 존재하면 기준 time에서 발생해야 하는 pulse와 receiver가 발생시키는 pulse 사이에 시간 차이가 발생한다. 이 차이가 clock offset이다. GPS timing에서는 이러한 clock offset을 계산하고 보정하여 **UTC(USNO)와 synchronization된 1PPS signal** 을 생성한다.<br/>

---

# 42. GPS에서 사용되는 4개의 Time Scale

### Satellite Clock

$$t^s$$

### GPS Time

$$t_{GPS}$$

### UTC(USNO)

$$t_{UTC}$$

### Receiver Clock

$$t_u$$

&ensp;각 clock은 서로 완전히 동일하지 않으므로 offset을 보정해야 한다.<br/>

&ensp;GPS Time Transfer에서는 네 가지 time scale이 등장한다.<br/>
* Satellite clock: $t^s$
* GPS Time: $t_{GPS}$
* UTC(USNO): $t_{UTC}$
* Receiver clock: $t_u$

&ensp;각 time을 별개의 식으로 외우기보다 어떤 clock offset을 통해 서로 연결되는지 이해하는 것이 중요하다.<br/>

&ensp;1. Satellite Clock → GPS Time<br/>
&ensp;Satellite clock bias는 $t^s-t_{GPS}$ 이다. 따라서 $t^s-\delta t^s$ 가 된다. 즉, satellite clock에서 satellite clock bias를 제거하면 GPS Time을 얻을 수 있다.<br/>

&ensp;2. Receiver Clock → GPS Time<br/>
&ensp;Receiver clock bias는 $t_u-t_{GPS}$ 이다. 따라서 $t_u-\delta t_u$ 이다. 즉, receiver clock에서 receiver clock bias를 제거하면 GPS Time을 얻을 수 있다.<br/>

&ensp;3. GPS Time → UTC<br/>
&ensp;GPS Time과 UTC 사이의 offset은 $t_{GPS}-t_{UTC}$ 이다. 따라서 $t_{GPS}- \delta t_{UTC}$ 가 된다.<br/>

&ensp;4. Receiver Clock → UTC<br/>
&ensp;앞의 두 관계를 연결하면 $t_u-\delta t_u$ 이고 $t_{GPS}-\delta t_{UTC}$ 이므로 $t_u-\delta t_u-\delta t_{UTC}$ 를 얻는다.<br/>

&ensp;전체 흐름<br/>
&ensp;Satellite Clock $t^s$<br/>
&ensp;↓ $-\delta t^s$
&ensp;GPS Time $t_{GPS}$ <br/>
&ensp;↓ $-\delta t_{UTC}$ <br/>
&ensp;UTC $t_{UTC}$ <br/>

&ensp;Receiver 쪽에서는<br/>
&ensp;Receiver Clock $t_u$ <br/>
&ensp;↓ $-\delta t_u$ <br/>
&ensp;GPS Time $t_{GPS}$ <br/>

> Time Transfer의 여러 식을 따로 외우기보다 모든 clock이 GPS Time을 기준으로 어떤 offset을 갖는지 이해하면 된다.

---

# 43. Satellite Clock Bias

&ensp;Satellite clock bias는 $\delta t^s = t^s-t_{GPS}$ 이다. Control Segment가 satellite clock을 monitor하고 correction parameter를 navigation message로 전달한다.<br/>
&ensp;Satellite clock bias는<br/>

$$\delta t^s = a_{f0} + a_{f1}(t_{GPS}-t_{0c}) + a_{f2}(t_{GPS}-t_{0c})^2 + \Delta t_r$$

&ensp;로 model된다.<br/>

&ensp;강의록에서는 satellite clock bias uncertainty를 약 $\sigma(\delta t^s) \approx 5ns$ 로 제시한다.<br/>

---

# 44. GPS Time과 UTC의 Offset

&ensp;GPS Time과 UTC 사이의 offset은 $\delta t_{UTC} = t_{GPS}-t_{UTC}$ 이다.<br/>
&ensp;Navigation message의 parameter를 이용하여<br/>

$$\delta t_{UTC} = A_0 + A_1(t_{GPS}-t_{0U}) + \Delta t_{LS}$$

&ensp;로 계산할 수 있다.<br/>
&ensp;여기서 $\Delta t_{LS}$ 는 leap second와 관련된 항이다.<br/>
&ensp;강의록에서는 $\sigma(\delta t_{UTC})\approx 10ns$ 를 제시한다.<br/>

---

# 45. Receiver Clock Bias

&ensp;Receiver clock과 GPS Time의 차이는 $\delta t_u = t_u-t_{GPS}$ 이다.<br/>
&ensp;이 값은 일반 GPS navigation receiver에서 position과 함께 계산한다.<br/>

&ensp;Clock bias uncertainty는<br/>

$$\sigma(\delta t_u) = \sigma_{URE}\times TDOP$$

&ensp;와 관련된다.<br/>
&ensp;강의록에서는 약 25ns 수준으로 제시한다.<br/>
&ensp;즉, 앞에서 학습한 **TDOP가 GPS timing accuracy와 직접 연결된다.**<br/>

&ensp;Satellite Clock Error와 URE<br/>
&ensp;Receiver clock bias uncertainty는 $\sigma_{\mathrm{URE}}\times TDOP$ 와 관련된다. 여기서 주의해야 할 점은 satellite clock error $\delta t^s$의 영향이 이미 URE에 포함되어 있다는 것이다.<br/>
&ensp;따라서 최종 timing uncertainty를 계산할 때 satellite clock uncertainty를 별도의 independent error로 다시 추가하면 같은 error를 중복하여 고려하게 된다.<br/>


---

# 46. UTC Time 생성

&ensp;Receiver clock을 기준으로 UTC를 계산하면 $t_{UTC} = t_u - \delta t_u - \delta t_{UTC}$ 가 된다.<br/>
&ensp;Time uncertainty는 $\sigma(t) = \sqrt{\sigma^2(\delta t_u) + \sigma^2(\delta t_{UTC})}$ 이며 강의록에서는 약 25ns 수준으로 제시한다.<br/>

<p align="center"><img src="/assets/img/위성항법시스템 개론/chap6/6-20.png" width="600"></p>

&ensp;최종 UTC time은 $t_u-\delta t_u-\delta t_{UTC}$ 로 계산된다.<br/>
&ensp;여기에는 주로<br/>
* Receiver clock bias uncertainty
* GPS Time–UTC offset uncertainty

&ensp;가 영향을 준다.<br/>

$$\sigma(\delta t_u)\approx25,\mathrm{ns}$$

$$\sigma(\delta t_{UTC})\approx10,\mathrm{ns}$$

&ensp;Independent한 error의 uncertainty를 합칠 때는 standard deviation을 단순하게 더하지 않는다. 각 error의 variance를 더한 뒤 square root를 취한다.<br/>

$$\sqrt{\sigma_1^2+\sigma_2^2+\cdots+\sigma_n^2}$$

&ensp;이를 RSS(Root Sum Square) 형태라고 볼 수 있다. 따라서 여러 independent error 중 uncertainty가 가장 큰 항이 전체 accuracy에 큰 영향을 준다.<br/>

&ensp;왜 Timing Receiver는 Fixed, Surveyed Location을 사용하는가?<br/>
&ensp;일반적인 GPS navigation receiver는 $x,\quad y,\quad z,\quad b$ 총 4개의 unknown을 estimation한다. => User position, Receiver clock bias를 동시에 계산해야 한다.<br/>
&ensp;하지만 GPS를 navigation이 아니라 정확한 timing을 얻기 위한 목적으로 사용한다면 receiver의 위치를 미리 정확하게 측정할 수 있다. 이것이 fixed, surveyed location​이다.<br/>

&ensp;Receiver position $x,\quad y,\quad z$ 를 를 이미 알고 있다면 이를 다시 unknown으로 estimation할 필요가 없다. 따라서 timing receiver에서는 position보다는 $\delta t_u$ 즉 receiver clock bias estimation에 집중할 수 있다.<br/>

> Navigation receiver는 Position + Time을 동시에 estimation하지만, surveyed location에 설치된 timing receiver는 position을 이미 알고 있으므로 Time estimation에 집중할 수 있다.

# 47. Common View Technique

&ensp;두 receiver가 **같은 satellite를 동시에 관측**하면 satellite와 관련된 여러 common error를 제거할 수 있다.<br/>
&ensp;예를 들어<br/>
* Receiver A — Clock A
* Receiver B — Clock B

&ensp;가 동일한 satellite signal을 동시에 측정한다.<br/>
&ensp;두 receiver의 measurement를 서로 교환하여 difference를 계산하면 common error가 cancel된다.<br/>
&ensp;따라서 두 clock 사이의 차이 $t_A-t_B$ 를 매우 정밀하게 측정할 수 있다.<br/>
&ensp;강의록에서는<br/>
* Precise post-processed ephemerides 사용
* Measurements 교환
* Common error compensation/cancellation

&ensp;등을 이용하여 약 $5\sim 10ns$ 수준의 time transfer accuracy를 제시한다.<br/>
