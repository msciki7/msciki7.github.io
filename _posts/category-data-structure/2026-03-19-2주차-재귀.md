# 재귀란?

&ensp;재귀(recursion)는 **함수나 알고리즘이 자기 자신을 다시 호출하는 방식**이다.<br/>
&ensp;즉 큰 문제는 더 작은 같은 형태의 문제로 나누어 해결하는 방법이다.<br/>
* 재귀 알고리즘 = 알고리즘 자신을 사용하여 정의된 알고리즘 (특히 반복문을 사용하는 반복적(iterative) 알고리즘과 대비)

&ensp;핵심 아이디어<br/>
&ensp;재귀는 보통 아래 두 요소로 이루어진다.<br/>
* 베이스 케이스(base case): 더 이상 자기 자신을 호출하지 않고 바로 답을 반환하는 경우
* 재귀 케이스(recursive case): 문제를 더 작은 문제로 바꾸어 자기 자신을 다시 호출되는 경우

# 재귀의 가장 기본 예시: 1부터 n까지의 합

&ensp;대표 예시: `sum(n)`<br/>
<p align="center"><img src="/assets/img/data structure/2주차/2-1.png" width="600"></p>

&ensp;의사코드<br/>
```cpp
sum(n)
if (n == 1)
    return 1
else
    return n + sum(n - 1)
```

&ensp;재귀인 이유<br/>
&ensp;예를 들어 `sum(4)` 를 구한다<br/>
* `sum(4) = 4 + sum(3)`
* `sum(3) = 3 + sum(2)`
* `sum(2) = 2 + sum(1)`
* `sum(1) = 1`

&ensp;이제 다시 올라오면<br/>
* sum(2) = 2 + 1 = 3
* sum(3) = 3 + 3 = 6
* sum(4) = 4 + 6 = 10

&ensp;큰 문제를 작은 문제로 계속 줄이다가 가장 작은 문제인 `sum(1)`에서 멈춘 뒤 결과를 되돌려 받는다.<br/>

# 재귀의 작동원리

&ensp;재귀 호출이 동작할 때 **보류된 호출들의 정보(매개변수, 지역변수, 복귀 주소)**가 자동으로 저장된고 복구된다.<br/>
