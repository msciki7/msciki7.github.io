# 재귀란?

&ensp;재귀(recursion)는 **함수나 알고리즘이 자기 자신을 다시 호출하는 방식**이다.<br/>
&ensp;즉 큰 문제는 더 작은 같은 형태의 문제로 나누어 해결하는 방법이다.<br/>
* 재귀 알고리즘 = 알고리즘 자신을 사용하여 정의된 알고리즘 (특히 반복문을 사용하는 반복적(iterative) 알고리즘과 대비)

&ensp;핵심 아이디어<br/>
&ensp;재귀는 보통 아래 두 요소로 이루어진다.<br/>
* 베이스 케이스(base case): 더 이상 자기 자신을 호출하지 않고 바로 답을 반환하는 경우
* 재귀 케이스(recursive case): 문제를 더 작은 문제로 바꾸어 자기 자신을 다시 호출되는 경우

# 재귀의 가장 기본 예시: 1부터 n까지의 합

&ensp;대표 예시: `sum(n)`<br/>
<p align="center"><img src="/assets/img/data structure/2주차/2-1.png" width="600"></p>

&ensp;의사코드<br/>
```cpp
sum(n)
if (n == 1)
    return 1
else
    return n + sum(n - 1)
```

&ensp;재귀인 이유<br/>
&ensp;예를 들어 `sum(4)` 를 구한다<br/>
* `sum(4) = 4 + sum(3)`
* `sum(3) = 3 + sum(2)`
* `sum(2) = 2 + sum(1)`
* `sum(1) = 1`

&ensp;이제 다시 올라오면<br/>
* sum(2) = 2 + 1 = 3
* sum(3) = 3 + 3 = 6
* sum(4) = 4 + 6 = 10

&ensp;큰 문제를 작은 문제로 계속 줄이다가 가장 작은 문제인 `sum(1)`에서 멈춘 뒤 결과를 되돌려 받는다.<br/>

# 재귀의 작동원리

&ensp;재귀 호출이 동작할 때 **보류된 호출들의 정보(매개변수, 지역변수, 복귀 주소)**가 자동으로 저장된고 복구된다.<br/>

<p align="center"><img src="/assets/img/data structure/2주차/2-2.png" width="600"></p>

* 함수가 자기 자신을 호출하면 현재 함수는 아직 끝나지 않은 상태로 잠깐 멈춘다.
* 컴퓨터는 그 상태를 스택(stack)에 저장한다.
* 가장 마지막에 호출된 함수부터 먼저 끝난다.
* 끝난 결과가 이전 호출로 돌아간다.

&ensp;`sum(4)`의 호출 흐름<br/>

```cpp
sum(4)
 -> 4 + sum(3)
      -> 3 + sum(2)
           -> 2 + sum(1)
                -> 1
```

&ensp;그 다음 복귀는 아래처럼 이루어진다.<br/>

```cpp
sum(1) = 1
sum(2) = 2 + 1 = 3
sum(3) = 3 + 3 = 6
sum(4) = 4 + 6 = 10
```

&ensp;재귀 함수는 내가 직접 저장/복구 코드를 짜지 않아도 컴퓨터가 호출 정보를 자동으로 관리해준다. 대신 그만큼 메모리 사용량이 늘고 성능이 떨어질 수 있다.<br/>

# 재귀의 기본 규칙

&ensp;**1. 베이스 케이스는 반드시 있어야 한다.**<br/>

&ensp;재귀는 언젠가 멈춰야 한다. 멈추는 조건이 없으면 함수는 끝없이 자기 자신을 호출한다.<br/>

&ensp;예<br/>
```cpp
if (n == 1)
    return 1;
```

&ensp;이 조건이 있어야 재귀가 종료된다.<br/>

&ensp;**2. 베이스 케이스 방향으로 진행해야 한다.**<br/>

&ensp;재귀 호출을 할 때만 문제 크기가 줄어들어야 한다.<br/>

&ensp;좋은 예<br/>
```cpp
sum(n - 1)
```

&ensp;나쁜 예<br/>
```cpp
sum(n + 1)
```

&ensp;이렇게 하면 `n`이 점점 커져서 절대 종료되지 않는다.<br/>

&ensp;**3. 모든 재귀 호출이 정상적으로 작동한다고 가정한다.**<br/>

&ensp;이 규칙은 재귀를 이해할 때 매우 중요하다. 예를 들어 `sum(4)` 를 생각할 때 우리는 `sum(3)` 이 제대로 계산된다고 믿고<br/>

```cpp
sum(4) = 4 + sum(3)
```

&ensp;처럼 작성한다. 즉 재귀는 **작은 문제가 해결된다고 가정하고 현재 문제를 푸는 방식**이다. 이 사고방식이 처음엔 낯설지만 익숙해지면 재귀가 훨씬 쉬워진다.<br/>

&ensp;**4. 꼭 필요할 때만 사용한다.**<br/>
&ensp;재귀는 코드가 간결해지는 장점이 있지만<br/>
* 함수 호출 비용이 들고
* 메모리를 더 사용하고
* 너무 깊어지면 스택 오버플로우가 날 수 있다.

&ensp;그래서 무조건 재귀가 좋은 것은 아니다.<br/>

# 나쁜 재귀(Bad Recursion)

## 베이스 케이스가 없는 경우

```cpp
sum1(n)
return n + sum1(n - 1)
```

&ensp;이 함수는 멈추는 조건이 없다. 그래서 끝없이 자기 자신을 호출한다.<br/>

&ensp;문제점<br/>
* 프로그램이 끝나지 않음
* 메모리가 계속 쌓임
* 결국 스택 오버플로우 발생 가능

## 베이스 케이스에 도달하지 못하는 경우

```cpp
sum2(n)
if (n == 1)
    return 1
else
    return n + sum2(n + 1)
```

&ensp;겉보기에는 베이스 케이스가 있지만 `n+1` 로 호출하므로 `1` 방향으로 가지 않는다.<br/>

&ensp;예를 들어 `sum2(4)`는 <br/>
* sum2(5)
* sum2(6)
* sum2(7)

&ensp;처럼 점점 커지기만 하므로 절대 종료되지 않는다.<br/>

&ensp;결론: 재귀는 단순히 자기 자신을 부르는 것만으로 되는 게 아니다.<br/>
&ensp;반드시<br/>
1. 멈추는 조건이 있어야 하고
2. 그 조건을 향해 가야 한다.

# 잘 설계된 재귀의 예

&ensp;각 자리 숫자 출력<br/>
&ensp;`printDigits` 예제<br/>
&ensp;양의 정수를 입력받아 한 줄에 한 자리씩 출력하는 함수이다.<br/>
&ensp;구조<br/>
* `printDigits()` : 입력받고 검사하는 driver 함수
* `rPrintDigits(n)` : 실제 재귀를 수행하는 함수

<p align="center"><img src="/assets/img/data structure/2주차/2-3.png" width="600"></p>

&ensp;의사코드<br/>
```cpp
printDigits()
    n 입력
    if (n < 0)
        에러 출력
    else
        rPrintDigits(n)

rPrintDigits(n)
    if (n < 10)
        write(n)
    else
        rPrintDigits(n / 10)
        write(n % 10)
```

&ensp;동작하는 이유<br/>
&ensp;예를 들어 `3408`을 출력한다고 하자<br/>
&ensp;호출과정<br/>
```cpp
rPrintDigits(3408)
 -> rPrintDigits(340)
     -> rPrintDigits(34)
         -> rPrintDigits(3)
```

&ensp;이제 3은 한 자리 수이므로 바로 출력한다.<br/>
&ensp;그 후 돌아오면서<br/>
* 34 % 10 = 4
* 340 % 10 = 0
* 3408 % 10 = 8

&ensp;을 차례로 출력한다.<br/>

&ensp;최종출력<br/>
```
3
4
0
8
```

&ensp;이 예제는 재귀가 단순 계산뿐 아니라 출력 순서를 제어하는 데도 매우 유용하다는 점을 보여준다.<br/>
&ensp;특히<br/>
* 먼저 앞자리들을 재귀로 처리하고
* 돌아오면서 현재 숫자를 출력

&ensp;하는 구조가 핵심이다.<br/>

# 응용 문제

## 1. 재귀적 곱셈, 나머지, 몫

&ensp;덧셈과 뺄셈만 이용해서 곱셈, 나머지, 몫을 재귀적으로 구하는 방법<br/>

&ensp;곱셈 `product(a, b)`<br/>
&ensp;아이디어<br/>
&ensp;곱셈은 같은 수의 반복 덧셈이다.<br/>
&ensp;예<br/>
* 3 × 4 = 3 + 3 + 3 + 3

&ensp;의사코드<br/>
```cpp
product(a, b)
if (b == 1)
    return a
else
    return a + product(a, b - 1)
```

&ensp;예시<br/>
&ensp;`product(3, 4)`<br/>
* 3 + product(3, 3)
* 3 + 3 + product(3, 2)
* 3 + 3 + 3 + product(3, 1)
* 3 + 3 + 3 + 3
* 결과: 12

&ensp;나머지 `modulo(a, b)` <br/>
&ensp;아이디어<br/>
&ensp;나머지는 a에서 b를 계속 빼다가 더 이상 뺄 수 없을 때 남는 값이다.<br/>

&ensp;의사코드<br/>
```cpp
modulo(a, b)
if (a < b)
    return a
else
    return modulo(a - b, b)
```

&ensp;예시<br/>
&ensp;`modulo(14, 4)<br/>
* modulo(10, 4)
* modulo(6, 4)
* modulo(2, 4)

&ensp;이제 2 < 4 이므로 결과는 2<br/>

&ensp;몫 `quotient(a, b)`<br/>
&ensp;아이디어<br/>
&ensp;a에서 b를 몇 번 뺄 수 있는지를 세면 몫이 된다.<br/>

&ensp;의사코드<br/>
```cpp
quotient(a, b)
if (a < b)
    return 0
else
    return 1 + quotient(a - b, b)
```

&ensp;예시<br/>
&ensp;`quotient(14, 4)`<br/>
* 1 + quotient(10, 4)
* 1 + 1 + quotient(6, 4)
* 1 + 1 + 1 + quotient(2, 4)
* 2 < 4 이므로 0

&ensp;결과는 3<br/>

## 2. 하노이탑 (Towers of Hanoi)

&ensp;문제 설명<br/>

<p align="center"><img src="/assets/img/data structure/2주차/2-5.png" width="600"></p>

&ensp;말뚝이 3개 있다.<br/>
* A : 시작 말뚝
* B : 보조 말뚝
* C : 목표 말뚝

&ensp;직경이 다른 원반 n개가 A에 쌓여 있다.<br/>
&ensp;목표는 모든 원반을 A에서 C로 옮기는 것이다.<br/>

&ensp;조건<br/>
* 한 번에 원반 1개만 옮길 수 있다.
* 큰 원반을 작은 원반 위에 놓을 수 없다.
* 남은 말뚝 하나를 보조로 사용할 수 있다.

&ensp;이동 횟수<br/>
&ensp;하노이탑의 이동 횟수가 일반적으로 `2^n - 1`회라고 설명한다.<br/>
&ensp;예<br/>
* n = 1 → 1회
* n = 2 → 3회
* n = 3 → 7회

&ensp;원반 개수가 1개 늘어날 때마다 이동 횟수가 매우 빠르게 증가한다.<br/>

&ensp;하노이탑의 핵심 아이디어<br/>
&ensp;하노이탑은 겉보기에 복잡하지만 사실 아주 규칙적<br/>
1. 위의 `n-1`개를 `from` 에서 `aux`로 옮긴다.
2. 가장 큰 원반 1개를 `from`에서 `to`로 옮긴다.
3. `aux`에 있던 `n-1`개를 `to`로 옮긴다.

&ensp;하노이탑 의사코드<br/>
```cpp
hanoi(n)
    rHanoi(n, 'A', 'B', 'C')

rHanoi(n, from, aux, to)
    if (n == 1)
        print("move from", from, "to", to)
        return

    rHanoi(n - 1, from, to, aux)
    print("move from", from, "to", to)
    rHanoi(n - 1, aux, from, to)
```

&ensp;매개변수 의미<br/>
* n: 이동할 원반 수
* from: 출발 말뚝
* aux: 보조 말뚝
* to: 도착 말뚝

&ensp;왜 이중 재귀(double recursion)인가?<br/>
&ensp;하노이탑 알고리즘은 한 번의 함수 안에서 재귀 호출이 두 번 나온다.<br/>

```cpp
rHanoi(n - 1, from, to, aux)
...
rHanoi(n - 1, aux, from, to)
```

&ensp;n = 3일 때 이동 순서<br/>

```
move from A to C
move from A to B
move from C to B
move from A to C
move from B to A
move from B to C
move from A to C
```

&ensp;하노이탑을 진짜로 이해하는 방법<br/>
&ensp;`rHanoi(n, from, aux, to)`의 흐름<br/>
1. `n-1` 개를 출발 말뚝에서 보조 말뚝으로 옮긴다.
2. 가장 큰 원반을 목표 말뚝으로 옮긴다.
3. `n-1` 개를 보조 말뚝에서 목표 말뚝으로 옮긴다.

&ensp;이 과정을 그림으로 보면 재귀가 훨씬 잘 보인다. 즉 하노이탑은 한 번에 다 해결이 아니라 **똑같은 패턴을 반복해서 적용**하는 문제다.<br/>

# 포인트

&ensp;1. 재귀는 정의 방식이다.<br/>
&ensp;재귀는 단순 문법이 아니라 문제를 표현하는 방식이다.<br/>
* 합 = 현재 값 + 더 작은 합
* 곱 = 현재 값 + 더 작은 곱
* 하노이탑 = 작은 하노이탑 + 한 번 이동 + 작은 하노이탑

&ensp;2. 베이스 케이스가 가장 중요<br/>
&ensp;재귀 함수에서 제일 먼저 확인할 것은 "이 함수는 언제 멈추는가?" 이다.<br/>

&ensp;3. 문제 크기가 줄어드는지 봐야 한다.<br/>
&ensp;재귀 호출을 할 때마다<br/>
* 입력이 작아지는지
* 종료 조건에 가까워지는지

&ensp;를 반드시 확인해야 한다.<br/>

&ensp;4. 호출 순서와 출력 순서를 구분해야 한다.<br/>
&ensp;특히 `printDigits`, `hanoi` 같은 문제는 언제 호출하고 언제 출력하는지가 매우 중요하다.<br/>
&ensp;호출은 먼저 내려가고 출력은 내려가는 중일 수도 있고 올라오면서 할 수도 있다.<br/>

`문제 4`

<p align="center"><img src="/assets/img/data structure/2주차/2-11.png" width="600"></p>

```cpp
#include <stdio.h>

int max(int num[20], int imm, int n, int idx);

int main() {
    int n;
    scanf("%d", &n);

    int num[20];

    for (int i = 0; i < n; i++) {
        scanf("%d", &num[i]);
    }

    int imm = num[0];
    int idx = 1;

    int max_num = max(num, imm, n, idx);

    printf("%d\n", max_num);
}

int max(int num[20], int imm, int n, int idx) {

    if (n == idx) {
        return imm;
    }

    if (num[idx] > imm) {
        imm = num[idx];
    }

    idx++;

    return max(num, imm, n, idx);
}
```

```cpp
    int n;

    rHanoi(n, 'A', 'B', 'C');

}

void rHanoi(int n, char from, char aux, char to) {

    if (n == 1) {
        printf("%c %c\n", from, to);
    }else {
        rHanoi(n-1, from, to, aux);
        printf("%c %c\n", from, to);
        rHanoi(n-1, aux, from, to);
    }

}
```

`문제 6`

<p align="center"><img src="/assets/img/data structure/2주차/2-13.png" width="600"></p>

```cpp
#include <stdio.h>

int gcd(int, int);

int main () {
    int n, m;
    scanf("%d %d", &n, &m);
    int result = gcd(n, m);
    printf("%d", result);
}

int gcd(int n, int m) {
    if (m == 0) {
        return n;
    }else {
        return gcd(m,n % m );
    }
}
```

```cpp
int cnt(char str[100], char find, int i) {
    if (str[i] == '\0') {
        return 0;
    }

    if (str[i] == find) {
        return 1 + cnt(str, find, i+1);
    }else {
        return cnt(str, find, i+1);
    }
}
```
