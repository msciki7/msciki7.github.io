# 스택 ADT

&ensp;: 정의<br/>
* 데이터를 저장하는 자료구조
* **후입선출(LIFO: Last-In First-Out)** 구조
* 삽입/삭제는 오직 top에서만 발생

&ensp;구조 이미지 느낌<br/>
```cpp
Top
 ↓
[ 30 ]
[ 20 ]
[ 10 ]
```

&ensp;마지막에 들어온 30이 가장 먼저 나감<br/>
&ensp;핵심포인트<br/>
* 입구 1개 (top)
* push/pop 모두 같은 위치에서 수행

&ensp;스택 기본 연산<br/>

&ensp;주요 연산<br/>

| 연산      | 의미         |
| ------- | ---------- |
| push(e) | 원소 삽입      |
| pop()   | 원소 삭제 + 반환 |

&ensp;보조 연산<br/>

| 연산        | 의미       |
| --------- | -------- |
| top()     | 맨 위 값 확인 |
| size()    | 원소 개수    |
| isEmpty() | 비었는지     |

&ensp;예외<br/>
* emptyStackException → pop/top 할 때 비어있음
* fullStackException → 배열 꽉 참

# 배열 기반 스택 구현

&ensp;핵심 구조<br/>
* 배열 S 사용
* t = top 위치를 저장하는 변수

```cpp
S[0 ... N-1]
t = 현재 top index
```

&ensp;의미<br/>
* t = -1 → 비어있음
* t = 0 → 원소 1개
* t = 1 → 원소 2개

&ensp;t는 마지막 원소 위치<br/>

* 초기 상태가 -1
* 다시 -1이면 비어있음

* 예시: t = 2 → 원소 3개

# 응용문제: 심볼 균형

&ensp;1. 문제 상황<br/>
&ensp;프로그램 코드 안에는 여러 괄호가 있다.<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-16.png" width="600"></p>

&ensp;여기서 괄호들이 제대로 닫혔는지 검사하는 문제이다.<br/>

&ensp;2. 균형이 맞는 경우<br/>

```
(...)
{ ... ( ... { ... } ... ) ... }
[ ... ]
```

&ensp;괄호가 열린 순서와 닫히는 순서가 맞아야 한다.<br/>
&ensp;예를 들어<br/>
```
{ ( [ ] ) }
```

&ensp;즉 괄호 구조는 스택 구조와 똑같다.<br/>
```
나중에 열린 괄호가 먼저 닫힘
= LIFO
= Stack
```

&ensp;3. 균형이 안 맞는 경우<br/>
&ensp;`[ ... ( ... ] ... )`<br/>
&ensp;현재 가장 최근에 열린 괄호는 `(`인데, 닫는 괄호는 `]`니까 짝이 안 맞는다.<br/>

&ensp;심볼 균형 알고리즘<br/>
&ensp;스택에는 아직 닫히지 않은 열린 괄호를 저장한다.<br/>

| 읽은 문자               | 처리         |
| ------------------- | ---------- |
| 열린 괄호 `(`, `{`, `[` | push       |
| 닫힌 괄호 `)`, `}`, `]` | pop해서 짝 확인 |
| 일반 문자               | 무시         |

&ensp;의사코드<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-17.png" width="600"></p>

&ensp;예시1<br/>
&ensp;입력: `{ ( [ ] ) }`<br/>

| 읽은 문자 | 동작      | 스택      |
| ----- | ------- | ------- |
| `{`   | push    | `{`     |
| `(`   | push    | `{ (`   |
| `[`   | push    | `{ ( [` |
| `]`   | pop `[` | `{ (`   |
| `)`   | pop `(` | `{`     |
| `}`   | pop `{` | empty   |

# 응용문제 2: 기간 Span

&ensp;1. 문제 정의<br/>
&ensp;배열 X가 있을 때, S[i]는 다음 의미이다.<br/>
&ensp;X[i] 바로 앞에서부터 연속해서 X[i]보다 작거나 같은 값의 개수<br/>
&ensp;단 자기 자신도 포함해서 세기 때문에 최소값은 항상 1이다.<br/>

<p align="center"><img src="/assets/img/data structure/9주차/9-18.png" width="600"></p>

&ensp;예시<br/>
```
X = [60, 30, 40, 10, 20, 30, 50, 40]
```

&ensp;i = 0<br/>
```
X[0] = 60
```

&ensp;앞에 아무것도 없음<br/>
```
S[0] = 1
```

&ensp;i = 1<br/>
```
X[1] = 30
앞: 60
```

&ensp;60은 30보다 크다. 바로 막힘<br/>
```
S[1] = 1
```

&ensp;i = 2<br/>
```
X[2] = 40
앞: 30, 60
```

&ensp;바로 앞의 30은 40보다 작거나 같음.<br/>
&ensp;그 앞의 60은 40보다 큼. 여기서 멈춤.<br/>
```
S[2] = 2
```

&ensp;i = 6<br/>
```
X[6] = 50
앞: 30, 20, 10, 40, 30, 60
```

&ensp;뒤에서부터 보면<br/>
```
30 ≤ 50
20 ≤ 50
10 ≤ 50
40 ≤ 50
30 ≤ 50
60 > 50
```

&ensp;총 6개<br/>
```
S[6] = 6
```

&ensp;결과<br/>
```
S = [1, 1, 2, 1, 2, 3, 6, 1]
```

&ensp;해결 A: 정의 그대로 풀기<br/>
&ensp;의사코드<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-19.png" width="600"></p>

```cpp
Alg spans(X, S, n)
input array X, S of n integers
output array S of spans of X

1. for i ← 0 to n - 1   // 배열의 모든 위치 i에 대해 span을 구한다.
       s ← 1            // 자기 자신은 무조건 포함하니까 시작값은 1

       while ((s ≤ i) & (X[i - s] ≤ X[i]))   // 현재 위치 i에서 왼쪽으로 한 칸씩 본다. 
           s ← s + 1  // 조건을 만족하면 span 개수를 늘리고 더 왼쪽으로 이동

       S[i] ← s     // 최종 span 값을 저장

2. return
```

&ensp;O(n²)인가<br/>
&ensp;최악의 경우를 보면<br/>
```
X = [10, 20, 30, 40, 50]
```

&ensp;각 위치에서 계속 왼쪽을 끝까지 봐야한다.<br/>
```
i=0 → 0번 비교
i=1 → 1번 비교
i=2 → 2번 비교
i=3 → 3번 비교
i=4 → 4번 비교
```

&ensp;총 비교 횟수:<br/>
```
1 + 2 + ... + (n-1)
= O(n²)
```

&ensp;해결 B: 스택 사용<br/>
&ensp;핵심 아이디어<br/>
&ensp;스택에는 값을 저장하지 않고 인덱스를 저장한다.<br/>
&ensp;그리고 스택에는 이런 인덱스만 남긴다.<br/>
>>현재 값보다 큰 값 위치

&ensp;즉, 현재 값을 기준으로 왼쪽에서 “장벽” 역할을 하는 위치를 찾는다.<br/>

&ensp;작은 값은 pop해도 되는 이유<br/>
&ensp;현재 값 X[i]보다 작거나 같은 값은 앞으로도 장벽 역할을 못 한다.<br/>
&ensp;예<br/>
```
X = [60, 30, 40]
```

&ensp;`i = 2`, `X[2] = 40` 스택에 30의 인덱스가 있다면?<br/>

&ensp;`30 ≤ 40`<br/>
&ensp;30은 현재 40보다 작으니까 span을 막을 수 없다. 그래서 pop한다. 남은 60은 40보다 크니까 장벽이 된다.<br/>

&ensp;의사코드<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-20.png" width="600"></p>

```cpp
Alg spans(X, S, n)
input array X, S of n integers
output array S of spans of X

1. A ← empty stack   // 인덱스를 저장할 스택을 만든다.

2. for i ← 0 to n - 1   // 왼쪽에서 오른쪽으로 배열을 하나씩 본다.

       while (!A.isEmpty() & (X[A.top()] ≤ X[i]))  // 현재 값보다 작거나 같은 값들은 스택에서 제거한다.
           A.pop()

       if (A.isEmpty())  // 스택이 비었다는 것은 왼쪽에 현재 값보다 큰 값이 없다
           S[i] ← i + 1
       else             // 스택이 비어 있지 않으면 top은 현재 값보다 큰 가장 가까운 왼쪽의 값의 인덱스이다.
           S[i] ← i - A.top()

       A.push(i)  // 현재 위치도 나중 값들의 장벽 후보가 될 수 있으므로 스택에 넣는다.

3. while (!A.isEmpty())
       A.pop()

4. return
```

&ensp;예제<br/>
```
X = [60, 30, 40, 10, 20, 30, 50, 40]
```

| i | X[i] | pop 과정         | 남은 top | S[i] | push 후 stack |
| - | ---: | -------------- | ------ | ---: | ------------ |
| 0 |   60 | 없음             | 없음     |    1 | [0]          |
| 1 |   30 | 60 > 30        | 0      |    1 | [0,1]        |
| 2 |   40 | 30 pop         | 0      |    2 | [0,2]        |
| 3 |   10 | 40 > 10        | 2      |    1 | [0,2,3]      |
| 4 |   20 | 10 pop         | 2      |    2 | [0,2,4]      |
| 5 |   30 | 20 pop         | 2      |    3 | [0,2,5]      |
| 6 |   50 | 30 pop, 40 pop | 0      |    6 | [0,6]        |
| 7 |   40 | 50 > 40        | 6      |    1 | [0,6,7]      |

&ensp;결과: `S = [1, 1, 2, 1, 2, 3, 6, 1]` <br/>

&ensp;시간복잡도 O(n)인 이유<br/>
&ensp;각 인덱스는 딱 한 번 push 된다. 그리고 pop도 최대 한 번만 된다.<br/>
```
push 최대 n번
pop 최대 n번
```

&ensp;그래서 전체 시간은<br/>
```
O(n)
```

# 응용문제 3: 후위수식

&ensp;1. 중위수식<br/>
>> 5 × 3 + 2 + (6 + 3) × 2

&ensp;특징:<br/>
* 연산자가 피연산자 사이에 있음
* 우선순위 필요
* 괄호 필요

&ensp;2. 후위수식<br/>
&ensp;연산자가 피연산자 뒤에 오는 방식<br/>
>> 5 3 × 2 + 6 3 + 2 × +

&ensp;특징<br/>
* 괄호 필요 없음
* 우선순위 필요 없음
* 왼쪽부터 처리 가능

&ensp;표기법 비교<br/>
&ensp;예시<br/>
```
(A + B) × C - (D × E)
```

| 표기법  | 형태                      |
| ---- | ----------------------- |
| 중위수식 | `(A + B) × C - (D × E)` |
| 후위수식 | `A B + C × D E × -`     |
| 전위수식 | `- × + A B C × D E`     |

&ensp;후위수식 처리 과정<br/>
&ensp;컴퓨터는 보통 두 단계로 처리한다.<br/>

```txt
1. convert: 중위수식 → 후위수식
2. evaluate: 후위수식 계산
```

&ensp;스택의 역할이 다르다.<br/>

| 단계       | 스택에 저장하는 것 |
| -------- | ---------- |
| convert  | 연산자        |
| evaluate | 피연산자       |

&ensp;중위수식 → 후위수식 변환<br/>
&ensp;핵심 규칙<br/>

| 현재 심볼 | 처리                 |
| ----- | ------------------ |
| 피연산자  | 바로 출력              |
| `(`   | push               |
| `)`   | `(` 나올 때까지 pop 출력  |
| 연산자   | 우선순위 비교 후 pop/push |

&ensp;의사코드<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-21.png" width="600"></p>

```cpp
Alg convert()
input stream of legal infix expression
output stream of postfix expression

1. S ← empty stack

2. while (!endOfFile())
       s ← getSymbol()

       if (isOperand(s))   // 숫자나 문자는 바로 출력
           write(s)

       elseif (s = '(')   // 괄호 안의 연산은 나중에 따로 처리해야 하므로 스택에 넣음
           S.push(s)

       elseif (s = ')')   // )가 나오면 (를 만날 때까지 연산자를 꺼내 출력
           while (S.top() ≠ '(') 
               write(S.pop())
           S.pop()

       else
           while (!S.isEmpty() & (P[s] ≤ P[S.top()]))  // 현재 연산자보다 스택 top의 연산자 우선순위가 높거나 같으면 먼저 출력
               write(S.pop())
           S.push(s)

3. while (!S.isEmpty())
       write(S.pop())

4. return
```

&ensp;변환 예시<br/>
&ensp;`a - b - c + (d + e × f) / g`<br/>
&ensp;결과:<br/>
&ensp;`a b - c - d e f × + g / +`<br/>

&ensp;흐름 요약:<br/>

1. `a` 출력
2. `-` push
3. `b` 출력
4. 두 번째 `-`가 오면 기존 `-` pop 출력
5. `c` 출력
6. `+`가 오면 기존 `-` pop 출력
7. 괄호 안 `d + e × f` 처리
8. 괄호 끝나면 `d e f × +`
9. `/ g` 처리
10. 마지막 남은 `+` 출력

&ensp;후위수식 평가<br/>
&ensp;핵심 규칙<br/>

| 현재 심볼 | 처리           |
| ----- | ------------ |
| 피연산자  | push         |
| 연산자   | 두 개 pop 후 계산 |

&ensp;의사코드<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-22.png" width="600"></p>

```cpp
a ← S.pop()
b ← S.pop()
S.push(doOperator(s, b, a))
```

&ensp;순서가 `b 연산 a`이다. 왜냐하면 스택에서는 뒤에 들어간 값이 먼저 나오기 때문이다.<br/>
&ensp;예<br/>
```txt
4 1 -
```

&ensp;스택<br/>
```txt
push 4
push 1
```

&ensp;`-` 를 만나면<br/>
```txt
a = pop() = 1
b = pop() = 4
b - a = 4 - 1
```

&ensp;결과는 3. 만약 `a - b` 로 하면 `1 - 4`가 돼서 틀림.<br/>

&ensp;doOperator<br/>
```txt
Alg doOperator(op, x, y)

if op = '+'
    return x + y
if op = '-'
    return x - y
if op = '×'
    return x × y
if op = '/'
    return x / y
```

&ensp;후위수식 평가 예시<br/>
```txt
4 1 - 2 - 4 2 3 × + 5 / +
```

&ensp;부분적으로 보면<br/>
```txt
4 1 -  → 3
3 2 -  → 1
2 3 ×  → 6
4 6 +  → 10
10 5 / → 2
1 2 +  → 3
```

# 응용문제 4: 다중스택

&ensp;문제: 스택이 하나가 아니라 여러 개 있을 때 어떻게 구현할까?<br/>

```
S0, S1, S2, ... Sn-1
```

&ensp;필요한 연산:<br/>
```
size(i)
isEmpty(i)
isFull(i)
top(i)
push(i, e)
pop(i)
```

&ensp;즉, i번 스택에 대해 연산해야 한다.<br/>

&ensp;해결 A: 1차원 배열 사용<br/>
&ensp;아이디어: 큰 배열 하나를 여러 구간으로 나눠서 각 스택에 배정한다.<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-23.png" width="600"></p>

&ensp;예: `A[0 ... 14], n = 3`<br/>

```
S0: A[0 ... 4]
S1: A[5 ... 9]
S2: A[10 ... 14]
```

&ensp;필요한 배열<br/>

| 배열   | 의미          |
| ---- | ----------- |
| b[i] | i번 스택의 base |
| t[i] | i번 스택의 top  |

&ensp;예시<br/>
```
b = [-1, 4, 9, 14]
t = [3, 6, 12]
```

&ensp;의미:<br/>
```
S0: base=-1, top=3  → 크기 4
S1: base=4, top=6   → 크기 2
S2: base=9, top=12  → 크기 3
```

&ensp;다중스택 배열 방식 의사코드<br/>
&ensp;initMultiStack<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-24.png" width="600"></p>

```cpp
Alg initMultiStack()
input array A, t, b, size N, integer n
output multistack

1. stacksize ← N / n   // 전체 배열을 n개의 스택이 똑같이 나눠 가진다.

2. for i ← 0 to n - 1
       b[i] ← stacksize × i - 1  // 각 스택의 시작 직전 위치를 base도 둔다.
       t[i] ← b[i]          

3. b[n] ← N - 1

4. return
```

&ensp;push / pop<br/>
<p align="center"><img src="/assets/img/data structure/9주차/9-25.png" width="600"></p>

&ensp;push(i, e): i번 스택의 top을 한 칸 증가시키면 그 위치에 e 저장<br/>
&ensp;pop(i): i번 스택의 top을 내리고 방금 제거된 위치의 값을 반환<br/>

&ensp;fullStackException 전략<br/>
&ensp;1. 고정 베이스<br/>
&ensp;각 스택의 구간을 고정한다.<br/>
&ensp;장점: 구현이 쉽다.<br/>
&ensp;단점: 다른 스택 공간이 비어 있어도 내 구간이 차면 overflow<br/>

&ensp;2. 부동 베이스<br/>
&ensp;공간이 부족하면 다른 스택의 빈 공간을 빌려온다.<br/>
&ensp;장점: 공간 활용이 좋다.<br/>
&ensp;단점: 스택들을 이동시켜야 해서 느려질 수 있다.<br/>

&ensp;3. 부동 베이스 + 재할당<br/>
&ensp;남은 공간을 각 스택의 성장 정도에 따라 다시 나눈다.<br/>
&ensp;장점<br/>
1. 공간 활용 최대화
2. overflow 재발 가능성 감소

&ensp;단점: 복잡하다.<br/>

&ensp;해결 B: 연결리스트 배열 사용<br/>
&ensp;아이디어<br/>
&ensp;각 스택을 연결리스트로 따로 만든다. 그리고 `t[i]` 가 i번 스택의 top을 가리킨다.<br/>

```
t[0] → A → B → C
t[1] → D
t[2] → E → F
```

```cpp
#include <stdio.h>
#include <string.h>

char stack[101];
int top = -1;
int N;

void push(char c) {
    if (top == N - 1) {
        printf("Stack FULL\n");
        return;
    }
    stack[++top] = c;
}

void pop() {
    if (top == -1) {
        printf("Stack Empty\n");
        return;
    }
    top--;
}

void peek() {
    if (top == -1) {
        printf("Stack Empty\n");
        return;
    }
    printf("%c\n", stack[top]);
}

void duplicate() {
    if (top == -1) {
        printf("Stack Empty\n");
        return;
    }

    if (top == N - 1) {
        printf("Stack FULL\n");
        return;
    }

    char temp = stack[top];
    pop();

    push(temp);
    push(temp);
}

void upRotate(int n) {
    if (n > top + 1) return;

    char temp = stack[top];

    for (int i = top; i > top - n + 1; i--) {
        stack[i] = stack[i - 1];
    }

    stack[top - n + 1] = temp;
}

void downRotate(int n) {
    if (n > top + 1) return;

    char temp = stack[top - n + 1];

    for (int i = top - n + 1; i < top; i++) {
        stack[i] = stack[i + 1];
    }

    stack[top] = temp;
}

void print() {
    for (int i = top; i >= 0; i--) {
        printf("%c", stack[i]);
    }
    printf("\n");
}

int main() {
    int M;
    scanf("%d", &N);
    scanf("%d", &M);

    char command[20];
    char c;
    int n;

    for (int i = 0; i < M; i++) {
        scanf("%s", command);

        if (strcmp(command, "PUSH") == 0) {
            scanf(" %c", &c);
            push(c);
        }
        else if (strcmp(command, "POP") == 0) {
            pop();
        }
        else if (strcmp(command, "PEEK") == 0) {
            peek();
        }
        else if (strcmp(command, "DUP") == 0) {
            duplicate();
        }
        else if (strcmp(command, "UpR") == 0) {
            scanf("%d", &n);
            upRotate(n);
        }
        else if (strcmp(command, "DownR") == 0) {
            scanf("%d", &n);
            downRotate(n);
        }
        else if (strcmp(command, "PRINT") == 0) {
            print();
        }
    }

    return 0;
}
```

```cpp
#include <stdio.h>
#include <string.h>
#include <ctype.h>

#define MAX_LEN 105

/* 내부 토큰 표현:
   '&' = &&(우선순위 2), '|' = ||(우선순위 1)
   '@' = 단항 +,  '~' = 단항 -,  '!' = 단항 !  (우선순위 6)
   그 외 연산자는 그대로 사용 */

char stack[MAX_LEN * 2];
int top = -1;

void push(char c)        { stack[++top] = c; }
char pop_op()            { return stack[top--]; }
char peek()              { return stack[top]; }
int  is_empty()          { return top == -1; }

int priority(char op) {
    switch (op) {
        case '!': case '@': case '~': return 6;
        case '*':                     return 5;
        case '/':                     return 5;
        case '+':                     return 4;
        case '-':                     return 4;
        case '>': case '<':           return 3;
        case '&':                     return 2;
        case '|':                     return 1;
        default:                      return 0;
    }
}

void print_op(char op) {
    switch (op) {
        case '&': printf("&&"); break;
        case '|': printf("||"); break;
        case '@': printf("+");  break;
        case '~': printf("-");  break;
        default:  printf("%c", op); break;
    }
}

/* 스택에서 우선순위가 높거나 같은(단항은 더 높은) 연산자를 꺼내 출력 */
void pop_and_print(char op, int is_unary) {
    while (!is_empty() && peek() != '(') {
        int cond = is_unary ? (priority(peek()) > priority(op))
                            : (priority(peek()) >= priority(op));
        if (!cond) break;
        print_op(pop_op());
    }
}

int main() {
    int n;
    scanf("%d", &n);

    while (n--) {
        char expr[MAX_LEN];
        scanf("%s", expr);
        top = -1;

        int len = strlen(expr);
        int prev_operand = 0;   /* 직전 토큰이 피연산자(또는 ')')이면 1 */

        for (int i = 0; i < len; ) {
            char c = expr[i];

            /* ── 피연산자(대문자) ─────────────────────────── */
            if (isupper(c)) {
                printf("%c", c);
                prev_operand = 1;
                i++;

            /* ── 왼쪽 괄호 ───────────────────────────────── */
            } else if (c == '(') {
                push('(');
                prev_operand = 0;
                i++;

            /* ── 오른쪽 괄호 ──────────────────────────────── */
            } else if (c == ')') {
                while (!is_empty() && peek() != '(')
                    print_op(pop_op());
                if (!is_empty()) pop_op();   /* '(' 제거 */
                prev_operand = 1;
                i++;

            /* ── && ──────────────────────────────────────── */
            } else if (c == '&' && i+1 < len && expr[i+1] == '&') {
                pop_and_print('&', 0);
                push('&');
                prev_operand = 0;
                i += 2;

            /* ── || ──────────────────────────────────────── */
            } else if (c == '|' && i+1 < len && expr[i+1] == '|') {
                pop_and_print('|', 0);
                push('|');
                prev_operand = 0;
                i += 2;

            /* ── ! (항상 단항) ────────────────────────────── */
            } else if (c == '!') {
                pop_and_print('!', 1);   /* 단항: 더 높은 것만 꺼냄 */
                push('!');
                prev_operand = 0;
                i++;

            /* ── + 또는 - : 단항/이항 구분 ───────────────── */
            } else if (c == '+' || c == '-') {
                if (!prev_operand) {
                    /* 단항 */
                    char op = (c == '+') ? '@' : '~';
                    pop_and_print(op, 1);
                    push(op);
                } else {
                    /* 이항 */
                    pop_and_print(c, 0);
                    push(c);
                }
                prev_operand = 0;
                i++;

            /* ── *, /, >, < ──────────────────────────────── */
            } else if (c == '*' || c == '/' || c == '>' || c == '<') {
                pop_and_print(c, 0);
                push(c);
                prev_operand = 0;
                i++;

            } else {
                i++;
            }
        }

        /* 스택에 남은 연산자 모두 출력 */
        while (!is_empty())
            print_op(pop_op());

        printf("\n");
    }
    return 0;
}
```

```cpp
#include <stdio.h>
#include <string.h>
#include <ctype.h>

#define MAX_LEN 105

int stack[MAX_LEN];
int top = -1;

/* 스택에 값 넣기 */
void push(int value) {
    stack[++top] = value;
}

/* 스택에서 값 꺼내기 */
int pop() {
    return stack[top--];
}

/* 스택이 비었는지 확인 */
int isEmpty() {
    return top == -1;
}

/* 연산자 계산 */
int calculate(int left, int right, char op) {
    if (op == '+') {
        return left + right;
    } else if (op == '-') {
        return left - right;
    } else if (op == '*') {
        return left * right;
    } else if (op == '/') {
        return left / right;   // 정수 나눗셈, 몫 계산
    }

    return 0;
}

int main() {
    int n;
    char expression[MAX_LEN];

    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        scanf("%s", expression);

        top = -1;

        int len = strlen(expression);

        for (int j = 0; j < len; j++) {
            char ch = expression[j];

            /* 1. 피연산자: 0~9 숫자 */
            if (ch >= '0' && ch <= '9') {
                push(ch - '0');
            }

            /* 2. 연산자: +, -, *, / */
            else {
                int right = pop();
                int left = pop();

                int result = calculate(left, right, ch);

                push(result);
            }
        }

        printf("%d\n", pop());
    }

    return 0;
}
```
